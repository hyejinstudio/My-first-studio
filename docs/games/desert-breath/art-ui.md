## 스타일 콘셉트
- **"조용한 사막의 하루"**: 납작한 단색 면 + 진한 외곽선(플랫). 광택·네온·화면 흔들림 없음. 깊이는 하늘 세로 그라데이션 1겹과 모래 언덕 1줄로만.
- **주인공은 선인장의 몸 모양**: 숫자 게이지가 없다. 물(W)은 **몸 굵기**, 키(H)는 **몸 높이 + 눈금자**, 열림(o)은 **팔·색·무늬**로만 읽힌다. 얼굴 없음(식물 그대로 — 귀엽되 유치하지 않게).
- **하루가 흐른다**: 하늘색이 새벽 회청 → 한낮 모래 베이지 → 해질녘 연보라로 150초 동안 천천히 바뀐다. 해의 위치(시계)는 상단 바의 작은 호(arc)에서 움직인다 — **장면 하늘에는 해를 그리지 않는다**(날씨 "한낮 해" 조각과 헷갈리지 않게).
- **날씨는 모양이 먼저**: 비 = 둥근 구름 + 세로줄, 모래 = 가로 물결 + 먼지, 해 = 원 + 빛살, 맑음 = 빈 하늘. 흑백 렌더에서 4종 구분 확인.
- 스튜디오 공통: 상단 바·버튼·오버레이 CSS는 `games/hungry-bear/index.html`의 `.top`, `.home`, `.title`, `.spacer`, `.btns`, `button`, `button.icon`, `button.primary`, `button.secondary`/`a.secondary`, `.kbd`, `.overlay`, `body.ov-full`, `.ov-home`, `#lbSlot`을 **그대로 복사**. 주 버튼 `--accent` 주황, 패널 radius 12~16px. `<meta name="theme-color" content="#e4572e">`.
- 글꼴: 글자 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **숫자는 CactusDigits**(아래).

### 숫자 글꼴 CactusDigits (Pretendard ExtraBold 800 서브셋, SIL OFL 1.1)
- 불곰·짝꿍 카드와 **같은 방식**. 파일 `lab/games/desert-breath/fonts/cactus-digits-800.woff2` + 같은 폴더 `OFL.txt`(`games/hungry-bear/fonts/OFL.txt` 그대로 복사).
- 글리프: `+ , - . /`(U+002B–002F), `0-9`(U+0030–0039). **`tnum` 유지**(키가 0.1cm씩 바뀔 때 폭 고정).
  - `pyftsubset Pretendard-ExtraBold.otf --unicodes="U+002B-002F,U+0030-0039" --flavor=woff2 --layout-features='tnum' --output-file=cactus-digits-800.woff2` 후 fontTools로 name 테이블 변경.
  - 원본: 이 세션 작업 폴더에 `…/scratchpad/pret/public/static/Pretendard-ExtraBold.otf`가 있다(전에 받은 것). 없으면 CEO에게 보고.
- **'cm' 글자는 넣지 않는다.** 단위는 스튜디오 규칙(짝꿍 카드 "초", 불곰 "번")대로 **시스템 글꼴 700, 숫자보다 작게, `--muted`**로 쓴다. 라틴 소문자를 넣으면 `unicode-range`가 넓어지고 숫자와 단위의 위계가 사라진다.
- **Reserved Font Name 때문에 이름 변경 필수**: "Pretendard"가 들어간 모든 name 레코드(ID 1, 3, 4, 6, 16, 17 등)를 `CactusDigits`로 바꾸고, 압축 푼 바이트에 "Pretendard" 문자열이 0개(QA fontTools 검사). 다른 게임 서브셋 재사용 금지.
```css
/* 숫자 전용 글꼴: Pretendard ExtraBold(SIL OFL 1.1)의 숫자·기호 서브셋. 수정본이라 내부 이름은 CactusDigits. 라이선스 fonts/OFL.txt */
@font-face { font-family: "CactusDigits"; src: url("fonts/cactus-digits-800.woff2") format("woff2");
  font-weight: 800; font-style: normal; font-display: swap; unicode-range: U+002B-002F, U+0030-0039; }
:root { --num-font: "CactusDigits", system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif; }
.num { font-family: var(--num-font); font-weight: 800; font-variant-numeric: tabular-nums; }
```
- Canvas 안 글자(눈금자 숫자 10·20…, 띠의 "3초")는 시스템 글꼴 `700 11px`. Canvas에서는 웹 글꼴 로딩 타이밍 문제를 피한다. 정확한 숫자를 보여 주는 곳(키, 늦게 뗌)은 모두 DOM.

### 표기 규칙
- 키: `52.6` + ` cm`(design.md: `(mm/10).toFixed(1)`). HUD·결과 모두 같은 형식. 증가분 `+42.6`.
- 늦게 뗌: `0.08초 늦게 뗌`(design.md 문구 그대로, 0.01초 올림). 1초 넘으면 "1초 넘게 늦게 뗌".
- 시각: `1분 47초`, `58초`(60초 미만은 초만).
- 물: `-71`, `1,120`(천 단위 쉼표). 마이너스는 서브셋에 있는 하이픈-마이너스 `-`(U+002D)를 쓴다(U+2212 `−`는 서브셋에 없어 시스템 글꼴로 떨어짐).

### 크기 계산 (art-ref.js `layout()`과 같음)
1. `--app-h = innerHeight px`(`resize`·`orientationchange`·`visualViewport.resize`), CSS 기본 `100dvh`/`100vh`. `html, body { height: var(--app-h); overflow: hidden; }`. body 패딩 `max(12px, env(safe-area-inset-*))`, 높이 ≤ 520이면 `max(6px, …)`. viewport `width=device-width, initial-scale=1, viewport-fit=cover`.
2. 상단 바 TB = 52(높이 ≤ 520이면 44), 아래 간격 8. **무대** `SW = min(패딩 뺀 폭, 1400)` 가운데 정렬, `SH = 남은 높이`. Canvas는 무대를 꽉 채우고 `width = SW × dpr`(dpr ≤ 2), CSS 크기 SW × SH.
3. 무대 안 (CSS px):
   - 땅선 `SZ = round(SH × r)`, r = 0.56(세로) / 0.60(가로) / 0.64(SH < 420). 단 누르는 곳 `SH − SZ ≥ 110`.
   - 띠 `by = 10`(SH < 420이면 6), `BH = clamp(round(SZ × 0.2), 52, 112)`.
   - "지금" 선 `nowX = round(SW × 0.30)`(SW < 520이면 0.34). 띠 오른쪽 끝 `right = SW − 8`.
   - **예고 속도 = (right − nowX) / 3 px/초** — 화면마다 다르지만 **예고는 항상 3.000초**(design.md `bandSeconds()`). 오른쪽 끝 밖은 잘라 그리지 않는다.
   - 지난 날씨: `nowX − 0.5초 × 속도` ~ `nowX`만 흐리게. 그보다 왼쪽은 빈 띠 바탕.
   - 선인장 공간 `space = SZ − (by + BH) − gap`(gap 26, SH < 420이면 16), 최대 표시 키 `Hmax = space × 0.86`.
   - 꽉 찬 몸 폭 `bw = clamp(round(min(SW × 0.1, space × 0.32)), 36, 96)`. 눈금자 x = `nowX − bw × 1.3 − 14`.
4. 회전·크기 변경 → 3단계만 다시. 시간 축은 그대로(design.md: 조각 위치는 시각으로 계산).

|---|---|---|---|---|---|---|
| iPad 세로 810×1080 | 786 × 996 | 558 | 112 | 181 | 79 | 353 |
| iPad 세로 820×1180 (QA) | 796 × 1096 | 614 | 112 | 183 | 80 | 401 |

### 키 눈금자와 확대 단계

## 선인장 그리기 (Canvas, art-ref.js `drawCactus`)

### 입력
`{ x: nowX, gy: 땅선, bw, h: 키 px, o, W, grains, flash, tilt, bloom, withered }`
- **o는 게임 엔진의 열림 정도 그대로**(선형 0.15초/0.10초). 보간 곡선을 따로 넣지 않는다 → 화면 모양 = 판정 상태(30% 문턱이 눈으로 보이는 그대로).

### 몸 굵기 = 물
- 폭 `w = bw × (0.5 + 0.5 × min(W, 90) / 90)` → W 0 = 50%, 60 = 83%, 90 = 100%.
- **90선**: 꽉 찬 몸(bw) 윤곽을 같은 모양으로 그린다. W < 88: 점선 [5,5] 1.5px `fullRing` α .4 / W ≥ 88: 실선 2.5px α .85. 몸이 이 선에 닿으면 "꽉 찼다", 이후 비는 키로 간다. 쓰러짐(withered)에서는 그리지 않음.

### 열림 vs 닫힘 (크게 다르게)
| | 펼침 (o = 1) | 웅크림 (o = 0) |
|---|---|---|
| 색 | `open` 연두 / `openEdge` | `closed` 회녹색 / `closedEdge` |
| 팔 2개 (높이 42%·60%, 굵기 w×0.34) | 몸에서 **w × 0.58** 바깥으로 벌리고 위로 높이 듦, 끝이 바깥으로 기욺 ("만세") | 몸에서 w × 0.16만 나와 몸에 **붙여 접음**, 끝이 안쪽으로 기욺 |
| 몸 높이 | 100% | **92%**(움츠림) |
| 몸 옆선 | 바깥으로 볼록(w × 0.07) | 살짝 오목(허리 −w × 0.035) |
| 물구멍 점 | **4줄 타원 점**(밝은 `pore` + 진한 가운데), o > 0.05부터 나타나 o 0.65에서 완전 | 없음 |
| 세로 골(갈비 3줄) | 넓게 벌어지고 옅음(α .28) | 모이고 진함(α .68, 1.2px 더 굵음) |
| 주름 | 없음 | 짧은 가로 주름 ︶ 3열, 몸 폭 × 0.17 간격, α (1−o)×.75 |
- 모든 값은 o로 선형 보간(art-ref.js). 열림 0.15초·닫힘 0.10초는 엔진 o가 이미 그 속도로 움직인다.
- 가시: 양옆 14px 간격 4px, 머리 3개, 팔 끝 1개(`spine`).

### 쭈글쭈글 (물 적음)
- `dry = clamp((35 − W)/35, 0, 1)`: 몸 색이 `dry` 쪽으로 최대 70% 섞임, 높이 −5%, 옆선이 물결처럼 흔들림(진폭 w × 0.035 × dry), 팔이 처짐(들어 올림 −50%), **몸 전체 가로 물결 주름**(w × 0.12 간격, α dry × .85). 렌더 확인: W 12는 W 90과 폭·색·주름이 한눈에 다름.
- W < 15: 외곽선이 `--loss-ink` 쪽으로 천천히 숨쉬듯 α .4↔.9 (1200ms 주기, sine). 번쩍임 아님(1Hz 미만).

### 넘친 물 → 키 (성장 연출)
- W = 90에서 비를 받아 H가 오르는 동안 **물방울**(`drawDrop`, 반지름 max(3, bw × 0.07), 흰 테두리)이 몸 옆(높이 40%)에서 생겨 몸을 따라 머리까지 올라가며 작아지고 사라진다: 500ms, ease-in, 마지막 120ms α → 0. 생성 간격 = **키 0.2cm 늘 때마다 1개**, 화면에 최대 8개.
- 물방울이 머리에 닿을 때 몸 높이는 이미 H로 그려져 있다(키는 엔진 값을 즉시 반영 — 연출이 점수를 앞서거나 늦추지 않음). 키 알약 테두리 `fullRing` 색 400ms 유지 후 원래대로(성장 중이면 계속 유지).
- 90선이 실선으로 바뀌는 순간(W ≥ 88) 윤곽 α .4 → .85 200ms.

### 비를 머금는 중 / 해·모래에 펴짐
- 펴진 채 비: 몸 양옆에 작은 물튀김(반원 호 2개, `rain`, 160ms)이 빗줄 굵기에 비례해 생김(초당 4 → 10개). 몸이 넓어지는 것 자체가 핵심 피드백.
- 펴진 채 해: 몸 위에 `heat` 색 덮개 α .25 (o에 비례). 몸이 눈에 띄게 줄어드는 것이 핵심.
- 펴진 채 모래: 먼지 점이 몸에 부딪혀 사라짐(초당 12개).

### 따끔 (모래알 박힘)
- 따끔 순간: ① 외곽선 `--danger` +2px 번쩍 (α 1 → 0, 400ms ease-out, 1회) ② 모래 따끔 = **모래알 1개가 몸에 영구로 박힘**(`grains` +1, hash로 정한 위치, 최대 16개 표시) / 해 따끔 = 모래알 없이 몸 색이 `dry` 쪽으로 50% 바랬다가 300ms에 돌아옴 ③ 짧은 흔들림: 선인장 translateX 0 → −3 → 3 → −2 → 0, 220ms (design.md "짧은 흔들림"). **화면 전체는 흔들지 않는다.**
- 박힌 모래알: 반지름 max(2.4, w × 0.05), `grain` + 1px `crease` 테두리 + `grainHi` 하이라이트 점.

### 말라 쓰러짐 (design.md 1.2초)
- W ≤ 0: 몸 색 → `dry` 100% (300ms) · o는 엔진 값대로 0으로 · 0~1200ms 동안 뿌리를 축으로 tilt 0 → 1.15 rad(약 66°), cubic-bezier(.5,0,.9,.6)(점점 빨라지며 넘어짐) · 900ms 지점부터 땅 닿는 자리에 모래 먼지 원 3개 퍼짐(300ms) · 날씨 띠는 그 시각에 멈춤. 1.2초 뒤 결과.

### 해질녘 도달
- t = 150: 띠의 조각이 α 1 → 0 (400ms), 하늘은 해질녘 색. 선인장 머리에 **꽃** 피어남: bloom 0 → 1, 700ms, cubic-bezier(.3,1.4,.5,1). 꽃 = 꽃잎 5장(`bloom`) + 가운데 원(`bloomC`), 크기 max(6, w × 0.2). 해 시계의 해가 지평선 오른쪽 끝에 닿음. 1.2초 뒤 결과.

## 날씨 그리기 (art-ref.js `drawSeg` 띠 안 / `drawSegScene` 띠 아래)

### 공통
- 조각은 **진짜 좌표**(x = nowX + (시각 − t) × 속도)로 그리고, 보이는 범위 [nowX − 0.5초, right]로 **잘라낸다(clip)**. 보이는 부분 가운데로 아이콘을 옮기지 않는다 → 해 원·빗줄 굵기가 조각에 붙어 함께 흐른다.
- 각 조각 띠 바탕 = 종류 tint, **시작·끝 경계선 2px**(비 `rain`, 모래 `sandWave`, 해 `sunEdge`). 비의 끝 경계가 "지금" 선에 닿는 순간 = 비 끝 — 실력 판단의 기준선이므로 반드시 선명하게.
- 맑음 = 아무것도 그리지 않음(띠 바탕만). 좌우 조각의 경계선으로 길이가 읽힌다.
- **"지금" 선**: x = nowX, 띠 위 2px 위에서 띠 아래까지 2px `--ink` α .85 + 띠 바로 아래 아래쪽 삼각형(14 × 8). 라벨 글자 없음(삼각형이 선인장을 가리킴).
- 예고 눈금: 띠 아래 가장자리에 1·2·3초 위치 작은 눈금(2 × 7px, `--ink` α .45), 오른쪽 끝 안쪽에 "3초" 11px 700.
- 띠 아래 장면 효과는 하늘 영역(띠 아래 ~ 땅선)에 조각과 **같은 x 범위**로 그린다 → 구름이 선인장 위에 오면 선인장이 비를 맞는다.

- 띠 아래 빗방울: 16px 간격, 굵기 1.2 → 3.8px, 길이 12 → 22px, α .5, 아래로 600px/초 흐름(세로로만 — 대각선이면 x=시각 대응이 깨짐).
### 모래바람 — 가로 물결 + 낮은 먼지

## 애니메이션·이펙트 (지속시간 ms, easing)
| 이펙트 | 내용 | ms | easing |
|---|---|---|---|
| 열림 / 닫힘 | 엔진 o 그대로 그림(팔·색·점·주름·높이 모두 o 선형) | 150 / 100 | linear (엔진) |
| 누름 물결 | 누른 자리 원 0 → 72px, α .35 → 0 | 300 | ease-out |
| 날씨 띠 흐름 | 매 프레임 시각으로 위치 계산 | — | — |
| 빗줄 낙하 | 띠 아래 빗방울 아래로 600px/초 | 반복 | linear |
| 모래 물결·먼지 | 무늬 왼쪽으로 30 / 90px/초 | 반복 | linear |
| 해 빛살 회전 | 0.12 rad/초 | 반복 | linear |
| 물튀김 (펴진 채 비) | 몸 옆 반원 호 2개 | 160 | ease-out |
| 넘친 물방울 | 몸 옆 40% → 머리, 작아지며 사라짐 | 500 | ease-in |
| 90선 실선 전환 | α .4 → .85 | 200 | ease-out |
| 키 알약 테두리 | `fullRing` 유지 후 복귀 | 400 | linear |
| 확대 단계 전환 | 눈금 간격·몸 높이 | 600 | ease-in-out |
| 따끔 외곽선 | `--danger` α 1 → 0 | 400 | ease-out |
| 따끔 흔들림 | 선인장 translateX 0,−3,3,−2,0 | 220 | ease-in-out |
| 따끔 표시 | 등장 / 유지 / 사라짐 | 120 / 1200 / 300 | cubic-bezier(.3,1.4,.5,1) / — / ease-in |
| 쓰러짐 | tilt 0 → 1.15 rad + 색 바램(300) + 먼지(900~1200) | 1200 | cubic-bezier(.5,0,.9,.6) |
| 해질녘 꽃 | bloom 0 → 1 (+ 띠 조각 α → 0 400ms) | 700 | cubic-bezier(.3,1.4,.5,1) |
| 하늘색 | 150초 동안 연속 | 150000 | smoothstep 구간 |
| 준비 고리 | 남은 시간 비율 호 | 2000 / 1500 | linear (JS) |
| 오버레이 | 공통 ovIn/ovUp | 200 | ease-out |
| 새 기록 알약 | scale .8 → 1 + α, 결과 +200ms | 220 | cubic-bezier(.3,1.4,.5,1) |
- 그리기는 `requestAnimationFrame` 1개. 엔진 단계(5ms)와 분리, 그리기는 마지막 단계 상태를 쓴다.
- 일시정지·탭 숨김 중에는 rAF를 멈추거나 그리기만 생략(배터리). 장식 애니메이션(빗줄 낙하 등)의 위상은 게임 시각이 아니라 실제 시간이어도 된다(판정 무관).
- 1초에 3번 넘는 번쩍임 없음(따끔이 짧은 간격으로 이어져도 외곽선 번쩍은 400ms 안에 다시 시작하지 않음).

### 모션 줄이기 (`prefers-reduced-motion: reduce`)
**판정과 연결된 움직임은 그대로**: 날씨 띠 흐름, 열림/닫힘 모양 변화(o), 몸 굵기·키 변화, 해 시계, 하늘색.
- 빗줄 낙하·모래 무늬 흐름·빛살 회전 → **정지 무늬**(같은 모양, 움직이지 않음).
- 넘친 물방울 → 없음. 대신 90선 실선 + 키 알약 테두리 유지로 성장 표시.
- 물튀김·먼지 부딪힘 → 없음.
- 따끔: 흔들림 없음, 외곽선 번쩍 대신 외곽선 `--danger` 400ms 고정 후 원래대로. 표시는 α만(scale 없음).
- 쓰러짐: 기울기 애니메이션 없이 300ms 크로스페이드로 쓰러진 모습. 꽃: α만.
- 확대 단계 전환: 즉시. 시작 화면 데모: **자동 재생하지 않고** 데모 창 위 ▶ 버튼(44×44)으로 재생, 기본은 정지 첫 장면 + 3칸 그림 캡션.
- 누름 물결 없음(누르는 곳 채움 색만).

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)
- **누르는 곳 = `.stage` 전체**(버튼 제외). `.stage { touch-action: none; }`, 그 밖 `body { touch-action: manipulation; }`.
- **iPad Safari 필수**(design.md: 길게 누르기 메뉴가 뜨면 치명적): `body, .stage { user-select:none; -webkit-user-select:none; -webkit-touch-callout:none; -webkit-tap-highlight-color: transparent; }`, `.stage`의 `contextmenu`·`selectstart`·`dblclick`·`gesturestart`에 `preventDefault`. 무대 안에 글자 선택 가능한 DOM 없음(따끔 표시도 `pointer-events:none`). 가로·세로 스크롤 0.
- 입력 처리는 design.md "입력" 표 그대로(pointerdown/up/cancel/lostpointercapture, setPointerCapture, 스페이스 repeat 무시, blur·visibilitychange·pagehide 강제 뗌).
- **스페이스와 버튼 포커스**: 플레이 중 스페이스가 포커스된 버튼(일시정지·음소거)을 누르면 안 된다 → 버튼은 `pointerdown` 후 `blur()`, 그리고 플레이 중 document 단계 keydown에서 스페이스는 항상 `preventDefault` 후 게임 입력으로만 쓴다. 오버레이(시작·일시정지·결과)가 열려 있을 때만 스페이스/Enter가 버튼을 누른다.
- 버튼(상단 바·오버레이) 44 × 44 이상, 주 버튼 52~56. 상단 바 버튼은 무대 밖이므로 누름과 겹치지 않는다.
- **키보드**:
| 키 | 동작 |
|---|---|
| Space (누르고 있기) | 펴기 / 떼면 닫기 |
| 마우스 버튼 (누르고 있기) | 펴기 / 떼면 닫기 |
| Enter | 시작(오늘의 날씨) · 다시 · 계속하기 |
| P, Esc | 일시정지 열기/닫기 |
| M | 음소거 |
| 조합키(Ctrl/Meta+…) | 무시 |
- 포커스 링 공통 `outline: 3px solid var(--accent); outline-offset: 2px`.

## 접근성 (대비, 색 외 구분 수단)
- **날씨 4종은 모양으로 구분**(구름+세로줄 / 가로 물결+먼지 / 원+빛살 / 빈칸) + 경계선 + 소리. 흑백 렌더 확인. QA는 Chromium 시각 장애 에뮬레이션(제1·제2색맹) 스크린샷 추가 권장(미검증).
- **열림/닫힘은 모양으로 구분**: 팔 벌림 vs 붙임, 물구멍 점 vs 주름, 키 92%. 연두/회녹색은 보조. 흑백 렌더에서 구분 확인.
- **물 상태**: 몸 폭 + 90선 윤곽(점선/실선) + 마른 주름. 숫자는 없음(design.md) — 대신 결과 화면에 물 숫자.
- **따끔**: 빨간 외곽선 + 모래알 박힘(영구) + 글자 표시 + 소리.
- 대비: 글자는 `--ink`/`--muted`/`--good-ink`/`--loss-ink`/`zoneInk`/`rulerTxt`만 — 각 바탕 대비 4.5:1 이상(`rulerTxt` #5c4a2e는 가장 밝은 하늘 #f6ebd3 위 약 8:1, 다크 #cbb98f는 #3d3424 위 약 6:1). 경계선·빗줄·외곽선은 비텍스트 3:1 이상.
- 스크린 리더: canvas `role="img"`, `aria-label` 10초마다 "키 41.3센티미터, 남은 하루 87초". 따끔 표시 `aria-live="polite"`. 결과 화면은 모두 DOM 글자(되돌아보기 띠는 요약 label). 이 게임은 시각 타이밍 게임이라 화면 없이 플레이는 어렵다 — 소리 신호(sound.md)가 보조.
- 다크 모드 자동 전환: 플레이 중 테마가 바뀌면 다음 프레임부터 새 팔레트.

## 개발자 체크리스트 (요약)
1. 장면은 Canvas 1장, 그리기는 `art-ref.js` 함수 구조·수치를 옮긴다. 선인장 모양은 **엔진 o를 그대로**(따로 easing 넣지 않음).
2. 예고 = (right − nowX)/3 px/초, 띠 오른쪽 끝 밖은 clip, 지난 날씨는 0.5초만. 조각은 진짜 좌표로 그리고 clip(빗줄 굵기·해 위치가 조각에 고정).
3. 비 빗줄 굵기 1.5 → 5px = 조각 진행률 p 선형. 비 조각 끝 경계선 2px 선명하게.
4. 물 = 몸 폭(50~100%) + 90선 윤곽, 키 = 몸 높이 + 눈금자(R 25/40/60/90 단계). 숫자 게이지 없음.
5. 따끔 표시는 DOM `.prick`, design.md 3유형 문구, 손 뗀 순간 숫자 덧붙임, 1200ms 유지. 결과 각주 조건부.
6. 일시정지: 불투명 `--well` + 캔버스 띠도 가림. 선인장 o는 그대로 멈춤. 재개 1.5초 고리.
7. 결과: 머리 칩(오늘의 날씨 날짜 / 연습 점선) → 큰 키 → 해질녘/마름 → 따끔·빗물 2칸 → 아까운 순간 → 되돌아보기 띠 → 기록 → 다시/처음으로 → 각주. 0.8초 잠금. 폰 가로 2열, 스크롤 0.
8. iPad: `touch-action:none`, 길게 누르기 메뉴·선택·확대 차단, 스페이스가 버튼을 누르지 않게 blur.
9. CactusDigits(0-9 + `+,-./`, tnum, 이름 변경, "Pretendard" 0, OFL.txt). 'cm'은 시스템 글꼴.
10. 실험실 카드: `--tile-cactus` 3곳 + 위 SVG. `lib/leaderboard.js` 불러오지 않음(`#lbSlot`·가드 유지).
