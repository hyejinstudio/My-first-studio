### 버그
- [높음] **"0.00초 늦게 뗌" 표시 — 따끔을 맞았는데 늦음이 0으로 나옴**
  - 증상: 완전히 편 상태에서 해/모래 조각 시작 **정확히 0.070초 전**(5ms 격자 기준)에 떼면 o(t_seg)가 정확히 0.3(180/600)이 됩니다. 판정이 `o ≥ 0.3`이라 따끔이 나는데, t* = t_seg − 70ms로 계산되어 lateMs = 0 → 화면에 "0.00초 늦게 뗌"(결과 화면 "가장 아까웠던 순간"도 같음). design §5의 "늦음 항상 > 0"에 어긋나고, 플레이어는 "안 늦었는데 따끔"으로 읽게 됩니다.
  - 빈도: 숙련 봇 400판에서 늦게 뗌 따끔 1,925개 중 353개(18.3%). 실제 입력은 timeStamp를 5ms로 반올림하므로 사람에게도 자주 생깁니다.
  - 같은 원인: 격자 위에서 실제로 피할 수 있는 가장 늦은 뗌은 t_seg − 75ms입니다. 그래서 완전히 편 경우의 늦음 숫자는 모두 5ms씩 작게 계산됩니다(표시는 올림이라 절반 정도의 경우만 0.01 차이).
  - 재현: `__cactus.simulate({segs:[{type:'clear',start:0,end:2000},{type:'sand',start:2000,end:3000},{type:'clear',start:3000,end:150000}], inputs:[{t:500,down:true},{t:1930,down:false}]}).stingList[0]` → `{kind:'late', lateMs:0}`. 실시간으로는 `press(s-1000); release(s-70)` 뒤 따끔 말풍선에 "0.00초 늦게 뗌".
  - 기대: 늦음은 0보다 커야 함(이 경우 "0.01초").
  - 수정 제안: t*를 "o(t_seg) < 180이 되는 가장 늦은 5ms 격자 시각"으로 정의합니다. 경계가 격자 위에 딱 걸리면 5ms를 뺍니다. 예: `tStar`에서 `Math.ceil(r/STEP - 1e-9)*STEP - STEP`. 그러면 0.065초 전 → 0.01(QA #8 그대로), 0.070초 전 → 0.01이 됩니다. design.md §5의 "t* = t_seg − 0.07"도 "− 0.075(5ms 격자)"로 함께 고쳐야 합니다(기획 확인 필요).
  - 코드 위치: `lab/games/desert-breath/index.html` 1021~1026행(`tStar`), 1744행(`lateText`).
- [낮음] **폰 세로(무대 폭 < 480px) 결과 화면에서 판 머리("오늘의 날씨 · 11월 27일" / "연습 날씨")가 사라짐**
  - 원인: `body.tb-480 .mode { display:none }`(267행)이 상단 바 칩을 숨기려는 규칙인데, 결과 머리 `#rHead`도 class `mode`를 함께 써서 같이 숨겨짐.
  - 재현: iPhone 13 세로 → 판 끝 → 결과(`shots/phone-light-result.png`).
  - 기대: art-ui 결과 순서 1번 "머리 칩"이 보여야 함. 수정 예: `body.tb-480 .top .mode`로 범위를 좁힘. iPad·PC에는 영향 없음.
- [낮음] **250ms보다 긴 프레임 끊김 중에 들어온 입력이 게임 시계상 늦게 적용됨**
  - 증상: 끊김이 생기면 `G.origin += gap − 250`(1959행)으로 시계를 밀지만, 끊김 중에 들어온 입력은 밀기 전 origin으로 `gameT`가 계산됩니다.
  - 측정: 800ms 끊김의 400ms 지점에서 뗌 → 다음 프레임 시계는 30,680인데 뗌은 약 30,820에 적용. 약 140ms 더 열려 있게 됩니다.
  - 영향: 끊김이 길 때만 생기고, 그 경우 억울한 따끔과 숫자가 나올 수 있습니다.
  - 수정 예: `inputAt`에서 시각을 "끊김 보정 후 현재 시각" 이하로 자르거나, 끊김 보정을 입력 처리 전에 반영.

### 참고 (버그 아님)
- 준비 2초 동안 `Sound.update`의 next는 0초 맑음이라, 첫 비(1초)의 예고 소리는 3초가 아니라 1초 전부터 들립니다. 늦게 들리는 쪽이라 공정성 문제는 없습니다.
- 시작 화면을 자정 넘어 열어 두면 "오늘의 날씨" 버튼 아래 날짜 글자는 예전 날짜로 남습니다. 시작할 때는 새 날짜로 정상 시작합니다.
- 난이도 의견: 초보 봇(반응 0.3초, 손 떨림 0.15초)은 30.7cm로 해질녘 0%, 욕심쟁이는 해질녘 2.8%입니다. "늦게 떼면 오후에 말라 죽는다"가 분명해 '쉽지 않게'에 맞습니다. 첫 판 초보 체감은 아침 20초 동안 2~3cm를 자라고, 40~70초 한낮 구간에서 따끔이 몰리며 1분 반~2분 사이에 마를 가능성이 높아 보입니다(추정). 해질녘까지 가려면 "비 끝보다 조금 일찍 떼기"를 깨달아야 하므로 2~4판 학습이 필요해 보입니다. 겁쟁이가 90%로 쉽게 살아남는 점은 CEO 판단대로 키 차이(27.7 vs 38.4)로 보상됩니다.
