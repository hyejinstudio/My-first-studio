# 선인장 키우기 (desert-breath) — 사운드 명세

모든 소리는 Web Audio API로 실시간 합성한다(음원 파일 없음). 코드: `docs/games/desert-breath/sound-module.js` — Developer가 `lab/games/desert-breath/index.html`의 독립 `<script>` 블록에 그대로 붙여 넣는다(`_test` 부분 포함해도 무해).

**톤 원칙**: 사막의 하루. 바람·비·모래의 **환경음**이 주인공이고, 효과음은 작고 둥글다(효과음 버스 9kHz 로우패스, 버저·사각파 없음).
**박자 없음(필수)**: 배경음악·루프 멜로디·일정한 박자를 쓰지 않는다. 환경음은 노이즈 + 서로 맞지 않는 느린 흔들림(0.041·0.067·0.113·0.23·0.31·0.53Hz 등), 빗방울·꿀렁·탁탁은 매번 무작위 간격(지수 분포). 박자 앵무새처럼 들리지 않아야 한다.
**공정성**: 다가오는 날씨는 화면 예고 띠와 똑같이 **도착 3초 전부터만** 작게 들린다(아래 2-1). 일시정지 중(띠가 가려짐)에는 환경음 전체가 꺼진다.

조성: D 장조 5음 음계(D E F# A B). 모든 음 배열은 오리지널.

## 0. 기획(design.md) 이벤트와 소리 대응

| 게임 이벤트 | 소리 |
|---|---|
| 시작 화면 8초 데모(반복) | **무음.** 데모 코드에서 `Sound`를 부르지 않는다(첫 터치 전이라 오디오 잠금 상태이기도 함) |
| 시작 버튼("오늘의 날씨"/"연습") click | `unlock` + `button` + `startAmbient` — 2초 준비 동안 이미 바람·예고가 흐름 |
| 2초 준비 / 재개 1.5초 준비 | 카운트 소리 없음(박자 금지). `update`는 계속 호출(`open:false`) |
| 누름: "모두 뗀 상태 → 첫 누름"(물 −2 순간, t ≥ 0) | `open` '스읍' 0.16초 (펴짐 0.15초와 같은 길이) |
| 모두 뗌 | `close` '톡' 0.03초 (닫힘 0.10초 안에 끝남) |
| 비 맞으며 펴져 있음 | 환경음이 자동으로 '꿀렁'(물 머금음) 추가 — `update`의 `open` |
| 키가 1cm 단위로 늘 때 | `grow {cm}` |
| 해 조각 따끔(−6, 조각당 1번) | `scorch` '지글' (+ 펴져 있는 동안 환경음 '치이—·탁탁') |
| 모래 조각 따끔(−12, 조각당 1번) | `sting` '츳' (+ 펴져 있는 동안 환경음 '사사삭') |
| 마름(W ≤ 0, 쓰러짐 1.2초) | `wilt` + `stopAmbient` |
| 해질녘(150초) | `dusk` + `stopAmbient` |
| 결과 화면 | 오늘의 날씨 새 기록이면 `record`, 아니면(연습 포함) `result` |
| 일시정지(Ⅱ/Esc/P/자동) / 계속 | `setPaused(true)` / `setPaused(false)` |

열기/닫기는 판당 수십~백 번 이상 난다 → 가장 작고 짧게, 동시 발음 최대 2개, 각각 50ms 스로틀, 연타 간격이 짧을수록 자동 축소(계수 = clamp(0.55 + 2.25·gap, 0.55, 1)). 열기 −2 물 비용 때문에 실제 연타는 드물다.

## 1. 신호 경로

```
sfxBus → lowpass 9kHz ─────────────────────┐
ambBus(환경음, 시작/정지/일시정지 페이드) → ambDuck(순간 덕킹) ─┴→ master(0.6, 음소거) → limiter → 출력
```
- 마스터 리미터: DynamicsCompressor threshold −6 dBFS, knee 2, ratio 20, attack 2ms, release 150ms.
- 순간 덕킹: `wilt`(1.8초)·`dusk`(2.4초)·`record`(2.0초) 때 환경음 0.45배.
- 엔벨로프는 0.0001에서 지수 어택/감쇠(클릭음 방지).
- **노이즈 버퍼 1개**(4초, 스테레오, 고정 시드, 루프 이음매 20ms 교차 페이드)를 환경음·효과음이 모두 재사용. 환경음은 이 버퍼를 도는 재생기 **2개**(A: 0~4초, B: 0.53~3.71초 ×0.97 속도)를 여러 필터로 나눠 쓴다 → 반복 무늬가 겹쳐 돌지 않고, iPad 부하가 낮다(상시 노드: 버퍼 재생기 2 + 느린 LFO 8 + 필터·게인 약 20).

## 2. 환경음 (연속, `startAmbient` ~ `stopAmbient`)

| 층 | 언제 | 레시피 | 측정 RMS (피크) |
|---|---|---|---|
| 바람 | 항상(해 날씨에는 0.5배 = 고요) | A → LP 450Hz(±140Hz, 0.041Hz) → 크기 흔들림 0.067·0.113Hz | 맑음 −44.6 dBFS (−31.9) |
| 비 | 지금 비 | B → HP 450 → LP 2.6k→6.5kHz(굵기) + **빗방울 알갱이**(밴드패스 2.2~6kHz 5~12ms, 초당 8→34개 무작위). 층 게인 0.045→0.125(굵기) | 가는 비 −38.8 (−26.0) / 굵은 비 −28.1 (−15.8) |
| 물 머금음 '꿀렁' | 지금 비 + 펴짐 | sine 260~340Hz → 1.8배 70ms + 한 옥타브 아래 받침, 0.18~0.6초 무작위 간격(굵을수록 잦고 큼) | 굵은 비 위에서 은은함(RMS 변화 거의 없음) |
| 모래바람 | 지금 모래 | A → BP 3.6kHz(±700Hz 흔들림)(고음 사르르) + B → LP 200Hz(낮은 바람), 돌풍 흔들림 0.31·0.53Hz | −32.2 (−17.8) |
| 모래 '사사삭' | 모래 + 펴짐 | B → BP 6.5kHz Q1.4, 0.37Hz 흔들림 | 모래 위 −32.1 (거의 같음, 음색만 거칠어짐) |
| 한낮 해 | 지금 해 | B → BP 5.5kHz Q2(±1.2kHz, 0.17Hz) 옅은 아지랑이 + 바람 절반 | −43.3 (−30.1) |
| 해 '치이—·탁탁' | 해 + 펴짐 | A → HP 4.2kHz + 무작위 탁탁 클릭 3ms(초당 약 12개) | −35.8 (−23.9) |

- **날씨가 바뀌는 순간**: 떠나는 층·도착하는 층 모두 시정수 50ms로 바뀐다(귀로도 경계가 분명). 같은 날씨 안의 굵기 변화는 150ms로 부드럽게.
- **굵기**: `heavy` = 그 비 조각 안 진행률 p(0→1). design.md의 흡수량 +12+18p와 같은 p를 넘기면 된다 → 비 끝물이 가장 크고 밝다.

### 2-1. 예고 소리 결정 (공정성)
- **결정: 화면 예고와 같은 3초만, 작게.** `nextIn ≤ 3`일 때만 다음 날씨(비·모래·해) 층이 0 → 50%까지(0.05 단위) 서서히 커진다. `nextIn > 3`이면 0(검증: 10초·3.05초·3.0초에서 0, 2.4초에서 > 0).
- 예고에는 **빗방울·꿀렁·탁탁 같은 알갱이가 없다** → 도착 순간 알갱이가 시작되고 층이 100%로 올라가 "지금 바뀌었다"가 분명하다.
- 측정(최대 예고 50%): 맑음 −44.5 → 비 예고 −39.9 / 모래 예고 −39.3 / 해 예고 −43.1 dBFS RMS. 비 끝물(−29) 위에 모래 예고가 겹치면 "멀리서 바람이 온다" 정도.
- 일시정지 화면은 띠를 가리므로 `setPaused(true)` 동안 환경음 전체 0(측정 −121 dBFS = 무음). 재개 준비(띠 보임)에서 `setPaused(false)`.

## 3. 효과음 목록

피크는 Chromium OfflineAudioContext 48kHz 렌더 측정값(마스터·리미터 통과 후, 환경음 없음).

| 이름 (`Sound.play`) | 언제 | 합성 레시피 | 길이 | 피크 |
|---|---|---|---|---|
| `button` | 일반 UI 버튼 | sine 640→500Hz 55ms + BP 노이즈 2.4kHz 20ms. 50ms 스로틀 | 0.04s | −21.7 dB |
| `open` | 첫 누름(물 −2) | 들숨 '스읍': BP 노이즈 700→1900Hz(Q1.1) 0.16s, 어택 90ms + sine 420→520Hz 아주 옅게. ±5% 무작위. 연타 축소 | 0.14s | −27.7 dB |
| `close` | 모두 뗌 | '톡': sine 950→620Hz 30ms + BP 노이즈 1.5kHz 30ms. 연타 축소 | 0.03s | −28.0 dB |
| `grow` | 키 1cm 늘 때 `{cm}` | sine을 4도 아래에서 목표음으로 쓱 올림 0.26s + 2배 반짝임. 음 = D 장조 5음 음계 D5~B6 10칸 중 `cm % 10`번째(1cm마다 한 칸 위, 10cm마다 처음으로 + 작은 종). 120ms 스로틀 | 0.19~0.30s | −23.0 dB |
| `sting` | 모래 따끔 | '츳': 모래알 클릭 3개(BP 3.8~5.2kHz 8ms, 11ms 간격) + HP 노이즈 3.2→5.2kHz 75ms + triangle 1.8kHz 30ms. 낮은 신음 없음 | 0.06s | −22.4 dB |
| `scorch` | 해 따끔 | '지글': 무작위 클릭 7개(0.3초 안) + BP 노이즈 6→3kHz 0.36s | 0.25s | −24.9 dB |
| `wilt` | 마름 | sine G4→165Hz 1.1s + triangle 아래 + '휘유' BP 노이즈 + 0.95초에 모래 '퍽'(LP 노이즈 + sine 110→70Hz). 덕킹 | 1.08s | −19.0 dB |
| `dusk` | 해질녘 | D add9 화음(D4 F#4 A4 E5, 어택 0.35s, 2.4s) + triangle D3 + 종 A5·D6. 덕킹 | 1.95s | −16.9 dB |
| `result` | 결과 화면(새 기록 아님) | 마림바 A5 → D6 | 0.33s | −22.4 dB |
| `record` | 결과 화면, 오늘의 날씨 새 기록 | 마림바 D5-E5-F#5-A5-B5-D6(55ms) + 종 D6 + G 화음 → D 화음 + 종 A6. 덕킹 | 1.51s | −12.8 dB |

레벨 의도: close·open(−28) < scorch(−25) < grow·sting·result(−22~−23) < wilt(−19) < dusk(−17) < record(−13).
- 열기/닫기는 굵은 비(RMS −28) 속에서 묻힐 정도로 작다 — 내 손이 곧 상태라 소리는 확인용일 뿐.
- 따끔 '츳'은 짧고 고음이라 모래바람(3.6kHz 사르르) 위에서도 "박혔다"가 들린다.

## 4. 오디오 시스템

### API
```
Sound.unlock()                     사용자 제스처(click/touchend/pointerup/keydown) 안에서. 여러 번 안전
Sound.play(name, opts?)            효과음. opts: grow {cm}
Sound.startAmbient() / Sound.stopAmbient()   환경음 시작 / 약 1.5초 페이드아웃 후 정지
Sound.update({ now, heavy, next, nextIn, open })   매 프레임. 바뀐 값만 반영(가벼움)
    now: 'clear'|'rain'|'sun'|'sand'   heavy: 0~1(비 조각 진행률 p)
    next: 다음 날씨|null   nextIn: 다음 날씨까지 초   open: 열림 정도 o ≥ 0.3
Sound.setPaused(bool)              일시정지 화면 true / "계속" false
Sound.setMuted(bool) / Sound.isMuted()     전체 음소거(저장)
Sound.startMusic() / stopMusic()   공통 인터페이스 호환용 = startAmbient/stopAmbient
```
알 수 없는 이름, unlock 전 호출, 음소거 중 `play()`는 조용히 무시된다. unlock 전에 `startAmbient()`가 불렸으면 unlock 시점에 시작.

### 저장 (localStorage, 읽기·쓰기 모두 try/catch)
- `desert-breath-muted`: `'1'` 음소거 / `'0'` 켬. 기본 켬. 저장소 차단 환경에서도 기본값으로 동작(검증함).
- 배경음악이 없으므로 음악 설정 키는 없다.

### iPad Safari
- AudioContext는 **첫 사용자 제스처 안에서** `Sound.unlock()`으로 생성·`resume()`하고 1샘플 무음 버퍼를 재생해 iOS 출력 경로를 연다. **시작 버튼의 click에서 반드시 unlock** — 게임 입력이 `pointerdown`(누르고 있기)이라 그것만으로는 iOS 잠금이 안 풀릴 수 있다. 시작 버튼을 거쳐야만 판이 시작되므로 이 흐름이면 안전. 게임 영역 `pointerup`·스페이스 `keydown`에서도 `unlock()`을 불러 둔다(무해).
- **무음 스위치/무음 모드**가 켜져 있으면 소리가 나지 않을 수 있다(게임 오류 아님). 도움말에 "소리가 안 나면 무음 모드를 확인하세요" 한 줄 권장. 소리 없이도 완전히 플레이 가능(모든 정보가 화면에 있음).
- 탭 전환: 모듈이 `visibilitychange`에서 `ctx.suspend()`/`resume()`. 게임은 design.md대로 자동 일시정지 → `setPaused(true)`도 같이 부른다.
- AudioContext 미지원·생성 실패 시 모든 메서드는 무시되고 게임은 정상 진행.

## 5. Developer 호출 지점

| 위치 | 호출 |
|---|---|
| 모든 사용자 입력 핸들러(버튼 click, 게임 영역 pointerdown/pointerup, keydown) 맨 앞 | `Sound.unlock()` |
| 시작 화면 데모 | **아무것도 부르지 않음** |
| "오늘의 날씨"/"연습"/「다시」 click (2초 준비 시작) | `Sound.play('button'); Sound.startAmbient();` |
| 「처음으로」, 일시정지 화면 버튼 등 | `Sound.play('button')` |
| 매 프레임(준비·플레이 중, 일시정지 중 제외) | `Sound.update({ now, heavy: p(비일 때), next, nextIn, open: o >= 0.3 })` — 준비 중엔 `open:false` |
| 누름 목록이 빔 → 첫 누름이 적용된 순간(물 −2, t ≥ 0만) | `Sound.play('open')` |
| 누름 목록이 비는 순간(손 뗌) | `Sound.play('close')` (일시정지로 강제 뗌일 때는 생략) |
| `floor(H / 10)`(cm)가 커진 순간 | `Sound.play('grow', { cm: 새 cm 값 })` (한 프레임에 여러 cm 올라도 1번) |
| 해 조각 따끔(−6) | `Sound.play('scorch')` |
| 모래 조각 따끔(−12) | `Sound.play('sting')` |
| W ≤ 0 (쓰러짐 연출 시작) | `Sound.play('wilt'); Sound.stopAmbient();` |
| t = 150초 해질녘 | `Sound.play('dusk'); Sound.stopAmbient();` |
| 결과 화면 표시(wilt/dusk 뒤 ≥ 1.5초 권장) | 오늘의 날씨 + 새 기록: `Sound.play('record')`, 그 밖(연습 포함): `Sound.play('result')` |
| 일시정지 진입(Ⅱ/Esc/P/blur/숨김) | `Sound.setPaused(true)` |
| "계속" → 1.5초 다시 준비 시작 | `Sound.setPaused(false)` |
| 판 도중 「처음으로」로 나감 | `Sound.stopAmbient()` |
| 음소거 버튼 / M 키 | `Sound.setMuted(!Sound.isMuted())` + 아이콘 갱신(초기 표시는 `Sound.isMuted()`) |

- 스로틀·동시 발음 제한·연타 축소·예고 3초 제한은 모듈이 처리한다. `nextIn`을 그대로 넘기면 된다(3초보다 큰 값은 자동 무시).
