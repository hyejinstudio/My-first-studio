# 똥비 피하기 기획서 (v2)
- slug: poop-rain
- 한 줄 소개: 하늘에서 쏟아지는 똥비를 좌우로 요리조리 피하면서, 사이사이 떨어지는 별사탕을 주워 점수를 올리는 한 방 생존 게임. 처음엔 보슬보슬, 30초가 넘으면 장대비!
- 참고: 한국의 "똥 피하기" 장르 규칙(위에서 떨어지는 것을 좌우로 피함)만 빌린 오리지널. 특정 기존 게임의 캐릭터·화면·수치를 쓰지 않는다.
- 난이도 목표 (v2): **처음 쉽게 → 점점 → 후반 확실히 어렵게.** 0~15초는 손 풀기(5초째 화면에 똥 2~3개, 초보도 거의 안 죽음), 15~30초 꾸준히 상승, 30초 이후 v1 수준을 넘어 계속 조여 옴. 초보 중앙값 25~35초, 숙련 50초 이상(아래 "난이도 목표와 검증").
- 사용자 취향 반영: 쉬우면 지루함 → 쉬운 구간은 15초로 짧게, 30초 이후는 v1보다 더 가파름. "중간에 먹으면 점수가 오르는 것" → 별사탕. "우산 더 자주" → 8초 첫 등장, 8~12초 간격. 설명보다 직접 해보기 → 튜토리얼 없이 첫 3개 똥이 머리 위로 천천히 떨어져 자연스럽게 피해 보게 한다.

## 핵심 루프
시작 탭 → 캐릭터(콩이)를 좌우로 움직여 떨어지는 똥 사이 틈으로 피함 → 사이사이 떨어지는 **별사탕**을 주워 점수 보너스(연속으로 주우면 조금씩 더) → 자주 내려오는 우산을 잡으면 3초 무적 → 시간이 갈수록 똥이 더 많이·더 빨리, 큰 똥·흔들 똥이 섞임 → 한 번이라도 맞으면 끝 → 점수(버틴 시간 + 별사탕)와 최고 점수 확인 → 한 번 탭으로 즉시 다시.

## 규칙

### 필드·좌표 (변경 없음)
- **논리 필드 600 × 800 u (가로:세로 = 3:4) 고정.** 모든 수치는 이 단위(u)로 적는다. 화면에는 비율을 유지해 최대한 크게 맞춰 넣는다(남는 공간은 배경 장식, art-ui.md).
  - 이유: iPad 세로(3:4)에선 꽉 차고, 가로(4:3)에선 가운데 세로형 필드 + 양옆 장식. 어느 방향이든 **같은 필드 = 같은 난이도·같은 기록**.
  - 양옆 빈 공간도 **터치 입력 영역**에 포함(아래 조작).
- 좌표: x = 0(왼쪽)~600, y = 0(위)~800. 바닥선 **y = 760**(아래 40 u는 땅).
- 똥·별사탕·우산은 필드 위 바깥(y = −40)에서 생겨 아래로 떨어진다. 똥은 바닥(y = 760)에 닿으면 철퍽 연출 0.4초 후 사라짐(닿은 뒤 판정 없음).

|---|---|---|---|---|---|
| 기본 똥 | 40 × 40 u | 원, 반지름 **13** | 단계 속도 × (0.92~1.08 무작위) | 처음부터 | 나머지 |
| 왕똥 (큰 똥) | 72 × 72 u | 원, 반지름 **24** | 단계 속도 × **0.80** | **18초**부터 (v1 12초) | 18~40초 10% → 40초 이후 14% |
| 흔들 똥 | 40 × 40 u | 원, 반지름 13 (흔들린 현재 위치 기준) | 단계 속도 × **0.90** | **28초**부터 (v1 20초) | 28~50초 10% → 50초 이후 15% |

- 변형 등장 시점 조정 이유: v1에서는 12초·20초가 "중반 시작"이었지만 v2는 0~15초가 손 풀기 구간이므로, 왕똥은 상승 구간 한가운데(18초), 흔들 똥은 "본게임" 진입 직전(28초)에 맞춰 각각 새 위협으로 느껴지게 한다. 15초 이전에는 변형 없음.
- 흔들 똥: x = 기준 x + **45 × sin(2π·t / 1.1초 + 무작위 위상)**. 기준 x는 45 ~ 555 범위.
- 왕똥: 화면에 동시 최대 **2개**. 흔들 똥: 동시 최대 **3개**. 넘으면 기본 똥으로 바꿈.
- 판정: 원(똥) vs 사각형(캐릭터 판정 상자) 겹침. 매 프레임 + **하위 스텝**(한 프레임 이동이 12 u를 넘으면 나눠서 검사).

- 곡선 모양: 0~15초 완만(간격 1.0 → 0.45), 15~30초 급경사(0.45 → 0.20, 초당 등장 2배 이상), 30~60초 v1 곡선보다 약 10초 늦게 따라가다 **60초 이후 v1을 따라잡고, 75초부터는 v1보다 어렵다**. → "처음 쉽게, 후반은 확실히 어렵게".
- 구현 메모: `SCHED` 표를 위 값으로 교체, 90초 이후 공식 `interval = max(0.07, 0.09 − 0.0004·(t−90))`, `speed = min(920, 800 + 2·(t−90))`, maxOnScreen 22, aimRatio 0.40.
- 일반 등장은 **1.0초**부터 시작(v1 0.5초). 등장 간격은 매번 ±15% 흔들기.
- **동시 최대** = 화면 위에 떠 있는(바닥에 안 닿은) 똥 수. 꽉 차면 0.05초마다 다시 시도.
- **조준 똥**: 비율만큼은 x를 "지금 캐릭터 중심 x ± 30 u 안"에서 뽑는다. 나머지는 x = 20 ~ 580 균등 무작위.
- **처음 3개 (해보며 배우기)**: 대본 똥 3개가 **0.6 / 1.6 / 2.6초**(v1 0.5/1.1/1.7)에 캐릭터 머리 위로 정확히(± 0) 떨어진다. 기본 똥만, **290~320 u/s**(약 2.6초 걸려 내려옴). 사이사이 일반 똥은 무작위 위치(조준 0%).
- 5초 시점 화면 위 똥 수 목표: **평균 2~3.5개**(v1은 5개 이상).
- 체감 계단 "더 쏟아진다!" 문구: **15 / 30 / 45 / 60 / 75 / 90초** (v1 10/20/30/45/60). 규칙엔 영향 없음. BGM 템포 단계도 이 시점에 맞춘다(sound.md).

### 공정성 보장 (피할 수 없는 배치 금지) — 규칙 유지 + 별사탕 예약 추가
똥을 하나 만들 때마다 아래 검사를 통과해야 등장시킨다. (1~5는 v1과 동일)

1. **도착 버킷**: 각 똥이 캐릭터 판정 높이(y = 716 ~ 756)를 지나는 시각 구간을 계산해, 그 시각이 속한 **0.25초 단위 버킷**(1개 또는 2개)에 등록한다. (흔들 똥은 흔들리는 범위 전체를 막힌 것으로 본다.)
2. **막힘 지도**: 버킷마다 캐릭터 중심 위치 17 ~ 583을 **10 u 칸 57개**로 나눈 막힘 표시. 똥 하나는 중심 x에서 ± (반지름 + 17 + 4 여유) 범위를 막는다.
3. **틈 조건**: 새 똥을 더한 뒤, 영향받는 각 버킷에
   - (a) 연속으로 비어 있는 칸이 **6칸(60 u) 이상**인 틈이 하나 이상,
   - (b) 그 틈 중 하나가 **바로 앞 버킷의 틈과 26칸 이내**로 이어짐,
   - (c) 막힌 칸 비율 ≤ **75%**.
4. 못 맞추면 x를 다시 뽑기(조준이면 조준 포기) **최대 6번**. 그래도 안 되면 그 등장을 **0.05초 미룬다**.
5. 무적 우산이 있어도 공정성 검사는 똑같이 한다.
6. **(v2 신규) 별사탕 예약 칸**: 별사탕이 생기면, 그 별사탕이 캐릭터 판정 높이를 지나는 버킷(1~2개)에 **"예약 칸"** = 별사탕 기준 x ± 30 u(6칸, 흔들림 중심 기준)를 등록한다.
   - 이후 생기는 똥은 예약 칸을 **6칸 중 3칸 이상 막을 수 없다**(겹치면 다시 뽑기 → 4번 규칙대로).
   - 예약 칸이 있는 버킷에서는 (b) 이어짐 검사를 "예약 칸 기준"으로도 한 번 더 한다: **예약 칸 ↔ 앞 버킷의 틈**, **예약 칸 ↔ 다음 버킷의 틈**이 각각 26칸 이내로 이어져야 한다. → "받으러 들어갈 길"과 "먹고 빠져나올 길"이 항상 있다.
   - 별사탕을 먹거나 바닥에 닿으면 예약을 지운다.
   - 결과: 별사탕 바로 옆에 똥이 떨어질 수는 있지만(위험), 별사탕 자리 자체가 막히거나 들어가면 빠져나올 수 없는 배치는 나오지 않는다.
- QA 확인 방법: 아래 "완벽 봇"(별사탕 무시)이 120초까지 죽지 않아야 하고, "완벽 봇(별사탕 전부 시도)"이 별사탕을 대부분 먹으면서도 살아야 한다.

### 점수 아이템 — 별사탕 (v2 신규)
- 이름·형태: CEO 제안 **"별사탕" 유지.** 뾰족한 작은 별 모양 사탕(파스텔 노랑·분홍 번갈아). 이유: 똥(갈색·둥근 소용돌이)과 색·실루엣이 정반대라 쏟아지는 비 속에서 한눈에 구분되고, "더러운 비 속의 반짝이는 간식"이라는 대비가 귀엽다. 특정 상용 게임 고유 아이템 아님.

| 항목 | 값 |
|---|---|
| 첫 등장 | **4.0초** |
| 이후 간격 | 직전 별사탕 **생성** 시각부터 **3.5 ~ 5.0초** 무작위 (먹었는지와 무관) |
| 동시 최대 | 화면에 **2개** (넘으면 0.3초 미룸) |
| 보이는 크기 | 34 × 34 u |
| **획득 판정** | 원, 반지름 **30** vs 캐릭터 판정 상자 (똥 13보다 훨씬 넉넉 — 중심 가로 거리 47 u 이내면 먹음) |
| 낙하 속도 | **240 u/s** + 2 × t (최대 **360 u/s**, 60초에 도달). 똥보다 느려서 비 사이로 천천히 내려옴 |
| 흔들림 | 좌우 ±15 u, 주기 1.4초 (sin, 무작위 위상) |
| 등장 x | 기준 x 40 ~ 560. 아래 "배치" 규칙 |
| 바닥 | 바닥에 닿으면 0.3초 반짝 사라짐. 놓친 것으로 처리(연속 끊김) |
| 무적 중 | 먹을 수 있음(무적은 별사탕 사냥 기회) |
| 똥과의 관계 | 서로 판정 없음(똥이 별사탕을 가리거나 밀지 않음) |

- **배치 (위험과 보상)**:
  - **"용기 별사탕" 40%**: 지금 화면의 똥 중 별사탕 도착 버킷과 같은(또는 이웃) 버킷에 도착하는 똥을 하나 골라, 그 똥 중심에서 **55 ~ 90 u** 옆(좌/우 무작위, 필드 안)에 놓는다. 그런 똥이 없으면 일반 배치.
  - **일반 별사탕 60%**: 기준 x 40 ~ 560 균등 무작위, 단 캐릭터 현재 x에서 **120 u 이상** 떨어진 곳(가만히 서서 공짜로 먹지 않게 — 움직여야 먹음).
  - 등장 시 검사: 별사탕 도착 버킷의 **현재** 막힘 지도에서 예약 칸(6칸)이 2칸 이하로만 막혀 있고, 예약 칸 ↔ 앞·뒤 버킷 틈이 26칸 이내로 이어져야 한다. 못 맞추면 x 다시 뽑기 최대 6번 → 실패 시 0.3초 미룸.
  - 15초 이전에는 "용기 별사탕" 비율 **20%**(손 풀기 구간에서는 덜 위험하게), 15초부터 40%.
- **우산과 겹치지 않게**:
  - 우산이 생긴 시각 ±**1.0초** 안에는 별사탕을 만들지 않는다(그 시점으로 미룸).
  - 우산과 별사탕이 동시에 화면에 있으면 기준 x가 서로 **150 u 이상** 떨어지게 뽑는다(같은 규칙을 우산 쪽에도 적용).

### 점수 (v2 변경)
- **점수 = 시간 점수 + 별사탕 점수** (정수).
  - **시간 점수 = floor(버틴 시간 × 10)** → 초당 10점. 예: 27.38초 → 273점.
  - **별사탕 점수**: 1개 **50점**. **연속 보너스**: 별사탕을 놓치지 않고 연달아 먹으면 2번째부터 +10씩 (50, 60, 70, 80, 90, **최대 100점**). 별사탕 하나라도 바닥에 닿으면(놓치면) 연속이 끊겨 다음은 50점부터.
  - 이유: 초당 10점이면 숫자가 계속 올라가 "버티는 것"이 기본 점수, 별사탕 하나(50점) = 5초 버틴 값이라 "위험을 감수할 만한" 크기. 연속 보너스는 최대 2배로 상한을 둬 별사탕만 노리는 플레이가 버티기를 압도하지 않게 한다.
  - 예상 비중(보통 봇 40초, 별사탕 약 9개 등장 중 5개 획득): 시간 400 + 별사탕 약 300 → 별사탕이 약 40%. 버티기가 여전히 주, 별사탕이 순위를 가르는 정도.
- HUD: **점수(크게)** + 버틴 시간(작게, NN.N초). 별사탕을 먹으면 그 자리에 "+50" / "+70" 같은 떠오르는 숫자(art-ui.md).
- **아슬아슬 회피**: v1과 동일(가로 간격 **12 u 이하** 스침 → "아슬!" 표시 + 효과음 + 횟수 +1). **점수에는 더하지 않는다**(결과 화면에 "아슬 N번"만).
- **최고 기록 (저장 키 호환)**:
  - 새 키 **`poop-rain-best-score`** (정수 점수) — 최고 기록의 기준. "새 기록!"은 점수로 판단.
  - 기존 키 **`poop-rain-best`** (초, 소수 1자리)는 **지우지 않고 "최장 버틴 시간" 기록으로 계속 사용**(더 오래 버티면 갱신).
  - **이전(마이그레이션)**: 로드 시 `poop-rain-best-score`가 없고 `poop-rain-best`에 유효한 값 s(>0)가 있으면, 최고 점수 초기값 = **floor(s × 10)** (그 시간의 시간 점수, 별사탕 기록은 알 수 없으므로 0으로 봄)으로 정하고 새 키에 저장한다. 한 번만 수행.
  - 둘 다 접근 실패 시 0으로 보고 정상 진행. simulate·setInvincible을 쓴 판은 저장하지 않음(v1과 동일).

## 난이도 목표와 검증 (QA 시뮬레이션 기준, v2)

### 반응 시간 봇 모델 — **모델 D를 공식 기준으로 고정**
- 봇은 **R초 전의 화면**을 보되, 각 물체 위치를 **"보인 위치 + 속도 × R × 0.75"**로 보정해 현재 위치를 추정한다(움직임 75% 보정, v1 QA의 모델 D). 0.05초마다 다시 결정.
- 결정: 후보 위치(10 u 간격)마다 보이는 똥들의 앞으로 1.0초 경로와 "520 u/s로 그 위치까지 가는 경로"가 겹치는지 검사 → 안전한 후보 중 가장 가까운 곳. 없으면 위험이 가장 늦게 오는 곳.
- 목표 x에 가우시안 σ 떨림, 키보드 방식(520 u/s, 가속 0.06초)으로 이동.
- 우선순위: **① 회피 > ② 우산(2초 안에 닿고 경로 안전) > ③ 별사탕(1.5초 안에 닿고 경로 안전하면 가장 빨리 닿는 별사탕)**.
- 모델 A(보정 없음)·B(100% 보정)는 참고용 하한·상한으로만 보고한다.

| 봇 | R (반응 시간) | σ (손 떨림) |
|---|---|---|
| 초보 | 0.42초 | 14 u |
| 보통 | 0.32초 | 10 u |
| 숙련 | 0.24초 | 6 u |

### 목표 (봇별 시드 0~99, 100판)
| 항목 | 초보 | 보통 | 숙련 |
|---|---|---|---|
| 생존 시간 **중앙값** | **25 ~ 35초** | **35 ~ 48초** | **50 ~ 80초** |
| 처음 15초 안에 죽는 판 비율 | **< 10%** | < 5% | < 2% |
| 별사탕 획득률 (먹은 수 ÷ 죽기 전까지 생긴 수) | ≥ 35% | ≥ 45% | ≥ 55% |
| 판당 별사탕 획득 수 중앙값 (참고) | 약 3~5개 | 약 5~7개 | 약 8개 이상 |
| 점수 중앙값 (참고) | 약 400~550 | 약 600~800 | 약 900 이상 |
- 숙련 상한 80초: "후반은 확실히 어렵게" — 숙련 봇도 75~90초 구간에서 대부분 끝나야 한다.
- 숙련 ÷ 초보 중앙값 비율 ≥ **1.6** (v1은 1.5 — 실력 차가 드러나야 함).

### 공정성·긴장감 기준
- **완벽 봇 (별사탕 무시)**: 100판 중 **98판 이상 120초 생존** (v1과 동일). 120초 이전 죽음은 버킷 지도 확인 후 위반 여부 보고.
- **완벽 봇 (별사탕 전부 시도)**: 100판 중 **95판 이상 120초 생존**, 생긴 별사탕의 **90% 이상** 획득. (예약 칸 규칙이 "받으러 가다 죽을 수밖에 없는 배치"를 막는지 확인.)
- **위험이 실제로 있는지**: 보통 봇의 "별사탕 시도" vs "별사탕 무시" 생존 중앙값 차이가 **3% 이상 25% 이하**(0이면 위험 없음 = 지루, 25% 넘으면 함정).
- 5초 시점 화면 위 똥 수 평균 **2 ~ 3.5개**.
- 30초 시점 화면 위 똥 수 평균 **7개 이상**(본게임 긴장감 확인).
- 무적 시간 비율(보통 봇, 무적 중인 시간 ÷ 생존 시간) **≤ 22%**.

### 벗어날 때 조정 순서 (그 외 수치는 건드리지 말고 CEO에게 보고)
- 초보만 벗어남(쉬운 구간 문제): **0~15초 행**의 등장 간격 ×0.9 / ×1.1.
- 보통·숙련이 벗어남(본게임 문제): ① **20초 이후 행**의 등장 간격 ×0.9(어렵게) 또는 ×1.1(쉽게) → ② 같은 행 낙하 속도 ±5% → ③ 조준 비율 ±5%p.
- 숙련이 80초 초과: 75·90초 행과 90초 이후 공식을 ① → ② 순서로 어렵게.
- 별사탕 획득률 미달: 획득 반지름 30 → 34 → 그래도 미달이면 낙하 속도 상한 360 → 320. 위험 차이 3% 미만: 용기 별사탕 비율 40% → 55%. 25% 초과: 40% → 25%.

## 테스트 훅 (QA 전용, 화면 노출 없음) — v2 추가·변경 표시
`window.__poop`:
- `start()` — 시작 화면 없이 즉시 새 판.
- `state()` → 복사본:
  ```
  { phase, time,
    score,          // (v2 변경) 총점 정수 = timeScore + starScore. v1의 '시간 점수'가 아님
    timeScore,      // (v2) floor(time × 10)
    starScore,      // (v2) 별사탕으로 얻은 합계
    best,           // (v2 변경) 최고 점수(정수)
    bestTime,       // (v2) 최장 버틴 시간(초)
    nearMiss,
    starStats: { spawned, caught, missed, chain },   // (v2) chain = 현재 연속 수
    player:{x, vx, invincible},
    poops:[{id, type, x, y, r, vy, baseX, age, phase, amp, period, landY}],
    stars:[{id, x, y, r(=30), vy, baseX, age, phase, amp(=15), period(=1.4), brave(bool, 용기 배치 여부)}],  // (v2)
    items:[{type:'umbrella', x, y, baseX, age, phase, r, vy}],
    spawn:{interval, speed, maxOnScreen, aimRatio},
    nextStarAt, nextUmbrellaAt }   // (v2) 다음 예정 시각(초, 없으면 null)
  ```
- `setTime(sec)` — 경과 시간 설정. (v2) 별사탕·우산 다음 예정 시각이 sec보다 이르면 sec로 당김. timeScore는 새 time 기준으로 다시 계산.
- `spawn(type, x, opts)` — 똥 즉시 생성, 공정성 무시. `spawnItem(x)` — 우산 생성.
- **`spawnStar(x, opts)`** (v2) — 별사탕을 기준 x에 즉시 생성, 공정성·우산 분리 검사 무시. `opts = {y, speed, phase, reserve(bool, 기본 true — 예약 칸 등록 여부)}`. 생성된 id 반환.
- **`setStars(on)`** (v2) — 별사탕 자동 생성 켜기/끄기(기본 켬). 끄면 예약 칸도 생기지 않음 → "별사탕 무시/없음" 공정성 비교용.
- `seed(n)` — 똥·별사탕·우산·흔들림 무작위 시드 고정(다음 `start()`부터). 별사탕은 똥과 **같은 난수열**을 쓰지 않고 별도 난수열(seed+1)을 쓴다 → `setStars(false)`여도 같은 시드의 똥 배치가 크게 달라지지 않게(예약 칸 영향 제외).
- `setPlayerX(x)`, `setInvincible(on)` — v1과 동일.
- `simulate(sec, bot)` — 1/60초 고정 스텝. 죽으면 `{dead:true, time, score, starsCaught}` 반환(v2: score·starsCaught 추가), 살아 있으면 `{dead:false, time, score, starsCaught}`.
- `fairness()` → `[{t0, blocked:bool[57], reserved:bool[57]}]` (v2: 예약 칸 추가).
- `clear()` — 화면의 똥·우산·**별사탕** 모두 제거(예약 칸도 제거).

## 콘텐츠
- 모드 1개(무한 생존), 낙하물 3종(기본·왕똥·흔들 똥), 아이템 2종(무적 우산, **별사탕**). 오리지널 캐릭터·배경(art-ui.md).
