# 똥비 피하기 (poop-rain) — 사운드 명세

## 변경 이력
- **v2 (2026-11-14)**: design.md v2 반영. 별사탕 획득음 `star`(연속 6단 사다리) 추가, 별사탕 놓침 `starMiss`(선택, 아주 작게) 추가, 우산이 자주 나와 `shieldOn`을 약 25% 작고 짧게(0.55→0.42초) 조정, `shieldWarn` 시점을 남은 **1.5 / 0.8초**로 갱신(`{ n: 1|2 }`), BGM 템포를 6단계(15/30/45/60/75/90초)에 맞춰 단계당 +0.065(상한 1.4)로 갱신. 기존 소리는 그대로.

모든 소리는 Web Audio API로 실시간 합성한다. 음원 파일은 쓰지 않는다. 코드는 `docs/games/poop-rain/sound-module.js`에 있다. Developer가 게임 HTML 안의 독립된 `<script>` 블록에 그대로 붙여 넣는다.
API는 기존 게임과 같다: `Sound = { unlock(), play(name, opts), setMuted(bool), isMuted(), startMusic(opts), stopMusic() }`. 여기에 **`setTempo(배율)`, `getTempo()`**를 추가했다.

**톤**: 경쾌하고 코믹하지만 지저분하지 않게. 똥 소리는 '철퍽'이 아니라 말랑한 **'퐁/뽁'**(sine 스윕 + 아주 짧은 lowpass 노이즈)으로 만든다. 질척한 노이즈나 방귀 같은 소리는 쓰지 않는다. 효과음과 BGM은 모두 **C 메이저**(장식음은 C 메이저 펜타토닉)에 맞췄다.
- 자주 나는 소리(`plop`)는 아주 작고 짧게, 간격을 제한한다.
- 피격·게임 오버는 비브라토 슬라이드('뽀잉~', '뿌우~')로 코믹하게 처리한다. 경고음이나 불협화음은 쓰지 않는다.

## 0. 공통 규칙

- **위치 패닝 `opts.x`** (선택): 0 = 화면 왼쪽, 1 = 오른쪽. 패닝 폭은 ±0.5다. 값이 없거나 0~1 밖이면 가운데에서 난다. `plop`, `bigLand`, `dodge`, `hit`에 쓰면 좋다(똥/플레이어의 x ÷ 화면 너비). `StereoPannerNode`가 없으면 가운데에서 난다. iPad 내장 스피커는 가로 방향일 때만 스테레오가 분명하게 들린다.
- **스로틀**: 같은 소리가 최소 간격 안에 다시 호출되면 무시한다. `gameOver`는 0.8초에 한 번만 난다.
- 엔벨로프는 0.0001에서 지수 어택으로 올라가고 0.0001까지 지수 감쇠한다(클릭 방지). 피크 값은 효과음 버스 기준이고, 여기에 마스터 0.5가 곱해진다.
- 실패 처리: AudioContext가 없거나, 생성이 실패했거나, 잠겨 있거나(running이 아님), 음소거 중이거나, 모르는 이름·문자열이 아닌 이름이 들어오면 아무 소리 없이 넘어간다. 예외는 밖으로 나가지 않는다.

| `tap` | (선택) UI 버튼 | – | sine 900→700Hz 50ms(0.08) | 60ms | 0.05s |

### `dodge` 사다리 (연속 회피마다 한 칸 위)

| combo | 1 | 2 | 3 | 4 이상 |
|---|---|---|---|---|
| 음 | C6 | D6 | E6 | G6 (고정) |

`combo`가 없거나 숫자가 아니면 1단(C6)으로 낸다. 연속 회피 개념이 없으면 그냥 `Sound.play('dodge')`.

### `star` 사다리 (v2, 별사탕 연속 획득 — design.md 점수 50→100과 같은 6단)

| chain | 1 (50점) | 2 (60) | 3 (70) | 4 (80) | 5 (90) | 6 이상 (100) |
|---|---|---|---|---|---|---|
| f '또' | C5 | D5 | E5 | G5 | A5 | C6 |
| f×2 '링' | C6 | D6 | E6 | G6 | A6 | C7 + '찡' |

- `chain` = 이번 별사탕이 연속 몇 번째인지(놓친 뒤 첫 별사탕 = 1). 없거나 숫자가 아니면 1, 7 이상은 6단 고정.
- **`dodge`와 구분**: `dodge`는 노이즈 '휙' + sine 단음, `star`는 노이즈 없는 triangle 2음 옥타브 도약 '또-링'(벨 느낌). 둘이 같은 프레임에 나도 겹쳐 들린다(스로틀이 따로).
- `item`(4음 아르페지오 '뾰로롱')과도 길이·음 수가 달라 구분된다.

### 판단 메모
- **`plop`(보통 똥 착지) — 넣되 아주 작게, 호출은 Developer가 줄일 수 있음.** 모듈에서 120ms 스로틀 + 피크 0.05로 막아 두었다. 후반에 똥이 많아져도 초당 약 8번이 상한이고, 그때도 BGM 아래에 깔리는 '톡톡' 정도다. 시끄러우면 다음 중 하나를 고른다(권장 순서):
  1. **플레이어 근처(예: 가로 거리 화면 너비의 30% 안)에 떨어진 똥만** 호출 — 공간감이 생기고 수도 줄어든다.
  2. 아예 호출하지 않는다. 다른 소리에 영향 없다.
- **큰 똥 `bigLand`**: 화면에 동시에 많지 않다는 전제로 전부 호출한다. 큰 똥이 땅에 닿을 때는 `plop` 대신 `bigLand`만 부른다.
- **`hit`과 `gameOver`**: 목숨제라면 피격마다 `hit`. 마지막 피격이면 `hit` → 약 0.6초 뒤 `gameOver`(둘은 겹치지 않게). 한 방 게임 오버라도 같은 순서.
- **`record`**: 신기록이면 `gameOver` 대신 `record`를 써도 되고, `gameOver` 약 1.3초 뒤 `record`를 이어 불러도 된다. 권장은 **`gameOver` → 1.3초 뒤 `record`**(결과 화면이 뜨는 시점).
- **`starMiss` — 생략 가능.** 별사탕은 3.5~5초마다 생겨 자주 놓치므로, 매번 울리면 잔소리처럼 들린다. 그래서 **연속이 끊길 때(놓친 시점의 chain ≥ 2)만** 부르고, 피크 0.035로 BGM 아래에 깔리게 했다. 거슬리면 호출하지 않으면 된다(다른 소리에 영향 없음).
- **`shieldOn` (v2)**: 우산이 8초 첫 등장, 이후 8~12초 간격으로 자주 나와 피크와 길이를 약 25% 줄였다. 무적 시간(3.0초, CEO 결정)과 무관하게 소리는 시작 순간 한 번뿐이다.
- **`item`과 `shieldOn`**: 우산 아이템은 획득 즉시 무적이면 `shieldOn`만 불러도 충분하다. 즉시 효과가 아닌 아이템(점수 보너스 등)은 `item`.
- **무적 중 똥이 우산에 맞을 때**: 따로 소리를 두지 않았다. 필요하면 `plop`(x 지정)을 재사용한다.
- **`levelUp`**: 아주 작게 만들었다. 단계가 오를 때 한 번. 동시에 `Sound.setTempo()`로 BGM을 한 칸 빠르게 하면 자연스럽다.

## 2. 배경음악 (낮은 볼륨)

- 기본은 켜짐, 볼륨은 낮다(음악 버스 0.05 × 마스터 0.5). **플레이 중에만** 재생하고 일시정지·게임 오버 때 멈춘다. 음악만 끄는 토글은 없다. 음소거 버튼 하나로 효과음과 음악을 함께 끈다.
- 오리지널 루프. C 메이저, **기본 120 BPM**, 8분음표 32스텝(4마디, 1.0배에서 8초)으로 반복한다.
- **멜로디**(통통 튀는 플럭): triangle(0.38, 길이 0.9스텝) + 옥타브 위 sine(0.06, 짧게)
  - 1마디: C5 · E5 G5 · E5 C5 · / 2마디: D5 · F5 A5 G5 · · · / 3마디: E5 G5 C6 · A5 G5 E5 · / 4마디: D5 E5 D5 B4 C5 · · ·
- **움-빠 베이스**: triangle. 박마다 근음(0.45, 스타카토), 그 사이 반박에 위 음(0.22). 마디 순서 C(C3/G3) → Dm(D3/A3) → Am(A2/E3) → G(G2/D3).
- **하이햇**: 뒷박마다 highpass 7kHz 노이즈 35ms(0.06).
- **코믹 '뽁'**: 1~3마디 마지막 스텝에 sine 300→600Hz 70ms(0.2). 4마디 끝은 비워서 루프 이음새를 숨긴다.
- **템포 가속**: `Sound.setTempo(배율)`. **1.0~1.4로 제한**(그 밖의 값은 잘림, 숫자가 아니거나 0 이하는 무시). 다음 스텝부터 바로 적용되며 음이 끊기지 않는다. 권장(v2): 단계 6개(**15/30/45/60/75/90초**)마다 **+0.065** → 1.065, 1.13, 1.195, 1.26, 1.325, **1.39**(최종 약 167 BPM). 상한 1.4는 모듈이 잘라 준다. 그 이상은 경쾌함보다 조급함이 커진다.
  - `Sound.startMusic()`은 템포를 **1.0으로 되돌린다**. 일시정지 후 재개처럼 현재 템포를 유지하려면 `Sound.startMusic({ tempo: Sound.getTempo() })`.
- 스케줄러: `setTimeout` 100ms 주기로 250ms 앞까지 미리 예약한다.

## 3. 오디오 시스템

- **잠금 해제 (iPad Safari)**: AudioContext는 **사용자 제스처 안에서 처음 만들거나 `resume()`해야 한다**. 시작/다시하기 버튼의 `click`/`pointerup`/`touchend` 핸들러 **안에서 동기로** `Sound.unlock()`을 부른다. 여러 번 불러도 안전하다. unlock은 무음 1샘플 버퍼를 재생해 iOS 출력 경로를 깨운다. unlock 전의 `play()`·`startMusic()`은 소리 없이 무시된다(테스트로 확인).
- **음소거**: `Sound.setMuted(bool)`, `Sound.isMuted()`. localStorage 키 **`poop-rain-muted`**(`'1'`/`'0'`), 읽기·쓰기 모두 try/catch. 저장이 막힌 환경에서는 기본값(소리 켜짐)으로 동작한다. 마스터 게인을 20ms에 걸쳐 부드럽게 바꾼다.
- **탭 전환·홈 화면 이동**: `visibilitychange`에서 숨겨지면 `ctx.suspend()`, 돌아오면 `ctx.resume()` + 음악 예약 시각 재조정. 게임 자체의 일시정지는 Developer 몫이다.
- **iPad 무음 스위치/무음 모드**: iOS에서 측면 무음 스위치나 제어 센터 무음 모드가 켜져 있으면 **Web Audio 소리가 나지 않을 수 있다**. 기기 설정이라 코드로 우회하지 않는다. 필요하면 "소리가 안 나면 무음 모드를 확인하세요" 안내 문구(Art/Developer 판단).
- 볼륨 조절 UI는 두지 않는다. 기기 볼륨을 따른다.

## 4. Developer 연결 지점

| 시점 | 호출 |
|---|---|
| 시작/다시하기 버튼 핸들러 안 (제스처 안, 동기) | `Sound.unlock()` |
| 플레이 시작 | `Sound.play('start'); Sound.startMusic();` |
| 보통 똥이 땅에 닿음 (판단 메모 참고: 플레이어 근처만 권장) | `Sound.play('plop', { x: poop.x / W })` |
| 큰 똥이 땅에 닿음 | `Sound.play('bigLand', { x: poop.x / W })` |
| 아슬아슬 회피 보너스 | `Sound.play('dodge', { combo, x: player.x / W })` |
| 별사탕 획득 (v2) | `Sound.play('star', { chain, x: star.x / W })` — `chain` = 연속 획득 수(1~, 점수 50/60/…/100과 같은 단계) |
| 별사탕이 바닥에 닿음 (v2, 선택) | 끊기기 전 chain ≥ 2일 때만 `Sound.play('starMiss')` 그 뒤 chain = 0 |
| 아이템 획득 (즉시 효과 아닌 것) | `Sound.play('item')` |
| 무적 시작 | `Sound.play('shieldOn')` |
| 무적 남은 시간 1.5초 / 0.8초 (v2) | `Sound.play('shieldWarn', { n: 1 })` / `Sound.play('shieldWarn', { n: 2 })` — 각각 한 번 |
| 무적 끝 | `Sound.play('shieldOff')` |
| 피격 | `Sound.play('hit', { x: player.x / W })` |
| 게임 오버 (마지막 피격) | `Sound.play('hit', …); Sound.stopMusic();` → 약 0.6초 뒤 `Sound.play('gameOver')` |
| 신기록 (결과 화면, gameOver 약 1.3초 뒤) | `Sound.play('record')` |
| 난이도 단계 상승 (v2: 15/30/45/60/75/90초, `stage` = 지난 단계 수 1~6) | `Sound.play('levelUp'); Sound.setTempo(Math.min(1.4, 1 + stage * 0.065));` |
| 일시정지 / 재개 | `Sound.stopMusic()` / `Sound.startMusic({ tempo: Sound.getTempo() })` |
| 음소거 버튼 | `Sound.setMuted(!Sound.isMuted())`. 아이콘 초기 상태는 `Sound.isMuted()` |
| UI 버튼 (선택) | `Sound.play('tap')` |

`W` = 게임 영역 너비(x를 0~1로 정규화). x를 안 넘겨도 된다.

## 5. 청취 확인 필요 (헤드리스 테스트로는 들을 수 없음)

- `plop`이 귀엽게 들리는지, 후반에 많이 떨어질 때 거슬리지 않는지 (거슬리면 플레이어 근처만 호출 / 생략)
- `bigLand`가 보통 똥과 무게 차이로 구분되는지, iPad 내장 스피커에서 저역(45~120Hz)이 너무 약하지 않은지
- `hit`·`gameOver`가 불쾌하지 않고 코믹하게 들리는지
- `dodge` '휙'이 회피 순간과 잘 맞는지
- (v2) `star` '또-링'이 맑고 귀엽게 들리는지, 연속 6단이 오르는 느낌이 나는지, 6단(C7, 약 2.1kHz)이 iPad 스피커에서 날카롭지 않은지, `dodge`와 확실히 구분되는지
- (v2) `starMiss`가 너무 작아 안 들리거나, 반대로 거슬리지 않는지 (거슬리면 생략)
- (v2) 우산이 자주 나올 때 `shieldOn`이 피곤하지 않은지, 줄인 뒤에도 무적 시작이 분명히 느껴지는지
- (v2) `shieldWarn` 두 번(1.5/0.8초)이 깜빡임(0.8초)과 잘 맞는지
- BGM 볼륨이 효과음보다 충분히 낮은지, 루프 이음새, 템포 1.3~1.39배(75~90초 이후)에서 너무 조급하지 않은지
- 좌우 패닝(x)이 iPad 가로/이어폰에서 느껴지는지
- iPad Safari에서 첫 터치 후 소리가 나는지, 탭 전환 후 복귀, 무음 스위치가 켜졌을 때의 동작
