# 박자 앵무새 아트·UI 명세

> slug: `parrot-beat` · `design.md`(박 나누기 수, 템포 BPM, 판정 창 ms, 하트 수, 단계 규칙, 패턴 목록)와 `sound.md`를 함께 본다. **수치는 design.md가 정하고**, 이 문서는 그것을 어떻게 보여 줄지만 정한다. 아래의 `8칸(8분음표)`, `하트 3`, `단계 3`, 점수 숫자는 자리 표시용이며, 레이아웃은 한 마디 **8칸 또는 16칸** 어느 쪽이어도 동작해야 한다.
> 그래픽: **두 캐릭터 = 인라인 SVG(DOM)**, **박자 타임라인 2줄 = Canvas 2D**(정확한 시간 위치에 그리기 위해), **HUD·오버레이 = DOM**. 이미지 파일 없음, 게임 화면에 이모지 그래픽 없음.
> 오리지널 원칙: 새 두 마리는 이 문서의 도형 좌표로 직접 그린 것. 리듬 천국 등 기존 리듬게임의 캐릭터·연출(무대·관객·특정 포즈·판정 문구·색 조합)을 따라 하지 않는다.

## 스타일 콘셉트
- **"조용한 오후의 새 음악 교실"**: 따뜻한 종이색 배경 위에 **선생님 새(위)**가 작은 북으로 한 마디를 들려주고, **내 앵무새(아래)**가 같은 북으로 따라 친다. 두 새 사이에 박자 줄(타임라인) 두 줄이 나란히 있어, 위 줄(선생님)과 아래 줄(나)을 **눈으로 비교**하며 배운다.
- **글 없이 배우기**: 정박/엇박/쉼은 **모양 + 크기 + 색 + 높이** 네 가지로 구분하고, 지금 누구 차례인지는 **불 켜진 새 + 테두리 색 + 움직이는 진행 커서**로 보인다. 글자는 시작 화면 범례 세 단어("정박/엇박/쉼")와 판정 짧은 단어뿐.
- **눈 피로 최소화 (사용자 누적 취향)**: 채도 낮은 색, 그라데이션·광택·화면 흔들림·전체 화면 번쩍임 없음. 움직임은 짧고 작게(최대 이동 10px, 최대 확대 1.15). 박마다 반복되는 움직임은 캐릭터 북·박 점에만 한정.
- **캐릭터는 단순·귀엽게, 얼굴은 눈 2개 + 부리 1개만.** 눈썹·입·속눈썹·광택 무늬 없음. 볼터치는 앵무새만 작게 하나씩.
- 스튜디오 공통: `--bg` 종이색, 흰 패널, 주황 `--accent` 주 버튼, 둥근 모서리, 그림자 대신 면 색 차이. 상단 바·버튼·오버레이 구조는 붕어빵 눈싸움·똥비 피하기와 같은 CSS(`.top`, `.home`, `button.icon`, `button.primary`, `.overlay`, `body.ov-full`)를 그대로 복사해 쓴다.
- 글꼴: 글자는 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **숫자(점수·콤보·단계·최고 기록·+점수 팝업)는 BeatDigits**.

### 숫자 글꼴 BeatDigits (Pretendard ExtraBold 800 서브셋, SIL OFL 1.1)
- 기존 게임(`games/bunny-ten/fonts/bunny-digits-800.woff2` + `OFL.txt`)과 같은 방식. 원본 Pretendard **ExtraBold(800)**.
- 파일: `games/parrot-beat/fonts/beat-digits-800.woff2` + 같은 폴더 `OFL.txt`(Pretendard 저작권 줄 + OFL 1.1 본문, 기존 게임 것 복사 가능).
- 글리프: `0-9`(U+0030–0039), `+`(U+002B, 점수 팝업 `+100`용). **`tnum` 유지**.
  - 예: `pyftsubset Pretendard-ExtraBold.otf --unicodes="U+0030-0039,U+002B" --flavor=woff2 --layout-features='tnum' --output-file=beat-digits-800.woff2` 후 fontTools로 name 테이블 교체.
- **Reserved Font Name 때문에 이름 변경 필수**: family/full/PostScript/typographic 이름 모두 `BeatDigits`, 압축 해제 바이트에 "Pretendard" 문자열이 없어야 함(QA가 기존 게임과 같은 fontTools 검사). 다른 게임 서브셋은 `+`가 없으므로 재사용 금지. 원본을 못 받으면 CEO에게 보고.
```css
@font-face { font-family: "BeatDigits"; src: url("fonts/beat-digits-800.woff2") format("woff2");
  font-weight: 800; font-style: normal; font-display: swap; unicode-range: U+0030-0039, U+002B; }
:root { --num-font: "BeatDigits", system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif; }
.num { font-family: var(--num-font); font-weight: 800; font-variant-numeric: tabular-nums; }
```

## 레이아웃 (PC / iPad 세로 / iPad 가로 / 폰)

### 구성 요소
```
가로 (innerWidth ≥ innerHeight) — "행" 두 개, 각 행 = [새][타임라인]
[← 게임 목록] 박자 앵무새   [단계 3 ●●○○] [점수 1240] [♥♥♡]  [🔈][Ⅱ]   ← 상단 바 52px
┌──────┐ ┌─────────────── 위 줄: 선생님 타임라인 ───────────────┐
│선생님│ │  ●    ◆    ●         ┊    ●    ◆                    │
│  새  │ │  ·         ·         ·         ·         ← 박 점      │

┌──────┐ ┌─────────────── 아래 줄: 내 타임라인 ─────────────────┐

  콤보 12 (앵무새 아래)

세로 (portrait) — 위아래 대칭, 두 타임라인이 가운데에서 맞닿음

        ( 선생님 새 )          ← 위 캐릭터 블록

```
- 탭 영역은 **화면 전체**(상단 바의 버튼·링크 제외). 타임라인이나 새를 정확히 누를 필요 없음.

### 높이 기준 레이아웃 규칙 (필수)
1. `--app-h` = `window.innerHeight + 'px'`, `resize`·`orientationchange`·`visualViewport.resize` 때 갱신. CSS 기본값 `100dvh`(미지원 `100vh`). `100vh` 단독 금지.
2. `html, body { height: var(--app-h); overflow: hidden; }`, body 패딩 `max(12px, env(safe-area-inset-*))` 네 방향, viewport meta `width=device-width, initial-scale=1, viewport-fit=cover`.
3. `W` = innerWidth − 좌우 패딩, `H` = app-h − 상하 패딩. 상단 바 `TB = 52`(H ≤ 520이면 44), 아래 간격 8. 무대 너비 `SW = min(W, 980)`, 가운데 정렬.
4. **가로**: 행 높이 `R = floor((H − TB − 8 − 8) / 2)`(두 행 사이 8).
   - 새 상자 `A = clamp(64, round(R × 0.78), 220)` (정사각, 행 세로 가운데).
   - 타임라인 높이 `S = clamp(56, round(R × 0.5), 132)`, 너비 `L = SW − A − 16`.
   - 콤보 알약은 앵무새 상자 아래 오른쪽 모서리에 겹쳐 띄움(absolute, 레이아웃 높이 차지 안 함).
5. **세로**: 타임라인 높이 `S = clamp(56, round(W × 0.16), 120)`, 너비 `L = min(W, 760)`.
   - 캐릭터 블록 높이 `B = floor((H − TB − 8 − 2S − 8 − 16) / 2)`(블록–줄 간격 8, 줄–줄 간격 8).
   - 새 크기 `A = clamp(64, min(round(B × 0.75), round(W × 0.5)), 200)`, 블록 안 가운데. 콤보 알약은 아래 블록의 오른쪽(새 오른쪽 16px 옆, 세로 가운데).
   - 폰 세로도 이 배치 그대로 플레이 가능(회전 안내 없음).
6. 타임라인 캔버스 내부 해상도 = CSS 크기 × `min(devicePixelRatio, 2)`. JS가 `--A`, `--S`, `--L` CSS 변수를 넣는다. 크기가 바뀌어도 기호 위치는 **마디 안 비율(0~1)**로 저장되어 있어 다시 그리기만 하면 된다.
7. 수치표 (패딩 12, 안전 영역 0 기준):

| 화면 | W × H | 배치 | A (새) | S (줄 높이) | L (줄 너비) | 8칸 한 칸 너비 |
|---|---|---|---|---|---|---|
| PC 1280×800 | 1256 × 776 | 가로 | 220 | 132 | 744 | ~90 |
| iPad 가로 1080×810 | 1056 × 786 | 가로 | 220 | 132 | 744 | ~90 |
| iPad 가로 1080×740 | 1056 × 716 | 가로 | 220 | 132 | 744 | ~90 |
| iPad 세로 810×1080 | 786 × 1056 | 세로 | 200 | 120 | 760 | ~92 |
| 폰 가로 844×390 | 820 × 366 | 가로, TB 44 | 119 | 76 | 685 | ~83 |
| 폰 세로 390×844 | 366 × 820 | 세로 | 183 | 59 | 366 | ~43 |

8. **검증 기준** (QA와 공유): 6개 뷰포트 모두 `scrollWidth ≤ innerWidth`, `scrollHeight ≤ innerHeight`, 두 새·두 타임라인·콤보 알약 `getBoundingClientRect()`가 화면 안, 상단 바 버튼 44×44, 상단 바 요소끼리 겹침 없음, 시작·결과 오버레이 주 버튼이 화면 안.

### 타임라인 안쪽 좌표 (두 줄 동일)
- 안쪽 여백 좌우 `pad = clamp(10, L × 0.03, 24)`. 한 마디 = 4박, 박 하나 = `(L − 2·pad) / 4` 너비의 **박 칸**. 칸(8칸이면 박당 2칸, 16칸이면 4칸)의 x = `pad + (i + 0.5) × 칸너비`. 즉 기호는 칸 가운데.
- 기준선 `y0 = S × 0.52`. 엇박 기호는 **조금 위**(`y0 − S × 0.12`) — "뒷박은 살짝 떠 있다"는 높이 단서.
- 박 구분선: 박 칸 경계 3개에 1px `--grid` 세로선(전체 높이의 70%). 반박 위치(8칸의 짝수 칸)엔 선 없음.
- **박 점(메트로놈)**: 각 박 칸 첫 칸 x에, `y = S − 10`에 지름 6 점 `--grid`. 커서가 그 박을 지날 때 `--ink` α .6으로 켜지고 150ms 동안 서서히 꺼짐. 반주 박과 같은 순간.

## 타임라인 디자인 (핵심)

### 기호 (정박 / 엇박 / 쉼) — 모양·크기·색·높이 4중 구분
`D = min(칸너비 × 0.62, S × 0.44)` (8칸 PC 기준 약 56px, 폰 세로 약 26px)

| 종류 | 모양 | 크기 | 색 | 높이 |
|---|---|---|---|---|
| **정박** (박 칸의 첫 칸에서 치는 음) | 꽉 찬 **원** | 지름 D | `--beat` | 기준선 y0 |
| **엇박** (박 칸의 나머지 칸에서 치는 음) | 꽉 찬 **둥근 마름모**(45° 회전 둥근 정사각, 모서리 r = 0.18·한 변) | 대각선 0.66·D | `--off` | y0 − 0.12·S |
| **쉼** (정박 자리인데 치지 않음) | **점선 빈 원**, stroke 2px dash 3/3 | 지름 0.62·D | `--muted` α .7 | y0 |
| 빈 엇박 자리 | 아무것도 없음 (짧은 1px 눈금만, 높이 6, `--grid`) | | | y0 + 0.5·D |

- 16칸 패턴이면 박 칸 첫 칸 = 정박, 셋째 칸(반박) = 엇박 마름모, 둘째·넷째 칸(16분) = 엇박 마름모를 0.8배로 — design.md에서 16칸을 쓸 때만.
- **쉼은 정박 자리만 표시**한다(정박 자리가 비어 있으면 "여기선 참아" 신호). 엇박 자리가 비는 건 평범하므로 표시 안 함.
- 새 종류가 처음 등장하는 패턴(예: 첫 엇박, 첫 쉼)에서는 그 기호에 **안내 고리**: 기호 바깥 +8px 원 stroke 2 `--ink` α .25, 1200ms 주기로 α .25↔.1 천천히(reduced-motion이면 고정 α .2). 그 패턴 동안만.

### 위 줄(선생님) — "보고 듣기"
- 부르기 마디가 시작되면 그 마디 패턴 기호가 **미리 흐리게(α .35)** 모두 보인다.
- 커서가 각 음에 닿는 순간(소리와 같은 프레임) 그 기호가 **α 1 + scale 1.25→1 (160ms ease-out)** 으로 켜지고 그대로 남는다.
- design.md가 상위 단계에서 "미리 보기 없음"을 쓰면: 미리 흐린 기호를 그리지 않고 칠 때만 나타나게(같은 애니메이션). 이 옵션 하나만 지원.
- 따라하기 마디 동안 위 줄은 비활성(바탕 `--panel`, 전체 α .6)이지만 **켜진 기호는 남아 있어** 아래 줄과 비교할 수 있다.

### 아래 줄(나) — "빈칸 채우기"
- 부르기 마디 동안, 선생님이 음을 칠 때마다 아래 줄 같은 x에 **빈 기호(유령)**가 생긴다: 같은 모양·크기, 채움 없음, stroke 2.5 같은 색 α .55. 쉼은 위 줄과 같은 점선 원. 나타남 120ms(scale .6→1, α 0→1).
- 따라하기 마디에서 내가 쳐서 맞히면 유령이 **채워진다**(아래 판정 참고). 즉 "빈 모양을 채운다"가 규칙 설명이 된다.
- 다음 부르기 마디가 시작될 때 아래 줄의 이전 결과는 200ms에 걸쳐 사라지고, 위 줄의 켜진 기호도 같은 200ms에 지워진 뒤 새 패턴이 흐리게 나타난다.

### 차례 표시 (글 없이)
| 요소 | 부르기 마디 (선생님 차례) | 따라하기 마디 (내 차례) |
|---|---|---|
| 위 줄 | 테두리 2px `--teacher-ink`, 바탕 `--teacher-tint`, α 1 | 테두리 1px `--grid`, 바탕 `--panel`, α .6 |
| 아래 줄 | 테두리 1px `--grid`, 바탕 `--panel`, α .75(유령이 보여야 하므로 .6보다 진하게) | 테두리 2px `--parrot-ink`, 바탕 `--parrot-tint`, α 1 |
| 선생님 새 | 활성 | 비활성(앵무새 쪽으로 고개) |
| 앵무새 | 비활성, 4박째 "준비" | 활성 |
| 진행 커서 | 위 줄에서 움직임 | 아래 줄에서 움직임 |
| 줄 왼쪽 끝 작은 아이콘(16px, 줄 안 pad 왼쪽 위 모서리) | 위 줄: 소리 호 아이콘 `--teacher-ink` | 아래 줄: 손가락 톡 아이콘(원 + 짧은 방사선 3개) `--parrot-ink` |
- 차례 전환 시 테두리·바탕·α는 **150ms ease-out** 크로스페이드. 커서는 위 줄 오른쪽 끝에서 사라지고 같은 순간 아래 줄 왼쪽 끝에서 나타난다(이동 애니메이션 없음 — 박에 정확해야 함).

### 진행 커서
- 2px 세로선 `--ink` α .55, 줄 높이의 84%, 위 끝에 아래 향한 작은 삼각형(너비 8 높이 6) — 활성 줄의 `--teacher-ink`/`--parrot-ink` 색.
- x = `pad + 마디진행(0~1) × (L − 2·pad)`. **마디진행은 반드시 오디오 시계(`AudioContext.currentTime`, 가능하면 `− outputLatency`)에서 계산**한다. `performance.now()`로 따로 세지 않는다(소리와 화면 어긋남 방지).
- 커서 지나간 부분 바탕을 아주 옅게(활성 색 α .06) 채워 "얼마나 왔는지" 보이게.
- 카운트인(게임 첫 시작 1마디, design.md가 정하면): 커서 없이 박 점 4개가 박마다 차례로 켜지고, 선생님이 박마다 고개 끄덕(머리 묶음 translateY 2px, 120ms). 그 다음 마디부터 부르기.

## 판정 피드백

### 탭 즉시 반응 (지연 없이)
- 입력은 **`pointerdown`**(터치·마우스 공통)과 **`keydown`**에서 처리하고, 같은 핸들러 안에서 바로 클래스·상태를 바꾼다(`click`·`touchend` 금지, 300ms 지연 원인). 화면 반영은 다음 rAF(≤16ms).
- 탭마다 무조건(차례·판정 무관): ① 앵무새 "북 치기" 애니메이션, ② **탭 물결**: 누른 위치(키보드면 앵무새 북 위치)에서 지름 24→72px 원 테두리 2px `--parrot-ink` α .35→0, 260ms ease-out. 전체 화면 번쩍임 없음.
- 따라하기 마디 중 탭이면 ③ 아래 줄의 **실제 시간 x 위치에 탭 표시 막대**: 폭 3px, 높이 S×0.6, `--parrot-ink`, radius 2, 마디 끝까지 남음.
- 부르기 마디 중 탭(판정 대상 아님 — design.md 기준): ①②만 하고 선생님이 앵무새 쪽으로 고개를 10° 더 돌렸다 돌아옴(300ms) — "지금은 들어" 신호. 탭 표시 막대는 그리지 않는다.

### 판정 표시 (짧은 단어 + 아이콘 + 기호 변화)
판정 단어는 해당 기호 위(기호 위쪽 가장자리 − 6px)에 뜨는 작은 글자 알약. 글자 13px 800(폰 세로 11px), 알약 패딩 2px 7px, radius 999, 바탕 `--panel`, 1px 테두리 판정 색.

| 판정 | 단어 | 기호 변화 | 아이콘·선 |
|---|---|---|---|
| **Perfect** | `딱!` (글자 `--ink`, 테두리 `--gold`) | 유령이 꽉 채워짐(원래 색) + scale 1.3→1 (180ms) | 기호 바깥 이중 고리 `--gold` (2px, +5px와 +10px), 300ms에 걸쳐 커지며 α 1→0 |
| **Good** | `좋아` (글자 `--ink`, 테두리 `--good`) | 꽉 채워짐, scale 1.15→1 (140ms) | 단일 고리 `--good` (+6px) 240ms 페이드 + **어긋남 선**(아래) |
| **Miss** (안 침) | `×` 기호만 (글자 `--muted`, 테두리 `--grid`) | 유령이 `--muted` α .5 점선으로 바뀜 | 없음 |
| 헛침 (쉼·빈 자리를 침) | 단어 없음 | 탭 표시 막대가 `--muted`로 그려지고 그 위에 작은 × (8px) | 쉼 기호 근처였으면 쉼 점선 원이 좌우 3px 흔들림 1회(200ms) |

- **빠름/늦음 (어긋남 선)**: Good일 때 기호 중심 x에서 탭 표시 막대 x까지 가로 2px 선을 기준선 아래 `y0 + 0.5·D + 6`에 그리고, 끝에 작은 화살촉(6px):
  - 빠름: 선·화살촉 `--early`, 화살촉이 **왼쪽**을 향함(‹), 판정 알약 왼쪽에 같은 색 작은 ‹ 하나 추가.
  - 늦음: `--late`, 화살촉 **오른쪽**(›), 알약 오른쪽에 ›.
  - Perfect는 선 없음(정답 위치에 막대가 거의 겹쳐 보임). 탭 표시 막대 자체가 위치를 보여 주므로 Miss는 선 없음.
  - 색(차가움/따뜻함) + 방향(‹/›) + 위치(막대가 왼쪽/오른쪽) 3중 구분.
- 판정 알약 수명: 나타남 120ms(translateY 4→0, α 0→1) → 유지 → 다음 부르기 마디 시작 때 줄과 함께 200ms에 사라짐. 같은 마디 안의 알약끼리 겹치면(폰 세로 16칸 등) 단어를 숨기고 아이콘(고리·×)만 남긴다: 칸너비 < 34px이면 알약 대신 고리만.

### 마디 결과
- 따라하기 마디가 끝나는 순간(다음 부르기 첫 박 전) 앵무새가 "기쁨" 또는 "앗" 상태. 전부 Perfect면 앵무새 머리 위로 작은 음표 3개(SVG 8분음표 모양, 12px, `--beat`/`--off`/`--gold`)가 위로 18px 떠오르며 사라짐(600ms).

### 상단 바 (붕어빵 눈싸움 `.top` 구조 복사)

| < 420px | 단계 알약의 계단 아이콘·진행 점 숨김(숫자만), 하트 16px, 점수 17px |

- 최악 폭(점수 `99999`, 단계 `99`, 하트 5개)에서 390px 폭 겹침 없음 확인.

### 콤보 알약
- 위치: 레이아웃 규칙 4·5. 높이 30, radius 999, `--panel` + 1px `--grid`, 안: `.num` 18px 숫자 + "연속" 11px 700 `--muted`.
- 2 미만이면 `visibility:hidden`(자리 유지). 증가 시 숫자 scale 1→1.12→1 (140ms). 10, 20, 30…마다 테두리 `--gold` 600ms 후 원래대로. 끊기면 숫자 α .4로 200ms 후 숨김(흔들림 없음).

### 오버레이 (붕어빵 눈싸움 `.overlay` CSS 그대로, 무대 위 absolute — 폰 세로·가로처럼 무대가 작으면 `body.ov-full`로 전체 화면)
1. **시작**: 제목 "박자 앵무새"(24px 800) → 두 새 미니(각 72px, 나란히, 선생님 왼쪽) → 한 줄 "선생님이 치면, 똑같이 따라 쳐요"(14px `--muted`) → **범례 카드 3개**(가로 나열, 각 76×64, `--panel` 1px `--grid` radius 12): 큰 원 `--beat` + "정박" / 작은 마름모 `--off`(살짝 위) + "엇박" / 점선 원 + "쉼". 아래 작은 글(12px): "화면 아무 데나 톡 · 스페이스" → `시작하기`(primary). 최고 기록이 있으면 "최고 1240점 · 5단계"(12px).
   - 범례 카드는 장식이 아니라 실제 타임라인과 **같은 그리기 함수/같은 SVG 모양**을 쓴다.
   - `시작하기`를 누르는 순간 AudioContext를 깨운다(iOS 규칙). 게임 화면 탭으로 시작하지 않는다(버튼으로만).
2. **일시정지**: "일시정지" + `계속하기`(primary) + `처음부터`(secondary) + `← 게임 목록`. 반주 정지. 계속하면 **다음 부르기 마디 처음부터** 재개하고, 그 전에 카운트인 1마디(박 점 4개)를 다시 보여 준다(박 감각 회복).
   - `visibilitychange`(앱 전환·화면 끄기) 시 자동 일시정지.
3. **결과**: 앵무새(96px, 마지막 상태가 기쁨이면 기쁨 눈) → 점수 `.num` 40px → "5단계까지 · 딱! 23번 · 최고 연속 14"(14px `--muted`, 숫자 `.num`) → 새 최고면 `--gold` 테두리 알약 "새 최고 기록". → `다시 하기`(primary) + `← 게임 목록`(secondary).
- 오버레이 위의 탭은 게임 입력으로 들어가면 안 된다(오버레이가 떠 있으면 입력 무시).

### 단계 상승 연출 (마디 사이 끊김 없이, 반주 계속)
- 단계가 오르는 따라하기 마디가 끝난 순간:
  1. 단계 알약 숫자 교체 + scale 1→1.15→1 (300ms ease-out), 진행 점 모두 비움(200ms).
  2. 선생님 새가 깡충 두 번(translateY 0→−10→0 ×2, 총 480ms, 박에 맞추지 않아도 됨).
  3. 선생님 머리 위로 음표 5개(결과 연출과 같은 SVG)가 부채꼴로 22px 떠오르며 사라짐(900ms).
  4. 두 타임라인의 박 구분선이 그 마디 동안 `--gold` α .5로 바뀌었다가 원래 색으로(900ms) — 줄 전체를 칠하지 않음.
- 다음 부르기 마디는 정상 시점에 시작(연출이 마디를 늦추지 않음). 새 요소가 처음 나오면 위 "안내 고리".
- 템포가 바뀌는 단계라면 박 점이 새 속도로 바로 따라간다(별도 표시 없음).

| 탭 물결 | 지름 24→72, α .35→0 | 260 | ease-out |
| 북 치기 | 날개 −28°, 가죽 scaleY .8, 소리 호 | 120 (호 180) | ease-out |
| 선생님 음 켜짐 | α .35→1, scale 1.25→1 | 160 | ease-out |
| 유령 생김 | scale .6→1, α 0→1 | 120 | ease-out |

- 캔버스는 rAF로 매 프레임 다시 그린다(두 줄뿐이라 가벼움). 탭 물결·판정 알약·캐릭터는 DOM/CSS.

### 모션 줄이기 (`prefers-reduced-motion: reduce`)
- **유지**: 진행 커서 이동, 기호 켜짐(α만, scale 없음), 유령 생김(α만), 판정 채움·알약(α만), 박 점, 차례 전환 색 변화 — 게임 진행에 필요한 정보.
- **끔/대체**: 대기 숨쉬기·깡충·좌우 흔들기·점프 없음(눈 모양 변화만), 탭 물결은 크기 고정 링이 α만 100ms 페이드, 북 치기는 가죽 색만 160ms 진하게(`--drum-side` 섞음), 음표 떠오름 없음, 안내 고리 깜빡임 없음(고정), 단계 상승은 알약 숫자 교체 + 박 구분선 색 변화만, 오버레이 애니메이션 없음.

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)
- **탭**: 화면 아무 곳(상단 바 버튼·링크, 오버레이 제외). 입력 영역은 `.app` 전체 `pointerdown`, `e.preventDefault()`. 멀티터치 두 손가락이 거의 동시(30ms 이내)면 한 번으로 친다(design.md가 다르게 정하면 그쪽).
- **iPad Safari**: `.app { touch-action: none; }`, `body { touch-action: manipulation; user-select:none; -webkit-user-select:none; -webkit-touch-callout:none; -webkit-tap-highlight-color: transparent; }`, `dblclick`/`gesturestart` `preventDefault`(더블탭 확대·핀치 방지), 가로 스크롤 금지. 길게 누르기 메뉴·텍스트 선택이 뜨지 않아야 한다(빠른 연타가 길게 누르기로 오인되기 쉬움).
- **키보드**:
| 키 | 동작 |
|---|---|
| Space, Enter, 그 밖의 글자·숫자·방향키 | 탭(치기) |
| P, Esc | 일시정지/계속 |
| M | 음소거 토글 |
| Tab, Shift/Ctrl/Alt/Meta 단독, 조합키(Ctrl+R 등) | 무시(브라우저 기본 동작 유지) |
  - `e.repeat`이면 무시(누르고 있기로 연타 방지). 게임 중 Space의 페이지 스크롤·버튼 재클릭을 막기 위해 `preventDefault` + 포커스된 버튼 `blur()`.
  - 오버레이가 떠 있을 때 Space/Enter는 포커스된 버튼(기본 포커스 = 주 버튼)을 누른다.
- 상단 바 버튼 44×44, 오버레이 버튼 primary 48 / secondary 44 높이.

## 접근성 (대비, 색 외 구분 수단)
- 정박/엇박/쉼: **모양(원/마름모/점선 원) + 크기 + 높이 + 색**. 흑백으로 봐도 구분된다.
- 차례: **새의 불투명도·받침·고개 방향 + 줄 테두리 굵기 + 커서 위치 + 줄 왼쪽 아이콘(소리 호/손가락)**. 색 없이도 커서가 있는 줄이 내 줄인지 알 수 있다.
- 판정: 단어(`딱!`/`좋아`/`×`) + 고리 개수(이중/단일/없음) + 기호 채움 여부. 빠름/늦음: 화살 방향 + 막대 위치 + 색.
- 하트: 채움 vs 테두리만. 콤보 10단위 강조는 색 외에 변화 없음(정보 아님, 장식).
- 대비: 글자는 모두 `--ink`/`--muted`(공통 값, 4.5:1 이상). `--teacher-ink`·`--parrot-ink` 테두리는 패널 대비 5:1 이상.
- 스크린 리더: 타임라인 캔버스 `aria-hidden`. `aria-live="polite"` 숨김 영역에 마디 결과 한 줄("성공, 딱 3 좋아 1" / "하트 1개 잃음") — 매 탭마다 읽지 않음. 버튼 `aria-label`·`aria-pressed`(음소거)는 기존 게임과 동일.
- 포커스 링: 공통 `outline: 3px solid var(--accent); outline-offset: 2px`.
- 깜빡임: 1초에 3번 넘게 번쩍이는 효과 없음(박 점은 작은 점이라 해당 없음).

## 개발자 체크리스트 (요약)
1. 커서·기호 켜짐·판정 위치는 **오디오 시계 기준**. 화면 타이머 따로 두지 않기.
2. 입력은 `pointerdown`/`keydown`에서 즉시 반응, `e.repeat` 무시, 오버레이 떠 있으면 무시.
3. 정박/엇박/쉼 = 원/마름모(살짝 위)/점선 원. 범례 카드도 같은 그리기 코드.
4. 아래 줄은 "유령 채우기" 방식, 빠름/늦음은 막대 위치 + ‹/› 화살 + 색.
5. 상단 바·버튼·오버레이 CSS는 붕어빵 눈싸움에서 복사, SVG 숨김은 `toggleAttribute('hidden')`.
6. 6개 뷰포트 수치표·검증 기준 통과, `prefers-reduced-motion` 분기 구현.
7. BeatDigits 폰트 이름 교체·OFL.txt 동봉.
