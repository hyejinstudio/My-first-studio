# 폭식 불곰을 찾아라 아트·UI 명세

> slug: `hungry-bear` · 배포: 실험실 `lab/games/hungry-bear/index.html` (HTML 1개 + `fonts/` 폴더)
> **수치·규칙(레벨별 연어 수, 먹는 간격, 라운드 길이, 동점 처리)은 design.md가 정하고**, 이 문서는 그것을 어떻게 보여 줄지만 정한다. 이 문서의 타이밍 상한·하한(아래 "먹기 한 번" 표)은 **눈으로 셀 수 있게 하는 화면 쪽 제약**이며, design.md의 속도 곡선이 이 하한을 넘지 않도록 CEO가 맞춘다.
> 그래픽: **강가 씬·곰·연어 = 인라인 SVG 하나(`<svg class="scene">`)**, HUD·띠·오버레이·해설 패널 = DOM. Canvas 없음, 이미지 파일 없음, **게임 화면에 이모지 그래픽 없음**.
> 오리지널 원칙: 곰·연어는 이 문서의 도형으로 직접 그린다. 기존 캐릭터(유명 곰 캐릭터, 마스코트)의 얼굴 비율·복장·로고를 따라 하지 않는다.

## 스타일 콘셉트
- **"늦여름 아침의 조용한 강가"**: 연한 안개빛 하늘, 멀리 흐린 침엽수 능선, 모래빛 강둑, 채도 낮은 청회색 강. 그 둑 위에 **같은 털색의 불곰 세 마리**가 정면을 보고 나란히 앉아 있다. 그라데이션·광택·화면 흔들림·번쩍임 없음. 면 색 차이로만 깊이를 만든다.
- **귀엽지만 유치하지 않게**: 곰은 단순한 타원 조합, 작은 눈(점), 큰 주둥이. 볼터치·반짝이·하트 없음. 표정은 "평소(입 다문 w)"와 "먹는 중(입 벌림)" 두 가지뿐.
- **세 곰은 목도리로 구분한다**: 털은 셋 다 똑같은 불곰 갈색(색 차이가 "누가 더 큰가" 같은 착각을 만들지 않도록). 구분 수단은 **목도리 색 + 목도리 무늬(민무늬/줄무늬/물방울) + 가슴 번호 배지(1·2·3) + 자리(왼쪽/가운데/오른쪽)** 네 가지다. 키보드 1/2/3도 이 순서와 같다.
- **보고 배우기**: 글 대신 그림. 시작 화면은 3칸 그림 설명(연어가 날아감 → 눈으로 센다 → 곰을 누른다). 해설은 **곰 바로 아래에 먹은 연어가 한 마리씩 쌓이는 다시보기**와 큰 숫자로 보여 주고, 문장은 한 줄만 붙인다.
- **공정성 (가장 중요한 시각 규칙)**: 라운드가 끝난 화면에는 **누가 몇 마리 먹었는지 짐작할 단서가 하나도 남지 않는다.** 뼈·가시·부스러기 없음, 배가 부풀거나 표정이 바뀌지 않음, 냠 말풍선이 쌓이지 않음, 곰별 카운터 없음, 강물 파문은 사라짐. 정보는 **먹는 순간의 애니메이션**(연어가 날아와 입에 들어가고 '냠')에만 있다.
- 스튜디오 공통: 상단 바·버튼·오버레이는 `games/parrot-beat/index.html`의 `.top`, `.home`, `button.icon`, `button.primary`, `button.secondary`/`a.secondary`, `.overlay`, `body.ov-full`, `.ov-home` CSS를 **그대로 복사**한다(악덕 사장과 같은 방식). 패널 radius 12~16px, 주 버튼은 `--accent` 주황.
- 글꼴: 글자는 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **숫자(레벨, 곰 번호, 먹은 수, 최고 기록, 카운트다운)는 BearDigits**.

### 숫자 글꼴 BearDigits (Pretendard ExtraBold 800 서브셋, SIL OFL 1.1)
- 악덕 사장(`lab/games/tiny-company/fonts/company-digits-800.woff2` + `OFL.txt`)·앵무새 비트와 **같은 방식**이다. 원본은 Pretendard **ExtraBold(800)**.
- 파일: `lab/games/hungry-bear/fonts/bear-digits-800.woff2`, 같은 폴더에 `OFL.txt`(`lab/games/tiny-company/fonts/OFL.txt`를 그대로 복사: Pretendard 저작권 줄 + Reserved Font Name 줄 + OFL 1.1 본문).
- 글리프: `0-9`(U+0030–0039), `+`(U+002B), `,`(U+002C), `-`(U+002D), `.`(U+002E, 속도 배율 `1.4`), `/`(U+002F), `×`(U+00D7, 속도 `×1.4`). **`tnum` 유지**(다시보기에서 숫자가 1씩 오를 때 폭이 흔들리지 않게).
  - 예: `pyftsubset Pretendard-ExtraBold.otf --unicodes="U+002B-002F,U+0030-0039,U+00D7" --flavor=woff2 --layout-features='tnum' --output-file=bear-digits-800.woff2` 후 fontTools로 name 테이블을 바꾼다.
  - 원본에 U+00D7이 없으면 unicode-range에서 빼고 `×`는 시스템 글꼴로 나오게 둔다(QA가 cmap 확인).
- **Reserved Font Name 때문에 이름 변경 필수**: family/full/PostScript/typographic 이름(name ID 1, 3, 4, 6, 16, 17 등 "Pretendard"가 들어간 모든 레코드)을 `BearDigits`로 바꾸고, 압축을 푼 바이트에 "Pretendard" 문자열이 없어야 한다(QA가 기존 게임과 같은 fontTools 검사). 다른 게임 서브셋(CompanyDigits 등)은 글리프 구성·이름이 달라 **재사용 금지**. 원본을 구하지 못하면 CEO에게 보고한다(시스템 글꼴 대체 금지가 아니라, 보고 후 결정).
```css
/* 숫자 전용 글꼴: Pretendard ExtraBold(SIL OFL 1.1)의 숫자·기호 서브셋. 수정본이라 내부 이름은 BearDigits. 라이선스 fonts/OFL.txt */
@font-face { font-family: "BearDigits"; src: url("fonts/bear-digits-800.woff2") format("woff2");
  font-weight: 800; font-style: normal; font-display: swap; unicode-range: U+002B-002F, U+0030-0039, U+00D7; }
:root { --num-font: "BearDigits", system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif; }
.num { font-family: var(--num-font); font-weight: 800; font-variant-numeric: tabular-nums; }
```
- SVG 안 숫자(가슴 배지)도 `font-family="var(--num-font)"`가 아니라 CSS 클래스(`.badge-num { font-family: var(--num-font); font-weight: 800 }`)로 지정한다(SVG 속성에서 var()가 안 먹는 브라우저 대비).

### 표기 규칙
- 먹은 수는 "마리": `9마리`. 숫자만 BearDigits, "마리"는 시스템 글꼴 700.
- 곰 이름은 항상 **"N번 곰"**(1번 곰/2번 곰/3번 곰). 해설에서 처음 부를 때만 무늬를 덧붙인다: "2번 곰(줄무늬 목도리)".
- 레벨은 `레벨 7`, 속도는 `×1.4`(design.md의 속도 배율. 배율 개념이 없으면 속도 표시는 막대만).

## 그래픽 요소 (인라인 SVG)

### 씬 SVG 좌표계 (`<svg class="scene" viewBox="0 0 960 VH" preserveAspectRatio="xMidYMid meet">`)
- 가로는 항상 **960 단위**, 세로 `VH`는 무대 비율로 정한다: `VH = clamp(560, round(960 × 무대높이 / 무대너비), 1280)`. 비율이 이 범위를 넘으면 meet으로 맞추고 남는 여백은 무대 배경(위 `--sky`, 아래 `--river` 두 div)이 이어 칠한다.
- 기준선: 발 선 `yF = round(VH × 0.60)`(VH ≥ 900이면 `round(VH × 0.52)` — 세로 화면에서 강을 넓혀 해설 칸 확보). 둑 띠 `yF − 70 … yF + 24`, 둑 가장자리 `yF + 18 … yF + 30`(`--bank-edge`), 강 `yF + 24 … VH`. 능선은 `yF − 70` 위로 높이 90의 완만한 곡선, 침엽수 묶음 4개(고정 위치, 곰 머리와 겹치지 않게 x 40·330·630·900).
- **곰 중심 x = 180 / 480 / 780** (열 폭 300). 곰 심볼(220 × 260)을 `translate(cx − 110, yF − 252)`로 놓는다.
- 입 위치(연어 도착점): 곰 좌표 (110, 130) → 씬 `(cx, yF − 122)`.
- 해설 칸(집계 쌓기)은 강 영역 `yF + 40 … VH − 16`에 곰 열마다 하나.

### 곰 심볼 (`<symbol id="bear" viewBox="0 0 220 260">`, 세 곰 공통 + 곰별 목도리 그룹)
뒤에서 앞 순서. 좌표는 심볼 기준.
```
그림자    ellipse (110,252) rx84 ry8           --shadow
발        ellipse (64,244) / (156,244) rx26 ry13  --fur-dark
몸        ellipse (110,192) rx82 ry64          --fur
배        ellipse (110,206) rx50 ry40          --muzzle      ← 크기 고정. 절대 scale 하지 않는다
팔        ellipse (50,198) rx18 ry34 rotate(12) / (170,198) rotate(−12)  --fur
<g class="head"> (transform-origin: 110px 150px)
  귀      circle (56,46) / (164,46) r22 --fur, 안 r12 --inner-ear
  머리    ellipse (110,92) rx70 ry60       --fur
  주둥이  ellipse (110,120) rx34 ry25      --muzzle
  코      ellipse (110,106) rx12 ry8       --nose
  눈      circle (82,84) / (138,84) r6.5   --eye  (+ 하이라이트 r2 #fff α.7, 다크도 동일)
  <g class="mouth-closed">  path "M98 125 Q104 131 110 125 Q116 131 122 125" stroke --nose 3, round, fill none
  <g class="mouth-open" hidden>  ellipse (110,131) rx13 ry11 --mouth-in + ellipse (110,137) rx8 ry4 --tongue
</g>
<g class="scarf">  (곰별로 다름 — 아래)
```
- **목도리** (`fill: var(--bN)`): 목 띠 `M42 148 Q110 174 178 148 L180 166 Q110 194 40 166 Z` + 오른쪽으로 늘어진 끝자락 `M138 168 L160 166 L164 214 L142 216 Z`(끝에 술 3가닥: 길이 8 선, stroke `--bN` 3).
  - 1번: 민무늬.
  - 2번: 띠와 끝자락에 가로 줄 3개(stroke `#ffffff` α.55, 폭 4, 띠 곡선을 따라 `clipPath`로 자름). 다크도 흰 줄 α.4.
  - 3번: 흰 원 r4 6개(띠 4개 x 70·100·130·160 + 끝자락 2개), `#ffffff` α.6(다크 α.45).
- **번호 배지**: 가슴 가운데 circle (110,184) r17, fill `--panel`, stroke `--bN` 3.5 + 숫자 text (110,185) 22단위 `.badge-num` fill `--bN-ink`, `text-anchor: middle; dominant-baseline: central`. 해설·선택 화면에서도 같은 배지를 쓴다.
- 눈 깜빡임: `.eye`를 scaleY .1로 120ms(transform-box: fill-box). **곰마다 2.5~5.5초 무작위 간격, 라운드 진행·먹은 수와 무관**(정보가 새지 않게).

### 냠 말풍선 (`<g class="yum">`, 곰마다 하나, 평소 hidden)
- 위치: 곰 머리 오른쪽 위 — 씬 `(cx + 64, yF − 262)`를 왼쪽 아래 꼭지로. 둥근 사각형 76 × 40 단위 rx 14, fill `--yum-bg`, stroke `--bN` 2.5 + 꼬리 삼각형(입 쪽 왼쪽 아래). 글자 "냠" 22단위 800 `--yum-ink` 가운데.
- 세 곰 모두 같은 모양·같은 글자. 테두리 색만 곰 색(어느 곰이 먹었는지 연결해 주는 단서, 남는 정보 아님).
- VH가 작아 말풍선이 씬 위로 잘리면(`yF − 262 < 4`) 말풍선을 `(cx + 70, yF − 200)` 머리 옆으로 내린다.

### 씬 장식 규칙
- 장식(돌 3개, 풀포기, 물결 띠)은 **고정 위치**. 라운드마다 바뀌거나 먹을 때 움직이지 않는다.
- 물결 띠 2~3개는 `translateX` ±6 단위 6000ms 무한 왕복(reduced-motion이면 정지). 이 움직임은 곰과 무관.

## 레이아웃 (PC / iPad 세로 / iPad 가로)

### 화면 구성 (위→아래, 모든 방향 공통 1열)
```
┌ .top 상단 바 (TB) ─ ← 게임 목록 · 제목 · (flex) · [레벨 알약] · 음소거 · 일시정지 ┐
├ .cue 안내 띠 (CB) ─ "잘 보세요" + 진행 막대 / "누가 제일 많이 먹었을까?" / 결과 한 줄 ┤
├ .stage 무대 ─ <svg class="scene"> + 곰 선택 버튼 3개(DOM, 씬 위에 겹침) + 해설 집계 칸 3개(DOM) ┤
└ .sheet 해설 하단 줄 (해설 때만, SH) ─ 문장 1줄 + 버튼 ┘
```
- 곰은 **어느 방향이든 가로 한 줄 3마리**(왼쪽부터 1·2·3). 세로 화면에서 세로로 쌓지 않는다(키 1/2/3과 위치가 어긋나지 않게).

### 높이 기준 규칙 (parrot-beat·악덕 사장과 같은 방식)
1. `--app-h = window.innerHeight + 'px'`를 `resize`·`orientationchange`·`visualViewport.resize`에서 갱신. CSS 기본값 `100dvh`(미지원 `100vh`). `html, body { height: var(--app-h); overflow: hidden; }`. body 패딩 `max(12px, env(safe-area-inset-*))`(H ≤ 520이면 위아래 `max(8px, …)`). viewport meta `width=device-width, initial-scale=1, viewport-fit=cover`.
2. `W`, `H` = 패딩 뺀 크기. `TB = 52`(H ≤ 520이면 44). `CB = 44`(H ≤ 520이면 36). 간격 `g = 8`(W < 420 또는 H ≤ 520이면 6).
3. 무대: 너비 `SW = min(W, 1100)` 가운데, 높이 `SH0 = H − TB − g − CB − g`. 해설 하단 줄 `SHt = 64`(H ≤ 520이면 52)는 **해설 때만** 무대 높이에서 뺀다(무대가 줄어들며 씬이 다시 맞춰짐 — 곰 크기가 살짝 줄어드는 것은 허용, 200ms 트랜지션 없이 즉시).
4. 씬 배율 `s = min(SW / 960, 무대높이 / VH)`, 곰 실제 폭 `220·s`, 열 폭 `300·s`.
5. **곰 선택 버튼**(`<button class="pick">` 3개): 씬 열 하나를 덮는 투명 버튼. 가로 = 열 폭 `300·s`, 세로 = 씬 `yF − 300 … yF + 40` 구간 × s(머리 위 말풍선 자리부터 발밑까지). JS로 씬의 실제 렌더 사각형(`getBoundingClientRect`)에서 계산한다. **최소 64 × 64px 보장**(아래 표 최솟값 114px).

## HUD·메뉴·오버레이

### 1. 시작 화면 (`#ovStart`, `body.ov-full`)
- 뒤에 씬과 곰 세 마리가 대기 숨쉬기 중(오버레이 바탕 `--well` 97%라 거의 가려짐 — 공통 방식).
- 카드(최대 폭 520): 제목 "폭식 불곰을 찾아라" 26px 800 → 부제 "연어를 제일 많이 먹은 곰을 찾아요" 15px `--muted` → **그림 설명 3칸**(가로 3칸, 폭 < 420이면 3칸 유지·칸 안 그림 48px):
  1. 미니 씬: 곰 머리 하나 + 아래에서 곡선 점선을 따라 올라오는 연어 → 캡션 "연어가 날아가요"
  2. 곰 셋 머리(목도리 색 띠 + 번호) 위에 작은 막대 셋 → "누가 몇 마리 먹는지 세요"
  3. 가운데 곰 머리 + 손가락 탭 아이콘(원 2겹) → "제일 많이 먹은 곰을 눌러요"
  - 칸 캡션 13px 700, 한 줄(keep-all). 칸 사이 `→` 아이콘(14px `--muted`).
- "레벨이 오를수록 더 빨리 먹어요" 13px `--muted` 한 줄.
- 최고 기록 줄: `최고 레벨` + `.num` 20px (`--gold` 아이콘 없이 숫자만, 기록 없으면 줄 숨김).
- `시작` 주 버튼(높이 52, 최소 폭 200) + PC만 "Enter" 키 라벨. `.ov-home` 공통.

### 2. 라운드 화면 (오버레이 없음)
- 씬 + 안내 띠 + 레벨 알약. 선택 버튼은 `disabled`(포인터 무시, 커서 기본). 라운드 중 탭은 아무 반응 없음(실수로 눌러도 판정되지 않음).
- 화면에 **곰별 숫자·누적 표시·남은 연어 수 없음.**

### 3. 선택 화면 (오버레이 없음)
- 마지막 먹기의 말풍선이 사라지고 **400ms 정적** 뒤 띠가 "누가 제일 많이 먹었을까?"로 바뀌며 선택 버튼 활성.
- 각 곰 발밑에 **선택 표시 링**(ellipse rx 96 ry 14, stroke `--bN` 3, fill 없음, α .5)과 그 아래 번호 원(지름 32px DOM, `--panel` + 2px `--bN`, `.num` 16px `--bN-ink`)이 나타남(α 0→1 160ms, 세 곰 동시·동일).
- 호버/포커스: 해당 곰 몸 translateY −4, 링 α 1·두께 4, 번호 원 scale 1.1. 누름(`:active`): 곰 scale .97.
- 탭/클릭/키 → 즉시 입력 잠금, 선택한 곰 링이 `--accent` 실선 4 + 발밑 "내 선택" 꼬리표(높이 24, radius 12, `--accent` 바탕, 흰 글자 12px 700). 300ms 뒤 해설 시작.

### 4. 해설 (`.explain`, 씬 위 DOM + 하단 줄 `.sheet`) — **이 게임의 핵심 화면**
목적: "누가 몇 마리, 어떤 순서로 먹었는지"를 정확하게, 그림으로 확인시킨다.

**4-1. 판정 표시 (0~300ms)**
- 정답 곰: 발밑 링 `--good` 실선 4 + 머리 위 체크 원(지름 36px, `--good` 바탕, 흰 체크 stroke 3) + "정답" 꼬리표.
- 오답이면 선택한 곰: 링 `--danger` **점선**(dash 8 6) 4 + X 원(`--danger`) + "내 선택" 꼬리표 유지. 정답 곰은 위와 같이 체크.
- 정답 맞혔으면 체크와 "내 선택"이 같은 곰에 함께 붙는다.

**4-2. 집계 쌓기 다시보기 (300ms~)**
- 강 영역이 `--river` 위로 `--panel` α .82 판 3개(곰 열마다 하나, 폭 = 열 폭 − 12px, radius 12, 위 테두리 3px `--bN`)로 덮인다. 각 판 맨 위에 큰 숫자 `.num` (판 폭에 따라 28~44px, `--bN-ink`) + "마리" 13px.
- **먹은 순서 그대로** 이벤트를 하나씩 재생: 이벤트 i마다 해당 곰 판에 **미니 연어 1마리**가 추가되고(위에서 툭 떨어지듯 translateY −8→0 + α), 숫자가 1 오르고, 씬의 그 곰 입이 짧게 벌렸다 닫힘(90ms). 간격 `d = clamp(1800 / N, 70, 180)`ms (N = 전체 먹은 수) → 전체 1.3~1.8초 내외.
- **미니 연어 배열**: 한 줄 5마리, 5마리마다 줄바꿈(오른쪽 정렬 없이 왼쪽부터). 줄과 줄 사이 4px. 판 폭이 좁아 5마리가 안 들어가면(폰 세로) 미니 연어 14 × 7px. 5단위 묶음이라 숫자 없이도 셀 수 있다.
- **낮은 화면 압축**(판 실제 높이 < 96px, 예: 폰 가로 750×342 해설 시 약 60px): 큰 숫자를 판 왼쪽(24px)으로 옮기고, 미니 연어(12 × 6px)는 그 오른쪽에 5마리씩 줄 맞춤(5단위 묶음 유지). 그래도 넘치면 10마리마다 한 줄. 먹은 순서 띠는 높이 8로 줄이고 무늬 생략. 어떤 경우에도 판 안 스크롤·잘림 0(QA 확인).
- **먹은 순서 띠** (판 3개 위, 높이 14, 폭 = 씬 폭 − 24): 라운드 전체 이벤트를 시간순 작은 칸으로(칸 폭 = 띠폭 / N, 칸 사이 2px, radius 3). 칸 색 `--bN` + 무늬(2번 칸은 대각 줄, 3번 칸은 가운데 점 — 칸 폭 ≥ 10일 때만). 재생 중 현재 칸에 `--ink` 테두리 2px. 띠가 칸 폭 4px 미만이면 무늬 생략. "빠르게 몰아서 먹은 곳"이 눈에 보이게 하는 장치다.
- 재생이 끝나면 최댓값 판에 `--good` 테두리 2px + 판 위 "제일 많이" 작은 알약(`--good` 바탕, 흰 12px 700). 다른 판은 그대로.
- **화면 탭/클릭 또는 Space** → 다시보기 건너뛰기(바로 최종 상태).

**4-3. 하단 줄 `.sheet` (높이 SHt)**
- 왼쪽 문장 1줄(15px, keep-all, 넘치면 ellipsis 대신 13px로 줄임):
  - 정답: "**2번 곰**이 **9마리**로 제일 많이 먹었어요. 1번 7마리, 3번 6마리."
  - 오답: "정답은 **2번 곰**(줄무늬 목도리) **9마리**. 고른 1번 곰은 7마리였어요."
  - 곰 이름은 `--bN-ink` 굵게, 숫자는 `.num`.
- 오른쪽 버튼:
  - `느리게 다시 보기`(secondary, 높이 48, 아이콘 되감기): 라운드를 **실제 그대로 0.5배속**으로 다시 재생. 이때는 각 곰 머리 위에 작은 누적 숫자 칩(`.num` 16px, `--panel` + 1px `--bN`)을 보여 준다(해설용이므로 허용). 재생 중 버튼 → "건너뛰기". 끝나면 4-2 최종 상태로 돌아옴.
  - 정답 → `다음 레벨` 주 버튼(높이 48, 오른쪽 화살표). 오답 → `결과 보기` 주 버튼.
  - 폭 < 640: 문장이 하단 줄 위 1줄로 올라가고(무대 안 판 위 공간, 13px), 하단 줄은 버튼 2개만(각 폭 50%). H ≤ 520: 버튼 높이 44.
- 주 버튼은 다시보기 재생 중에도 누를 수 있다(건너뛰고 진행).

### 5. 게임 오버 (`#ovResult`, `body.ov-full`)
- 제목 "여기까지!" 24px 800 (자극적인 붉은 글씨 없음).
- 헤드라인: `레벨` + `.num` 56px 도달 레벨 + 같은 줄에 `<span id="lbSlot"></span>`(flex-wrap, 실험실에서는 비어 있음. 출시 때 순위 칩 자리). 새 최고면 그 아래 `--gold` 테두리 알약 "새 최고 기록".

- 마지막 라운드 미니 요약: 곰 머리 3개(지름 40, 목도리 띠·번호) 아래 `.num` 숫자와 정답 체크/내 선택 X — 해설을 다시 한 번 압축해 보여 줌.
- 버튼: `다시 하기`(주, 52, Enter) / `게임 목록`(secondary, `.ov-home`).

## 애니메이션·이펙트 (지속시간 ms, easing)

### 먹기 한 번 (핵심 — 빠른 레벨에서도 한 번 한 번 구분되게)
design.md가 정하는 값: 레벨별 **도착 간격**. 이 문서는 아래 화면 제약을 요구한다.
- `G` = 연속된 두 먹기(곰 무관)의 도착 시각 차이. **G ≥ 220ms 필수**(어떤 레벨에서도 두 연어가 동시에 입에 닿지 않는다).
- `Gs` = 같은 곰의 연속된 두 먹기 차이. **Gs ≥ 380ms 필수**(말풍선·입이 한 번 닫혔다 다시 열리는 것이 보여야 2번으로 셀 수 있다).
- 위 두 하한을 design.md의 최고 속도가 넘지 못하게 한다(넘으면 레벨 상승은 연어 수·라운드 길이로 난이도를 올린다 — CEO 조정 사항).

| 단계 (도착 시각 t=0 기준) | 내용 | ms | easing |
|---|---|---|---|
| 물튀김 | 출발점에 `--ripple` 고리(ellipse rx 0→34, α .9→0) + 물방울 3개 | 260 | ease-out |
| 비행 | 출발 `(cx + r, yF + 70)` (r = −90…+90 무작위, 자기 열 안), 제어점 `(중간x, yF − 122 − 110)`, 도착 입 `(cx, yF − 122)`의 2차 베지어. 접선 방향 회전 | `F = clamp(1.3 × G, 300, 620)` | 시작 ease-out, 전체 cubic-bezier(.3,.6,.4,1) |
| 고개 들기 | `.head` rotate 0→−5°, 도착 120ms 전부터 | 120 | ease-out |
| 입 벌림 | mouth-open 표시, 도착 100ms 전 | 즉시 | — |
| 삼킴 | 연어가 입에서 scale 1→.3, α 1→0 | 80 | ease-in |
| 와앙 | 입 닫힘(t+60), `.head` rotate→0 + translateY 0→3→0 | 140 | ease-out |
| 냠 말풍선 | scale .7→1 + α (90) / 유지 / α→0 (90). 전체 `Y = min(360, Gs − 40)` | Y | ease-out |
- **한 번에 날고 있는 연어는 최대 3마리**(F ≤ 620, G ≥ 220 이면 자동으로 지켜짐). 같은 곰을 향하는 연어는 동시에 최대 2마리.
- 같은 곰에 말풍선이 떠 있는데 다음 먹기가 오면: 말풍선을 끄고(α 0, 40ms) **다시 팝**한다(이어 붙여 늘리지 않음 — 한 번 = 한 팝).
- 출발점 r은 매번 무작위이므로 연어의 출발 위치가 정답을 알려 주지 않는다. 비행 경로는 자기 열 폭(±150)을 넘지 않는다.
- 사운드 연동: **도착 시각 t=0에 "냠" 소리 트리거**(Sound Designer와 맞춤). 물튀김 소리는 출발 시각.
- 라운드 종료 처리: 마지막 말풍선 사라짐 → 입 다문 상태·머리 각도 0·물튀김 없음 확인 → 400ms 정적 → 선택 단계. **끝난 뒤 곰 셋의 그림은 픽셀 단위로 똑같은 상태**(목도리 제외)여야 한다.

| 이펙트 | 내용 | ms | easing |
|---|---|---|---|
| 준비 카운트다운 | 띠의 점 3개 하나씩 채움, 곰 셋 동시에 고개 −3°(강을 봄) | 3 × 350 | linear |

| 호버/포커스 | 곰 translateY −4, 번호 원 scale 1.1 | 120 | ease-out |
| 판정 체크/X | scale .6→1, α | 200 | cubic-bezier(.3,1.4,.5,1) |
| 오답 곰 | translateX 0→−4→4→0 한 번(작게) | 240 | ease-in-out |
| 집계 판 등장 | translateY 12→0 + α | 200 | ease-out |

- 움직임은 `transform`/`opacity`만. SVG 그룹은 `transform-box: fill-box` 또는 지정한 `transform-origin`(px, 심볼 좌표). 비행은 requestAnimationFrame으로 위치·각도를 매 프레임 계산(CSS 애니메이션 아님) — 일시정지·탭 숨김과 동기화하기 위해서.
- **`.app`·`.stage`와 그 조상에는 transform/filter 금지**(ov-full position:fixed 보호, parrot-beat 교훈).
- 화면 흔들림·번쩍임 없음.

### 모션 줄이기 (`prefers-reduced-motion: reduce`)
연어가 날아와 먹히는 것이 정보 그 자체이므로 **먹기 표시는 남기고 이동만 줄인다.**
- 비행 대신: 연어가 **입 아래 40단위 지점에 나타나**(α 0→1 80ms) 위로 24단위만 직선 이동(160ms linear) 후 사라짐(α 80ms). 물튀김 고리는 α만(크기 고정).
- 입 벌림·닫힘·냠 말풍선(α만, scale 없음)은 그대로. 고개 들기·와앙 흔들림 없음.
- 숨쉬기·물결·오답 흔들기·호버 이동 없음. 눈 깜빡임은 유지(정적 그림처럼 보이지 않게, 짧은 상태 교체).
- 해설 다시보기: 미니 연어가 이동 없이 α 80ms로 추가, 간격 d 그대로(정보 전달 속도는 같게). 체크/X는 α만.
- 레벨 속도·하한(G, Gs)은 같다(난이도는 바꾸지 않는다).

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)
- **곰 선택 버튼은 열 전체**(최소 114 × 129px 실측, 요구 64 이상). 곰 그림 밖의 빈 하늘·둑을 눌러도 그 열의 곰이 선택된다. 열 사이 경계는 씬 x 330·630 단위.
- 입력은 `pointerup`이 아니라 **`click`**(실수로 쓸어 넘길 때 오선택 방지). `touch-action: manipulation`으로 지연 제거. 선택 직후 300ms 동안 추가 입력 무시(두 번 탭으로 다른 곰이 눌리지 않게).
- 라운드 중 무대 탭: 반응 없음. 해설 재생 중 무대 탭: 다시보기 건너뛰기.
- **iPad Safari**: `body { touch-action: manipulation; user-select:none; -webkit-user-select:none; -webkit-touch-callout:none; -webkit-tap-highlight-color: transparent; }`, `dblclick`·`gesturestart`에 `preventDefault`(더블탭 확대·핀치 방지). 가로 스크롤 금지, 무대 스크롤 없음. 길게 누르기 메뉴 없음(SVG 텍스트 선택도 막음).
- 기타 버튼(시작·다음 레벨·다시 보기·결과·다시 하기·상단 바)은 44 × 44 이상(주 버튼 48~52).
- **키보드**:
| 키 | 동작 |
|---|---|
| 1 / 2 / 3 (숫자열·키패드) | 선택 단계: 1번(왼쪽)/2번(가운데)/3번(오른쪽) 곰 선택 |
| ← / → + Enter | 선택 단계: 곰 포커스 이동 후 선택(포커스 링 = 발밑 링 `--accent`) |
| Enter | 시작 화면: 시작 / 해설: 주 버튼(다음 레벨·결과 보기) / 결과: 다시 하기 |
| R | 해설: 느리게 다시 보기 |
| Space | 해설 재생 중: 건너뛰기 |
| P, Esc | 일시정지 열기/닫기 |
| M | 음소거 |
| 조합키(Ctrl/Meta+…) | 무시(브라우저 기본 동작) |
- PC(`hover:hover and pointer:fine`)에서만 번호 원 옆에 키 라벨이 따로 보이지는 않는다 — **번호 원 자체가 키 번호**다. 안내 띠의 키캡 `1 2 3`이 이를 알려 준다.
- 라운드 중 숫자키는 무시(미리 눌러 두기 불가).

## 접근성 (대비, 색 외 구분 수단)
- **곰 구분**: 목도리 색 + 무늬(민무늬/줄무늬/물방울) + 가슴 번호 + 자리. 해설 판·먹은 순서 띠·결과 미니 요약 모두 번호를 같이 쓴다.
- **정답/오답**: 색 + 모양(체크/X, 실선 링/점선 링) + 단어("정답"/"내 선택", "맞았어요"/"아쉬워요").
- **대비**: 글자는 `--ink`, `--muted`, `--good-ink`, `--loss-ink`, `--b1-ink`~`--b3-ink`만(패널·`--well` 대비 4.5:1 이상). `--bN`, `--good`, `--danger`, `--accent` 링은 비텍스트 3:1 이상. 집계 판(`--panel` α .82) 위 숫자도 `--bN-ink`.
- **스크린 리더**:
  - 선택 버튼 `aria-label="1번 곰, 청록 민무늬 목도리"`(무늬 단어 포함). 라운드 중에는 `aria-disabled="true"`.
  - 안내 띠 `aria-live="polite"`: "잘 보세요" → "누가 제일 많이 먹었을까? 1, 2, 3 중에서 고르세요" → "맞았어요. 정답 2번 곰".
  - **라운드 중 먹기마다 읽어 주지 않는다**(시각 게임이므로 이벤트 낭독은 게임을 대신 풀어 줌). 대신 해설이 끝나면 하단 문장을 `aria-live`로 한 번 읽음.
  - 집계 판 `role="img" aria-label="2번 곰 9마리"`. 먹은 순서 띠 `aria-hidden`(문장으로 대체).
  - 씬 SVG 장식 `aria-hidden="true"`.
- **포커스 링**: 공통 `outline: 3px solid var(--accent); outline-offset: 2px`. 곰 선택 버튼은 outline 대신 발밑 링을 `--accent`로(투명 버튼의 사각 outline이 곰을 가리지 않게) + `:focus-visible`일 때만.
- 1초에 3번 넘게 번쩍이는 효과 없음(말풍선 팝은 위치 이동 없는 작은 면, 화면 전체 번쩍임 아님).

## 개발자 체크리스트 (요약)
1. 세 곰은 **털 같고 목도리(색+무늬)+번호+자리**로 구분. 키 1/2/3 = 왼→오.
2. **공정성**: 라운드 후 곰 그림 상태가 완전히 같아야 함(입 닫힘, 각도 0, 말풍선·물튀김·연어 잔여 없음, 배 크기 고정, 곰별 숫자 없음). 눈 깜빡임은 무작위·무관.
3. 먹기 한 번 = 물튀김 → 베지어 비행(F = clamp(1.3G, 300, 620)) → 입 벌림 → 삼킴 → 와앙 → "냠" 팝. **G ≥ 220, Gs ≥ 380**을 design.md 속도 곡선이 지키는지 확인. 같은 곰 연속 먹기는 말풍선을 다시 팝.
4. 씬은 viewBox 폭 960·VH 가변 SVG 하나, 곰 x 180/480/780. 선택 버튼은 열 전체 투명 버튼(≥ 64px, 실측 최소 114).
5. 해설: 체크/X 판정 → 곰 아래 판에 **먹은 순서대로 미니 연어가 5개씩 줄 맞춰 쌓임** + 숫자 + 먹은 순서 띠 → "제일 많이" → 한 줄 문장. `느리게 다시 보기`(0.5배속 실제 재생 + 누적 칩). 탭/Space로 건너뛰기.
6. 게임 오버 헤드라인 레벨 숫자 옆 `<span id="lbSlot">`(실험실은 비움, leaderboard.js 로드 안 함).
7. BearDigits 서브셋: 이름 교체, "Pretendard" 문자열 0, OFL.txt 동봉, 글리프 `0-9 + , - . / ×`, tnum.
8. 상단 바·버튼·오버레이 CSS는 parrot-beat 복사, `.app`·`.stage` 조상 transform 금지, `--app-h`, 안전 영역, 8개 화면 + 다크 스크롤 0.
9. reduced-motion: 비행 → 입 아래 짧은 직선 상승, 말풍선 α, 숨쉬기·물결 정지. 난이도는 동일.
10. lab/index.html 카드 맨 앞 + `--tile-bear` 3곳.
