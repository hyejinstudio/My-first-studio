### 버그
- **[높음] 헛물기 특수 해설 문장의 조건이 기획서와 다르고, 근거가 틀린 설명이 자주 나옴**
  - 증상: 오답 때 "X는 a마리 먹고 b번 헛물었어요. 헛물기까지 세면 a+b번이라 많아 보였을 거예요."가 나온다. 이 문장은 "고른 곰의 진짜+헛물기 ≥ 정답 곰의 **진짜만**"이면 나온다. 그런데 다른 곰도 헛물기를 했다면, 헛물기까지 세어도 고른 곰이 최다가 아닌 경우가 많다. 이때 문장은 틀린 이유를 대고, 다른 곰의 헛물기 정보("헛물기 N번은 먹은 게 아니에요 (…)")는 문장에서 빠진다.
  - 실제 재현 예: `?seed=1&level=15`(또는 `__bear.start(1,15)`). counts 9/7/10, fakes 2/0/2에서 1번(단풍) 선택 → "단풍(1번)은 9마리 먹고 2번 헛물었어요. 헛물기까지 세면 11번이라 많아 보였을 거예요." 그러나 헛물기까지 세면 솔방울은 12번이라 여전히 더 많다. 솔방울의 헛물기 2번은 문장에 나오지 않는다(패널에는 표시됨).
  - 빈도(레벨당 2,000라운드 × 오답 2가지): 특수 문장이 나오는 오답 가운데 "헛물기를 더해도 고른 곰이 최다가 아님"인 경우가 L8~10 656/약 2,200, L11~13 약 1,070/2,480, L14~16 약 1,410/2,770. 다른 곰 헛물기 누락은 L11 이후 특수 문장 전부다.
  - 기대: design.md "해설 3." — "헛물기를 더했을 때 고른 곰이 최다가 되는 오답이면" 특수 문장을 쓴다. 즉 모든 곰을 진짜+헛물기로 셌을 때 고른 곰이 최다(또는 동률 최다)일 때만 쓴다. 그 밖에는 일반 문장을 쓴다. 특수 문장을 쓸 때도 다른 곰의 헛물기가 있으면 일반 문장(헛물기 합계·곰별 내역)을 함께 보여 주는 것을 권장한다.
  - 위치: `lab/games/hungry-bear/index.html` 1846행 `if (!last.ok && f[p] > 0 && c[p] + f[p] >= c[w])`. 비교 대상을 `max(c[b]+f[b], b≠p)`로 바꾸면 된다.
- **[낮음] 레벨 6 배너(헛물기 시연) 중 일시정지·화면 이탈 → 재개하면 배너 없이 카운트로 넘어감.** `pause()`가 banner 단계를 void로 바꾸고 `resume()`이 `startPrep(300)`을 부르기 때문이다(2103·2127행, 코드 확인만 함). 헛물기를 처음 설명하는 배너를 놓칠 수 있다. 기대: 배너를 다시 보여 준다.
- **[낮음] 곰을 고른 직후(판정까지 300ms) 일시정지하면 판정·해설·집계가 오버레이 뒤에서 진행된다.** 재현: 선택 화면에서 1을 누르고 곧바로 P를 누른다 → 오버레이 아래에서 screen=explain. 결과는 이미 정해져 있어 공정성 문제는 아니고, 집계 애니메이션을 못 보는 정도다(2097~2119행).

### 밸런스 의견 (수치 근거)
- 1~3레벨: L1은 1초 간격, 최다−2위 3, N 8~10, 동시·헛물기 없음이다. 최다 곰이 5~6마리, 나머지가 1~3마리라 대충 봐도 맞힌다. 튜토리얼 의도에는 맞지만 처음 2라운드(약 35초)는 지루할 수 있다. L3부터 차이가 2라 집중이 필요하다. 1~2레벨을 그대로 두되 L2 간격을 750까지 당기는 정도는 고려할 만하다(선택 사항).
- 고레벨: L7부터 차이 1 + 역전 규칙이다. L12부터는 380ms 간격에 동시 약 25%, 비행 494ms라 화면에 연어가 최대 3~4마리 동시에 떠 있다(실측). 21~31마리를 세 곰으로 나눠 1마리 차이를 가려야 하므로 L10 이후는 숙련자에게도 운이 크게 작용할 것으로 본다. 목숨이 2개라 기획 목표(6~9레벨에서 게임 오버)와 대체로 맞는다고 판단한다. 다만 사람이 직접 해 본 체감은 **미검증**이다(자동화 환경이라 사람 플레이 불가).
