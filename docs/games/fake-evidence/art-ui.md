# 증거 조작범 아트·UI 명세

> slug: `fake-evidence` · 함께 볼 문서: `design.md`(점수·사건 수·힌트·타이머 유무), `cases.json`(사건 데이터), `sound.md`.
> **수치·규칙은 design.md가 우선**하고, 이 문서는 "어떻게 보이고 어떻게 누르는지"만 정한다. 아래 점수 숫자(+100 등)는 자리 표시용이다.
> 그래픽: 모든 그림은 **인라인 SVG(DOM) + CSS**. Canvas 없음, 이미지 파일 없음. 게임 화면에서 이모지를 그래픽으로 쓰지 않는다(아이콘은 아래 SVG 세트).
> 오리지널 원칙: 특정 추리 게임(법정·탐정물)의 로고·캐릭터·"이의 있음" 같은 연출·문구를 따라 하지 않는다. 사람 캐릭터 없음 — 사건 파일과 증거 카드만으로 보여 준다.

## 스타일 콘셉트
- **"조용한 수사 보드"**: 종이색 책상 위에 마닐라색 **사건 파일**(왼쪽/위)이 펼쳐져 있고, 오른쪽/아래에 **증거 카드 6장**이 3×2(폰 세로는 2×3)로 놓여 있다. 판정 때만 가짜 카드에 **"조작" 도장**이 찍히고, 가짜 카드와 그것과 모순되는 정보가 **벽돌색 실(연결선)**과 **같은 번호 배지**로 이어진다.
- **글보다 보고 배우기**: 글이 많은 게임이므로 정보 위계를 엄격히 한다.
  1. 아이콘(무슨 증거인지) → 2. 제목(한 줄) → 3. **시간 칩**(시계 아이콘 + "오후 7시") → 4. 짧은 요약 → 5. 세부(열람해야 보임).
  - 증거 4종류는 **아이콘 타일 바탕색**으로 묶는다(흔적 / 기록 / 물건 / 환경). 색은 보조이고 아이콘 모양이 1차 구분.
  - 해설은 긴 글보다 **연결 그림(가짜 카드 ↔ 근거)** + **문구 하이라이트**가 먼저 보이고, 글은 3문장 이내.
- **눈 피로 최소화 (사용자 누적 취향)**: 낮은 채도, 그라데이션·광택·그림자 강조·화면 흔들림·전체 번쩍임 없음. 움직임은 짧고 작게(이동 ≤ 8px, 확대 ≤ 1.25 — 도장만). 오답도 조용하게(빨간 경고색 대신 회색 점선 + ×).
- 스튜디오 공통: `--bg` 종이색, 흰 패널, 주황 `--accent` 주 버튼, 둥근 모서리, 면 색 차이로 구분. 상단 바·버튼·오버레이 CSS는 박자 앵무새/붕어빵 눈싸움의 `.top`, `.home`, `button.icon`, `button.primary`, `button.secondary`, `.overlay`, `body.ov-full`, `.sr`, `tb-760/640/420` 구조를 **그대로 복사**한다.
- 글꼴: 글자 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. 숫자(점수, 사건 n/5, 증거 번호, +점수, 결과 큰 숫자, 시간 칩 숫자)는 **CaseDigits**.

### 숫자 글꼴 CaseDigits (Pretendard ExtraBold 800 서브셋, SIL OFL 1.1)
- 기존 게임(`games/parrot-beat/fonts/beat-digits-800.woff2` + `OFL.txt`)과 같은 절차. 원본 Pretendard **ExtraBold(800)**.
- 파일: `games/fake-evidence/fonts/case-digits-800.woff2` + 같은 폴더 `OFL.txt`.
- 글리프: `0-9`(U+0030–0039), `+`(U+002B), `/`(U+002F, "2/5"), `:`(U+003A, 시간 표기 대비). **`tnum` 유지**. 다른 게임 서브셋은 `/`·`:`가 없으므로 재사용 금지.
- **Reserved Font Name 때문에 이름 변경 필수**: family/full/PostScript/typographic 이름 모두 `CaseDigits`, 압축 해제 바이트에 "Pretendard" 문자열 없음(QA가 기존과 같은 fontTools 검사). 원본을 못 받으면 CEO에게 보고.
- `@font-face`의 `unicode-range: U+0030-0039, U+002B, U+002F, U+003A` → 한글이 섞인 시간 칩("오후 7시")에 `--num-font`를 줘도 한글은 시스템 글꼴로 자연스럽게 떨어진다.

## 화면 구성 요소

### 1) 사건 파일 패널 `.case`
```
┌ 사건 파일 02 ─────────────┐   ← 탭 라벨: 11px 700 --folder-ink, 숫자 .num
│ [문] 잠긴 미술실            │   ← 장소 아이콘 20 + 제목 20px 800
│ 오후 5시에 잠긴 미술실에서   │   ← 사건 소개 15px --ink, 최대 3줄(넘치면 패널 안 스크롤)
│ 그림 한 점이 사라졌다.      │
│ ── 추가 정보 ──            │   ← 12px 700 --folder-ink + 1px 선
│ [비] 오후 6시부터 비      ⏱6시 │   ← 사실 행: 타일 28 + 14px 글 + 시간 칩(있으면)
│ [잠금] 미술실 5시에 잠김   ⏱5시 │
│ [해] 8시 사진 속 강한 햇빛     │
└───────────────────────────┘
```
- 바탕 `--folder`, 1px `--folder-edge`, radius 14, 왼쪽 위에 탭 모양(높이 22, 폭 내용+20, radius 8 8 0 0, 같은 색)이 패널 위로 살짝 튀어나온다(패널 `margin-top: 14px`).
- **사실 행** `.fact`: 최소 높이 40, radius 10, 패딩 6 8, 바탕 투명. 아이콘 타일 28×28(radius 8, 아이콘 18). 판정 때 근거가 되면 아래 「판정」 상태로 바뀐다.
- 사실 문구는 짧아야 한다(**한 행 24자 이내 권장 — Game Designer에게 전달**). 넘치면 2줄 줄바꿈 허용.

### 2) 증거 카드 `.ev` (6장, `<button>`)
```
┌──────────────────────┐
│ 3                 ◉  │ ← 증거 번호 .num 12px --muted(왼쪽 위) · 상태 표식(오른쪽 위, 18px)
│ ┌────┐               │
│ │CCTV│ CCTV 기록       │ ← 아이콘 타일 40(종류색) + 제목 16px 700, 최대 2줄
│ └────┘               │
│ (⏱ 오후 7시)          │ ← 시간 칩(데이터에 시간이 있을 때만)
│ 복도를 지나는 사람이     │ ← 요약 13px --muted, 최대 2줄 (작은 카드에선 숨김)
│ 찍혀 있다             │
└──────────────────────┘
```
- 바탕 `--card`, 1px `--grid`, radius 14, 패딩 10 12, 그림자 없음. 내용은 위 정렬, 남는 높이는 아래 여백.
- **시간 칩** `.tchip`: 높이 24, radius 999, 패딩 0 8, 바탕 `--bg`(다크 `--well`), 1px `--grid`, 시계 아이콘 14 + 13px 700 글자, 숫자는 `--num-font`. 같은 모양을 사실 행·세부 패널·해설에서 반복해 "시간끼리 비교"가 눈에 들어오게 한다.
- 카드 크기에 따른 단계(카드 실제 크기로 판단 — `ResizeObserver` 또는 컨테이너 쿼리 `@container`):

| 카드 폭 × 높이 | 아이콘 타일 | 제목 | 시간 칩 | 요약 |
|---|---|---|---|---|
| ≥ 200 × 160 | 44 | 16px, 2줄 | 보임 | 2줄 |
| ≥ 150 × 120 | 36 | 15px, 2줄 | 보임 | 숨김 |
| 그보다 작음 | 30 | 14px, 2줄 | 보임(아이콘 12, 글 12px) | 숨김 |

#### 증거 카드 상태
| 상태 | 테두리 | 바탕 | 오른쪽 위 표식 | 기타 |

| 기본(안 봄) | 1px `--grid` | `--card` | 없음 | — |

- **"조작" 도장** `.stamp`: 카드 오른쪽 아래 기준 absolute, 글자 "조작" 16px 800 `letter-spacing .12em` `--thread`, 테두리 2px `--thread` + 안쪽 1px 선(이중 테두리, `outline: 1px solid; outline-offset: -5px`), radius 6, 패딩 4 10, 바탕 `--card` α .85, rotate(−8°). 작은 카드에서는 13px. 카드 내용(제목)을 가리지 않도록 아래 오른쪽.
- **연결 번호 배지** `.lnk`: 원 20, `--thread` 채움, 흰 숫자 `.num` 12px. 해설 연결 그림의 번호와 같다(①이 그림의 1번 선). 가짜 카드에는 번호 대신 작은 연결 아이콘(고리 2개 14px) 배지.

### 3) 세부 패널 `.detail` (증거 열람)
```
[◀]  증거 3 / 6  [▶]                     [×](시트일 때만)
┌────┐
│CCTV│ CCTV 기록                          ← 타일 48 + 제목 20px 800
└────┘
 ⏱ 오후 7시   📍 2층 복도                  ← 속성 칩 줄: 시간·장소·상태(있는 것만, 아이콘+글)
 ─────────────────
 2층 복도 카메라. 오후 7시 3분, 우산을    ← 세부 설명 16px --ink, 줄간격 1.55
 든 사람이 미술실 쪽으로 걸어간다.
 ─────────────────
 [ 🔍 이 증거가 가짜다 ]                   ← primary, 폭 100%
```
- 속성 칩은 시간 칩과 같은 모양(아이콘은 SVG — 위 그림의 기호는 설명용).
- `◀ ▶`(각 44×44 `button.icon`)으로 닫지 않고 다음/이전 증거로 넘긴다 = **비교하며 읽기**. 넘길 때 내용만 120ms 크로스페이드.
- 지목 버튼: 아이콘 돋보기 + "이 증거가 가짜다". 이미 지목한 카드면 버튼이 "지목 취소"(secondary)로 바뀐다. 다른 카드를 지목하면 이전 지목은 자동 해제(지목은 1장만).
- 아무 카드도 안 열었을 때(와이드 레이아웃 빈 상태): 가운데에 손가락 탭 아이콘 32 `--muted` + "증거 카드를 눌러 자세히 보세요" 14px `--muted`.

### 4) 이유 선택 `.reason`
```

│ (1) 사진 속 햇빛이 비 오는 날씨와 맞지 않는다 │  ← 선택지 버튼, 최소 높이 56
└──────────────────────────────────┘
│ (2) …                                     │
│ (3) …                                     │
│ (4) …                                     │
[        판정하기        ]                ← primary 폭 100%, 선택 전 disabled
```

### 5) 판정·해설 `.verdict` (이유 패널이 있던 자리를 그대로 대체)
```
 ✓✓ 정확한 추리                   +150    ← 결과 머리줄: 아이콘 + 18px 800 + 점수 .num 20 --ok
 ┌ ✓ 가짜 증거   오후 8시 사진         ┐    ← 판정 2행(각 40): ✓/× + 항목 + 내 답
 └ ✓ 조작 이유   햇빛 ↔ 비            ┘
 ── 연결 그림 ───────────────────────
 ┌──────────────┐        ┌───────────────┐
 │[사진] 오후 8시 사진│──①──│[비] 6시부터 비    │
 │  [조작]         │        └───────────────┘
 │ "햇빛이 강하게"   │──②──┌───────────────┐
 └──────────────┘        │[잠금] 5시에 잠김  │
                          └───────────────┘
 오후 6시부터 비가 왔으니 8시에 강한 햇빛이 비칠 수 없어요.   ← 해설 15px, ≤ 3문장, 핵심어 굵게
 [        다음 사건 →        ]            ← primary (마지막 사건: "결과 보기")
```
- **결과 머리줄 3종**(글 + 아이콘 + 색):
  | 경우 | 아이콘 | 문구 | 색 |
  |---|---|---|---|
  | 가짜·이유 모두 맞음 | 체크 두 개 겹침 | 정확한 추리 | `--ok` |
  | 가짜만 맞음 | 체크 1 + 빈 원 | 증거는 맞혔어요 | `--ok`(아이콘), 글 `--ink` |
  | 가짜 틀림 | 빈 원 안 × | 다른 증거였어요 | `--miss` |
  (문구는 design.md에 따로 있으면 그쪽)
- **판정 2행**: 맞음 = `--ok-tint` 바탕 + ✓ `--ok`; 틀림 = `--panel` 바탕 + × `--miss` + 내 답 취소선 없이 `--muted`, 그 아래 줄에 "정답: …" 14px `--ink`(정답 아이콘 ✓ `--ok`).
- **연결 그림** `.links` (핵심 — "보고 배우기"):
  - 왼쪽 노드 = 가짜 증거(타일 28 + 제목 14px 700 + 도장 미니 "조작" 11px + 인용 1줄), 테두리 2px `--thread`.
  - 오른쪽 노드 1~3개 = 모순 근거. 종류 꼬리표 11px `--muted`("추가 정보" 또는 "증거 2"), 타일 28 + 짧은 글 + 인용, 바탕 `--thread-tint`, 1px `--thread` α .5.
  - 선: 왼쪽 노드 오른쪽 가운데 → 각 오른쪽 노드 왼쪽 가운데, 3차 베지어, 2px `--thread`, 끝 둥글게. 선 가운데에 번호 배지 `.lnk`(보드의 배지와 같은 번호).
  - **인용 하이라이트** `mark.hl`: 바탕 `--thread-tint`, 글자 `--ink`, 아래 2px `--thread` 밑줄(`text-decoration-thickness: 2px; text-underline-offset: 3px`), radius 3. 가짜 쪽 문구와 근거 쪽 문구가 짝으로 보인다. (예: "햇빛이 강하게" ↔ "오후 6시부터 비")
  - 노드와 선은 **같은 컨테이너 안**에 있어 레이아웃이 달라도 항상 함께 보인다. SVG는 컨테이너 기준 absolute, 좌표는 컨테이너 안 노드 위치(`offsetLeft/Top`)로 계산, 컨테이너 `ResizeObserver`로 다시 그림.
  - 컨테이너 폭 < 440px: **세로 배치** — 가짜 노드 위(폭 100%), 근거 노드는 아래로 쌓고(왼쪽 들여쓰기 28px), 선은 가짜 노드 아래 왼쪽(x=14)에서 내려와 각 근거 노드 왼쪽 가운데로 꺾이는 가지(가지 모서리 radius 8). 번호 배지는 각 가지의 꺾이는 지점.
- **보드 동시 표시**: 판정 순간 보드에서 가짜 카드 도장, 근거 사실 행/근거 카드에 `--thread-tint` 바탕 + 왼쪽 3px `--thread` 막대 + 번호 배지 + 해당 문구 `mark.hl`. 패널을 닫거나 스크롤해도 보드에 남아 있다(다음 사건으로 넘어갈 때 지움).
- 판정 후 카드는 여전히 열람 가능(세부 패널에 하이라이트 포함 표시), 지목은 불가.

## 레이아웃 (PC / iPad 세로 / iPad 가로 / 폰)

공통: `html, body { height: var(--app-h) }`(박자 앵무새와 같은 `--app-h` 계산), `.app`은 세로 flex(상단 바 + 무대), 안전 영역 패딩 `max(12px, env(safe-area-inset-*))`. **페이지 스크롤 0, 가로 스크롤 0.** 넘칠 수 있는 곳은 패널 내부 스크롤(`overflow-y: auto; touch-action: pan-y; overscroll-behavior: contain`)뿐이고 **증거 그리드는 절대 스크롤하지 않는다**(6장이 한눈에 보여야 비교 가능).

무대 모드는 JS가 `.app` 크기(W×H, 상단 바 제외 전)로 정해 `body`에 클래스 1개를 단다:

| 모드 | 조건 | 대표 기기 |
|---|---|---|
| `lay-wide` | W ≥ 900 그리고 W ≥ H 그리고 H > 500 | PC, iPad 가로(1180×820, 1024×768) |
| `lay-tall` | W ≥ 600 그리고 H > 500 (`lay-wide` 아님) | iPad 세로(820×1180, 768×1024), 좁은 PC 창 |
| `lay-phone` | W < 600 그리고 H > 500 | 폰 세로(390×844, 375×667, 360×640) |
| `lay-short` | H ≤ 500 | 폰 가로(844×390, 740×342, 667×375, 568×320) |

### `lay-wide` (PC, iPad 가로)
```
[← 게임 목록] 증거 조작범        [사건 2/5 ●●◐○○] [점수 240] [🔈][Ⅱ]   ← 상단 바 52
┌ 왼쪽 열 340 (PC ≥ 1280: 380) ─┐ ┌ 증거 그리드 3×2 ─────────────────┐
│ 사건 파일 (내용 높이, 최대 45%) │ │ [1]      [2]      [3]            │
│ ─────────                    │ │                                  │
│ 세부 / 이유 / 판정 패널         │ │ [4]      [5]      [6]            │
│ (남은 높이, 안쪽 스크롤)        │ │ 본 증거 ●●●○○○ 3/6               │ ← 그리드 아래 상태 줄 28
└──────────────────────────────┘ └──────────────────────────────────┘
```
- 열 간격 12, 그리드 gap 12. 카드 크기 = 그리드 영역을 3×2로 나눈 값, 단 카드 높이 최대 260·폭 최대 300(넘치면 그리드를 가운데 정렬).
- 사건 파일이 길면 파일 패널 자체가 최대 45% 높이까지, 넘치면 그 안에서 스크롤.
- 1180×820 기준: 그리드 폭 ≈ 1180−24−340−12 = 804 → 카드 ≈ 260×(820−24−52−8−28−12)/2 ≈ 260×348 → 높이 260으로 제한.
- 1024×768: 카드 ≈ 216×≈ 256.

### 그리드 아래 상태 줄 "본 증거"

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)

- 버튼 크기: 상단 바 44×44, primary 48 높이, secondary 44, 이유 선택지 ≥ 56(폰 가로 ≥ 48), 시트 × 44×44, 세부 ◀▶ 44×44, 텍스트 버튼("바꾸기", "펼치기")은 글자가 작아도 터치 영역 44(`::after` 확장).

## 접근성 (대비, 색 외 구분 수단)
- **색 외 구분**:
  - 지목: 두꺼운 테두리 + 돋보기 배지 + "지목" 글자 띠.
  - 정답/가짜/내 오답: ✓ 배지 / "조작" 도장(글자) / 점선 + × + "내 지목" 글자. 흑백으로도 구분.
  - 모순 연결: 선 + **같은 번호 배지**(보드·그림 양쪽) + 하이라이트 밑줄(바탕색만이 아님).
  - 증거 종류: 아이콘 모양이 1차, 타일 색은 보조.
  - 진행 점: 채움/반 채움/빈 원/굵은 테두리.
- 대비: 글자 `--ink`/`--muted`(공통, 4.5:1 이상). `--pick`·`--thread`·`--ok` 글자·테두리는 패널 대비 5:1 이상(토큰 표 참고). `--miss`는 라이트에서 `--muted`와 같은 값(흰색 대비 4.8:1).
- **마크업·aria**:
  - 증거 그리드 `<ul role="list" aria-label="증거 6개">`, 카드 `<li><button>` + `aria-label="증거 3, CCTV 기록, 오후 7시, 봤음, 지목함"`(상태 바뀌면 갱신). 열람 중 카드 `aria-current="true"`.
  - 세부 패널 `role="region" aria-label="증거 자세히" aria-live="polite"`(와이드/세로 태블릿). 시트는 `role="dialog" aria-modal="true" aria-labelledby=제목`, 열면 제목에 포커스, 닫으면 원래 카드로 포커스 복귀, 시트 안 포커스 가둠.
  - 이유 `role="radiogroup" aria-labelledby="왜 조작됐을까?"`, 선택지 `role="radio" aria-checked`. [판정하기] `aria-disabled` 상태 반영.
  - 판정: 숨김 `aria-live="polite"`에 한 줄 — "정확한 추리. 가짜는 오후 8시 사진. 이유: 사진 속 햇빛이 비 오는 날씨와 맞지 않음. 150점." 연결 그림 SVG는 `aria-hidden`, 노드들은 `<ol aria-label="모순 연결">` 목록(①…)으로 읽힌다.
  - 아이콘 SVG 전부 `aria-hidden="true"`(옆 글자가 의미 전달). 도장 "조작"은 실제 텍스트.
- 포커스 링: 공통 `outline: 3px solid var(--accent); outline-offset: 2px`. 카드는 radius에 맞춰 `outline-offset: 3px`.
- 글자 크기: 본문 최소 13px(폰 가로 카드 제목만 14), 세부·해설 15~16px. 줄간격 1.5 이상.
- 깜빡임 없음.

## 개발자 체크리스트 (요약)
1. **증거 그리드는 어떤 화면에서도 스크롤하지 않는다.** 6장이 동시에 보여야 한다. 넘치는 것은 사건 파일·세부·이유·판정 패널 안쪽 스크롤로만 해결.
2. 레이아웃 모드 4개(`lay-wide/tall/phone/short`)를 JS가 `.app` 크기로 정하고, 카드 내용 단계는 카드 실제 크기로 정한다(뷰포트 폭 media query만으로 정하지 않기).
3. 연결선은 **해설 패널 안의 연결 그림**에만 그린다(같은 컨테이너, `ResizeObserver`). 보드 쪽은 선 없이 **같은 번호 배지 + 하이라이트**로 연결을 보여 준다(보드↔패널 사이 선을 긋지 않음 — 시트·스크롤에서 어긋남).
4. 도장 "조작"은 텍스트, 상태는 색 + 모양 + 글자 3중. 내 오답은 빨강 금지(`--miss` 점선).
5. 판정은 2단 확정(선택지 → [판정하기]). 시트/패널 열고 닫을 때 포커스 이동·복귀.
6. `.app { touch-action: manipulation }`, 스크롤 영역 `pan-y` + `overscroll-behavior: contain`, 핀치·더블탭 확대 방지, 가로 스크롤 0.
7. 결과 화면 `#lbSlot`은 통계 줄 바로 아래, 740×342에서 결과 오버레이 스크롤 0(예산 258px).
8. CaseDigits 서브셋(0-9 + / :) 새로 만들고 이름 변경·OFL 동봉.
9. `prefers-reduced-motion`이면 도장·선·시트 애니메이션 없이 최종 모습 즉시 표시.
