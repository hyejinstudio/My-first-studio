# 붕어빵 눈싸움 기획서
- slug: bungeo-snowfight
- 한 줄 소개: 눈밭에서 붕어빵을 새총처럼 당겨 던져 눈밭을 내 색으로 칠하는 60초 땅따먹기. 묵직한 팥붕은 길을 막고, 통통 튀는 슈붕은 멀리 파고든다!
- 원안: 사용자가 직접 고안한 오리지널 게임. 아래 세 규칙은 사용자 원문이며 바꾸지 않는다.
  - 팥붕은 묵직해서 멀리 못 가지만, 맞은 자리에 오래 남아 길을 막는다.
  - 슈붕은 가볍고 통통 튀어서 멀리 날아가지만, 금방 사라진다.
  - 붕어빵을 던져 눈밭을 내 편 색으로 바꾸고, 제한 시간 안에 더 많이 차지하면 승리.
- 난이도 목표: 짧고 긴장감 있게. 컴퓨터 "보통"은 처음 하는 사람이 지기도 하는 수준(쉽게 이기면 지루하다는 사용자 취향 반영).

## 핵심 루프
모드 선택(컴퓨터 상대 쉬움/보통/어려움, 또는 2인 대결) → 3·2·1 → 팥붕/슈붕 고르기 → 뒤로 당겨 겨누기(점선 궤적 확인) → 놓아서 던지기 → 착지한 곳 주변이 내 색으로 바뀜 → 재장전 동안 상대 수를 보고 다음 수 결정(팥붕으로 길 막기 / 슈붕으로 상대 진영 파고들기) → 60초 뒤 점유 칸 수가 많은 쪽 승리.

## 규칙

### 좌표·필드
- 위에서 내려다보는 눈밭 격자 **가로 16 × 세로 10 = 160칸**. 좌표 단위는 "칸"(1칸 = 1.0). 칸 (c, r): c = 0~15(왼→오), r = 0~9(위→아래). 칸 중심 = (c+0.5, r+0.5).
- 칸 상태: 0 = 눈(중립, 흰색), 1 = P1(왼쪽, 파랑 계열), 2 = P2(오른쪽, 빨강 계열). 색은 art-ui.md.
- 초기 진영: **c 0~2 = P1(30칸)**, **c 13~15 = P2(30칸)**, 가운데 c 3~12 = 중립(100칸).
- 1인 모드에서 사람은 항상 P1(왼쪽), 컴퓨터는 P2(오른쪽).

### 발사대 (결정: 진영마다 고정 1곳)
- P1 발사대 = 필드 바깥 왼쪽 가운데 **(-0.6, 5.0)**, P2 발사대 = **(16.6, 5.0)**. 모든 붕어빵은 자기 발사대에서 출발한다.
- 이유: (1) 2인 모드에서 두 사람 손이 각자 화면 끝 쪽에 머물러 겹치지 않음, (2) 출발점이 하나라서 팥붕 장애물로 "길을 막는" 전략이 성립함, (3) AI·궤적 계산이 단순.

### 당겨서 쏘기
- **당김 시작 영역**: 1인 모드 = 버튼을 뺀 화면 아무 곳. 2인 모드 = P1은 화면 왼쪽 절반, P2는 오른쪽 절반(시작 지점 기준. 누른 뒤에는 손가락이 반대쪽으로 넘어가도 같은 손가락(pointerId)이면 계속 추적).
- 당김 벡터 = 처음 누른 점 → 현재 손가락 위치. **던지는 방향 = 당김 벡터의 반대 방향**(새총). 세기 = 당김 길이.
- 길이는 화면 px를 칸 크기(px)로 나눈 "칸" 단위로 계산(기기 크기와 무관하게 같은 손맛).

| 항목 | 값 |
|---|---|
| 최소 당김 | **0.6칸** (미만에서 놓으면 취소, 아무 일 없음, 궤적도 안 보임) |
| 최대 당김 | **3.0칸** (더 당겨도 3.0으로 고정) |
| 세기 p | (당김 − 0.6) / (3.0 − 0.6), 0~1 |
| 각도 범위 | 정면(P1은 오른쪽, P2는 왼쪽) 기준 **±60°**. 범위 밖으로 당기면 ±60°로 고정 |
| 사거리(착지점까지 거리) | 최소 + p × (최대 − 최소), 아래 종류별 표 |

- **필드 밖 착지 방지**: 계산된 착지점이 필드 안쪽 여유 영역 [0.3, 15.7] × [0.3, 9.7]을 벗어나면 같은 방향선 위에서 그 경계까지로 사거리를 줄인다(낭비 던지기 없음).
- 플레이어 던지기에는 무작위 오차 없음(보이는 대로 간다).

### 궤적 미리보기 (당기는 동안)
- 발사대 → 착지점까지 바닥 위 **점선**, 착지점에 칠해질 범위를 반투명 원으로.
- 슈붕은 착지 후 바운스 지점들까지 옅은 점선 + 작은 원 2개.
- 경로가 **현재** 상대 장애물에 막히면 점선은 막히는 지점에서 끝나고 그 자리에 × 표시(팥붕이면 "깨기" 표시, art-ui.md).
- 재장전 중에도 당겨서 겨눌 수 있다(점선 표시). 단, 재장전이 끝나기 전에 놓으면 **취소**("장전 중" 짧은 표시), 붕어빵은 나가지 않음.
- 2인 모드에서는 두 사람의 미리보기가 동시에 보인다(서로 볼 수 있음, 의도된 심리전).

### 붕어빵 2종

| 항목 | 팥붕 (묵직) | 슈붕 (통통) |
|---|---|---|
| 착지 사거리 | **2.0 ~ 8.0칸** | **3.0 ~ 11.5칸** |
| 비행 시간 | 0.30 + 0.045 × 거리 초 (8칸 = 0.66초) | 0.25 + 0.035 × 거리 초 (11.5칸 = 0.65초) |
| 착지 칠하기 반경 | **1.5** (칸 중심 기준, 보통 9칸) | **0.8** (1~4칸, 평균 약 2칸) |
| 바운스 | 없음 | 착지 후 같은 방향으로 **2번**: 2.2칸 → 1.6칸, 각 0.16초. 바운스 지점마다 반경 0.8 칠하기 |
| 최대 도달(정면) | x ≈ 7.4 (가운데까지) | x ≈ 10.9 + 3.8 = 14.7 (상대 진영 안쪽) |
| 착지 후 | **장애물**로 남음 (아래) | 마지막 바운스 후 0.3초 페이드로 **사라짐**(필드에 남지 않음) |
| 재장전 | **1.3초** | **0.8초** |

- 칠하기 규칙: 칠하기 중심에서 칸 중심까지 거리 ≤ 반경인 칸을 모두 내 색으로. 중립·상대 칸은 내 색으로 뒤집히고, 이미 내 색이면 변화 없음. **상대 장애물이 있는 칸은 칠해지지 않음**.
- 칠하기는 착지(바운스) 순간에 즉시 적용. 같은 프레임에 두 쪽이 같은 칸을 칠하면 나중에 처리된 쪽(처리 순서 = 착지 시각 순, 같으면 P2 → P1 순)이 이긴다. 실제로는 거의 없음.
- 슈붕 바운스가 위·아래 벽(y < 0.3 또는 y > 9.7)에 닿으면 반사되어 계속 튄다. 좌우 끝(x < 0.3 또는 x > 15.7)에 닿으면 그 경계 지점에서 칠하고 바운스 종료.
- **"금방 사라져"의 해석 (결정)**: 슈붕 **본체**가 필드에 남지 않는다는 뜻으로 본다. 칠해진 색은 팥붕과 똑같이 계속 유지된다.
  - 이유: 원문은 "맞은 자리에 오래 남아 길을 막아"(팥붕)와 대비되는 문장이라, 사라지는 대상은 "붕어빵(장애물)"이 자연스럽다. 칠한 색이 바래면 점수(점유 칸)가 저절로 줄어 "더 많이 차지하면 승리"가 헷갈리고, 슈붕만 쓸모없어진다.

### 팥붕 장애물 ("길을 막는다"의 정의)
- 팥붕이 착지하면 착지점에 장애물이 생기고 **8초** 동안 남는다(마지막 1.5초 깜빡임). 착지점이 속한 칸 1개가 "장애물 칸".
- **효과 1 — 칸 잠금**: 장애물 칸은 남아 있는 동안 주인 색으로 고정, 상대가 칠할 수 없다.
- **효과 2 — 길 막기**: 상대 붕어빵의 **바닥 경로**(발사대→착지점 직선, 슈붕은 바운스 구간 포함)가 장애물 중심에서 **0.55칸 이내**를 지나가면 거기서 부딪혀 멈춘다. 붕어빵은 낮게 날아간다고 본다(포물선은 연출만).
  - **상대 슈붕이 부딪힘**: 부딪힌 지점(장애물 중심에서 0.6칸 앞)에서 반경 0.8 칠하고 바로 사라짐, 남은 바운스 없음. 장애물은 그대로(가벼워서 못 깸).
  - **상대 팥붕이 부딪힘**: 장애물과 함께 **둘 다 부서짐**. 부서진 뒤 부딪힌 지점에 반경 **1.0** 칠하기(장애물 칸도 이때 칠해질 수 있음). 새 장애물은 생기지 않음. → 팥붕 벽을 깨는 방법은 팥붕뿐.
- **내 장애물은 내 붕어빵을 막지 않는다**(통과).
- 한 사람이 동시에 가질 수 있는 장애물 **최대 3개**. 4번째가 생기면 가장 오래된 것이 즉시 사라짐.
- 부딪힘 판정은 매 프레임 "현재 날아가는 위치까지의 구간"으로 한다(비행 중에 생기거나 사라진 장애물도 반영). 미리보기는 겨누는 순간의 장애물 기준.
- 붕어빵끼리 공중 충돌은 없음.

### 점수·승패
- 점수 = 내 색 칸 수. 점유율 = 칸 수 / 160 × 100 (소수 첫째 자리 반올림 표시). 중립 칸은 누구의 것도 아님.
- 제한 시간 **60초**. 0초가 되면 새 던지기 불가, 겨누던 것은 취소. **이미 날아가는 붕어빵은 끝까지 착지·바운스·칠하기 처리**(버저비터 허용, 최대 약 1.3초) → 모두 끝난 뒤 0.5초 후 결과.
- 칸 수가 많은 쪽 승리. **같으면 무승부**(연장전 없음).
- 장애물이 사라지는 것은 칸 색을 바꾸지 않는다(잠금만 풀림).

### 시간 연출
- 시작: "3, 2, 1, 시작!" 카운트다운 3초(입력 잠금). "시작!"과 동시에 두 쪽 모두 장전 완료 상태, 기본 선택 팥붕.
- 상단 남은 시간 + 양쪽 점유율 막대(줄다리기형, art-ui.md).
- **마지막 10초 "스퍼트"**: 시간 표시 빨강 + 1초마다 맥동, 재장전 시간 **×0.75**(팥붕 0.98초, 슈붕 0.6초). 마지막 3초는 큰 숫자 카운트.

### 재장전·종류 선택
- 발사대는 한 번에 하나만 장전. 던진(놓은) 순간부터 그 종류의 재장전 시간이 지나야 다음 던지기 가능. 발사대 주변 링으로 진행 표시.
- 종류 선택: 각자 발사대 옆 **팥붕/슈붕 버튼 2개**(누르면 선택, 계속 유지). 재장전 중에도 바꿀 수 있고 바꿔도 재장전 시간은 변하지 않음(이미 걸린 시간 그대로).
- PC: 숫자 **1 = 팥붕, 2 = 슈붕**, Space = 전환(1인 모드의 P1만). 2인 모드 PC에서는 버튼 클릭만.
- 버튼을 누른 터치는 당기기를 시작하지 않는다.

### 결과 화면
- 1인: "승리!" / "패배…" / "무승부", 양쪽 점유율 %, 칸 수, 던진 횟수(팥붕/슈붕), 이 난이도 최고 점유율·승리 수, 새 기록이면 "새 기록!".
- 2인: "파랑 승리!" / "빨강 승리!" / "무승부", 양쪽 점유율. 2인은 기록 저장 없음.
- 결과가 뜬 뒤 **0.8초** 동안 버튼 입력 무시(던지던 손가락 오작동 방지).
- 버튼: "다시 하기"(같은 모드·난이도로 바로 3·2·1), "처음으로"(모드 선택).

### 기록
- localStorage 키 **`bungeo-snowfight-best`**, 값 JSON: `{"easy":{"wins":0,"best":0},"normal":{...},"hard":{...}}` (best = 최고 점유율 %, 소수 첫째 자리). 1인 모드 종료마다 갱신(승리면 wins +1, 점유율이 더 크면 best 갱신, 승패와 무관).
- 시작 화면에 난이도별 "승리 N · 최고 NN.N%".
- 저장소 접근 실패·형식 오류 시 0으로 보고 정상 진행.
- 음소거 키: `bungeo-snowfight-muted` (sound.md).

### 일시정지
- **두 모드 모두** 가능. Ⅱ 버튼(화면 위 가운데, 2인 모드에서 누구나 누를 수 있음) / PC P·Esc. 탭 숨김(visibilitychange hidden) 시 자동 일시정지.
- 일시정지 시: 시간·비행·재장전·장애물 타이머·AI 모두 정지. 진행 중이던 당기기는 취소. 필드는 덮개로 가림(겨누기 엿보기 방지).
- 덮개: "일시정지" + "계속" + "처음으로".
- "계속" → **2, 1 카운트다운(2초)** 후 재개(2인 모드 공정성). 카운트다운 중 입력 무시.
- 카운트다운·결과 화면·메뉴에서는 자동 일시정지 안 함.

## 컴퓨터 AI (P2)
- AI는 실제 손가락 대신 `(종류, 각도, 세기)`를 정해 사람과 **같은 규칙**(사거리·재장전·장애물)으로 던진다.
- 장전이 끝나면 "생각 시간"을 기다린 뒤 던진다. 생각 시간의 마지막 0.3초 동안 AI의 겨누는 점선을 보여준다(긴장감·공정성).
- 목표 정하기: 후보 = 각 종류별로 도달 가능한 칸 중심(팥붕 약 60곳, 슈붕 약 100곳). 후보마다 실제 규칙으로 결과를 시뮬레이션해 점수를 매긴다.
  - 가치 = 중립→내 색 칸 수 × 1.0 + 상대→내 색 칸 수 × **2.0**(상대 감소까지 2칸 차이).
  - 막힘: 경로가 상대 장애물에 막히면 막힌 결과로 계산(대개 낮은 값). 단, 팥붕으로 장애물을 깨는 수는 +3 보너스(보통·어려움).
  - 어려움 전용 "방어 가치": 팥붕 후보마다, 사람 발사대 (-0.6, 5.0)에서 AI 소유 칸 중심으로 가는 직선 중 그 후보점 0.55칸 이내를 지나는 칸 수 × **0.3**을 더한다(내 땅 앞에 벽 세우기).
- 그 뒤 착지점에 **조준 오차**(가우시안, 표준편차 σ칸, ±2σ로 자름)를 더해 던진다.

| 항목 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 생각 시간(장전 후) | 1.0 ~ 1.6초 | **0.45 ~ 0.8초** | 0.2 ~ 0.4초 |
| 조준 오차 σ | 1.2칸 | **0.6칸** | 0.3칸 |
| 목표 선택 | 가치 상위 40% 중 무작위 | 상위 3개 중 무작위 | 최고값 |
| 종류 선택 | 50:50 무작위 후 그 종류 안에서 고름 | 두 종류 후보 모두 비교 | 비교 + 방어 가치 |
| 장애물 회피·깨기 | 고려 안 함(그냥 던짐) | 고려 | 고려 |
| 판당 예상 던지기 | 약 25회 | 약 40회 | 약 50회 |

- 의도: 사람은 겨누는 데 0.5~1.0초가 걸리므로 "보통"은 손 빠르기는 사람과 비슷하지만 계산이 정확해, 처음 하는 사람은 지기도 한다. "어려움"은 거의 쉬지 않고 던지며 벽까지 세운다.
- QA 밸런스 기준(시뮬레이션): "사람 모델"(장전 후 0.6~1.0초 지연, σ 0.5칸, 가치 최고값 고르기, 방어 없음)이 쉬움 상대 승률 ≥ 80%, 보통 상대 40~60%, 어려움 상대 ≤ 30%. AI끼리: 어려움→보통 ≥ 70%, 보통→쉬움 ≥ 70%. 벗어나면 생각 시간·σ만 조정하고 CEO에게 보고.

## 2인 모드 (한 iPad)
- P1 = 화면 왼쪽 절반, P2 = 오른쪽 절반. **각자 동시에 멀티터치**(pointerId별로 독립 추적, 한 사람당 동시 당기기 1개 — 이미 당기는 중이면 그쪽의 추가 손가락은 무시).
- 각자 자기 쪽에 팥붕/슈붕 버튼, 재장전 링. Ⅱ 버튼은 공용.
- 결과: 승자 색과 이름(파랑/빨강) 크게. 글자 방향(양쪽 끝에 마주 앉는 경우 회전 여부)은 art-ui.md에서 결정.
- PC에서 2인 모드도 선택 가능(마우스 1개로 번갈아). 실사용 대상은 iPad.

## 테스트 훅 (QA 전용, 화면 노출 없음)
`window.__bungeo`:
- `start(mode, difficulty)` — mode `'ai'|'pvp'`, difficulty `'easy'|'normal'|'hard'`. 카운트다운 없이 즉시 플레이.
- `state()` → 복사본 `{ phase('menu'|'countdown'|'playing'|'paused'|'ending'|'result'), mode, difficulty, timeLeft, grid: number[10][16], counts:{p1,p2,neutral}, obstacles:[{owner,x,y,c,r,timeLeft}], projectiles:[{owner,type,x,y,stage}], players:[{type, reload, aiming}], result:null|{winner:1|2|0, p1Pct, p2Pct} }`.
- `setTime(sec)` — 남은 시간 설정.
- `throwAt(player, type, tx, ty, {ignoreReload})` — 착지점 (tx,ty)를 노리는 각도·세기를 계산해 규칙대로 던짐(사거리·각도 범위로 잘림). 반환: 실제 예정 착지점 `{x,y}`, 던지지 못했으면 `null`.
- `throwRaw(player, type, angleDeg, power)` — 정면 기준 각도(−60~60), 세기 0~1.
- `setCell(c, r, owner)`, `placeObstacle(owner, x, y)` — 상황 재현용.
- `setAI(on)` — 컴퓨터 동작 켜기/끄기(결정적 테스트용).
- `simulate(sec)` — 실제 시간 대신 고정 스텝(1/60초)으로 sec만큼 진행(밸런스 시뮬레이션용).
- `seed(n)` — AI 무작위(생각 시간·오차·선택) 시드 고정.
