# 두더지 뿅뿅 기획서
- slug: mole-pop
- 한 줄 소개: 60초 동안 3×3 구멍에서 뿅 튀어나오는 두더지를 눌러 잡는 반응속도 게임. 황금 두더지는 크게, 폭탄은 피하기!
- 상태: 기획 (최초)
- 참고: "두더지 잡기" 장르 규칙만 빌린 오리지널. 참고 이미지 게임의 캐릭터·디자인·화면 구성은 쓰지 않는다.
- 난이도 목표: **낮음**. 처음 10~15초는 누구나 다 잡을 수 있을 만큼 느리게 시작하고, 끝으로 갈수록 조금 바빠지는 정도.

## 핵심 루프
시작 → 구멍에서 두더지가 튀어나옴 → 들어가기 전에 누름(누르는 순간 판정) → 점수 + 콤보 → 콤보가 쌓이면 배율 상승 → 폭탄은 누르지 않고 흘려보냄 → 60초 뒤 결과 화면에서 점수·최고 콤보 확인 → 다시 하기.

## 규칙

### 보드
- 구멍 3×3 = 9개. 번호 0~8 (왼쪽 위 0, 행 우선: 0 1 2 / 3 4 5 / 6 7 8).
- 각 구멍의 터치 판정 영역 = 그 칸 전체(구멍 + 위로 솟은 두더지 그림 포함, 칸 사이 간격 제외). 칸 크기·간격은 art-ui.md. 최소 판정 크기는 한 변 88pt 이상.

### 두더지 한 마리의 생애 (구멍 1개 기준)
| 단계 | 시간 | 탭 가능? |
|---|---|---|
| 올라옴 (rise) | 0.15초 | **가능** (올라오기 시작한 순간부터 판정) |
| 머묾 (stay) | 종류·단계별 (아래 표) | 가능 |
| 내려감 (sink) | 0.15초 | 앞 0.08초까지 가능, 이후 불가 |
| 잡힘 연출 | 0.30초 | 불가 (한 번 잡힌 두더지는 즉시 판정 대상에서 빠짐) |
| 구멍 쉬는 시간 | 내려감/잡힘 연출이 끝난 뒤 0.40초 | 이 구멍에는 새 두더지 등장 금지 |

- 잡힌 순간: 점수·콤보 즉시 반영 → 두더지는 잡힘 연출(눌림/별 등, art-ui.md) 후 구멍 속으로 사라짐.
- 내려감이 끝날 때까지 잡히지 않으면 **도망감**(아래 콤보 규칙 적용).
- 난이도가 낮으므로 판정은 너그럽게: 올라오는 도중에 눌러도 인정, 내려가기 시작해도 절반 정도까지 인정.

### 두더지 종류
| 종류 | 등장 확률 | 머무는 시간 | 잡았을 때 | 도망갔을 때 |
|---|---|---|---|---|
| 일반 | 나머지 (기본 82%) | 단계별 기본값 ×1.0 | **+10점 × 콤보 배율**, 콤보 +1 | 콤보 0으로 끊김 |
| 황금 | 8% | 단계별 기본값 ×0.6 (최소 0.55초) | **+50점 × 콤보 배율**, 콤보 +1 | 아무 일 없음 (콤보 유지) |
| 폭탄 | 10% | 단계별 기본값 ×1.0 | **−30점**(배율 없음, 점수는 0 미만 안 됨), 콤보 0으로 끊김 | 아무 일 없음 (흘려보내는 게 정답) |

- 확률은 "새 두더지를 뽑을 때" 적용. 아래 공정성 규칙에 걸리면 그 등장은 일반으로 바꾼다.
- 시작 후 처음 5초는 폭탄·황금 없이 일반만(익숙해지는 시간).

### 콤보·배율
- 콤보 = 끊기지 않고 연속으로 잡은 수(일반+황금). 잡은 직후 값으로 배율을 정한다(5번째로 잡은 두더지부터 ×1.5).

| 콤보(잡은 직후) | 배율 | 일반 | 황금 |
|---|---|---|---|
| 1~4 | ×1 | 10 | 50 |
| 5~9 | ×1.5 | 15 | 75 |
| 10~14 | ×2 | 20 | 100 |
| 15~19 | ×2.5 | 25 | 125 |
| 20 이상 | ×3 (최대) | 30 | 150 |

- 콤보가 끊기는 경우: **일반 두더지 도망감**, **폭탄 누름**. 이 두 가지뿐.
- 콤보에 영향 없는 경우: 빈 구멍 탭(벌점도 없음), 황금 도망감, 폭탄 도망감, 잡힘 연출 중인 구멍 탭.
- 최고 콤보(이번 판 최대값)를 기록해 결과 화면에 표시.
- 콤보 표시: 콤보 2 이상일 때 HUD에 "N 콤보", 배율이 오르는 순간(5·10·15·20) 짧게 강조 + 효과음(sound.md).

### 등장 스케줄과 난이도 곡선
- 첫 두더지는 시작 후 0.6초에 등장.
- 단계는 **경과 시간** 기준 계단식.

| 단계 | 경과 시간 | 등장 간격 | 일반 머무는 시간 | 동시에 나와 있는 최대 수 |
|---|---|---|---|---|
| 1 | 0~15초 | 1.10초 | 1.40초 | 1 |
| 2 | 15~30초 | 0.90초 | 1.20초 | 2 |
| 3 | 30~45초 | 0.75초 | 1.00초 | 2 |
| 4 | 45~60초 | 0.62초 | 0.85초 | 3 |

- 등장 간격은 매번 ±15% 균등 무작위 흔들기(예: 1.10초 → 0.935~1.265초).
- "동시에 나와 있는 수" = 올라옴·머묾·내려감 상태인 두더지 수(잡힘 연출 중은 제외). 최대에 도달했으면 그 등장은 건너뛰지 않고 **0.1초마다 다시 시도**(자리가 나면 바로 등장).
- 예상 등장 수: 판당 약 70마리 (일반 약 57 / 황금 약 5 / 폭탄 약 7).
- 참고 목표 점수: 처음 하는 사람 600~1,000점, 익숙하면 1,500점 이상.

### 공정성 규칙
1. **같은 구멍 쉬는 시간**: 두더지가 사라진 구멍은 0.40초 동안 다시 쓰지 않는다.
2. **같은 구멍 연속 금지**: 바로 직전에 등장한 구멍은 다른 후보가 있으면 고르지 않는다.
3. 구멍 선택 = 비어 있고 쉬는 시간이 아닌 구멍 중 균등 무작위. 후보가 없으면 0.1초 뒤 다시 시도.
4. **폭탄**: 동시에 최대 1개. 폭탄 바로 다음 등장은 폭탄이 아님(2연속 금지).
5. **황금**: 동시에 최대 1개, 직전 황금 등장 후 4초 이내에는 다시 나오지 않음.
6. 시간 0초에 가까울 때: 남은 시간이 머무는 시간보다 짧아도 등장은 허용(종료 시 모두 사라짐, 도망 처리 안 함).

### 입력 판정
- `pointerdown` 순간 판정(손 뗄 때가 아님). 누른 좌표가 속한 구멍 칸 1개를 판정.
- **멀티터치 허용**: 손가락 여러 개가 각자 pointerdown하면 각각 판정(두 마리를 두 손가락으로 동시에 잡기 가능).
- 같은 두더지를 두 번 잡을 수 없음(첫 판정에서 잡힘 상태로 바뀜).
- 칸 사이 간격·보드 밖 탭은 무시(빈 구멍 탭과 같은 취급 아님, 아무 일 없음).

### 시간·종료
- 제한 시간 **60초**, "시작" 버튼을 누른 순간부터.
- 상단 시간 막대 + 남은 초. 마지막 10초: 시간 표시 빨강 + 1초마다 맥동(경고음은 sound.md).
- 0초 → 입력 즉시 정지, 나와 있던 두더지는 모두 내려감(도망 처리·콤보 변화 없음) → 0.5초 뒤 결과 화면.

### 결과 화면
- 제목 "시간 끝!", 이번 점수, 최고 콤보, 잡은 수(일반 N · 황금 N), 폭탄 누른 수, 최고 점수, 새 기록이면 "새 기록!".
- 최고 점수: localStorage `mole-pop-best`. 종료 시 더 크면 갱신. 저장소 접근 실패 시 0으로 보고 정상 진행.
- 음소거 설정 키: `mole-pop-muted` (sound.md).
- 결과 화면이 뜬 뒤 **0.7초 동안 재시작 입력 무시**(두더지 누르던 손가락에 바로 눌리는 것 방지).
- "다시 하기" → 점수·콤보·통계 0, 시간 60초, 단계 1로 즉시 시작.

### 일시정지
- Ⅱ 버튼 / P / Esc. 탭이 숨으면(visibilitychange hidden) 자동 일시정지.
- 일시정지 중 타이머·두더지 타이머 모두 정지(재개 시 남은 시간 그대로 이어감). 보드는 덮개로 가림.
- 덮개: "일시정지" + "계속" + "처음부터" 버튼.
- "계속"을 누른 그 탭(포인터)이 아래 구멍 판정으로 넘어가지 않게 한다. 재개 후 0.3초 동안 구멍 탭은 무시.

## 조작
| 동작 | PC | iPad |
|---|---|---|
| 두더지 잡기 | 구멍 칸 마우스 왼쪽 클릭(누르는 순간) | 구멍 칸 탭(닿는 순간), 여러 손가락 가능 |
| 시작 | "시작" 버튼 / Enter / Space | "시작" 버튼 탭 |
| 일시정지/재개 | Ⅱ 버튼 / P / Esc (재개: 같은 키 또는 Enter) | Ⅱ 버튼 / "계속" |
| 다시 하기 | "다시 하기" / Enter / Space | "다시 하기" 버튼 |

- 보드에 `touch-action: none`, `user-select: none`, 길게 누르기 메뉴·더블탭 확대 방지.
- 키보드로 구멍 누르기는 없음(범위 밖).
- 세로·가로 모두 3×3 정사각 보드를 화면 가운데에 최대한 크게(세부는 art-ui.md).

## 화면 흐름
1. 시작 화면: 제목 "두더지 뿅뿅", 규칙 한 줄(예: "두더지를 눌러요! 황금은 크게, 폭탄은 피해요"), 최고 점수, "시작".
2. 플레이: HUD(점수 / 콤보·배율 / 남은 시간 / Ⅱ) + 3×3 보드.
3. 일시정지 / 4. 결과 / 5. 재시작 — 위 규칙대로.

## 테스트 훅 (QA 전용, 화면 노출 없음)
`window.__mole`:
- `state()` → `{ phase, timeLeft, score, combo, maxCombo, holes: [{state, type}, ...9] }` 복사본.
- `spawn(hole, type)` → 지정 구멍(0~8)에 `'normal'|'gold'|'bomb'` 두더지를 즉시 등장(공정성 규칙 무시, QA 재현용).
- `setTime(sec)` → 남은 시간 설정(단계·종료 테스트용).
