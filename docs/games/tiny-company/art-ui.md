# 악덕 사장 아트·UI 명세

> slug: `tiny-company` · 제목은 「악덕 사장」(2026-11-16 사용자 결정으로 「꼬마 사장님」에서 변경, 표시 이름만 변경·slug/키는 그대로).
> **수치·규칙은 design.md가 정하고**, 이 문서는 그것을 어떻게 보여 줄지만 정한다. 이 문서에 나오는 수치(자리 6개 2×3, 월급 7단계 / 업무 5 / 휴식 5, 행복 기준선 30·흔들림 40, 피로 70·90, 이웃 충격 −12·보너스 −6, 그 외 −3, 금액 만원)는 design.md 2026-11-16 초안 기준이다. design.md가 바뀌면 숫자만 따라 바꾸고 화면 구조는 그대로 둔다.
> 그래픽: **사무실 씬·직원·아이콘·자리 연결선·그래프 = 인라인 SVG(DOM)**, **HUD·패널·오버레이 = DOM**. Canvas는 쓰지 않는다. 이미지 파일 없음. **게임 화면에 이모지 그래픽 없음**(design.md의 ✉·하트·침대는 아래 SVG 아이콘으로 그린다).
> 오리지널 원칙: "콩 직원" 캐릭터는 이 문서의 도형으로 직접 그린 것이다. 기존 경영 시뮬레이션(게임 회사·카페·병원 경영 등)의 캐릭터, 도트 그래픽, UI 배치를 따라 하지 않는다.

## 스타일 콘셉트
- **"오후 3시의 작은 사무실"**: 따뜻한 종이색 배경, 창문과 **주문 보드**가 걸린 낮은 벽, 나무 책상 6개가 2줄 × 3칸으로 놓인 **정면 미니 씬**. 책상마다 동글동글한 **콩 직원**이 앉아 있고, 얼굴 하나로 기분을 보여 준다.
- **보고 배우기 (사용자 핵심 취향)**: 단계 버튼을 누르는 순간 ① 직원 표정 ② 주문 보드의 처리량 막대 ③ 예상 매출·비용 막대 ④ 예상 이익 숫자 ⑤ 자리 연결선 위의 연쇄 숫자가 **같은 프레임에 바뀐다**. 글을 읽지 않아도 "일을 많이 시키면 막대가 길어지고 얼굴이 지친다"를 눈으로 익힌다.
- **얼굴 규칙은 두 가지뿐 (모든 화면 공통)**: **입 = 행복**(활짝/웃음/일자/울상 4단계), **눈 = 피로**(동그란 눈/반쯤 감김/감은 눈 + 땀). 시작 범례, 책상 카드, 리포트, 결과 화면이 이 규칙을 똑같이 쓴다.
- **자리는 이어져 있다 (사용자 추가 결정)**: 이웃한 책상 사이에 **연결 고리**가 늘 보인다. 기분이 좋든 나쁘든 이 고리를 따라 옆자리로 번진다. 누가 퇴사하면 고리를 따라 충격이 옆자리로 전해지는 모습이 보이고, 위험한 고리는 붉은 점선과 `−12` 숫자로 미리 표시된다.
- **원인에서 결과로, 그림으로**: 월말 리포트는 `[원인 칩] ━▶ [결과 칩]` 줄 + 짧은 문장 한 줄로 구성한다. 숫자에는 항상 부호·단위·▲▼를 붙인다. 퇴사는 "어느 게이지가 어느 선을 넘었는지"를 게이지 그림으로, 연쇄는 "누구에게서 누구에게로"를 미니 자리표와 화살표로 보여 준다.
- **눈 피로 최소화**: 채도 낮은 색을 쓴다. 그라데이션, 광택, 화면 흔들림, 전체 화면 번쩍임은 쓰지 않는다. 움직임은 짧고 작게 한다(퇴사자 퇴장만 최대 24px 이동, 나머지는 8px 이하, 최대 확대 1.12).
- 스튜디오 공통: 상단 바·버튼·오버레이 구조는 `games/parrot-beat/index.html`(붕어빵 눈싸움과 같은 CSS)의 `.top`, `.home`, `button.icon`, `button.primary`, `button.secondary`/`a.secondary`, `.overlay`, `body.ov-full`, `.ov-home`를 **그대로 복사**한다. 둥근 모서리(패널 12~16px), 그림자 대신 면 색 차이, 주 버튼은 주황 `--accent`.
- 글꼴: 글자는 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **숫자(현금·이익·매출·게이지 값·월·단계 값·그래프 값)는 CompanyDigits**를 쓴다. "만", "월", "h", "일" 같은 단위 글자는 `unicode-range` 덕분에 자동으로 시스템 글꼴로 나온다.

### 숫자 글꼴 CompanyDigits (Pretendard ExtraBold 800 서브셋, SIL OFL 1.1)
- 기존 게임(`games/parrot-beat/fonts/beat-digits-800.woff2` + `OFL.txt`)과 같은 방식이다. 원본은 Pretendard **ExtraBold(800)**.
- 파일: `games/tiny-company/fonts/company-digits-800.woff2`, 같은 폴더에 `OFL.txt`(기존 게임 것 복사: Pretendard 저작권 줄 + OFL 1.1 본문).
- 글리프: `0-9`(U+0030–0039), `%`(U+0025), `+`(U+002B), `,`(U+002C), `-`(U+002D), `.`(U+002E), `/`(U+002F, "52/70"), `−`(U+2212, 음수 표시). **`tnum` 유지**(자릿수 폭을 고정해 숫자가 바뀔 때 흔들리지 않게).
  - 예: `pyftsubset Pretendard-ExtraBold.otf --unicodes="U+0025,U+002B-002F,U+0030-0039,U+2212" --flavor=woff2 --layout-features='tnum' --output-file=company-digits-800.woff2` 후 fontTools로 name 테이블을 바꾼다.
  - 원본에 U+2212가 없으면 음수는 `-`(U+002D)로 표시하고 unicode-range에서 U+2212를 뺀다(QA가 cmap 확인).
- **Reserved Font Name 때문에 이름 변경 필수**: family/full/PostScript/typographic 이름을 모두 `CompanyDigits`로 바꾸고, 압축을 푼 바이트에 "Pretendard" 문자열이 없어야 한다(QA가 기존 게임과 같은 fontTools 검사). 다른 게임 서브셋은 글리프 구성이 달라 재사용 금지. 원본을 구하지 못하면 CEO에게 보고한다.
```css
@font-face { font-family: "CompanyDigits"; src: url("fonts/company-digits-800.woff2") format("woff2");
  font-weight: 800; font-style: normal; font-display: swap; unicode-range: U+0025, U+002B-002F, U+0030-0039, U+2212; }
:root { --num-font: "CompanyDigits", system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif; }
.num { font-family: var(--num-font); font-weight: 800; font-variant-numeric: tabular-nums; }
```

### 숫자 표기 규칙 (모든 화면 공통)
- 금액은 design.md의 만원 단위 정수를 쓰고 화면에는 `1,500만`처럼 쓴다("원"은 붙이지 않는다). 연 매출처럼 큰 수도 `38,450만`(억으로 바꾸지 않는다. 순위표와 같은 숫자로 보이게).
- 변화량에는 **항상 부호**를 붙인다: `+420만`, `−12`, `+0`. 처리량은 `52/70`.
- 이익 숫자 색은 흑자 `--good-ink`, 적자 `--loss-ink`, 0은 `--ink`이고, **색과 함께 반드시 부호와 ▲/▼**를 붙인다.
- 게이지 값(행복·피로)은 0~100 정수(반올림).

### 직원 몸 색 6종 (`--e0`~`--e5`, **자리 번호 = 색**)
자리마다 색을 고정한다. 새로 온 직원은 그 자리 색을 물려받는다(자리와 색이 같아 리포트의 미니 자리표에서 알아보기 쉽다).
| 자리 | 라이트 | 다크 | 이름(내부) |
|---|---|---|---|
| 0 | #f2c6a0 | #c99a74 | 살구 |
| 1 | #b8c9e6 | #8aa0c4 | 하늘 |
| 2 | #e8d08f | #c4ab64 | 버터 |
| 3 | #b9d4b0 | #8fae86 | 세이지 |
| 4 | #e6bfd0 | #c0909f | 장미 |
| 5 | #c3b6e0 | #9a8cc0 | 라일락 |
- 몸 외곽선은 각 색을 `color-mix(in srgb, var(--eN) 70%, #000)`로 만든다(별도 토큰 불필요).
- **직원 구분 = 이름 + 머리 모양 + 색**. 머리 모양은 사람마다 고정한다(이름 풀 순서로 6종 중 하나, 아래). 색만으로 구분하지 않는다.

### 좋고 나쁨 색 규칙 (중요)
- **화살표 방향 = 수치가 오르는지 내리는지**, **색 = 회사에 좋은지 나쁜지**. 둘은 다르다.
  - 매출 ▲ = 좋음(`--good-ink`), 피로 ▲ = 나쁨(`--loss-ink`), 비용 ▼ = 좋음, 행복 ▼ = 나쁨.
- 좋음/나쁨은 색 말고 **칩 모양**으로도 구분한다: 좋음 = 실선 테두리, 나쁨 = 실선 테두리 + 왼쪽 4px 굵은 띠(`--loss`). 변화 없음 = `--grid` 테두리, 화살표 자리에 `–`.

### 자리 연결 고리 (`.links`, 사용자 추가 결정 — 이웃 영향의 핵심 그림)
- 이웃은 design.md 그대로 0-1, 1-2, 3-4, 4-5(가로)와 0-3, 1-4, 2-5(세로)다.
- 책상 격자 위에 SVG 한 장(`pointer-events: none`, `aria-hidden="true"`)을 겹치고, 이웃한 두 카드 사이 틈에 **고리**를 그린다. 위치는 카드 `getBoundingClientRect()`로 계산하고, 레이아웃이 바뀔 때 다시 그린다.
  - 가로 고리: 두 카드 사이 틈 한가운데, 카드 세로 가운데 높이. 길이 = 틈 + 8(양쪽 카드 안으로 4px씩 걸침), 굵기 6, radius 3.
  - 세로 고리: 두 카드 사이 틈 한가운데, 카드 가로 가운데. 같은 크기를 세로로.
  - 고리 가운데에는 작은 **숫자 배지**(높이 18, radius 9, `.num` 11px)가 필요할 때만 붙는다. 배지는 고리 위에 겹쳐 그리며 카드 내용을 가리지 않게 틈 쪽으로 붙인다(폰에서 틈이 6px이면 배지가 카드 가장자리에 4~6px 걸치는 것은 허용).
- **고리 상태 (색 + 선 모양 + 배지, 세 가지를 함께 쓴다)**:

| 상태 | 조건 (design.md) | 고리 | 배지 |
|---|---|---|---|
| 평상시 | 양쪽에 사람이 있고 아래 조건 없음 | 실선 `--link` | 없음 |
| 빈자리와 연결 | 한쪽이 빈자리 | 점선 `--link` α .5 | 없음 |
| 좋은 기운 | 이웃 영향 항 ≥ +2 (행복한 쪽에서 덜 행복한 쪽으로) | 실선 `--happy` | `+2` (`--happy-ink`), 영향 받는 쪽을 향한 작은 ▸ |
| 나쁜 기운 | 이웃 영향 항 ≤ −2 | 실선 `--loss` α .7 | `−3` (`--loss-ink`), ▸ 방향 |
| **연쇄 예고** | 한쪽이 ✉(flag) 직원 | **점선 `--danger`**(dash 4 3), 굵기 6 | `−12` 또는 보너스를 받으면 `−6` + `icShield` 10px |
| 흔들림 진행 중 | 한쪽이 퇴사로 비고, 다른 쪽이 shaken | 점선 `--warn` | 금 간 하트 10px + 남은 달 수 |

- 이웃 영향 배지 숫자는 design.md 공식의 이번 달 예상값이다(±2 미만이면 배지를 달지 않고 고리 색만 바꾸지도 않는다 — 화면이 어지럽지 않게).
- 한 고리에 여러 상태가 겹치면 **연쇄 예고 > 흔들림 > 나쁜 기운 > 좋은 기운** 순으로 하나만 표시한다.
- 고리는 늘 보이지만 평상시 고리는 연한 색이라 조용하다. 사용자가 "자리끼리 이어져 있다"를 처음부터 알 수 있게, 시작 화면 범례에서 고리를 설명한다(아래).

### 책상 카드 (직원 1명, `<button class="desk">`)

2. **이름 줄**: 이름 13px 700 `--ink`(폰 11px), 한 줄 말줄임. 오른쪽에 **조치 배지**(아래)와 신입 알약.

#### 개별 조치 (design.md: 카드 탭 → 없음 → 휴가 → 보너스 → 없음 순환)
- **카드를 탭할 때마다** 조치가 순환한다. 조치 배지가 이름 오른쪽에 붙는다.
  - 없음: 배지 없음.
  - 휴가: 알약 `icVacation` + "휴가"(`--rest` 테두리). 직원 α .55 + 책상 위 `icVacation`(진행 후 실제로 비울 때는 .35).
  - 보너스: 알약 `icBonus` + "보너스 −50"(`--money` 테두리).
- 탭할 때마다 카드 위로 **조치 말풍선**이 1600ms 떠 있다: 휴가 = `[피로 −35 ▼] [행복 +6 ▲] [처리 −10 ▼]`, 보너스 = `[행복 +10 ▲] [비용 +50 ▲]` + 이웃 중 ✉이 있으면 `[icShield 충격 절반]`. 숫자는 design.md 예측값.
- 휴가 한도(직원 수 − 1)에 걸려 휴가로 넘어갈 수 없으면 순환에서 휴가를 건너뛰고, 말풍선에 `icWarn` "휴가 한도" 1줄을 띄운다.
- 순환식이라 지금 상태가 숨지 않도록, **조치 배지는 늘 보이고** 키보드·스크린 리더용으로 `aria-label="바름, 조치 보너스. 누르면 없음으로 바뀜"`을 준다.
- 키보드 1~6 = 해당 자리 순환(design.md).

- ✉ 직원이 있는 달에는 그 직원과 이웃 카드에 **차단 힌트**를 보여 준다.
  - ✉ 직원 카드 위험 줄 오른쪽 끝에 작은 회색 글자 "보너스·휴가로 막기"(11px, TW ≥ 150에서만).
  - 이웃 카드(연쇄 위험/주의)도 같은 자리에 "보너스로 충격 절반"을 쓴다.
- 플레이어가 조치를 바꾸면 효과가 **바로 그림으로** 보인다.
  - ✉ 직원에게 보너스나 휴가를 주어 예상 H가 기준선 이상이 되면 `.e-mark` 봉투가 α .35로 옅어지고 위험 줄이 "고민 중"으로 바뀐다. 그 직원에게서 나가는 연쇄 고리는 점선 `--danger`에서 점선 `--warn`으로 바뀌고, 배지는 `−12`인 채 α .5가 된다("떠나지 않을 것 같지만 아직 ✉").
  - 이웃에게 보너스를 주면 그 고리 배지가 `−12`에서 `−6` + `icShield`로 바뀌고, 연쇄 고스트 상자가 절반 길이로 줄어든다. 충격 뒤 H가 40 이상이 되면 위험 줄이 "연쇄 위험"에서 "연쇄 주의"로 내려간다.

### 빈 자리 카드 & 채용
- 바탕은 투명, 테두리 1.5px 점선 `--grid`. 가운데에 빈 의자(`--chair`, 둥근 등받이 + 다리 2)를 작게 그린다.
- 이번 달 채용 후보가 있고 채용 조건(직원 < 6, 현금 ≥ 200)을 만족하면 의자 위에 **`+ 채용` 버튼**(높이 ≥ 44, `icHire` + "채용" 13px 700, 바탕 `--panel`, 1px `--accent` 테두리, radius 999)과 아래 `.num` 11px `−200만`을 둔다. 조건이 안 되면 버튼 대신 의자만 보이고, 의자를 탭하면 상태 바 현금 칸이 `--warn` 테두리로 600ms 강조된다(이유를 글 없이 가리킨다).
- **`+ 채용` 탭 → 후보 시트** (폰: 아래에서 올라오는 시트, 그 외: 해당 카드 옆 팝오버 폭 300):
  - 후보 콩 직원 64px(그 자리 색, 표정 = 첫 달 H 65·F 10), 이름 18px 800, `icStar` 숙련, "체력 강/보통/약", "기대 300"(`.num`).
  - **이 자리의 이웃 미리보기**: 이 자리와 이어진 이웃들의 얼굴(28px) + 고리 모양 아이콘 + 예상 이웃 영향 `+2`/`−3` 배지. "행복한 이웃 옆이면 덜 지쳐요" 같은 문장 대신 얼굴과 배지로 보여 준다. 이웃 중 ✉이 있으면 `icLink` "옆자리 퇴사 위험" 경고 1줄.
  - 버튼: `이 자리에 채용 −200만`(primary 48) / `닫기`(secondary 44).
  - 시트가 열려 있는 동안 씬에서는 이 자리와 이웃 사이 고리가 굵기 8로 강조된다.
- 채용을 예약한 자리: 의자 위에 점선 콩 실루엣(α .4, 그 자리 색)과 이름, 버튼은 `취소`(secondary 44). 예상 비용 막대, 상태 바, 주문 보드 처리량(신입 ×0.5)에 바로 반영한다.
- 키보드 H = 빈 자리 중 번호가 가장 작은 곳의 후보 시트를 연다(design.md).

### 높이 기준 레이아웃 규칙 (필수, parrot-beat와 같은 방식)
1. `--app-h` = `window.innerHeight + 'px'`. `resize`·`orientationchange`·`visualViewport.resize` 때 갱신한다. CSS 기본값은 `100dvh`(미지원이면 `100vh`). `100vh` 단독 사용 금지.
2. `html, body { height: var(--app-h); overflow: hidden; }`. body 패딩은 `max(12px, env(safe-area-inset-*))` 네 방향(H ≤ 520이면 위아래 `max(8px, …)`). viewport meta는 `width=device-width, initial-scale=1, viewport-fit=cover`.
3. `W` = innerWidth − 좌우 패딩, `H` = app-h − 상하 패딩. 상단 바 `TB = 52`(H ≤ 520이면 44). 요소 사이 간격 `g = 8`(W < 420이면 6). 무대 너비 `SW = min(W, 1200)`, 가운데 정렬.
4. 상태 바 `SB = 56`(H ≤ 520이면 36 한 줄 압축, W < 420이면 48).
5. **가로 배치** (W ≥ H 그리고 W ≥ 640):
   - 패널 폭 `P = clamp(300, round(SW × 0.34), 400)`, **H ≤ 520이면 `P = 340` 고정**(월급 7칸 버튼이 각 44px 이상이 되도록).
   - 씬 폭 `OW = SW − P − g`, 씬·패널 높이 `MH = H − TB − g − SB − g`. 상태 바는 전체 폭.
6. **세로 배치**: 패널은 내용 높이 `PH`, 폭 `min(W, 640)` 가운데. 씬 높이 `OH = H − TB − g − SB − g − PH − g`, 씬 폭 `min(W, 760)`.
7. **책상 격자 (2행 × 3열 고정)**: 씬 안쪽 여백 `pad = 12`(W < 420 또는 H ≤ 360이면 8), 카드 간격 `cg = 10`(같은 조건에서 6). 연결 고리가 이 틈에 놓인다.
   - 벽 띠 `WB`: 폰 세로나 H ≤ 520이면 주문 보드 한 줄만 `WB = 28`(H ≤ 360이면 24). 그 밖에는 `WB = clamp(44, round(씬높이 × 0.12), 72)`.
   - `TW = min(floor((씬폭 − 2·pad − 2·cg) / 3), 240)`.
   - `TH = min(floor((씬높이 − WB − 2·pad − cg) / 2), round(TW × 1.25), 260)`. 격자는 가로 가운데, 세로는 바닥 쪽(아래)으로 붙인다.
   - 직원 크기 `C = min(round(TW × 0.58), round(TH × 0.5), 120)`.
   - **TH < 84이면 카드 압축 모드**: 게이지 2줄을 이름 줄 오른쪽 짧은 세로 막대 2개(폭 5, 높이 = 카드 높이 40%, 기준선 눈금 유지)로 바꾸고, 예상 변화 숫자는 숨기며(고스트 빗금은 유지) 이름은 11px로 한다.
8. **결정 패널 내부** (위에서 아래, 간격 g, 패널 패딩 상하 10 / H ≤ 520이면 8):
   - **돈 막대 `PV`** (매출·비용 2줄 + 이익 줄): 가로 배치에서 H > 520이면 104, iPad 세로 104, 폰 세로는 H ≥ 760일 때만 76(이익을 막대 오른쪽에 한 덩어리로), 그 밖(폰 세로 H < 760, H ≤ 520)은 **숨김**(이익은 상태 바에 이미 있음).
   - **설정 줄 3개**, 줄 높이 `RH` = 이름 줄 + 4 + 단계 버튼 높이. 가로 배치(H > 520)와 iPad 세로는 20 + 4 + 48 = 72, 그 밖은 14 + 2 + 44 = 60.
   - 버튼 줄 `BH`: 48(폰 세로 44, H ≤ 520이면 44).
   - `PH = PV + 3·RH + BH + 패딩 + 간격`.
   - **H ≤ 360이면 버튼 줄을 패널에서 빼서 상태 바 오른쪽 끝에 붙인다**: `N월 시작` 버튼(높이 36, `::after`로 터치 영역 44 확보). `되돌리기`는 일시정지 메뉴로 옮긴다. **패널 안 세로 스크롤 금지.**
9. **수치표** (패딩 12, 안전 영역 0 기준, 계산값 ±2px):

### 결정 패널 (`.panel`, `<section aria-label="이번 달 결정">`)
#### 1) 돈 막대 (`.preview`)
```
매출  [▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬   ┊]  2,600만      ┊ = 지난달 값 눈금
비용  [▬▬▬▬▬▬▬|▬▬▬▬▬     ┊]  2,180만      (월급 | 임대료·보너스·채용)
      ───────────────────────────────
                       이익  +420만 ▲
```
- 두 막대는 **같은 눈금**이다(최대값 = max(예상 매출, 예상 비용, 지난달 두 값) × 1.1). 매출 `--rev`, 비용 `--cost`. 높이 12(폰 10), radius 6, 트랙 `--well`.
- 비용 막대는 **구성별로 나눠** 칠한다: 월급 합계(진한 `--cost`) | 임대료 600(α .6) | 보너스·채용비(빗금). 구간 사이 1px `--panel` 구분선.
- **지난달 값 눈금**: 각 트랙에 지난달 실제 값 위치를 2px × (막대 높이 + 6) `--ink` α .4로 표시한다. 1월은 눈금 없음.
- 이익 줄: "이익" 12px `--muted` + `.num` 22px 색 규칙 + ▲/▼. 적자면 이익 줄 바탕 `--cost-tint` + `icWarn`. 예상 월말 현금이 0 미만이면 이익 줄 아래 11px `--loss-ink` "월말 현금 −120만".
- 매출의 "왜"는 벽의 주문 보드(처리량 52/70)가 보여 준다. 패널 막대와 주문 보드는 같은 프레임에 갱신한다.

| 휴식 | `icRest` `--rest` | `0일` `1일` `2일` `3일` `4일` (5) | 피로 ▼ · 매출 ▼ |
- **세그먼트**: 바깥 radius 12, 1px `--grid`, 바탕 `--well`, 칸 사이 1px `--grid`. 글자는 `.num` 15px(폰 13px) `--muted` 600.
  - 선택된 칸: 바탕 = 줄 색 α .16 (`color-mix`), 2px 안쪽 테두리 줄 색, 글자 `--ink` 800. 선택 칸 아래 가장자리 가운데에 작은 막대(폭 16, 높이 3, 줄 색).
  - **강도 표시**: 칸 바탕 아래쪽에 낮은 막대(높이 = 단계 번호 × 2px, 줄 색 α .25)를 둔다. 오른쪽으로 갈수록 "많다"는 것이 모양으로 보인다.

- **조작 말풍선** (모든 화면): 칸을 누르면 그 칸 위 6px에 **이번 조작 한 번의 예상 변화량** 칩 2~3개가 뜬다. 예: `[처리 +6 ▲] [이익 +180만 ▲] [평균 피로 +6 ▲]`. 바탕 `--panel`, 1px `--grid`, 아래 꼬리 6px. 마지막 조작 후 1600ms 유지하고 200ms에 걸쳐 사라진다. 위 공간이 모자라면(H ≤ 520) 패널 위쪽 가장자리에 고정해서 띄운다.
- 접근성: 각 줄은 `role="radiogroup" aria-labelledby=이름`, 칸은 `role="radio" aria-checked`, `aria-label="업무량 주 52시간"`. 방향키 ←/→로 이동(roving tabindex, 줄 하나에 Tab 정지점 1개). 효과 칩 문장은 `aria-describedby`("올리면 매출과 피로가 늘어요").

#### 3) 버튼 줄
- `되돌리기`(secondary, 높이 44, ↺ 아이콘): 이번 달에 바꾼 설정·조치·채용 예약을 지난달 상태로 되돌린다. 바꾼 게 없으면 α .4 + disabled.
- `3월 시작`(primary, 높이 48/폰 44, flex 1, ▶ 아이콘 + "N월 시작"): **한 달 진행**을 시작한다.
- 버튼 바로 위 안내 한 줄(12px, 하나만, 우선순위 순서. 막지 않고 알리기만 한다):
  `icWarn` "파산 위험: 2달 연속 적자" > `icLetter` "퇴사 고민 1명" > `icLink` "연쇄 위험 2명" > `icWarn` "적자 예상" > `icBed` "번아웃 예정 1명". 공간이 없는 화면(H ≤ 520)에서는 숨긴다(카드와 상태 바가 이미 보여 줌).

### 직원 미리보기 반응 (보고 배우기의 핵심)
- 결정 중에는 직원 얼굴이 **이번 결정대로 한 달을 보냈을 때의 예상 표정**으로 바뀐다(design.md 예측 패널 공식, RNG 없음). 게이지에는 고스트 빗금과 예상 변화 숫자가 붙는다.
- 이 상태임을 알리려고, 설정이나 조치가 지난달과 다르면 씬 왼쪽 위에 **"미리보기" 알약**(높이 24, 12px 700, `--panel` + 1px 점선 `--accent`, 눈 모양 아이콘)을 띄운다. 설정이 지난달과 같아도 예측은 늘 보이지만(매달 E가 오르는 등 변화가 있으므로) 알약은 숨긴다.
- 표정이 바뀌는 직원만 몸이 2px 위로 톡 튄다(140ms). 누가 반응했는지 보인다. 고리 배지·위험 줄도 같은 프레임에 다시 계산한다.
- 한 달 진행이 끝나면 실제 결과가 들어가므로 알약을 숨긴다.

### 5. 한 달 진행 연출 (`.running`, 오버레이 없이 씬 위에서)
- 시작하면 결정 패널 전체가 α .5 + `inert`(입력 막음)가 되고, `N월 시작` 자리에 **`건너뛰기 ▶▶`**(secondary, 높이 44)가 나온다. 씬 오른쪽 아래에도 건너뛰기 아이콘 버튼(44×44, 폰에서 엄지가 닿는 위치)을 둔다.
- 주문 보드 아래에 **날짜 진행 막대**(높이 4, `--accent`) + `.num` 일 수.
- 전체 길이는 **1500ms**(design.md). 순서:

| 시각(ms) | 보이는 것 |
|---|---|
| 0–100 | 패널이 흐려지고 날짜 막대가 나온다. 창문 색이 천천히 저녁색으로(1500ms 동안) |
| 100–1000 | 날짜가 1일에서 30일로. 일하는 직원은 손(`.e-arm`) 타이핑(translateY 0→2px, 200ms 주기. 업무량이 많으면 손 움직임 폭만 3px로, 속도는 그대로), 노트북 화면 `--screen-on`. 휴가·병가 직원은 α .35 그대로. **처리량**: 주문 보드 막대가 0에서 실제 판매량까지 채워진다. **매출 동전**: 400·700·1000ms에 일한 책상 위에서 동전(12px)이 떠올라 상태 바 "올해 매출" 칸으로 날아간다(곡선 360ms, 한 번에 최대 4개). 도착할 때마다 매출 숫자가 늘어난다(3번에 나눠서) |
| 100–1000 (같이) | 표정과 게이지가 3단계로 최종값까지 움직인다(400·700·1000ms). 감은 눈 단계에 들어가면 땀방울이 4px 떨어지며 나타난다(200ms). **좋은/나쁜 기운**: 배지가 있던 고리(±2 이상)에서 작은 점(지름 6, 고리 색)이 고리를 따라 영향 받는 쪽 카드로 1번 흘러간다(400ms). 받는 카드 머리 위에 `+2`/`−3` 칩이 600ms 떠오른다(위로 8px, 사라짐) |
| 1000–1150 | **월급날**: 상태 바 현금 칸에서 동전 묶음이 각 책상으로 날아가고(240ms) 현금 숫자가 줄어든다. 동시에 들어온 매출이 현금에 더해진다(현금 칸 숫자가 최종값으로 바뀌며 이익이 흑자면 `--good`, 적자면 `--loss` 테두리 600ms) |
| 1150–1500 | **퇴사·연쇄** (아래 "연쇄 연출") 또는 퇴사가 없으면 새 ✉·흔들림 말풍선이 scale .6→1로 등장. 채용 예약자는 점선 실루엣에서 실제 직원으로(scale .8→1 + α, 240ms) |
| 1500 | 날짜 막대가 사라지고 → **월말 리포트** 오버레이 |
- 퇴사가 있는 달은 연쇄 연출 때문에 **최대 2100ms**까지 늘어난다(아래).
- **건너뛰기**: 버튼, 씬 아무 곳 탭, Space/Enter/Esc. 모든 수치·표정·고리·퇴사·채용을 즉시 최종 상태로 바꾸고 리포트를 바로 띄운다. 퇴사와 연쇄는 리포트에서 다시 그림으로 설명하므로 연출을 건너뛰어도 정보가 빠지지 않는다.

#### 연쇄 연출 (퇴사·이직 1명마다, 같은 달 여러 명이면 자리 번호 순으로 이어서, 1명당 600ms)
1. (0–200) 퇴사자 머리 위 말풍선이 `icDoor`로 바뀌고, 직원이 의자에서 일어나(translateY −6) 오른쪽으로 24px 가며 α 1→0(200ms 동안 시작, 300ms에 끝).
2. (100–400) **충격 물결**: 퇴사자 카드 가운데에서 둥근 고리(테두리 2px `--loss`, α .35→0)가 카드 크기의 1.0배에서 1.3배로 퍼진다(300ms). 이웃으로 가는 **각 고리를 따라 점(지름 8, `--loss`)이 이웃 카드로 이동**(250ms). 고리 색은 그 순간 `--loss` 실선이 되었다가 끝나면 "흔들림 진행 중"(점선 `--warn`) 상태로 바뀐다.
3. (350–600) 이웃 카드에 도착하면: 머리 위에 **`−12` 칩**(`.num` 13px 800 `--loss-ink`, 바탕 `--panel`, 1px `--loss` 테두리, 보너스를 받은 직원이면 `−6` + `icShield`)이 위로 8px 떠오르며 900ms 유지 후 사라진다. 행복 게이지가 줄어들고(200ms) 얼굴이 바뀌며, 기준선 눈금이 30에서 40으로 옮겨 간다(`icCrack` 등장). 충격 뒤 H < 40이면 **봉투 말풍선이 바로 나타난다**(scale .6→1, 200ms) — 다음 연쇄 후보.
4. 이웃이 아닌 직원에게는 고리 이동 없이 `−3` 칩만 작게(11px) α로 나타났다 사라진다.
5. 퇴사자 카드는 빈 자리 카드로 바뀐다(크로스페이드 200ms). 빈 자리에서 나가는 고리는 "흔들림 진행 중" 점선(shaken이 남은 동안).

### 6. 월말 리포트 (`#ovReport`) — **이 게임의 핵심 화면**

#### ① 머리줄
- 왼쪽 "3월 결산" 20px 800(월은 `.num`). 오른쪽에 `icCoin` "현금" + `.num` 18px, 그 아래 `icRev` "올해 매출" + `.num` 18px(점수가 어떻게 쌓이는지 매달 보이게).
- 가운데 큰 이익: `.num` 40px(폰 32, H ≤ 520이면 28) + ▲/▼ 20px + 단어 "흑자"/"적자"/"본전" 15px 700, 색 규칙. 적자면 블록 바탕 `--cost-tint`.
- 적자 경고(design.md 빨간 배지): 적자 1달째 = `--warn` 알약 `icWarn` "적자 1달째 · 한 번 더면 파산"; 현금 < 0 = `--danger` 알약.

#### ② 돈
- 줄마다 `[아이콘 14] 이름 12px(폭 32) [막대] .num 15px 값`. 매출 `--rev`, 비용 `--cost`(결정 패널과 같은 구성 분할). 막대 오른쪽 작은 글 11px `--muted` "(월급 1,580 · 임대료 600 · 보너스 50)".
- 맨 아래 **현금 전→후**: `.num` 이전 현금 → 굵은 화살표(이익 색) 위에 `+420만` 칩 → `.num` 이후 현금.
- 막대는 왼쪽부터 채워지며 나타난다(400ms, 줄마다 80ms 시차).

#### ③ 매출 이유 (design.md 2번 블록)
- **첫 줄 = 원인→결과 사슬**: `[icOrder 주문 70]` ━▶ `[처리 52 + 처리량 막대]` ━▶ 결과 칩. 결과 칩은 놓친 주문이 있으면 `[놓침 18 = −900만]`(나쁨), 다 처리했으면 `[주문 전부 처리 · 여유 8]`(좋음).
- **둘째 줄 = 생산력 계수 칩**: `[기본 40]` × `[icWork 업무 ×1.15]` × `[icRest 휴식 ×0.90]` × `[icHappy 기분 ×1.00]` × `[icStar 숙련 ×1.05]` × `[icTired 피로 ×0.93]`. 칩 높이 26, 11px. 1.0보다 크면 좋음(▲), 작으면 나쁨(▼). **지난달과 달라진 계수 칩은 굵은 2px 테두리 + 오른쪽 위 작은 `--accent` 점**(design.md "지난달 대비 바뀐 계수 강조"). 칩 사이 `×`는 `--muted` 12px. 폭이 좁으면 줄을 바꾸고, 폰 가로에서는 바뀐 계수 칩만 남긴다.
- 셋째 줄: 문장 1개(13px `--muted`). design.md 자동 생성(가장 큰 항 2개)을 쓰고 20자 안팎으로 자른다. 예: "일손이 모자라 주문을 놓쳤어요", "업무를 늘려 처리량이 올랐어요".
- 첫 판 1월(최고 기록 없음): 이 블록을 맨 위(① 바로 아래)로 올리고 처리량 막대를 2배 높이로 키운다. design.md 한 줄 "업무량을 올리면 이번 달 처리량이 늘지만, 피로는 다음 달에 쌓여요"를 `icWork` 아이콘과 함께 넣는다.

#### ④ 퇴사·연쇄 (`.chain`, 사용자 추가 결정 — 있을 때만, 리포트에서 가장 눈에 띄게)
퇴사나 이직이 있었던 달, 또는 새 ✉·흔들림이 생긴 달에 나온다. 위쪽 4px 띠 `--danger`, 블록 제목 "퇴사와 연쇄"(11px 700 `--loss-ink`).
- **미니 자리표** (왼쪽, 3×2 칸, 칸 크기 22(폰 18), 간격 4, 칸 사이 고리 포함): 각 칸은 그 자리 색 원에 얼굴을 아주 작게 그린다(입 모양만 보이게). 퇴사한 칸 = 빈 칸 + `icDoor`. 충격을 받은 이웃 칸 = 테두리 2px `--loss` + 칸 아래 `.num` 10px `−12`. 퇴사자에서 이웃으로 가는 고리 = `--loss` 실선 + 화살촉. 이웃이 아닌 칸은 α .5. **자리 관계를 공간으로 보여 주는 그림**이다.
- **퇴사자 줄**: `[마지막 얼굴 28] → [icDoor 28]` 이름 15px 800 + "퇴사"(이직이면 "이직") 알약 `--danger` 테두리.
  - **근거 게이지**: 행복 게이지(폭 160, 폰 120, 높이 10)에 기준선 눈금 + 현재 값 + 기준선 아래 구간 `--loss` 빗금 + 오른쪽 `.num` "18 · 기준 30 아래 2달 · 확률 80%"(design.md 퇴사 문장의 숫자). 피로·번아웃이 원인에 들어가면 피로 게이지 줄을 더한다.
  - **가장 큰 이유** 칩 1개: 행복 공식에서 가장 큰 음수 항, 예: `[icPay 월급이 기대보다 45 적음 −5.6/월]`.
  - 스카우트 이직이면 근거 게이지의 기준선이 60이고 문장은 "다른 회사로 옮겼어요".
- **연쇄 줄** (퇴사자 줄 아래, 왼쪽 들여쓰기 20 + `━▶` 화살표로 이어짐): 이웃 1명당 한 줄.
  - `━▶ [얼굴 이전→이후 24] 이름  행복 46→34 −12 ▼` + 상태 아이콘: 충격 뒤 H < 40이면 `icLetter`(새 ✉, `--danger`) "다음 달 위험", 아니면 `icCrack` + `.num` "2달 흔들림"(`--warn`). 보너스로 반만 받았으면 `−6` 옆에 `icShield` "보너스로 절반".
  - 이웃이 아닌 직원은 한 줄로 묶는다: "그 외 [얼굴들 20] 행복 −3".
- **문장 1줄** (13px): "소리가 떠나 옆자리 두 명이 흔들려요" / "보너스 덕분에 충격이 절반이었어요".
- **막으려면 (차단 안내)**: 새 ✉이 생긴 이웃마다 한 줄. `막으려면` 12px 700 + `[그 직원 얼굴 20 이름]` + **바로 쓸 수 있는 조치 버튼**:
  - `[icBonus 보너스 · 행복 +10 · −50만]` `[icVacation 휴가 · 행복 +6]` (각 높이 44, secondary 작은 버튼). 누르면 다음 달 그 직원 조치로 **미리 설정**되고 버튼이 선택 상태(테두리 `--accent` + 체크)가 된다. 다시 누르면 해제된다. design.md "직원당 한 달 1개" 규칙대로 둘 중 하나만 고를 수 있다.
  - 함께 회사 전체 칩(버튼 아님) `[icWork 업무량 ▼]`을 보여 준다(design.md 예고 문장 "보너스 +10 또는 휴가 +6, 업무량↓").
- 연쇄가 이전 달에서 이어진 경우(흔들림 중이던 직원이 이번에 퇴사): 퇴사자 줄 이름 옆에 작은 꼬리표 `[icLink 3월 소리 퇴사의 여파]`. 결과 화면 "연쇄 퇴사" 개수로 센다.
- **새 ✉만 생긴 달**(퇴사는 없음): 이 블록에 퇴사자 줄 없이 "다음 달 위험" 줄만: `[icLetter 얼굴 이름] 행복 28 < 30` + 그 직원 이웃 미니 자리표(고리가 점선 `--danger`로 보이는 예고 상태) + 막으려면 버튼.

#### ⑤ 직원 (design.md 3번 블록, 최대 3명 + 접힌 "외 n명")
- 줄: `[이전 얼굴 28] → [이후 얼굴 28]` 이름 14px 700, 오른쪽 `[icHappy 60→52 −8 ▼]` `[icTired 30→47 +17 ▲]` 미니 칩(색 = 좋음/나쁨).
- 줄 아래 **이유 칩**(높이 22, 11px): 행복 변화 항 중 큰 것 2개. 예: `[icWork 업무 과중 −3]` `[icPay 기대보다 월급 20 적음 −2.5]`. 이웃 영향 항이 ±2 이상이면 **고리 칩** `[고리 아이콘 옆자리 새봄 덕분 +2]`(좋음, `--happy` 테두리) / `[고리 아이콘 옆자리 한결 때문에 −3]`. 이웃 기운이 어디서 왔는지 보인다.
- 번아웃 예고·병가는 이유 칩 `[icBed 피로 90 이상 → 다음 달 병가]`.
- ④에 나온 직원은 여기서 뺀다. 나머지는 (|ΔH| + |ΔF|) 큰 순서. 변화가 없으면 "모두 그대로예요" 한 줄.
- "외 n명" 칩(높이 32, 터치 영역 44)을 누르면 블록이 펼쳐져 전원을 보여 준다(그때만 리포트 안 스크롤 허용).

#### ⑥ 올해 매출 막대 + 다음 달 (`.year-chart`, SVG)
- 가로 12칸. 각 칸에 **월 매출 막대**(`--rev`, 폭 = 칸의 60%, radius 2)를 그린다. 이것이 쌓여 점수가 된다. 위에 **현금 꺾은선**(`--ink` α .55, 2px, 월말 점 r2.5). 현금 < 0인 달은 점을 `--loss` 속 빈 원으로. 이번 달 칸 바탕 `--accent` α .08 + 아래 월 숫자 굵게. 미래 칸은 빈 점선 바닥선만.
- **남은 달 예보**: 아직 오지 않은 달에는 기본 주문표 × 단가 높이의 점선 빈 막대(`--rev` α .55)를 그려 바쁜 달·한가한 달을 미리 보여 준다(결과 화면 큰 그래프에는 그리지 않는다).
- 높이 64(폰 48, H ≤ 520이면 숨김). 눈금 숫자는 없고 이번 달 막대 위에만 `.num` 11px 값.
- 오른쪽 끝: "다음 달 주문" `icOrder` + `.num` D(다음 달 사건이 예고되면 사건 아이콘도). 다음 결정을 미리 생각하게 한다.

#### 버튼
- `4월 결정하기 ▶`(primary, 높이 48, 오른쪽 아래). 12월 리포트에서는 `1년 결산 보기`. 게임오버가 확정된 달에는 `결과 보기`.
- 월 알약을 누르면 지난 리포트를 다시 볼 수 있다(최근 달부터, `‹ ›` 44px 버튼으로 이전 달 이동, 읽기 전용, 닫기 버튼).

### 7. 결산 / 게임오버 (`#ovResult`) — 순위 = 연 매출 (사용자 결정)
```

[ 월별 매출 막대 12개 (큰 그래프) + 현금 선 ]
[칩] 최종 현금 1,240만 · 퇴사 3명 (연쇄 1) · 남은 직원 5명
[ 남은 직원 얼굴 줄 (최대 6, 각 32px) ]
[ 다시 하기 ]  [ ← 게임 목록 ]
```
- **헤드라인 = 올해 매출**: 라벨 "올해 매출" 13px 700 `--muted`, 아래 줄 `.score-row`(`display:flex; flex-wrap:wrap; align-items:center; justify-content:center; gap:8px 12px`)에 `.num` 매출 숫자 44px(폰 세로 36, 폰 가로 32) + "만" 18px + **`<span id="lbSlot">`** 순위 칩. 순위 칩은 `lib/leaderboard.js`가 채우며 높이 36(H ≤ 520이면 28)이다. 매출 숫자와 같은 가로 줄에 세로 가운데 정렬하고, 폭이 모자라면 숫자 아래로 줄을 바꾼다. 이 줄의 높이 계산에 칩 높이를 포함한다.
  - 칩이 비어 있어도(순위표 모듈이 없거나 아직 불러오는 중) 자리가 흔들리지 않게 `min-width: 0`, 높이는 숫자 줄 높이 안에 들어간다.
- **사장 칭호**(design.md "사장 칭호"): 제목 아래 알약(14px 800, 1.5px `--accent` 테두리) "진짜 악덕 사장" / "천사 사장" / "명사장" / "깐깐한 사장". 게임오버 화면에도 표시.
- **등급 배지**(design.md: S ≥ 38,000 / A ≥ 33,000 / B ≥ 27,000 / C): 제목 옆 원형 배지 지름 32, `.num`이 아닌 글자 16px 900. S = `--gold` 바탕 + `--ink` 글자, A·B·C = `--panel` + 2px `--ink` 테두리. 등급 글자와 함께 아래 작은 글 "다음 등급까지 1,550만"(11px, S면 숨김).
- **상태 그림 (64px, 인라인 SVG)**:
  - 완주: 남은 콩 직원 최대 3명(활짝/웃음 얼굴 그대로) + 머리 위 `icStar` 3개. 제목 "1년을 버텼어요!".
  - 파산: `icEmpty` + 울상 콩 1명. 제목 "회사 돈이 바닥났어요". 부제 13px "N월, 2달 연속 적자"(12월 적자면 "12월 결산 적자").

- **남은 직원 얼굴 줄**: 마지막 표정 그대로, 자리 순서, 사이에 작은 고리. 폰 가로에서는 숨긴다.

- **폰 가로 750×342 (스크롤 0 필수)**: `ov-full`, 2열 grid(1fr 1fr, gap 12). 왼쪽 = 상태 그림 40 + 제목 18px + 등급 배지 24 / 라벨 + 매출 32px + 순위 칩(28, 같은 줄 또는 아래 줄) / 그래프 72. 오른쪽 = 게임오버 알약(해당 시) + 기록 칩 2×2 + 새 최고 알약 + 버튼 2개 가로. 측정 목표는 내용 높이 ≤ 318.

### 모션 줄이기 (`prefers-reduced-motion: reduce`)
- **유지**(정보): 단계 선택, 돈 막대·주문 보드·예상 숫자·표정 변경(즉시 교체, 이동 없음), 고리 색·배지, 봉투·금 간 하트 말풍선(α만), 리포트 내용과 미니 자리표, 날짜 막대.
- **끔/대체**:
  - 한 달 진행은 **600ms**다. 날짜 막대만 채워지고 끝에 모든 수치·표정이 한 번에 바뀐다.
  - 퇴사자는 이동 없이 α 200ms로 사라진다. 충격 물결과 점 이동 없이 **이웃 고리가 바로 `--loss` 실선(400ms 유지) → 점선 `--warn`**으로 바뀌고, 이웃 머리 위 `−12` 칩이 α만으로 900ms 보였다 사라진다(숫자 정보는 남긴다). 기운 점 이동 대신 받는 쪽 `+2`/`−3` 칩만 α로.
  - 동전 날기·타이핑·숨쉬기·톡 튀기·코치 링 맥동(고정 링으로 대체)은 없다.
  - 리포트 블록은 순서대로 나타나지 않고 한 번에(α 120ms), 막대·화살표·자리표 고리는 즉시. 사건 카드·오버레이 애니메이션은 없다.

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)
- **터치 대상은 모두 44×44 이상**: 단계 버튼(높이 44~48, 폭 ≥ 44, 320 폭 예외 40), 책상 카드(최소 88×59), `+ 채용`, 후보 시트 버튼, 막으려면 버튼(44), 리포트·결과 버튼(48/44), 상단 바 버튼과 월 알약(터치 44), "외 n명" 칩(높이 32, `::after`로 44 확보), 사건 확인 버튼(48).

## 접근성 (대비, 색 외 구분 수단)
- **행복/피로**: 아이콘(웃는 얼굴/땀방울) + 게이지 위치(위/아래 줄 고정) + 색. 얼굴은 입과 눈의 **모양**으로 표현한다(색이 아니다).
- **좋음/나쁨**: 색 + 칩 왼쪽 굵은 띠(나쁨) + 문장. **오름/내림**: ▲/▼ 모양 + 부호.
- **흑자/적자**: 색 + 부호 + ▲/▼ + 단어("흑자/적자").
- **퇴사 고민·흔들림·병가**: 서로 다른 아이콘(봉투/금 간 하트/침대) + 카드 테두리 모양(실선 2px / 1.5px / 없음) + 위험 줄 글자.
- **고리 상태**: 색 + 선 모양(실선/점선) + 배지 숫자 + 방패 아이콘(보너스). 색을 못 봐도 점선과 숫자로 연쇄 예고를 알 수 있다.
- **직원 구분**: 이름 + 머리 모양 + 자리 위치 + 색.
- **대비**: 글자는 `--ink`/`--muted`/`--good-ink`/`--loss-ink`/`--happy-ink`/`--tired-ink`만 쓴다(모두 패널 대비 4.5:1 이상, 표의 값). `--good`·`--loss`·`--warn`·`--rev`·`--cost`·`--happy`·`--tired`·`--link`는 막대·테두리·고리 같은 **비텍스트에만** 쓴다(`--link` 평상시 고리는 장식 수준이라 3:1 미만 허용, 정보가 있는 고리 상태는 모두 3:1 이상 색 + 배지).
- **스크린 리더**:
  - 책상 카드 `aria-label="자리 2, 소리, 행복 28 예상 24, 피로 55, 퇴사 고민 35%, 조치 없음. 누르면 휴가"`.
  - 연결 고리 SVG는 `aria-hidden`이며, 대신 각 카드 `aria-describedby`에 이웃 정보를 넣는다: "옆자리: 바름, 새봄. 소리가 떠나면 바름 행복 46에서 34".
  - 상태 바 각 칸 `aria-label`. 예상 이익 칸은 `aria-live="polite"`, 조작 후 400ms 디바운스로 "예상 이익 플러스 420만, 처리 52 / 주문 70".
  - 리포트가 열리면 제목으로 포커스를 옮기고, 블록마다 `<section aria-labelledby>`를 단다. 원인→결과 줄과 연쇄 줄은 숨김 텍스트로 "소리 퇴사. 그래서 옆자리 바름 행복 12 줄어 34, 다음 달 퇴사 위험".
  - 미니 자리표·그래프 SVG에는 `role="img"`와 요약 `aria-label`("소리 자리 비었고 바름, 새봄이 충격 받음" / "12달 매출 합계 38,450만, 최고 11월").
  - 장식 SVG(벽, 동전, 서류, 날아가는 점)는 `aria-hidden="true"`.
- **포커스 링**: 공통 `outline: 3px solid var(--accent); outline-offset: 2px`.
- 1초에 3번 넘게 번쩍이는 효과는 없다. 화면 흔들림도 없다.

## 개발자 체크리스트 (요약)
1. 얼굴 규칙 고정: **입 = 행복(4단계 70/45/30), 눈 = 피로(45/70)**. 시작 범례·카드·후보 시트·리포트·결과 모두 같은 SVG 심볼과 같은 경계값 함수.
2. 단계 버튼·조치·채용을 바꾸면 **같은 프레임에** 주문 보드 처리량, 돈 막대, 예상 이익, 직원 예상 표정·고스트, 고리 배지, 말풍선이 바뀐다(애니메이션 200ms 이하).
3. **자리 연결 고리 7개**를 카드 틈에 늘 그린다. 상태 우선순위는 연쇄 예고(점선 `--danger` `−12`/보너스 `−6`+방패) > 흔들림 > 나쁜 기운 > 좋은 기운. 레이아웃이 바뀌면 다시 계산한다.
4. 연쇄 연출: 충격 물결 → 고리를 따라 점 이동 → 이웃 머리 위 `−12` 칩 → 게이지 감소·기준선 40 이동·새 봉투. reduced-motion이면 이동 없이 색과 칩만.
5. 숫자에는 항상 부호·단위·▲▼. 색은 좋음/나쁨 규칙(방향 ≠ 좋음). 텍스트에는 `*-ink` 토큰만.
6. 월말 리포트: ① 이익(+올해 매출) → ② 돈 → ③ 매출 이유(주문→처리→놓침 사슬 + 계수 칩) → ④ **퇴사와 연쇄**(미니 자리표, 근거 게이지, `이름 퇴사 → 옆자리 이름 −12`, 막으려면 버튼) → ⑤ 직원(이유 칩, 옆자리 덕분/때문 칩) → ⑥ 올해 매출 막대. 화면별 배치표를 지키고 폰 가로 스크롤 0.
7. 한 달 진행 1500ms(퇴사 있으면 최대 2100), 건너뛰기 = 버튼·씬 탭·Space/Enter/Esc.
8. 결과 화면 헤드라인 = **올해 매출 숫자 + 바로 옆 `<span id="lbSlot">` 순위 칩**(flex-wrap 한 줄), 게임오버는 "그때까지 매출" + "12월까지 버텨야 순위에" 알약. **750×342 스크롤 0**.
9. 레이아웃 수치표 9개 화면 + 다크를 검증한다. 결정 패널 스크롤 0(H ≤ 360이면 시작 버튼을 상태 바로 옮김), `--app-h`, 안전 영역.
10. 상단 바·버튼·오버레이 CSS는 parrot-beat에서 복사, SVG 숨김은 `toggleAttribute('hidden')`, `.app` 조상에는 transform 금지.
11. CompanyDigits 폰트 이름 교체, OFL.txt 동봉, 글리프 `0-9 % + , - . / −`.
12. `prefers-reduced-motion` 분기(진행 600ms, 이동 없음, 숫자 칩은 유지).
