# 토끼 텐 (bunny-ten) — 사운드 명세

모든 소리는 Web Audio API로 실시간 합성한다(음원 파일 없음). 코드: `docs/games/bunny-ten/sound-module.js` — Developer가 게임 HTML의 독립 `<script>` 블록에 그대로 붙여 넣는다. API는 뱀 정원 모듈과 같은 형태이고, `play(name, opts)`에 옵션 인자가 추가됐다.

톤: 귀엽고 말랑한 "토끼" 느낌. 기본 재료는 sine/triangle, 그리고 토끼가 뛰는 소리인 **'깡충' 블립**(sine, 70ms 동안 피치가 2.2배로 올라감)이다. 자주 나는 소리(선택·미리 알림·실패)는 작고 짧게, 보상 소리(지우기·신기록)는 지운 개수만큼 풍성하게 한다. 조성은 F 메이저(펜타토닉 위주)로 BGM과 효과음을 맞췄다.

## 1. 효과음 목록

| 이름 (`Sound.play`) | 언제 | 합성 레시피 | 길이 |
|---|---|---|---|
| `start` | 게임 시작(첫 시작·다시 하기) | triangle F5→A5→C6, 90ms 간격, 피크 0.25 + 마지막 음에 깡충 블립(500Hz, 0.10) | ~0.4s |
| `select` | 드래그(선택) 시작 — **선택 사항** | sine 900→700Hz 35ms, 피크 **0.035**(아주 작은 '톡'). 80ms 안의 연속 호출 무시 | 0.035s |
| `ready` | 드래그 중 선택 합이 **10이 아니다가 10이 된 순간**(1회) | sine C6 70ms(0.07) → 50ms 뒤 F6 100ms(0.06), 작은 반짝 2음. 150ms 스로틀 | ~0.15s |
| `clear` | 합 10으로 지우기 성공. `{ count }` = 이번에 지운 토끼 수 | 아래 단계표 참조 | 0.3~0.7s |
| `miss` | 손을 뗐는데 합 ≠ 10 (선택 칸이 1개 이상일 때) | sine 330→220Hz 160ms(0.10, 어택 10ms) + 50ms 뒤 triangle 247→196Hz 140ms(0.05). 부드러운 하강 '뿌우'. 120ms 스로틀 | ~0.2s |
| `tick` | 남은 시간 10,9,…,1초 정수 경계마다 1회. `{ urgent: true }` = 마지막 3초 | sine 1200→960Hz 40ms(0.10) + bandpass 1.8kHz 노이즈 30ms(0.035) — 우드블록 '톡'. urgent: 1600Hz, 0.14 / 노이즈 0.05 | 0.04s |
| `timeUp` | 시간 0 → 게임 종료 | sine 벨 C6 600ms(0.16) + 배음 C6×2.76 250ms(0.03) → triangle A5, F5, C5 하강(0.18) + sine F3 저음(0.12) | ~1.0s |
| `highScore` | 최고 점수 갱신 (아래 규칙) | 깡충 3번(450/520/600Hz) → square C5-F5-A5 각 90ms(0.08) → triangle C6+F5 화음 500ms(0.24/0.12) + sine A6 반짝(0.04) + highpass 노이즈 쉬머 | ~1.1s |
| `pause` / `resume` | 일시정지 / 재개 (선택) | sine A4→F4 하강 / F4→A4 상승, 120ms, 0.10 | 0.12s |

### `clear` 단계 (지운 수가 많을수록 풍성하게)

모든 단계 공통: 지운 토끼 수만큼 **깡충 블립**을 45ms 간격으로 연속 재생(최대 6번, 시작 피치 420Hz에서 한 번마다 +60Hz씩 올라감, 피크 0.09) — 토끼들이 차례로 뛰는 느낌. 그 위에 40ms 뒤부터 차임:

| 지운 수 | 차임 | 체감 |
|---|---|---|
| 2개 (최소) | triangle C6 100ms(0.20) → F6 160ms(0.18) | 가볍고 짧은 '띵동' (~0.3s) |
| 3개 | triangle A5-C6-F6 60ms 간격(0.20) + sine A6 반짝(0.04) | 3음 아르페지오 (~0.4s) |
| 4개 이상 | triangle F5-A5-C6-F6 50ms 간격(0.20) → F6 길게 400ms(0.16) + sine A6(0.06) + sine F4 저음 450ms(0.12) + highpass 7kHz 노이즈 쉬머 300ms(0.035) | 화음과 반짝임이 있는 풍성한 소리 (~0.65s) |
| 6개 이상 | 4개+ 소리에 고음 반짝 꼬리 2음(A6, C7) 추가 | 가장 화려함 |

- `count`가 없거나 숫자가 아니면 2개 단계로 재생한다. 1개(숫자 10 토끼가 있다면)도 2개 단계 차임 + 깡충 1번.
- 효과음 마스터 볼륨 0.5. 모든 엔벨로프는 gain 0.0001 → 피크 지수 어택 → 0.0001 지수 감쇠(클릭음 방지).

### 판단 메모
- **`select`(선택 시작)**: 모듈에는 넣었지만 **기본은 호출하지 않는 것을 권장**. 이 게임은 드래그가 매우 잦고 `ready`/`clear`/`miss`가 이미 피드백을 준다. 청취 후 터치 반응이 밋밋하다고 느껴질 때만 Developer가 드래그 시작에 `Sound.play('select')`를 추가한다.
- **`ready`(합 10 미리 알림)**: 넣는다. 큰 판에서 "지금 놓으면 된다"를 알려 주는 유용한 신호. 단 **합이 10으로 '바뀐' 순간에만** 호출해야 한다(드래그 이동 중 계속 10이면 다시 부르지 않음, 10→11→10이면 다시 1회). 모듈의 150ms 스로틀은 안전장치일 뿐이고, 상태 변화 판정은 Developer가 한다.
- **`miss`**: 벌칙이 아니라 "아니야~" 정도의 부드러운 소리. 선택 칸이 0개(빈 공간 탭)일 때는 울리지 않는다.
- **`tick`**: 마지막 10초 동안 1초에 1번. 마지막 3초(3, 2, 1)는 `urgent`로 조금 높고 크게. 일시정지 중에는 울리지 않는다(남은 시간이 줄지 않으므로 자연히 호출되지 않아야 함).

## 2. 배경음악 (낮은 볼륨)

- **판단**: 기본 켜짐, 매우 낮은 볼륨(음악 버스 0.06 × 마스터 0.5). 플레이 중에만 재생, 일시정지·시간 종료 시 정지. 별도 음악 토글 없이 음소거 버튼 하나로 효과음+음악을 함께 끈다.
- **오리지널 루프**: 뮤직박스풍. F 메이저 펜타토닉, 92 BPM, 8분음표 그리드, 32스텝(4마디, 약 10.4초) 반복.
  - 멜로디(sine 본음 0.5 + 한 옥타브 위 sine 배음 0.12, 짧게 감쇠):
    `C5 · F5 G5 A5 · G5 · | F5 · D5 · C5 · · · | D5 · F5 · G5 A5 C6 · | A5 · G5 · F5 · · ·` (· = 쉼표)
  - 베이스(triangle): 마디마다 F3, D3, A3, C3를 1·3박에 짧게 '퐁' + 2·4박 뒤에 5도 위(×3) 작은 '톡'
- 스케줄링: `setTimeout` 100ms 주기, 250ms 룩어헤드로 `ctx.currentTime` 기준 예약. 탭 복귀 시 다음 예약 시각을 현재 시각 뒤로 당겨 밀린 음이 한꺼번에 몰려 나오지 않게 한다.
- 기존 게임 음악·멜로디를 재현하지 않은 오리지널 패턴이다.
- 마지막 10초에도 BGM은 그대로 두고 `tick`만 얹는다(템포 변경 없음 — 단순성 우선).

## 3. 오디오 시스템

### 음소거 토글
- `localStorage` 키 **`bunny-ten-muted`** (`'1'` = 음소거, `'0'` = 소리 켬). 모듈 로드 시 읽고 `setMuted()` 때 저장. 읽기/쓰기 모두 `try/catch` — 사생활 보호 모드 등 저장소 접근 불가 시에도 기본값(소리 켬)으로 동작.
- 음소거 시 마스터 게인을 20ms 시정수로 0으로 내림. `play()`는 음소거 중 아무 노드도 만들지 않는다.
- UI: 🔊/🔇 버튼. 표시 상태는 페이지 로드 시 `Sound.isMuted()`로 초기화.

### iPad Safari 오디오 잠금 해제
- AudioContext는 **사용자 제스처 핸들러 안에서** 처음 생성/`resume()`해야 한다. `Sound.unlock()`이 처리한다(최초 호출 시 컨텍스트 생성 + `resume()` + 1샘플 무음 버퍼 재생으로 iOS 출력 경로 활성화). 여러 번 불러도 안전.
- Developer는 시작 버튼 `click`, 판의 `pointerup`/`touchend`, `keydown`, 일시정지·음소거 버튼 핸들러 맨 앞에서 `Sound.unlock()`을 호출한다. iOS에서는 `touchstart`/`pointerdown`보다 `touchend`/`pointerup`/`click`이 더 확실하다. 시작 버튼 클릭이 가장 확실한 첫 지점이다.
- unlock 전의 `play()`/`startMusic()`은 조용히 무시된다. 따라서 **시작 버튼 핸들러에서는 반드시 `Sound.unlock()` → `Sound.play('start')` → `Sound.startMusic()` 순서**.
- **무음 스위치**: iPad 측면 무음 스위치/제어 센터 무음 모드가 켜져 있으면 Web Audio 소리가 나지 않을 수 있다. 게임 오류가 아니다. 도움말에 "소리가 안 나면 무음 모드와 볼륨을 확인하세요" 한 줄을 권장.
- 탭 전환/홈 화면: `visibilitychange`에서 `ctx.suspend()`, 복귀 시 `ctx.resume()` (모듈이 자동 처리). 게임 타이머 일시정지는 Developer 몫.
- AudioContext 미지원·생성 실패 시 모든 메서드는 조용히 무시(게임은 소리 없이 정상 진행).

## 4. Developer 호출 지점

| 위치 | 호출 |
|---|---|
| 모든 사용자 입력 핸들러(시작/다시 하기 버튼 click, 판 pointerup/touchend, keydown, 일시정지·음소거 버튼) 맨 앞 | `Sound.unlock()` |
| 게임 시작/다시 하기 | `Sound.play('start'); Sound.startMusic();` |
| (선택, 기본 미사용) 드래그 시작 | `Sound.play('select')` |
| 드래그 중 선택 합이 10이 **아니었다가 10이 된** 순간 | `Sound.play('ready')` |
| 손 뗌 + 합 = 10 → 토끼 제거 | `Sound.play('clear', { count: 지운토끼수 })` |
| 손 뗌 + 합 ≠ 10 (선택 칸 1개 이상) | `Sound.play('miss')` |
| 남은 시간이 10, 9, …, 4초가 되는 순간 | `Sound.play('tick')` |
| 남은 시간이 3, 2, 1초가 되는 순간 | `Sound.play('tick', { urgent: true })` |
| 시간 0 → 종료 | `Sound.stopMusic(); Sound.play('timeUp');` |
| 최고 점수 갱신 | 기본: 종료 시 신기록이면 `timeUp` 약 1.0초 뒤 `Sound.play('highScore')` (결과 화면 표시와 함께). 플레이 중 이전 최고 점수를 처음 넘은 순간에 1회 울리는 방식도 가능 — 둘 중 하나만 택하고 게임당 1회 |
| 일시정지 | `Sound.stopMusic(); Sound.play('pause');` |
| 재개 | `Sound.play('resume'); Sound.startMusic();` |
| 음소거 버튼 | `Sound.unlock(); Sound.setMuted(!Sound.isMuted());` 후 아이콘 갱신 |
| 페이지 로드 시 음소거 아이콘 초기화 | `Sound.isMuted()` |

- 최고 점수 기록 0(첫 플레이)일 때 신기록 처리 여부는 기획(design.md)에 따른다. 점수 0으로 끝나면 `highScore`는 울리지 않는 것을 권장.

## 5. 검증 / 청취 확인 필요
- 확인됨: `node --check` 문법 통과. Node `vm`(window에 AudioContext 없음, localStorage 접근 시 예외)에서 로드·모든 메서드 호출 예외 없음. Chromium(Playwright) 빈 페이지에 주입해 unlock 전후 모든 `play()`(clear count 1/2/3/4/5/6/10/170, 인자 없음, 잘못된 값, tick urgent)·음악 1.2초 재생·정지·재시작, 음소거 저장(`'1'`→`'0'`) 시 페이지 오류 없음. AudioContext를 지운 페이지에서도 예외 없음. localStorage가 막힌 about:blank에서도 로드됨.
- **청취 확인 필요**(헤드리스로는 들을 수 없음): `clear` 2/3/4+ 단계 차이가 귀로 구분되는지, 깡충 블립이 귀엽게 들리는지(너무 '삑' 같으면 피크 낮춤), `ready`가 충분히 작은지, `miss`가 불쾌하지 않은지, `tick`이 BGM 위에서 잘 들리면서 거슬리지 않는지, BGM 볼륨·루프 이음매, 실제 iPad Safari에서 첫 터치 후 소리가 나는지·무음 스위치 동작.
