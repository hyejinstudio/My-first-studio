# 토끼 텐 기획서
- slug: bunny-ten
- 한 줄 소개: 숫자를 든 토끼들을 네모로 감싸 합이 10이 되면 깡충 뛰어 사라지는 숫자 퍼즐
- 상태: 기획 (첫 버전)
- 참고: "합이 10이면 사라지는 숫자 상자" 장르 규칙만 빌린 오리지널. 원작의 이름·아트·화면 구성은 쓰지 않는다.

## 핵심 루프
1~9 숫자를 든 토끼가 17 × 10 격자에 가득 → 드래그로 직사각형을 그림 → 직사각형 안 숫자 합이 실시간으로 보임 → 손을 떼는 순간 합이 정확히 10이면 그 토끼들이 깡충 뛰어 사라지고 사라진 수만큼 점수 → 빈칸이 늘수록 멀리 떨어진 토끼끼리도 묶을 수 있게 됨 → 120초 동안 최대한 많이 지운다.

## 규칙
### 보드·숫자 배치
- 격자 17열 × 10행 = 170칸. 시작 시 모든 칸에 토끼 1마리, 숫자는 1~9 균등 무작위.
- **시작 판 총합을 10의 배수로 맞춘다.**
  - 방법: 170개를 무작위로 만든 뒤 총합 % 10 = r 이 0이 아니면, 무작위 칸 하나를 골라 값을 바꿔 r을 줄인다(값이 1~9 범위를 벗어나지 않는 만큼만 조정). r이 0이 될 때까지 반복.
  - 이유: 모든 토끼를 지우려면 총합이 10의 배수여야 한다(필요조건). 비용이 거의 없고 "이론상 전부 지울 수 있을지도" 하는 목표감을 준다. 완전 클리어를 보장하지는 않는다.
- **시작 판 최소 조합 보장**: 생성 직후 "합 10인 직사각형" 개수(아래 판정과 같은 방법으로 셈)가 15개 미만이면 판을 다시 만든다(최대 20회, 그래도 미달이면 마지막 판 사용). 사실상 거의 발동하지 않는 안전장치.
- 토끼가 사라진 칸은 빈칸(값 0)으로 남는다. 위 토끼가 떨어지거나 새 토끼가 채워지지 않는다.

### 선택 판정
- 드래그 시작점과 현재 손가락/마우스 위치를 두 꼭짓점으로 하는 축 정렬 직사각형.
- **포함 기준: 셀의 중심점이 직사각형 안(경계 포함)에 있으면 포함.** 반 칸 이상 덮어야 들어가므로 손가락이 약간 빗나가도 의도대로 잡힌다.
- 드래그 시작은 보드 영역(보드 바깥 여백 0.5칸 포함) 안에서만 인정. 드래그 중 포인터가 보드 밖으로 나가면 직사각형을 보드 경계로 잘라서 계속 유지(포인터 캡처).
- 시작점에서 8px 미만 움직이고 뗀 경우(탭)는 선택 없음, 판정 없음.
- **빈칸 포함 허용**: 빈칸은 0으로 더한다. 직사각형 안 토끼가 1마리뿐이면 합이 10이 될 수 없으므로 자연스럽게 무효.
- 동시 터치: 첫 번째 포인터만 사용, 이후 포인터는 무시.
- `pointercancel`(시스템 제스처 등) 시 선택 취소, 판정 없음.

### 실시간 표시와 피드백
- 드래그 중 직사각형 테두리 + 포함된 토끼 강조 + 직사각형 모서리 근처(손가락에 가리지 않게 손가락 위쪽)에 현재 합계 숫자 표시.
- 합에 따른 상태:

| 합 | 드래그 중 표시 | 손 뗐을 때 |
|---|---|---|
| 0~9 (미만) | 중립색 테두리, 합계 숫자 | 선택 사라짐 + 작은 "툭" 흔들림(0.2초), 벌점 없음 |
| 10 | 초록 계열 강조, 합계 "10" 강조 | 포함 토끼 전부 깡충 사라짐, 점수 + 사라진 수 |
| 11 이상 (초과) | 빨강 계열 테두리 | 미만과 동일(흔들림), 벌점 없음 |

- 실패에 벌점·시간 감소 없음. 부담 없이 드래그해 합을 확인하는 것도 플레이 방식으로 허용.
- 사라짐 연출 0.35초 동안에도 다음 드래그 가능(판정은 즉시 반영, 연출만 남음).

### 점수
- 점수 = 지운 토끼 수. 한 번에 지운 마리 수만큼 더한다(2마리 조합 +2, 1+2+3+4 조합 +4). 배율·콤보 없음.
- 최대 점수 170 (판 전체 클리어).
- 최고 점수: localStorage `bunny-ten-best`. 게임 종료 시 현재 점수가 더 크면 갱신. 저장소 접근 실패 시 0으로 보고 게임은 정상 진행.

### 시간·종료
- 제한 시간 120초. 첫 드래그가 아니라 "시작" 버튼을 누른 순간부터 흐른다.
- 상단 시간 막대 + 남은 초 표시.
- **마지막 10초 경고**: 시간 표시와 막대가 빨강으로 바뀌고 1초마다 한 번 맥동(크기 1.0 → 1.15 → 1.0). 매초 경고음은 sound.md에 따름.
- 종료 조건 (먼저 오는 것):
  1. 시간 0초 → "시간 끝!"
  2. 판 전체 클리어(170마리) → "판 완성!"
  3. **더 이상 합 10 조합이 없음** → "더 이상 10을 만들 수 없어요" 로 **조기 종료**.
     - 판단: 매 성공 판정 직후 모든 직사각형(170칸 기준 약 8,400개)을 2차원 누적합으로 검사. 토끼가 2마리 이상 들어 있고 합이 10인 직사각형이 하나도 없으면 종료. 계산량 작아 즉시 처리 가능.
     - 이유: 남은 시간을 헛되이 기다리게 하지 않음. 시간이 남아 있어도 점수는 그대로(보너스 없음).
- 시간이 0이 되는 순간 드래그 중이면 그 선택은 취소(판정하지 않음).

### 일시정지
- Ⅱ 버튼 / P / Esc로 일시정지, 탭이 숨으면(visibilitychange) 자동 일시정지.
- 일시정지 중 타이머 정지, **보드는 불투명 덮개로 가림**(멈춘 채 조합을 찾는 것 방지). "일시정지" + "계속" 버튼.
- 드래그 중 일시정지되면 선택 취소.

## 조작
| 동작 | PC | iPad |
|---|---|---|
| 직사각형 선택 | 마우스 왼쪽 드래그, 버튼 놓을 때 판정 | 손가락 드래그, 손 뗄 때 판정 |
| 시작 | "시작" 버튼 클릭 / Enter / Space | "시작" 버튼 탭 |
| 일시정지/재개 | Ⅱ 버튼 / P / Esc (재개: 같은 키 또는 Enter) | Ⅱ 버튼 / "계속" 버튼 |
| 재시작 (종료 후) | "다시 하기" / Enter / Space | "다시 하기" 버튼 |

- 게임 화면에서 터치 스크롤·확대·더블탭 확대·길게 눌러 텍스트 선택/돋보기를 막는다(보드에 `touch-action: none`, `user-select: none`).
- 키보드로 셀을 선택하는 기능은 없음(범위 밖).

### iPad 셀 크기 검토
| 환경 | 보드에 쓸 수 있는 폭(대략) | 셀 한 변 |
|---|---|---|
| iPad 10.2" 가로 (1080 × 810pt) | 폭 1040 / 높이 약 620(HUD·브라우저 바 제외) | 약 61 → 높이 제한으로 **약 60pt** |
| iPad mini 가로 (1133 × 744pt) | 높이 약 560 | **약 54pt** |
| iPad 세로 (810pt 폭) | 폭 780 | **약 45pt** |
| iPad mini 세로 (744pt 폭) | 폭 714 | **약 42pt** |

- 셀 크기 = min(사용 가능 폭 / 17, 사용 가능 높이 / 10), 정사각 셀. 보드는 화면 가운데.
- 판정이 "셀 중심 포함"이라 손가락 정밀도 요구가 낮다(셀 반 칸, 약 21pt 오차 허용). 세로 42pt도 플레이 가능.
- **가로 모드 권장**: 17 × 10 비율이 가로형이라 가로에서 셀이 30% 이상 크고 화면을 꽉 채운다. 세로 모드에서도 막지 않고 동작하되, 시작 화면에 "가로로 돌리면 더 크게 보여요" 안내 한 줄만 표시(세로일 때만).
- 숫자 글자 크기는 셀의 약 50%. 토끼 그림이 숫자를 가리지 않게(세부는 art-ui.md).

## 화면 흐름
1. **시작 화면**: 제목 "토끼 텐", 규칙 한 줄("네모로 감싸서 합이 10이면 사라져요"), 최고 점수, "시작" 버튼, (세로일 때) 가로 권장 안내. 보드는 흐리게 배경으로 보임.
2. **플레이**: 상단 HUD에 점수 / 최고 점수 / 남은 시간(막대+초) / Ⅱ 버튼. 아래 보드.
3. **일시정지**: 위 "일시정지" 규칙.
4. **종료**: 입력 정지 → 덮개에 종료 사유("시간 끝!" / "판 완성!" / "더 이상 10을 만들 수 없어요"), 이번 점수, 최고 점수, 새 기록이면 "새 기록!", "다시 하기" 버튼.
   - 덮개가 뜬 뒤 0.7초 동안 재시작 입력 무시(드래그 중이던 손가락으로 바로 눌리는 것 방지).
5. **재시작**: 새 판 생성(위 배치 규칙), 점수 0, 시간 120초로 즉시 플레이.

## 난이도·밸런스 수치
| 항목 | 값 |
|---|---|
| 격자 | 17열 × 10행 (170칸) |
| 숫자 | 1~9 균등 무작위, 시작 총합 10의 배수로 보정 |
| 시작 판 최소 조합 수 | 15개 (미달 시 재생성, 최대 20회) |
| 목표 합 | 정확히 10 |
| 포함 기준 | 셀 중심이 직사각형 안(경계 포함) |
| 빈칸 | 선택에 포함 가능, 값 0 |
| 드래그 인정 최소 이동 | 8px |
| 제한 시간 | 120초 |
| 시간 경고 | 마지막 10초 (빨강 + 1초마다 맥동) |
| 점수 | 지운 토끼 1마리당 1점, 최대 170 |
| 실패 벌점 | 없음 |
| 사라짐 연출 | 0.35초 (입력 막지 않음) |
| 실패 흔들림 | 0.2초 |
| 조합 없음 | 즉시 조기 종료 |
| 종료 후 입력 잠금 | 0.7초 |
| 최고 점수 저장 | localStorage `bunny-ten-best` |

- 난이도 곡선: 별도 단계 없음. 초반엔 인접한 쉬운 짝(1+9, 4+6 등)이 많고, 후반엔 빈칸이 많아져 멀리 떨어진 토끼를 큰 네모로 묶는 판단이 필요해지는 자연스러운 곡선. 참고 목표치: 처음 하는 사람 40~70점, 익숙하면 100점 이상.

## 콘텐츠
- 모드 1개(120초 타임어택), 판 1종(17 × 10 무작위). 아이템·특수 토끼 없음.
- 토끼는 모두 같은 모양, 숫자만 다름. 분위기는 풀밭/들판의 밝은 톤(세부는 art-ui.md).
