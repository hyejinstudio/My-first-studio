# 토끼 텐 아트·UI 명세

> slug: `bunny-ten` · 기획서 `docs/games/bunny-ten/design.md`와 같은 수치 사용 (판 17열×10행, 숫자 1~9, 제한 시간 120초, 점수 = 지운 토끼 수).
> 선택 판정 규칙(어느 칸이 사각형에 포함되는지)은 design.md를 따른다. 이 문서는 **판정된 칸 범위를 어떻게 보여 줄지**를 정한다.
> 모든 그래픽은 Canvas 2D 도형과 CSS로 그린다. 이미지 파일·이모지 그래픽 없음. 원작(Fruit Box)의 사과 모양·빨강 판·레이아웃을 따르지 않는다.

## 스타일 콘셉트
- "봄 들판의 토끼 학교": 연한 풀빛 들판 위에 하얀 토끼 170마리가 줄지어 앉아 저마다 숫자를 얼굴에 붙이고 있다. 합이 10이 되게 감싸면 토끼들이 깡충 뛰어 화면 밖으로 사라지고, 그 자리엔 작은 굴 구멍만 남는다.
- 스튜디오 공통: 따뜻한 종이색 배경(`--bg`), 흰 패널 카드, 주황 강조색(`--accent`), 둥근 모서리, 그림자 대신 면 색 차이 (블록 스택·뱀 정원과 같은 플랫 톤).
- **가독성이 최우선**: 토끼는 모두 같은 흰 털, 숫자는 모두 같은 진한 글자색. 숫자별로 색을 바꾸지 않는다.
  - 이유: 합 10 조합은 2~5개 숫자가 섞이므로 색 규칙이 오히려 시선을 흩뜨리고, 170칸이 알록달록하면 숫자 판독이 느려진다. 색은 "선택 상태(합 <10 / =10 / >10)" 전달에만 쓴다.
- 폰트: 사이트 공통 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **토끼 숫자만** `ui-rounded, "SF Pro Rounded", system-ui, sans-serif` 800 (iPad/Mac에서 둥근 숫자, 없으면 시스템 폰트). 모든 숫자 `tabular-nums`.

## 레이아웃 (PC / iPad 세로 / iPad 가로)

### 공통 구조 (위→아래, 한 화면 안, 스크롤 없음)
```
[← 게임 목록] 토끼 텐     [점수][최고][시간]  [🔈][Ⅱ]   ← 상단 바 52px (아이콘은 SVG)
[■■■■■■■■■■■■■■■■■■■■■■■■■■■□□□□□□□□]               ← 시간 막대 10px
┌──────────── 들판 보드 (17×10 또는 10×17) ────────────┐
│  토끼 토끼 토끼 ...                                    │
└───────────────────────────────────────────────────────┘
```
- 뱀 정원과 달리 링크 행과 HUD 행을 **한 줄(상단 바)로 합친다** — 판을 최대한 크게 쓰기 위해.
- 상단 바: 왼쪽 "← 게임 목록" 링크 + 제목 "토끼 텐"(18px 800), 오른쪽 HUD 카드 3개 + 음소거 + 일시정지. 너비 < 560px이면 제목 숨기고 링크 글자를 "← 목록"으로.
- 시간 막대: 보드와 **같은 너비**, 보드 바로 위.
- 상단 바·시간 막대·보드 묶음은 가로 가운데 정렬, 세로로는 남는 공간이 있으면 묶음 전체를 가운데(`justify-content: center`)에 둔다.

### 높이 기준 레이아웃 규칙 (필수)
1. **`--app-h`**: JS로 `window.innerHeight + 'px'`를 `resize`·`orientationchange`·`visualViewport.resize` 때 갱신. CSS 기본값 `100dvh`(미지원 시 `100vh`). `100vh` 단독 사용 금지.
2. `html, body { height: var(--app-h); overflow: hidden; }` — 세로·가로 스크롤 없음.
3. body 패딩 `max(12px, env(safe-area-inset-*))` 네 방향, viewport meta에 `viewport-fit=cover`.
4. 고정 높이 합 `F = 52(상단 바) + 8(간격) + 10(시간 막대) + 8(간격) = 78px`.
   가용 영역 `W = innerWidth − 좌우 패딩`, `H = app-h − 상하 패딩 − F`.
5. **판 방향 자동 선택 (회전 규칙)** — JS로 계산:
   - 가로형(17열×10행): `cA = min(W/17, H/10)`
   - 세로형(10열×17행): `cB = min(W/10, H/17)`
   - `cB > cA × 1.1`이면 **세로형으로 회전**, 아니면 가로형. 결과적으로 iPad 세로·폰 세로는 10×17, iPad 가로·PC·폰 가로는 17×10.
   - 칸 크기 `c = floor(min(선택한 값, 64))` (최대 64px — PC 큰 화면에서 판이 과하게 커지지 않게). 보드 픽셀 = `c × 열` × `c × 행` + 테두리.
   - 회전은 **표시만** 바꾼다. 논리 판은 항상 17×10(`x 0~16, y 0~9`). 세로형 표시 좌표 = 전치(`표시열 = y, 표시행 = x`). 직사각형은 전치해도 직사각형이고 합도 같으므로 규칙 영향 없음. 숫자 글자는 회전하지 않고 항상 똑바로.
   - 게임 중 기기를 돌리면: 진행 중인 드래그는 취소(판정 없음), 판을 새 방향으로 다시 그린다. 시간은 계속 흐름(일시정지 안 함).
6. 수치 (패딩 12px 기준, 계산 예):

| 화면 | 방향 | 칸 c | 보드 크기 |
|---|---|---|---|
| PC 1280×800 | 17×10 | min(73.8, 69.8, 64) = **64** | 1088×640 |
| iPad 가로 1080×810 | 17×10 | min(62.1, 70.8) = **62** | 1054×620 |
| iPad 가로 1080×740 (Safari 주소창) | 17×10 | min(62.1, 63.8) = **62** | 1054×620 |
| iPad 세로 810×1080 | 10×17 | min(78.6, 57.5) = **57** (가로형이면 46) | 570×969 |
| iPad 세로 Safari 실높이 ~1000 | 10×17 | **53** | 530×901 |
| 폰 세로 390×750 (Safari ~660) | 10×17 | **33** (가로형이면 21) | 330×561 |
| 폰 가로 844×390 | 17×10 | **28** | 476×280 |

7. **셀 최소 크기**: 목표 ≥ 32px, 허용 하한 28px. c < 36이면 토끼 눈·볼을 생략(아래 참조). c < 28이 되는 아주 작은 화면도 스크롤 없이 그대로 축소(경고 없음).
8. 캔버스 내부 해상도 = 표시 크기 × `devicePixelRatio`(최대 2). 크기 바뀌면 캔버스·스프라이트 다시 생성.
9. **검증 기준** (QA와 공유): `node tests/smoke.js bunny-ten`로 PC, 810×1080, 1080×810(가능하면 1080×740, 390×750)에서 `document.documentElement.scrollHeight ≤ innerHeight`, `scrollWidth ≤ innerWidth`, 보드 `getBoundingClientRect().bottom ≤ innerHeight − 4`, 810×1080에서 세로형(보드 높이 > 너비).

### 보드
- 테두리 `4px solid var(--meadow-edge)`, `border-radius: 14px`, 안쪽 캔버스 `border-radius: 10px`, 바탕 `--meadow`. 칸 사이 선 없음.
- 보드 감싸는 요소(`.board-wrap`)에 패딩 10px을 두고 그 영역에서도 드래그 시작 가능(가장자리 토끼를 잡기 쉽게). 좌표는 보드 안으로 clamp.

### "← 게임 목록" 링크
- 뱀 정원과 동일: 14px `var(--muted)`, 밑줄 없음, `min-height: 44px; display: inline-flex; align-items: center; padding: 0 8px; margin-left: -8px`, hover/focus 시 `var(--ink)`, 대상 `../../`. 확인창 없이 이동.

## 토끼 그리기 (Canvas 2D, 칸 왼쪽 위 기준, c = 칸 크기)
숫자 9종 × 상태(보통/선택됨)를 **오프스크린 캔버스 스프라이트로 미리 그려** `drawImage`한다 (170칸 매 프레임 도형 그리기 방지). c·테마·dpr이 바뀌면 다시 생성.

그리는 순서 (뒤 → 앞):
1. **귀 2개** (머리보다 먼저 — 머리가 귀 아래쪽을 덮음)
   - 타원 중심 `(.5c ∓ .15c, .25c)`, 가로반지름 `.085c`, 세로반지름 `.19c`, 바깥쪽으로 ∓12° 기울임(왼귀 −12°, 오른귀 +12°).
   - 채움 `--fur`, 윤곽 `--fur-edge` lineWidth `max(1, .03c)`.
   - 귀 안쪽: 같은 중심에서 아래로 `.02c`, 가로반지름 `.04c`, 세로반지름 `.12c`, `--ear-in`.
2. **머리**: 원 중심 `(.5c, .60c)`, 반지름 `.36c`, 채움 `--fur`, 윤곽 `--fur-edge` 같은 굵기. (꼭대기 .24c, 바닥 .96c — 칸 안에 들어감)
3. **눈** (c ≥ 36일 때만): 원 반지름 `.035c`, `--num`, 위치 `(.5c ∓ .21c, .50c)`. 숫자 양옆 위.
4. **볼** (c ≥ 36일 때만): 타원 `(.5c ∓ .24c, .72c)`, 가로 `.055c` 세로 `.032c`, `--blush` alpha .55.
5. **숫자**: 머리 중앙 `(.5c, .64c)`, `textAlign center`, `textBaseline middle`, 글꼴 `800 max(13px, .42c) ui-rounded, ...`, 색 `--num`. 숫자가 얼굴의 "입" 자리에 있어 가장 크게 보인다.
- 6과 9 혼동 방지: 숫자 6·9 아래에 짧은 밑줄(폭 `.14c`, 굵기 `max(1.5, .025c)`, `--num`, 숫자 아래 `.2c`)을 그린다. 판이 회전돼도 글자는 항상 똑바로지만, 사용자가 기기를 돌려 보는 경우 대비.
- **빈 칸**(지워진 자리): 칸 중심 아래쪽 `(.5c, .78c)`에 타원 가로 `.20c` 세로 `.07c`, `--burrow`. 토끼가 떠난 굴 구멍.
- **선택 중인 토끼**: 털 색을 상태색과 섞은 버전(`--fur` 80% + 상태색 20%)으로 그린다. 합 = 10일 때는 귀가 쫑긋(아래 애니메이션).

## HUD·메뉴·오버레이

### 상단 바 HUD
- 카드 3개(`점수`, `최고`, `시간`): 뱀 정원 `.card`와 동일 — 배경 `--panel`, 테두리 1px `--grid`, radius 10px, 패딩 4px 12px, 높이 ≤ 48px. 라벨 11px 600 `--muted` 자간 .08em, 값 20px 700 `--ink` tabular-nums, 최소 너비 64px.
- `시간` 값은 남은 초 정수(올림). 마지막 10초는 아래 경고 규칙.
- 이번 판에서 최고 점수를 넘는 순간부터 `최고` 카드 값 색 `--accent`.
- 버튼 2개 (44×44px, 카드와 같은 배경·테두리, radius 10px, 인라인 SVG 아이콘 20px `--ink`):
  - 음소거: 스피커 모양 / 스피커+사선. `aria-label="소리 끄기"`/`"소리 켜기"`, `aria-pressed`. 상태는 localStorage에 저장.
  - 일시정지: `Ⅱ` / `▶` (뱀 정원과 동일), `aria-label="일시정지"`/`"계속하기"`.
- 폰(너비 < 560px): 제목 숨김, 카드 패딩 4px 8px, 값 17px, 최소 너비 52px.

### 시간 막대
- 높이 10px, radius 999px, 트랙 `--grid`, 채움 `--time`. 왼쪽 기준으로 `남은시간/120` 비율 너비 — 오른쪽에서 줄어든다. 너비 변화는 `transform: scaleX()`(transform-origin left)로, 매 프레임 갱신(끊김 없이).
- `role="progressbar"`, `aria-valuemin=0 aria-valuemax=120 aria-valuenow`(초 단위로만 갱신).

### 마지막 10초 경고
- 시간 막대 채움 `--danger` + 사선 줄무늬(`repeating-linear-gradient(45deg, transparent 0 6px, rgba(255,255,255,.35) 6px 12px)`) — 색 외 구분 수단.
- `시간` 카드 값 `--danger`, 매 초 바뀔 때 scale 1 → 1.18 → 1 (200ms ease-out).
- 보드 테두리 `--meadow-edge` → `--danger`로 300ms 전환해 10초 내내 유지.
- 깜빡이는 전체 화면 효과는 쓰지 않는다(퍼즐 집중 방해).

### 실시간 합계 배지 (드래그 중)
- DOM 요소(`.sum-badge`)를 `.board-wrap` 안에 absolute로. 알약 모양, 높이 32px, 패딩 0 12px, radius 999px, 글자 18px 800 tabular-nums, 배경 = 상태색, 글자 `--sel-on`.
- 내용: 합 < 10 → `7` / 합 = 10 → `10 ✓` / 합 > 10 → `13 ✕` (글자 기호로도 상태 구분). 선택 칸이 비었거나 합 0이면 숨김.
- 위치: 선택 사각형 가로 가운데. **손가락에 가리지 않게** 포인터가 사각형 아래쪽 절반에 있으면 사각형 위 8px, 위쪽 절반이면 사각형 아래 8px. 보드 밖으로 나가면 반대쪽으로 뒤집고, 그래도 안 되면 사각형 안쪽 위에. 시간 막대와 겹쳐도 됨(z-index 위).

### 선택 사각형 (Canvas)
- 판정된 칸 범위를 **칸 경계에 스냅한 사각형**으로 그린다(손가락 위치 그대로의 사각형은 그리지 않음 — 무엇이 포함되는지 정확히 보이게). 모서리 radius `.18c`, 칸 경계에서 안쪽으로 2px 들인다.
- 드래그 시작점에 최소 1칸은 항상 표시(탭만 해도 1칸 사각형).

| 상태 | 테두리 | 채움 | 추가 |
|---|---|---|---|
| 합 < 10 | `--sel-under` 3px **점선** `[8, 6]` | 같은 색 alpha .12 | — |
| 합 = 10 | `--sel-ok` 4px 실선 | 같은 색 alpha .22 | 안의 토끼 귀 쫑긋 반복 |
| 합 > 10 | `--sel-over` 3px 실선 | 같은 색 alpha .14 | — |

### 오버레이 (보드 위에 겹침)

## 애니메이션·이펙트 (지속시간 ms, easing)

| 이펙트 | 내용 | 시간 | easing |
|---|---|---|---|
| 판 등장 (시작) | 토끼가 열(가로형)/행(세로형) 순서로 아래 .3c에서 올라오며 alpha 0→1, 줄마다 15ms 지연 | 각 220, 전체 ≤ 480 | ease-out-back (`1 + 2.7(t−1)³ + 1.7(t−1)²`) |
| 선택 = 10 대기 | 사각형 안 토끼 귀가 −4°↔+4° 쫑긋 + 몸 translateY 0↔−.04c | 주기 360 반복 | sine |
| **성공: 깡충 사라짐** | 토끼마다 ① 0–90ms 웅크림: 바닥 기준 scaleX 1.12 / scaleY .84 ② 90–300ms 점프: translateY 0 → −.8c, scale 1 (ease-out) ③ 300–460ms 계속 위로 −1.2c까지, scale 1 → .6, alpha 1 → 0 (ease-in). 사각형 왼쪽 위 토끼부터 칸마다 25ms 지연(최대 지연 200ms). 점프 중인 토끼는 다른 칸 위에 그린다(효과 레이어). | 토끼당 460, 전체 ≤ 660 | 위 구간별 |
| 먼지 | 각 토끼 발밑 `(.5c, .92c)`에서 원 3개(반지름 .06c→.14c, `--fur-edge` alpha .6→0)가 좌·우·아래로 .2c 퍼짐 | 300 | ease-out (`1−(1−t)³`) |
| 굴 구멍 생김 | 빈 칸 타원 크기 0 → 1 (웅크림이 끝날 때 시작) | 180 | ease-out |
| 점수 팝업 | 사각형 가운데에 "+N"(20px 800 `--sel-ok`, 흰 2px 외곽선 `paint-order: stroke`) 위로 28px 떠오르며 alpha 1→0 | 700 | ease-out |
| HUD 점수 | 값 scale 1 → 1.15 → 1 | 160 | ease-out |
| 실패 (합 ≠ 10, 손 뗌) | 사각형이 `--sel-over`(합<10이면 `--sel-under`)로 유지된 채 좌우 ±5px 3회 흔들림 후 alpha 1→0. 안의 토끼는 머리를 좌우로 도리도리(rotate ±10°, 2회). 감점 없음 — 짧고 가볍게. | 흔들림 220 + 사라짐 120 | linear / ease-out |
| 빈 선택 해제 (합 0) | 사각형 alpha 1→0 | 120 | ease-out |
| 시간 종료 | 입력 즉시 중지(진행 중 드래그 취소), 모든 토끼 동시에 한 번 작게 깡충(translateY −.15c, 200ms) → 300ms 뒤 오버레이 페이드 인 | ~500 | ease-out |
| 오버레이 | opacity 0→1, 내용 translateY 8px→0 | 200 | ease-out |
| 버튼 눌림 | scale .94, 배경 `--grid` | 80 | ease-out |

- 선택 사각형은 지연 없이 `pointermove` 다음 프레임에 그대로 따라간다(사각형 크기 변화에 트윈 없음 — 반응성 우선).
- 이펙트는 로직과 분리된 `effects[]` 배열로 관리. 판정·점수는 손 뗀 즉시 확정되고 애니메이션은 보여주기만 한다(애니메이션 중에도 다음 드래그 가능, 사라지는 중인 토끼 칸은 이미 빈 칸으로 취급).
- 일시정지 중엔 이펙트 시간도 정지.
- `prefers-reduced-motion: reduce`: 판 등장·점프·먼지·흔들림·도리도리·쫑긋·시간 경고 pulse 끔. 성공 시 토끼 alpha 1→0 150ms만, 실패 시 사각형 테두리 색 그대로 120ms 유지 후 사라짐. 경고 줄무늬·색은 유지(정보 손실 없음).

## 조작 UI (터치 버튼 크기 ≥ 44px, 제스처, 키 매핑)

### 드래그 (iPad 손가락 — 가장 중요 / PC 마우스)
- `.board-wrap`에 `touch-action: none`, 포인터 이벤트(`pointerdown/move/up/cancel`) + `setPointerCapture`. 마우스·손가락·펜 같은 코드.
- `pointerdown`: 시작 칸 기록, 선택 표시 시작. `pointermove`: 현재 칸까지 사각형 갱신, 합계 배지 갱신. 포인터가 보드 밖으로 나가도 캡처 유지, 좌표는 보드 가장자리로 clamp.
- `pointerup`: 판정(합 10 → 성공 이펙트, 아니면 실패 이펙트). `pointercancel`(시스템 제스처, 회전 등): **판정 없이** 취소.
- 멀티터치: 첫 번째 포인터만 사용, 드래그 중 두 번째 손가락은 무시(`isPrimary` 또는 활성 pointerId 비교).
- 시작·일시정지·시간 종료 중엔 드래그 무시.
- 판을 실수로 스크롤·확대하지 않도록 보드 영역의 `touchstart`/`gesturestart`에 `preventDefault`(passive: false).
- 우클릭 메뉴(`contextmenu`)·길게 누르기 콜아웃 차단.

### 키보드 (PC)
| 키 | 동작 |
|---|---|
| Space / P / Esc | 일시정지 ↔ 계속 |
| Enter | 시작 / 다시 하기 (잠금 0.5초 뒤) |
| M | 소리 켜기/끄기 |
- 창이 포커스를 잃으면(`blur`, `visibilitychange`) 자동 일시정지(드래그 중이면 취소).
- 퍼즐 조작은 마우스 드래그 전용(키보드 칸 선택은 이번 범위 밖).

### iPad Safari 공통
- `body { touch-action: manipulation; user-select: none; -webkit-user-select: none; -webkit-touch-callout: none; -webkit-tap-highlight-color: transparent; }`
- 더블탭 확대 방지: `touch-action` + 버튼 `dblclick` 기본 동작 차단. 가로 스크롤 금지(`overflow: hidden`).
- `apple-mobile-web-app-capable` 등 메타는 목록 페이지와 동일.
- 버튼 반응은 `pointerdown`이 아닌 `click`(오버레이 버튼) — 단, 시간 종료 직후 0.5초 잠금으로 오터치 방지.

## 접근성 (대비, 색 외 구분 수단)
- 대비: `--num`(#1f2430) 대 `--fur` 라이트 #ffffff 약 15:1, 다크 #ebe5da 약 12:1. `--ink` 대 `--bg`/`--panel` 12:1 이상, `--muted` 대 `--panel` 4.5:1 이상(공통 토큰).
- 합계 배지: 라이트 흰 글자 대 상태색은 3:1 이상 + 18px 800(큰 글자 기준), 다크는 진한 글자 `#12141a` 대 밝은 상태색 7:1 이상.
- **선택 상태는 색 외에도**: 합 <10 = 점선 테두리 + 숫자만, =10 = 굵은 실선 + `✓` + 토끼 귀 쫑긋, >10 = 실선 + `✕`. 적록색약에서도 점선/실선·기호로 구분.
- 마지막 10초: 색 + 막대 줄무늬 + 숫자 pulse.
- 숫자 6·9 밑줄로 구분.
- 오버레이 열릴 때 주 버튼에 `focus()`, 포커스 링 `outline: 3px solid var(--accent); outline-offset: 2px`.
- `aria-live="polite"` 영역은 시간 종료 결과만 문장으로("시간 끝. 토끼 84마리, 최고 102마리"). 마지막 10초 진입 시 한 번 "10초 남음".
- 캔버스 `role="img" aria-label="토끼 텐 게임 판"`.
