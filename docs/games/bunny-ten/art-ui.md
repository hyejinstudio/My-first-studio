# 토끼 텐 아트·UI 명세

> slug: `bunny-ten` · 기획서 `docs/games/bunny-ten/design.md`와 같은 수치 사용 (판 17열×10행, 숫자 1~9, 제한 시간 120초, 점수 = 지운 칸 수).
> 선택 판정 규칙(어느 칸이 사각형에 포함되는지)은 design.md를 따른다. 이 문서는 **판정된 칸 범위를 어떻게 보여 줄지**를 정한다.
> 모든 그래픽은 Canvas 2D 도형과 CSS로 그린다. 이미지 파일·이모지 그래픽 없음. 원작(Fruit Box)의 사과 모양·빨강 판·레이아웃을 따르지 않는다.
> **v3**: 캐릭터가 토끼 → **하늘다람쥐**로 바뀌었다. 게임 이름은 아직 "토끼 텐"(이름 변경은 사용자 결정 대기). 문서·코드 주석의 캐릭터명은 "하늘다람쥐". 토큰 이름(`--meadow`, `--fur` 등)은 코드 변경을 줄이려고 **이름은 그대로 두고 값만 바꾼다**.

## 스타일 콘셉트
- "흐린 하늘의 하늘다람쥐 둥지": 은은한 회청색 하늘 판 위에 하얗고 폭신한 하늘다람쥐 170마리가 줄지어 앉아 몸 가운데에 숫자를 하나씩 품고 있다. 합이 10이 되게 감싸면 비막을 펴듯 납작하게 몸을 펴고 왼쪽 위로 **활공하듯 날아가** 사라진다.
- **눈 피로 최소화가 최우선 (v3)**: 같은 그림이 170번 반복되므로 —
  - 판·몸·꼬리는 모두 **밝기 차이가 작은 차분한 색**(회청·흰·연하늘)으로, 화면에서 가장 진한 것은 **숫자 하나뿐**이 되게 한다.
  - 외곽선은 얇고 연한 회청색. 체크무늬·줄무늬·칸 구분선·그림자·하이라이트 없음.
  - 하늘다람쥐 디테일은 몸 + 둥근 귀 2개(안쪽 아주 연한 하늘색) + 큰 꼬리 1개뿐.
- **하늘다람쥐 모양 (v3, 오리지널)**: 칸은 정사각형. 가로로 약간 넓은 **흰 타원 몸** 하나 + 몸 위쪽 양옆에 반쯤 묻힌 **작고 둥근 귀 2개** + 몸 뒤 오른쪽 위로 비스듬히 솟은 **연한 하늘색 큰 꼬리**(타원 하나) + 몸 가운데 큰 숫자.
  - **얼굴 없음**: 눈·입·볼·코·수염 없음. 몸 가운데는 숫자 전용 자리.
  - 팔·발·비막(앉아 있을 때)은 그리지 않는다. 실루엣 = 몸 + 귀 2 + 꼬리 1.
  - 특정 캐릭터 복제 금지: 사용자 참고 그림은 기존 만화 캐릭터이므로 **그 얼굴(눈·볼·입), 누워서 손 든 자세, 굵은 검정 손그림 선 스타일을 쓰지 않는다.** 우리는 "흰 몸·둥근 귀·연하늘 큰 꼬리"라는 동물 하늘다람쥐의 일반 특징만 쓰고, 얼굴 없는 몸에 숫자를 품은 "숫자 둥지" 디자인 + 얇은 회청 외곽선 + 활공 퇴장 동작이 이 게임 고유 요소다.
- 스튜디오 공통: 따뜻한 종이색 페이지 배경(`--bg`), 흰 패널 카드, 주황 강조색(`--accent`), 둥근 모서리, 그림자 대신 면 색 차이. (판만 회청색 — 종이색 페이지 위의 차분한 "창" 느낌.)
- **가독성**: 하늘다람쥐는 모두 같은 흰 털, 숫자는 모두 같은 진한 남색. 숫자별 색 구분 없음(색은 선택 상태 3가지 전달에만 사용).
- 폰트: 사이트 공통 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif` (HUD·배지·오버레이·점수 팝업). **판 위 숫자만 BunnyDigits(Pretendard ExtraBold 800 서브셋)** — 변경 없음.

### 숫자 글꼴 (Pretendard, SIL OFL 1.1) — v2와 동일
- 굵기 **800 한 가지**. 파일 `games/bunny-ten/fonts/bunny-digits-800.woff2`(U+0030–0039 서브셋) + 같은 폴더 `OFL.txt`. CSS 별칭 `"BunnyDigits"`.
  ```css
  @font-face { font-family: "BunnyDigits"; src: url("fonts/bunny-digits-800.woff2") format("woff2");
    font-weight: 800; font-style: normal; font-display: swap; unicode-range: U+0030-0039; }
  ```
- `NUM_FONT = '"BunnyDigits", "Pretendard", ui-rounded, "SF Pro Rounded", system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif'`.
- 시작 시 `document.fonts.load('800 32px "BunnyDigits"')` → 성공하면 스프라이트·예시 그림 재생성. 1.5초 초과·실패면 대체 글꼴로 진행(현재 코드 방식 유지).

## 레이아웃 (PC / iPad 세로 / iPad 가로)

### 공통 구조 (위→아래, 한 화면 안, 스크롤 없음)
```
[← 게임 목록] 토끼 텐     [점수][최고][시간]  [🔈][Ⅱ]   ← 상단 바 52px (아이콘은 SVG)
[■■■■■■■■■■■■■■■■■■■■■■■■■■■□□□□□□□□]               ← 시간 막대 10px
┌──────────────── 하늘 판 (항상 17×10) ────────────────┐
│  하늘다람쥐 ...                                        │
└───────────────────────────────────────────────────────┘
```
- 상단 바·시간 막대·보드 묶음(`.app`)은 가로 가운데, 세로로도 남는 공간의 **가운데**(`body { justify-content: center }` — 현재 코드 그대로). 세로 화면에서는 위아래에 같은 크기의 여백이 생겨 판이 화면 한가운데(엄지·시선 높이)에 온다.
- 상단 바 너비 `min(100%, max(보드 너비, 560px))`, 너비 < 560px이면 제목 숨김·"← 목록" (기존 그대로).

### 높이 기준 레이아웃 규칙 (필수)
1. `--app-h` = `window.innerHeight + 'px'` (resize·orientationchange·visualViewport.resize 때 갱신). `100vh` 단독 금지.
2. `html, body { height: var(--app-h); overflow: hidden; }`, body 패딩 `max(12px, env(safe-area-inset-*))`, `viewport-fit=cover`.
3. 고정 높이 `F = 52 + 8 + 10 + 8 = 78px`. `W = innerWidth − 좌우 패딩`, `H = app-h − 상하 패딩 − F`. 보드 테두리 4px×2 제외: `Wi = W − 8`, `Hi = H − 8`.
4. **판 방향은 항상 가로 17열×10행 (v3 — 회전 규칙 삭제).**
   - `c = floor(min(Wi / 17, Hi / 10, 64))`, 하한 8 (코드 안전장치).
   - 보드 픽셀 = `17c × 10c` + 테두리 8.
   - 삭제할 것: `cB`, `rotated`, `disp()`의 전치, 선택 범위 전치(`sel.r0 = xr…`), 판 등장의 행/열 분기, 회전 시 드래그 취소 중 "방향 바뀜" 처리. 기기를 돌리면 **크기만** 다시 계산(진행 중 드래그는 취소, 시간은 계속 — 기존과 동일).
5. 수치 (패딩 12px, 안전 영역 0 기준 — 실제 코드 계산식 그대로):

| 화면 | 칸 c | 보드(테두리 포함) | 세로 여백(위·아래 각각) |
|---|---|---|---|
| PC 1280×800 | min(73.4, 69, 64) = **64** | 1096×648 | 약 25 |
| iPad 가로 1080×810 | floor(1048/17=61.6) = **61** | 1045×618 | 약 45 |
| iPad 가로 1080×740 (Safari 주소창) | min(61.6, 63) = **61** | 1045×618 | 약 10 |
| **iPad 세로 810×1080** | floor(778/17=45.8) = **45** | 773×458 | 약 260 |
| iPad 세로 Safari 실높이 ~1000 | **45** | 773×458 | 약 220 |
| **폰 세로 390×844** | floor(358/17=21.1) = **21** | 365×218 | 약 262 |
| 폰 가로 844×390 | min(47.7, 28) = **28** | 484×288 | 0 |

   - 세로 화면에서는 너비가 칸 크기를 결정하고 높이는 남는다 → 묶음 전체를 세로 가운데. 남는 여백에 다른 UI를 넣지 않는다(시선 분산 방지). 대신 시작 오버레이에서 "가로로 돌리면 더 크게 볼 수 있어요" 안내.
6. **칸 크기 하한**: 목표 ≥ 32px (PC·iPad 가로·iPad 세로 충족). **폰 세로는 21px** — 사용자 결정(항상 가로 판)에 따른 의도된 결과. 스크롤·경고 없이 그대로 축소. c < 24일 때만 귀 안쪽 색 생략(1px 미만 디테일 → 노이즈). 숫자 글자 최소 14px는 유지(아래 표).
7. **작은 보드의 오버레이 (v3 신규)**: 보드 바깥 높이(`10c + 8`) **< 300px**이면 `body`에 클래스 `ov-full`을 붙여 오버레이를 보드 안이 아닌 **화면 전체**에 띄운다. 폰 세로(218px)·폰 가로(288px)가 해당. iPad 세로(458px)·가로는 기존처럼 보드 안.
   ```css
   body.ov-full .overlay { position: fixed; inset: 0; border-radius: 0; z-index: 10;
     padding: max(16px, env(safe-area-inset-top)) max(16px, env(safe-area-inset-right))
              max(16px, env(safe-area-inset-bottom)) max(16px, env(safe-area-inset-left)); }
   ```
   - 시작 오버레이 배경 `--meadow`(판과 같은 색) 그대로, 일시정지 97%, 시간 종료 84% — 전체 화면 위에서도 같은 값.
   - 주의: `.board`·`.board-wrap`·`.app`에 `transform`/`filter`를 걸면 `fixed`가 깨진다. 걸지 말 것.
   - 기존 `@media (max-height: 520px)` 축약 규칙(예시 그림·작은 안내 숨김)은 유지.
8. 캔버스 내부 해상도 = 표시 크기 × `devicePixelRatio`(최대 2). 크기 바뀌면 캔버스·스프라이트 재생성.
9. **검증 기준** (QA와 공유): `node tests/smoke.js bunny-ten`의 모든 뷰포트에서 `scrollHeight ≤ innerHeight`, `scrollWidth ≤ innerWidth`, 보드 `bottom ≤ innerHeight − 4`, **모든 뷰포트에서 보드 너비 > 높이(가로형)** — v2의 "810×1080에서 세로형" 기준은 폐기. 810×1080에서 c = 45, 보드가 화면 세로 가운데(위·아래 여백 차 ≤ 2px). 390×844에서 시작 오버레이가 화면 전체를 덮고 "시작하기" 버튼이 화면 안에 보임.

### 보드
- 테두리 `4px solid var(--meadow-edge)`, `border-radius: 14px`, 캔버스 `border-radius: 10px`, 바탕 `--meadow` 단색. 칸 사이 선·체크무늬·그라데이션 없음.
- `.board-wrap` 패딩 10px 영역에서도 드래그 시작 가능, 좌표는 보드 안으로 clamp (기존).

### "← 게임 목록" 링크
- 기존과 동일 (14px `--muted`, min-height 44px, 대상 `../../`).

## 하늘다람쥐 그리기 (Canvas 2D, 칸 왼쪽 위 기준, c = 칸 크기)
숫자 9종 × 상태 4종(보통 / 합<10 / =10 / >10)을 **오프스크린 스프라이트로 미리 그려** `drawImage` (기존 방식). c·테마·dpr 바뀌면 재생성.

```
 0 ┌──────────────────────┐   (c × c 정사각형)
   │                ╱‾╲    │   꼬리: 중심 (.75,.38) 기울기 +22°
.27│    ◜◝      ◜◝ │   │   │   귀: 중심 (.33,.35) (.67,.35) 반지름 .085
.31│  ╭──────────────╮ │   │   몸: 중심 (.50,.62) 반지름 .36 × .31
   │  │      8       │╱    │   숫자: 중심 (.50,.63)
.93│  ╰──────────────╯     │
 1 └──────────────────────┘
   0  .14          .86 .92 1
```

**공통 선 설정**: `lineWidth = lw = max(1, .028c)`, `lineJoin = lineCap = 'round'`, `strokeStyle = --fur-edge`.
c=64 → 1.8px, 45 → 1.26px, 28 → 1px, 21 → 1px. (v2의 .045c 굵은 갈색 선 → 얇은 회청 선)

그리는 순서 (뒤 → 앞):
1. **꼬리** (가장 뒤):
   ```js
   g.save(); g.translate(.75*c, .38*c); g.rotate(22 * Math.PI/180);
   g.beginPath(); g.ellipse(0, 0, .15*c, .27*c, 0, 0, Math.PI*2);
   g.fillStyle = tail; g.fill(); g.stroke(); g.restore();
   ```
