### 버그 (심각도: 치명/높음/보통/낮음)
- [보통] 음소거 버튼을 눌러도 아이콘이 바뀌지 않음 (항상 소리 켜짐 모양 🔊)
  - 재현: 게임 페이지에서 소리 버튼 클릭/탭 → 소리는 꺼지고 localStorage `snake-garden-muted`='1', aria-label "소리 켜기"로 바뀌지만 화면의 아이콘은 그대로 스피커+음파. 새로고침 후에도 마찬가지(PC·iPad 에뮬레이션 모두). 사용자는 소리가 꺼졌는지 알 수 없고, iPad에서 무음 스위치와 구분이 안 됨.
  - 원인: SVG 요소에는 `hidden` 속성 프로퍼티가 없음(`'hidden' in SVGElement.prototype` → false). `$('icoOn').hidden = m` 은 JS 속성만 만들고 HTML `hidden` 속성을 바꾸지 않아, CSS `button.icon svg[hidden]`가 처음 상태(icoOff만 숨김)에서 변하지 않음.
  - 기대: 음소거 시 🔇(icoOff) 표시, 해제 시 🔊(icoOn) 표시.
  - 관련 코드: games/snake-garden/index.html 670행 `$('icoOn').hidden = m; $('icoOff').hidden = !m;` → `toggleAttribute('hidden', …)` 또는 `setAttribute/removeAttribute` 사용 필요. (CSS 90행은 그대로 둬도 됨)
- [낮음] 맨 위 줄에서 열매를 먹으면 "+10/+50" 점수 팝업이 보드 위쪽 밖으로 나가 잘려 보임
  - 재현: 뱀 머리가 y=0 줄에서 산딸기를 먹음 → 팝업이 캔버스 위로 떠올라 대부분 안 보임(스크린샷 pc-long.png).
  - 기대: 보드 안에서 보이거나, 위 줄에서는 아래로 띄우는 등 처리.
  - 관련 코드: 965행 `y - .4c - .8c*easeOut(t)`.
- [낮음] (이론상) 보드가 거의 다 찬 상태에서 산딸기가 생기지 못하고 황금 열매가 시간 초과로 사라지면 그 뒤로 산딸기가 다시 생기지 않음
  - 재현(코드 분석): 길이 224칸에서 마지막 빈칸을 황금 열매가 차지 → 760행 `randomEmpty()`가 null → `berry = null`. 황금 열매가 6초 뒤 사라지면 빈칸 1개가 남지만 산딸기 재생성 경로가 없어 클리어 불가, 게임이 끝나지 않음. 225칸 근처라 실제로는 거의 일어나지 않음.
  - 기대: 황금 열매가 사라지거나 먹힐 때 `berry`가 null이면 다시 생성 시도.
  - 관련 코드: 1008~1013행(황금 시간 초과), 760~761행.
