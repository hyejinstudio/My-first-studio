# 뱀 정원 기획서
- slug: snake-garden
- 한 줄 소개: 정원을 기어 다니며 열매를 먹고 몸이 길어지는 뱀 게임
- 상태: 기획 (첫 버전)

## 핵심 루프
정원(격자)을 한 칸씩 이동 → 열매를 먹으면 몸 +1칸·점수 → 점점 빨라짐 → 가끔 나타나는 황금 열매를 사라지기 전에 노림 → 울타리(벽)나 자기 몸에 부딪히면 게임 오버

## 규칙
### 보드·시작
- 정원 15 × 15칸, 테두리는 울타리(벽). 장애물 없음.
- 시작 길이 3칸. 머리 위치 (7, 7) (0부터 셈, 가운데), 몸은 그 왼쪽 2칸. 시작 방향 → (오른쪽).
- 시작 시 산딸기 1개를 뱀이 없는 빈칸 중 무작위 위치에 놓는다.

### 이동·충돌
- 매 틱마다 머리가 현재 방향으로 1칸 이동, 꼬리가 1칸 따라옴.
- 먹은 틱에는 꼬리를 줄이지 않아 몸이 1칸 길어짐.
- 다음 칸이 울타리 밖이면 게임 오버 (반대편으로 넘어가지 않음).
- 다음 칸이 자기 몸이면 게임 오버. 단, 이번 틱에 비워질 꼬리 끝 칸은 안전(그 틱에 열매를 먹어 꼬리가 남는 경우는 제외).
- 승리: 몸이 225칸 전부를 채우면 "정원 완성!" 클리어 화면 (사실상 드묾, 처리만 해 둠).

### 열매 (2종)
| 열매 | 점수 | 몸 증가 | 속도 영향 | 출현 |
|---|---|---|---|---|
| 산딸기 (일반, 빨강) | +10 | +1칸 | 먹을 때마다 빨라짐 | 항상 1개. 먹으면 즉시 빈칸에 새로 생김 |
| 황금 열매 (보너스, 금색) | +50 | +1칸 | 없음 | 산딸기 5개 먹을 때마다 1개 등장, 6초 후 사라짐 |

- 황금 열매는 뱀·산딸기가 없는 빈칸에 생긴다. 남은 시간 마지막 2초는 깜빡여 곧 사라짐을 알린다.
- 황금 열매가 이미 있을 때 다음 등장 조건이 와도 추가로 만들지 않는다 (동시에 최대 1개).
- 빈칸이 없으면 생성하지 않는다.
- 황금 열매 타이머는 일시정지 중 멈춘다.

### 점수
- 산딸기 +10, 황금 열매 +50. 그 외 점수 없음(생존 시간 점수 없음).
- 최고 점수: localStorage `snake-garden-best`. 게임 오버/클리어 시 현재 점수가 더 크면 갱신. 저장소 접근 실패 시 0으로 보고 게임은 정상 진행.

## 조작
| 동작 | PC | iPad |
|---|---|---|
| 방향 전환 | ← ↑ → ↓ / W A S D | 보드 스와이프, 화면 하단 D-pad(▲ ◀ ▶ ▼) |
| 시작 | Space / Enter / 방향키 | "시작" 버튼 탭, D-pad |
| 일시정지/재개 | P / Esc | Ⅱ 버튼 (일시정지 중 화면 탭 또는 "계속" 버튼으로 재개) |
| 재시작 (게임 오버 후) | Space / Enter | "다시 하기" 버튼 |

- 스와이프: 보드 위에서 시작한 터치가 30px 이상 움직이면, 가로·세로 중 더 크게 움직인 축의 방향으로 1회 입력. 한 번의 터치에서 손을 떼기 전에는 1회만 인정.
- D-pad: 보드 아래 십자 배치, 버튼 한 변 최소 64px. 누르는 순간(pointerdown) 입력. 길게 눌러도 반복 입력 없음.
- 게임 화면에서는 터치 스크롤·확대·더블탭 확대를 막는다.

### 방향 입력 규칙
- **입력 버퍼(최대 2개 큐)**: 방향 입력은 큐에 쌓이고, 매 틱 시작 시 큐에서 1개만 꺼내 방향으로 적용한다.
- **180도 반대 무시**: 새 입력이 "큐의 마지막 방향(큐가 비었으면 현재 이동 방향)"의 정반대면 버린다.
- 같은 방향 입력(위 기준과 동일 방향)도 버린다.
- 큐에 이미 2개가 있으면 새 입력은 버린다.
- 예: 오른쪽 이동 중 한 틱 안에 ↑ → ← 입력 → 큐 [↑, ←] → 다음 틱 위로, 그 다음 틱 왼쪽 (즉시 반대로 꺾여 자기 몸에 부딪히는 일 없음).
- 일시정지·게임 오버 시 큐를 비운다.

## 화면 흐름
1. **시작 화면**: 제목 "뱀 정원", 최고 점수, "시작" 버튼, 조작 안내 한 줄. 뱀은 시작 배치로 정지 상태로 보임.
2. **플레이**: 상단에 점수 / 최고 점수 / Ⅱ 버튼. 가운데 보드, 아래 D-pad.
3. **일시정지**: 보드 위 반투명 덮개 + "일시정지" + "계속" 버튼. 탭이 바깥으로 숨으면(visibilitychange) 자동 일시정지.
4. **게임 오버**: 부딪힌 순간 이동 정지, 머리를 0.5초 깜빡임 → "게임 오버" 덮개에 이번 점수, 최고 점수, 새 기록이면 "새 기록!" 표시, "다시 하기" 버튼.
   - 덮개가 뜬 뒤 0.5초 동안은 재시작 입력을 무시 (실수로 바로 재시작 방지).
5. **재시작**: 점수 0, 길이 3, 속도 초기값, 열매 재배치로 시작 배치부터 즉시 플레이.

## 밸런스 수치
| 항목 | 값 |
|---|---|
| 격자 | 15 × 15 |
| 시작 길이 | 3칸 |
| 시작 속도 | 170ms/칸 |
| 속도 증가 | 산딸기 1개 먹을 때마다 −4ms/칸 |
| 속도 하한 | 75ms/칸 (산딸기 24개째에 도달) |
| 산딸기 | +10점, +1칸 |
| 황금 열매 | +50점, +1칸, 산딸기 5개마다 등장, 6초 유지(마지막 2초 깜빡임) |
| 입력 큐 | 최대 2개, 틱당 1개 소비 |
| 스와이프 최소 거리 | 30px |
| D-pad 버튼 최소 크기 | 64 × 64px |
| 게임 오버 후 입력 잠금 | 0.5초 |
| 최고 점수 저장 | localStorage `snake-garden-best` |

## 콘텐츠
- 맵 1개(15 × 15 정원, 장애물 없음), 열매 2종(산딸기, 황금 열매). 레벨 구분 없음 — 난이도는 속도 증가로만 오른다.
- 분위기: 풀밭 초록 바탕에 옅은 격자 무늬, 뱀은 머리에 눈이 있는 둥근 마디. 색과 모양으로 열매 2종을 확실히 구분.

## 범위 밖 (이번에 만들지 않는 것)

- 효과음/배경음악, 멀티플레이, 온라인 순위표
