# 블록 스택 기획서
- slug: block-stack
- 한 줄 소개: 떨어지는 블록을 쌓아 가로줄을 가득 채워 지우는 퍼즐 게임
- 상태: 출시됨 (현재 코드 기준으로 역작성한 문서)

## 핵심 루프
블록이 위에서 떨어짐 → 이동·회전해 배치 → 가로줄이 가득 차면 삭제·점수 → 점점 빨라짐 → 블록이 맨 위를 넘으면 게임 오버

## 규칙
- 보드 10 × 20칸, 7종류 블록 (I, O, T, S, Z, J, L)
- 7개 묶음을 섞어 순서대로 출현 (같은 블록 연속 편중 방지)
- 다음 블록 3개 미리보기, 보관(hold) 1개 — 블록 하나당 1번만 보관 가능
- 떨어질 위치 미리보기(고스트)
- 회전 시 벽에 막히면 좌우 1~2칸, 위 1칸 순서로 밀어서 재시도

## 조작
| 동작 | PC | iPad |
|---|---|---|
| 이동 | ← → | ◀ ▶ 버튼(길게 누르면 반복), 보드 좌우 스와이프 |
| 회전 | ↑ / X (반대: Z) | ⟳ 버튼, 보드 탭 |
| 천천히 내리기 | ↓ | ▼ 버튼, 보드 아래 스와이프 |
| 바로 놓기 | Space | "바로 놓기" 버튼, 보드 위 스와이프 |
| 보관 | C / Shift | ⇄ 버튼 |
| 일시정지 | P / Esc | Ⅱ 버튼 |

## 밸런스 수치
| 항목 | 값 |
|---|---|
| 낙하 간격 | max(60ms, 800ms × 0.85^(레벨−1)) |
| 레벨 | 지운 줄 수 ÷ 10 + 1 |
| 줄 삭제 점수 | 1줄 100 / 2줄 300 / 3줄 500 / 4줄 800 × 레벨 |
| 천천히 내리기 | 1칸당 1점 |
| 바로 놓기 | 떨어진 칸당 2점 |
| 최고 점수 저장 | localStorage `blockstack-best` |

## 범위 밖 (현재 없음)
- 효과음/배경음악, 연속 삭제(콤보) 보너스, 특수 회전 보너스, 멀티플레이
