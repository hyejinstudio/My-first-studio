### 버그 (심각도: 치명/높음/보통/낮음)
- [보통] iPad 가로 화면에서 터치 패드 아래 줄(▼, 바로 놓기, Ⅱ)이 화면 아래로 잘림
  - 재현: iPad (gen 7) 가로(1080x810) 에뮬레이션으로 게임 페이지 열기 → 패드 하단 y=822px로 뷰포트 높이 810px를 12px 넘음. 버튼 일부가 보이지 않고 전체를 보려면 세로 스크롤 필요. 실제 Safari는 주소창·탭바로 보이는 높이가 더 작아 더 많이 잘릴 가능성 있음.
  - 기대: 가로 화면에서도 모든 조작 버튼이 스크롤 없이 한 화면에 보여야 함 (예: 가로일 때 보드 높이를 화면 높이 기준으로 제한하거나 패드를 보드 옆에 배치)
  - 관련 코드: games/block-stack/index.html 48행 `#board { width: min(300px, 62vw) }` (높이 기준 제한 없음), 69~72행 `.pad` 레이아웃, 38행 body padding

### 미검증
- 실제 줄 삭제가 일어나는 상황의 런타임 점수·레벨 증가: 게임 상태가 클로저 안에 있어 외부에서 보드를 구성할 수 없고, 무작위 블록 순서로 자동 플레이 구성은 하지 않음. 점수·레벨 공식은 코드 대조와 node 계산으로만 확인.
- 고레벨 실제 낙하 속도 체감, 회전 벽차기, 보관(hold) 1회 제한, 고스트 표시, 보드 스와이프/탭 조작, 버튼 길게 누르기 반복: 이번 회차에서 자동 검증하지 않음 (코드상 구현은 확인).

### 실기기 확인 필요
- 실제 iPad Safari(WebKit) 동작 전반 — 이 환경은 Chromium 기기 에뮬레이션만 가능
- iPad 가로 화면에서 Safari 주소창 포함 시 패드 잘림 정도
- 보드 스와이프(좌우/아래/위) 와 탭 회전의 실제 손맛, 길게 누르기 반복 간격
- 홈 화면 추가(standalone) 실행
- 소리: 이 게임은 효과음/BGM이 없음(기획서 "범위 밖"). 실제 소리 검증은 이 환경에서 불가
