## 핵심 루프 (한 마디)
1. **면 다듬기**(0.30초): 탑 꼭대기(대목 윗면)를 정원사가 새로 다듬는다 — 사각 소리, 부스러기, **윗면이 각도 θs로 한 줄 빛난다.** 이 빛나는 선이 "맞춰야 할 각도"다.
2. **접수 내려오기**(0.45초, 1과 동시에 시작): 위에서 집게가 접수(초록 몸통 80mm + 아래 갈색 밑동)를 칼 높이까지 내린다.
3. **겨누기**(제한 시간 L 안): 접수가 집게에 매달려 위아래로 오르내리고(주기 T) 좌우로 살짝 흔들린다(진폭 A). 플레이어는 끌어서 칼을 기울여 두고, 원하는 순간 손을 뗀다.
4. **싹둑**: 칼선 아래쪽(갈색 밑동 포함)은 옆으로 떨어져 버려지고, 칼선 위쪽 초록 조각이 집게에서 풀려 대목 위로 떨어진다(0.25초).
5. **판정**(0.45초): 완벽 "착"(접합선 전체 한 줄 빛) / 좋음(한쪽만 빛나고 틈) / 어긋남(틈이 벌어져 미끄러져 떨어짐) / 무름(물컹, 처지며 떨어짐) / 말라 버림(시간 초과).
6. **자람**(0.35초): 붙었으면 탑이 그만큼 높아지고 화면이 위로 따라 올라간다(대목 윗면이 항상 같은 화면 높이). → 다음 마디.

마디 사이 고정 연출 합계 1.5초(1·2 0.45 + 4 0.25 + 5 0.45 + 6 0.35). 평균 겨누기 1.2초 가정 시 30마디 ≈ 81초(추정).

## 규칙

### 1. 좌표와 용어 (모든 길이는 "세계 mm", 각도는 도°)
| 용어 | 기호 | 정의 |
|---|---|---|
| 각도 부호 | | **+ = 오른쪽 끝이 올라감**(화면에서 시계 반대 방향). 0° = 수평 |
| 탑 기울기 | tilt | 탑 축이 수직에서 기운 각. 각도 부호 규칙과 같다: + = 탑이 시계 반대 방향으로 기욺(꼭대기가 왼쪽으로 가고, 축에 수직인 윗면은 오른쪽 끝이 올라감). 시작 0, 갱신할 때마다 0.1° 단위로 반올림해 저장 |
| 이번 마디 면 기울기 | d_k | 마디 k에서 다듬은 윗면이 탑 축의 수직선과 이루는 각. 표 참고 |
| 대목 면 각도 | θs | **θs = tilt + d_k** (화면 기준 절대 각도). 빛나는 선이 이 각도 |
| 칼 각도 | φ | 정수 °, 범위 −35 ~ +35. 마디마다 0°로 돌아감 |
| 칼 중심 | K | 화면에 고정된 점(접수 집게의 바로 아래, 세로 위치 아래 "화면 배치"). 칼선 = K를 지나고 각도 φ인 직선 |
| 접수 | | 폭 **w = 36mm**. 위에서부터 집게 / 초록 몸통 80mm / 갈색 밑동 B mm. 초록과 갈색의 경계를 "갈색 경계"라 한다 |
| 접수 흔들림 | α(τ) | 접수 축이 수직에서 기운 각(+ 부호 규칙 동일). 축은 집게 고정점을 중심으로 돈다 |
| 경계 높이 | u(τ) | 칼선과 접수 **중심축**의 교점에서 갈색 경계까지, 축을 따라 잰 거리(mm). + = 교점이 경계보다 위(초록 안), − = 갈색 안 |
| 비스듬함 | δ | δ = φ − α. 칼선이 "접수 축에 수직인 선"과 이루는 각 |
| 반폭 처짐 | s | s = (w/2) × \|tan δ\| = 18 × \|tan δ\|. 비스듬한 칼선의 낮은 쪽 끝이 중심보다 축 방향으로 s만큼 아래 |
| 붙는 길이 | h | **h = 80 − u** (0 ~ 80으로 자름). 칼선 중심에서 초록 꼭대기까지의 길이. 낮게 자를수록 길다 |
| τ | | 겨누기 시작부터 흐른 게임 시간(초) |

### 2. 접수의 움직임 (겨누기 동안, 해석식 — 프레임과 무관하게 정확히 계산)
- 오르내림: **u(τ) = U_mid + U_amp × cos(2π τ / T)**. τ = 0에서 맨 위(u 최대 = 가장 짧게 잘리는 자리), τ = T/2에 맨 아래(가장 길게, 그리고 4마디부터는 갈색에 걸리는 자리).
  - 시작 위상은 **모든 마디 고정**(외울 수 있는 리듬. 무작위 아님).
- 흔들림: **α(τ) = σ_k × A × sin(2π τ / (1.6 T))**, σ_k = +1 또는 −1(시드). τ = 0에서 0°.
- 내려오기(0.45초) 동안 접수는 u = U_mid + U_amp(맨 위) 자리로 내려와 멈춰 있다가 τ = 0부터 움직인다.

### 3. 자르기 판정 (자른 순간 τc 하나로 결정)
자른 순간의 φ, θs, u(τc), α(τc)로 아래 순서대로 판정한다.

| 순서 | 조건 | 결과 | 붙는 길이 | 탑 기울기 변화 |
|---|---|---|---|---|
| ① | **u − s ≤ 0** (칼선 낮은 쪽 끝이 갈색 경계에 닿거나 그 아래) | **무름** (실패 1) | 0 | 없음 |
| ② | e = \|φ − θs\| ≤ 완벽 허용 P | **완벽** | h | tilt를 0 쪽으로 1° 회복(\|tilt\| < 1이면 0) |
| ③ | e ≤ 좋음 허용 G | **좋음** | h × 0.6 | tilt += 0.7 × (φ − θs) |
| ④ | e > G | **어긋남** (실패 1) | 0 | tilt += 0.7 × clamp(φ − θs, −6, +6) |
| — | 겨누기 시간 L 안에 자르지 않음 | **말라 버림** (실패 1) | 0 | 없음 |

- 무름이 각도보다 먼저다(물렀으면 각도가 맞아도 떨어진다). 해설에는 각도 오차도 함께 기록한다(아래 결과 화면).
- 비교는 실수 그대로: `e <= P + 1e-9`. φ는 정수, θs는 0.1° 단위라 e는 0.1° 단위.
- 1~3마디는 **탑 기울기를 바꾸지 않는다**(배우기 구간. 아래 "기획안 대비 변경점" 2).
- 길이 저장: 붙는 길이는 0.1mm 단위로 반올림해 더한다(`Math.round(x*10)/10`). 좋음은 반올림된 h에 0.6을 곱해 다시 0.1mm 반올림.
- 칼이 집게에 닿는 경우(u + s ≥ 80)는 아래 수치 범위에서 생기지 않는다(최대 50 + 19.3 = 69.3). QA 확인 항목.

### 4. 연속 완벽 · 끝
| 항목 | 내용 |
|---|---|
| 연속 완벽 | 완벽이 연속될 때 **3번째 완벽부터** 그 마디에 새순 **+5mm** 추가. 좋음·어긋남·무름·말라 버림이면 연속 0으로 |
| 실패 | 어긋남·무름·말라 버림 각 1. 하트 ♥♥♥로 표시(실패마다 하나 빔) |
| 끝 ① 실패 3번 | 3번째 실패 판정 직후 탑이 흔들리다 쓰러짐(1.2초) → 결과 |
| 끝 ② 쓰러짐 | 판정 후 **\|tilt\| ≥ 10.0°** → 기운 쪽으로 쓰러짐(1.2초) → 결과. ①②가 동시면 ②로 표시 |
| 끝 ③ 완주 | 30마디째 판정 후 ①②가 아니면 꼭대기에 **꽃이 핌(1.5초) + 100mm** → 결과 |
| 점수 | **키 mm 정수 = floor(H)**. H = 붙은 길이 합 + 새순 + 꽃. 쓰러져도 그때까지의 H가 점수 |
| 키의 기준 | 눈금자 0 = 처음 화분에 꽂힌 대목(시작 탑, 키 0으로 침)의 윗면. 시작 키 0.0cm |
| 화면 표시 | `(점수/10).toFixed(1) + " cm"` (예: 1234 → "123.4 cm") |
| 마디 수 | 접수 1개 = 1마디. 실패해도 마디 수는 오른다(30번 자르면 끝) |

### 5. 이론상 최대와 서버 상한
- 1~3마디: u 최소 14 → h ≤ 66. 4~30마디: u − s > 0이어야 하므로 h < 80.
- 새순: 3~30마디 모두 연속 완벽이면 28 × 5 = 140. 꽃 100.
- 최대 = 3×66 + 27×80 + 140 + 100 = **2,598mm** (모든 칼을 갈색 경계에 0mm 차로 + 전부 완벽 — 사람은 불가능).
- **서버 score_cap 2700** 제안 (기획안 값 유지. 여유 102mm).

- 1~3마디는 **무를 수 없다**: u ≥ 14, 흔들림 0이라 s ≤ 18 × tan35° = 12.6 < 14. → 각도만 배운다. 갈색은 8mm 짧은 꼭지로 그려 "있다"는 것만 보인다.
- 4마디부터 오르내림의 맨 아래가 갈색 안으로 8mm(→12→12mm, 조정 후) 들어간다 → **기다리면 길어지지만 너무 기다리면 무른다.** 4~10마디에서 한 주기 중 u < 0인 시간 비율 24.2%, h 70~80mm(갈색 경계 위 0~10mm)인 비율 약 13.4%(조정 후 값).
- 면이 많이 기울수록(θs 큼) 칼도 기울여야 하므로 s가 커져 경계 바로 위를 노리기 어렵다(예: δ = 20°면 s = 6.6mm, δ = 29°면 10.0mm). 접수가 면과 같은 방향으로 흔들린 순간(α ≈ φ)을 기다리면 s가 줄어 더 길게 자를 수 있다(숙련자가 발견하는 요소).
- 칼 범위 ±35°는 θs 최대(\|tilt\| < 10 + 20 = 30°)를 항상 덮는다.

### 면 기울기 방향과 흔들림 방향 (시드)
- 판마다 시드 = `crypto.getRandomValues(new Uint32Array(1))[0]`(없으면 `Math.random()*2**32 >>> 0`). 난수 = mulberry32(시드) (desert-breath와 같은 표준 구현).
- 호출 순서(고정): 마디 4, 5, …, 30 각각 ① d 부호 ② 흔들림 부호 σ_k. 각 `rng() < 0.5 ? +1 : −1`.
- d 부호는 **같은 부호 4연속 금지**: 앞 3마디 d 부호가 모두 같으면 ①의 난수는 뽑되 결과를 반대 부호로 바꾼다(난수 호출 수는 그대로).
- 1~3마디는 d = 0, +10, −10, σ 무관(A = 0) — 모든 판 동일.
- 매 판 시드만 다르고 크기·리듬은 같으므로 판 사이 운의 차이는 작다(추정. 아래 봇 측정으로 확인).

## 조작

### 핵심 규칙 (세 입력 방식 공통)
**"칼을 기울여 둔다 → 원하는 순간에 놓는다(자른다)."**

| 동작 | iPad 터치 | PC 마우스 | PC 키보드 |
|---|---|---|---|
| 칼 기울이기 | 화면 아무 데나 누른 채 끌기. **칼선은 손가락이 그은 선과 나란해진다**(누른 점 → 지금 점의 방향) | 같음(왼쪽 버튼 누른 채 끌기) | **←** 칼이 시계 반대(오른쪽 끝 올라감, +1°) / **→** 시계 방향(−1°). 1번 누름 = 1°, 누르고 있으면 60°/초(키를 누른 지 0.25초 뒤부터 연속) |
| 자르기 | 손 떼기 | 버튼 떼기 | **스페이스** (누르는 순간) |
| 자르지 않고 취소 | 처음 누른 자리 근처(40px 안)로 손가락을 되돌려 떼기 / 짧게 톡 치기 | 같음 | (해당 없음) |
| 일시정지 | Ⅱ 버튼 | Ⅱ 버튼 | Esc / P |
| 음소거 | 음소거 버튼 | 음소거 버튼 | M |
| 시작·다시 | 버튼 | 버튼 | Enter |

> 키보드 방향 메모: "← = 칼을 왼쪽으로 돌린다(시계 반대)"로 맞췄다. 실험실에서 혜진님이 반대가 편하다고 하면 바꾼다(코드 상수 1개).

### 끌기 → 각도 계산 (정확한 정의)
1. `pointerdown`(버튼 제외 게임 영역): 시작점 S 저장, `setPointerCapture`. **첫 번째 포인터만** 쓰고 이후 동시 포인터는 무시.
2. `pointermove`: (가능하면 `getCoalescedEvents()`로) 위치와 `event.timeStamp`를 버퍼에 쌓는다.
3. **기준점 E(t)** = 시각 t − 50ms 이하인 샘플 중 가장 늦은 것. 없으면 S(= 끌기 시작 50ms 동안은 거리 0).
4. 벡터 v = E − S (화면 px). 거리 \|v\| < **40px**이면 "**준비 안 됨**"(놓으면 취소). 40px 이상이면 "**준비됨**".
5. 준비됨일 때 칼 각도 = `atan2(−v.y, v.x)`를 도로 바꾸고 (−90, 90]으로 접은 뒤(±180 더하기) **정수로 반올림**(0.5는 0에서 먼 쪽), −35 ~ +35로 자른다. 오른쪽으로 긋든 왼쪽으로 긋든 같은 선이다.
6. 준비 안 됨일 때 칼 각도는 직전 값을 유지한다(끌기 시작 전 0°, 키보드로 돌려 둔 값 등).
7. `pointerup`: 놓은 시각 t_up = `event.timeStamp`를 게임 시계로 바꾼 값. **t_up 기준으로 3~5를 계산한 값으로 자른다.** 준비 안 됨이면 취소(아무 일 없음).
8. `pointercancel` / `lostpointercapture` / `blur` / 화면 숨김: **취소**(절대 자르지 않음).

- **미리보기 = 실제로 잘릴 선**: 화면의 칼선은 매 프레임 "지금 놓으면 잘릴 각도"(위 3~5를 현재 시각으로 계산한 값)를 그린다. 따라서 미리보기는 손가락보다 50ms(약 3프레임) 늦게 따라오지만, **놓았을 때 잘리는 선과 놓기 직전 보인 선이 항상 같다.** (떼는 순간 손가락이 미끄러져 튀는 것도 무시된다.) QA 9번.
- 빠른 한 칼: 누르고 휙 그어 떼어도 같은 규칙(놓기 50ms 전 위치까지의 방향)으로 잘린다.
- 자르는 순간의 접수 위치는 프레임이 아니라 **t_up(키보드는 keydown의 timeStamp) 시각의 해석식 값**으로 계산한다. 입력 시각은 [겨누기 시작, 현재]로 자른다.
- 겨누기 단계가 아닐 때(면 다듬기·내려오기·판정·자람) 칼은 미리 기울여 둘 수 있지만 **놓기·스페이스는 무시**(자르지 않음, 각도 유지). 다음 마디가 시작되면 칼은 0°로 돌아간다.
- 끄는 중에 ←→는 무시. 끄지 않을 때만 키보드로 돌린다.
- 키보드는 연속 회전 중 각도를 실수로 갖고, 화면·자르기에는 반올림한 정수를 쓴다.

- `touch-action:none`, `user-select:none`, 길게 누르기 메뉴·확대·스크롤 방지 필수.

## 첫 판 배우기 (글 없이 — 이 게임의 최우선 설계)

### 원칙
- 플레이 화면에 설명 글을 쓰지 않는다. 숫자(키·마디·해설의 각도/mm)와 아이콘만.

### C. 첫 실패 해설 (실패 종류별 기기당 1회, 게임이 멈춘 상태)

| 실패 | 그림 (위→아래) | 숫자 |
|---|---|---|

## 시간·입력·일시정지
- 게임 시각 = `performance.now()` 누적(일시정지 제외). 판정은 해석식이라 고정 단계가 필요 없다. 한 프레임이 250ms보다 길게 끊기면 250ms만 진행(그 이상 버림).
- 겨누기 시간 L 초과 판정: τ ≥ L이 되는 순간(그 전에 받은 입력이 있으면 입력 먼저 처리).
- 말라 가는 표시: τ/L에 따라 접수 색이 초록 → 바랜 올리브로 선형 보간, **마지막 1.0초** 접수 끝이 고개를 숙인다. 숫자 타이머 없음.
- 판 시작: "시작" → **1.5초 준비**(첫 면 다듬기 연출만, 입력 무시) → 1마디 면 다듬기.
- 일시정지: Ⅱ / Esc / P / `blur` / `visibilitychange`(hidden) / `pagehide`.
  - 끄는 중이면 **취소**(자르지 않음), 칼 각도는 유지.
  - 일시정지 화면은 플레이 영역을 **불투명하게 가린다**(멈춘 채 각도를 오래 재는 이점 차단).
  - "계속" → 1.0초 준비(화면 보임, 시간 멈춤, 입력 무시) → 재개.
- 끝 연출(쓰러짐 1.2초 / 꽃 1.5초) 뒤 결과 화면, **0.8초 입력 잠금**.

### 난이도 곡선 (의도)
- **1마디**(약 3초): 끌고 떼면 잘린다. 면 0°라 수평으로만 그으면 된다.
- **2·3마디**: 면이 +10°, −10°로 눈에 띄게 기운다. 칼을 기울여야 붙는다 — "각도"를 배운다. 무를 수 없다.
- **4마디**: 갈색 밑동이 길게 나타나고 오르내림 맨 아래가 갈색에 걸린다 — "높이(욕심)"를 배운다. 평행 빛이 꺼진다.
- **11마디**: 면 ±12°, 흔들림 3°~ — 각도와 갈색이 서로 얽히기 시작(기울수록 비스듬해져 욕심을 줄여야 함).
- **21마디**: 면 ±20°, 완벽 허용 2.7° → 2°, 제한 시간 3초 안팎.
- 쉬운 게임 방지 장치: 좋음은 탑을 기울게 만들어 다음 면을 더 어렵게 하고, 기울기 10°면 하트가 남아도 끝난다.

### 봇 측정 (Developer 구현 후 측정 → QA 재현)
기획안의 봇 표는 이 문서와 다른 가정의 시뮬레이션이라 **다시 측정해야 한다.** `__graft.runBots`로 시드 1~400.

봇 행동(봇 전용 난수 `mulberry32(seed ^ 0x9E3779B9)`, 정규분포는 Box–Muller):
- 각도: φ = clamp(round(θs + N(0, σa)), ±35).
- 준비 시간: 겨누기 시작 후 r초 동안은 놓지 않는다. 터치 봇 r = 0.35초, 키보드 봇 r = \|φ\|/60 + 0.25초(누름 지연 포함).
- 놓기 목표: τ ≥ r이고 **여유 m(τ) = u(τ) − s(τ) ≤ g**가 처음 되는 시각 τ\*(오르내림이 내려가는 중). 실제 놓기 = τ\* + N(0, σt). 1~3마디(무를 수 없음)도 같은 규칙.
- L − 0.1초까지 τ\*가 없으면 그때까지 m이 가장 작은 시각에 놓는다. 놓기 시각이 L 이상이면 말라 버림.

| 봇 | σa | σt | g(욕심 여유, mm) | 목표 범위 (중앙값 mm · 완주율) |
|---|---|---|---|---|
| 초보 | 5.5° | 0.13초 | 20 | 250~500 · 0% |
| 보통 | 3.2° | 0.08초 | 12 | 700~1,200 · ≤ 5% |
| 숙련(욕심 중간) | 1.7° | 0.045초 | 8 | 1,400~2,000 · 40~80% |
| 숙련(욕심 큼) | 1.7° | 0.045초 | 2 | 중앙값 < 숙련(욕심 중간), p90 > 숙련(욕심 중간) p90 |
| 키보드 | 2.0° | 0.05초 | 10 | 보통 이상, 숙련(욕심 중간) 이하 |

- 순서 조건(필수): 초보 < 보통 < 숙련(욕심 중간). 숙련 봇의 실패 원인 1위 = 무름(각도만으로는 고득점 불가 확인).
- 판 길이 중앙값: 숙련(욕심 중간) 75~95초.
- 판 사이 운: 숙련(욕심 중간), 게임 시드 1~400 × 봇 시드 1~5 → 게임 시드별 중앙값의 p10~p90 폭 ≤ 150mm.
- 목표를 벗어나면 조정 순서: ① u 범위의 맨 아래(−10/−14/−18, 각 ±6) ② 좋음 배율 0.7(0.6~0.8) ③ 탑 기울기 계수 0.5(0.4~0.7) ④ 띠별 G(±1.5°). **바꾸지 말 것**: 칼 ±35°·정수 반올림, 40px·50ms 규칙, 실패 3번, 쓰러짐 10°, 30마디·꽃 100mm, 1~3마디 무름 불가, 1~3마디 면 0/+10/−10. 조정 내역과 최종 봇 표는 이 문서 변경 이력에 기록하고 CEO에게 보고.
- 봇은 사람의 "글 없이 이해"와 터치 손 떨림을 반영하지 못한다 → 실기기 항목.

## 기획안 대비 변경점
1. **1~3마디 면 각도 0° / +10° / −10°** (기획안: 1~3마디 모두 0°). 칼이 마디마다 0°에서 시작하므로 면이 계속 0°면 "기울여 맞추기"를 한 번도 해 보지 않고 4마디(±5°, 도움 끔)를 맞는다. "1~3마디 = 각도만 배우기"라는 기획안의 목적을 지키려고 2·3마디에 눈에 띄는 기울기를 넣었다. **(결정 필요 1)**
2. **1~3마디는 탑 기울기를 바꾸지 않음**(기획안에 없음). 좋음으로 붙어도 다음 면이 정해진 0/+10/−10을 유지해, 배우기 구간이 모든 판에서 같고 "대목이 수평"이라는 기획안 설명과도 맞는다.
3. **1~3마디는 무를 수 없게 수치로 보장**(u ≥ 14, 갈색 8mm). 기획안 "갈색이 아주 짧아"를 명확화.
4. **매 마디 시작에 대목 윗면을 새로 다듬음**(θs = tilt + d_k). 실패한 뒤에도 그 마디 띠의 면 기울기로 다시 다듬는다(실패 후 면이 그대로 남아 쉬워지는 것 방지 + 빛나는 면에 시선이 가게 하는 연출).
5. **끌기 = "자를 선을 긋는 방향"**: 칼선은 손가락이 그은 선과 나란(좌우 어느 쪽으로 그어도 같음). **40px 미만에서 놓으면 취소**(기획안: 40px 이상이어야 칼이 나타남). 칼선은 항상 보이고, 실선 = 지금 자르면 잘림 / 점선 = 놓으면 취소.
6. **미리보기도 "50ms 전 위치" 규칙으로 그림** → 화면에 보인 선과 잘리는 선이 항상 같음(기획안은 자를 때만 50ms 규칙).
7. **기하 정의 확정**: 붙는 길이 h = 칼선 중심에서 초록 꼭대기까지, 무름 = 칼선 낮은 쪽 끝(u − 18·\|tan(φ − α)\| ≤ 0), 흔들림은 무름 기하에만 영향(각도 판정은 φ와 θs만), 오르내림 식·시작 위상 고정, 갈색 길이 띠별 30/34/38mm, u 범위 띠별 확정.
8. 무름·말라 버림은 탑 기울기를 바꾸지 않음(기획안 미정). 무름이 각도 판정보다 우선.
9. 기획안에 없던 것 추가: 칼선 갈색 물듦(기획안 리스크 표의 대책을 전 마디 적용), 첫 실패 해설 카드(종류별 기기당 1회), 수평계, 시작 화면 데모 5박자, 결과 화면 마디 띠·가장 아까운 한 칼.
10. 이론 최대 2,650 → **2,598mm**(1~3마디 h ≤ 66, 새순 3마디부터 28회). score_cap 2700은 유지.
11. 시드: 기획안 "seed: true 검토" 문장 정리 — 순위표 `seed: true`는 옛 기록 업로드 옵션이고 게임 난수와 무관. 게임은 매 판 무작위 시드, 오늘/연습 구분 없음.
12. 기획안의 봇 표(초보 374mm 등)는 다른 가정의 추정이라 이 문서 규칙으로 **다시 측정해야 함**(목표 범위만 기획안 값 근처로 잡음).
