## 스타일 콘셉트
- **"사막 정원사의 작업대"**: 전작 「선인장 키우기」의 플랫 그림체(단색 면 + 진한 외곽선, 세로 골 3줄, 흰 가시 점, 광택·네온·화면 흔들림 없음)를 그대로 잇는다. 깊이는 하늘 세로 그라데이션 1겹과 모래 땅 1줄로만.
- **시리즈로 이어받는 것**: 선인장 초록 `#7cc35a`/외곽 `#3f7f2c`(전작 펼침색), 모래 `#e4cc9c`, 하늘 3단 색(한낮 베이지 → 해질녘 연보라)을 같은 hex로, 오른쪽 키 눈금자, 아래 점선 상자 "누르는 곳" 모양, 상단 바(hungry-bear `.top` 복사)·키 알약(눈금자 아이콘 + `52.6 cm`), 숫자 글꼴 CactusDigits, 결과 화면 해설, 꽃(분홍 꽃잎 + 노란 가운데).
- **새로 생기는 것**: 옆에서 본 **화분 + 접붙인 탑**, 위에서 내려오는 **집게 + 접수**, **칼(칼날 아이콘 + 칼선)**, 빛나는 **대목 면 + 보조선**, **수평계**. 하늘은 시간 대신 **키**로 바뀐다(높이 자랄수록 해질녘 → 밤하늘, 별) — "하늘까지 자란다".
- **글 없이 읽히는 그림 문법 3가지** (모든 화면이 이 규칙을 지킨다)
  1. **빛나는 노란 선 = 맞춰야 할 각도**(대목 면). 같은 각도의 초록 점선 보조선이 양옆으로 길게 뻗어, 위쪽 칼선과 **두 긴 선을 나란히 비교**하게 한다.
  2. **진한 칼선 = 지금 떼면 잘리는 곳**(실선) / 흐린 점선 = 떼면 취소. 칼선은 손가락이 그은 선과 같은 기울기로 접수 위에 그려진다(손가락이 가리지 않음).
  3. **갈색 + 빗금 + 검은 반점 + 들쭉날쭉한 끝 = 무른 밑동**. 칼선이 그 위를 지나면 **그 구간만** 갈색으로 물든다(실제 판정과 같은 기하).
- 스튜디오 공통: 상단 바·버튼·오버레이 CSS는 `games/hungry-bear/index.html`의 `.top`, `.home`, `.title`, `.spacer`, `.btns`, `button`, `button.icon`, `button.primary`, `button.secondary`/`a.secondary`, `.kbd`, `.overlay`, `body.ov-full`, `.ov-home`, `#lbSlot`을 **그대로 복사**(전작과 같음). 주 버튼 `--accent` 주황, 패널 radius 12~16px. `<meta name="theme-color" content="#e4572e">`.
- 글꼴: 글자 `system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`. **숫자는 CactusDigits**(아래).

### 숫자 글꼴 CactusDigits — 전작 파일을 그대로 재사용 (가능, 권장)
- **재사용 가능**: 전작 `lab/games/desert-breath/fonts/cactus-digits-800.woff2`는 이미 Reserved Font Name 처리(내부 이름 CactusDigits, "Pretendard" 0개)를 마친 Pretendard ExtraBold 서브셋이고, 글리프 `+ , - . /`(U+002B–002F) + `0-9` + `tnum`이 이 게임에 필요한 전부다: 키 `123.4`, 마디 `12/30`, 증가 `+7.1`, 해설 `9`(°), `3`(mm)·`41.0`, 결과 `2.8`.
- **방법**: 두 파일을 **복사**한다(같은 바이트). `lab/games/cactus-graft/fonts/cactus-digits-800.woff2` + `lab/games/cactus-graft/fonts/OFL.txt`. **`../desert-breath/fonts/` 상대 경로로 공유하지 않는다** — 두 게임이 출시될 때 따로 `games/`로 옮겨지므로 경로가 깨진다. 같은 패밀리 이름이라 두 게임 사이 충돌은 없다(페이지가 다름).
- `@font-face`·`.num` CSS는 전작과 글자 하나 다르지 않게(`font-display: swap`, `unicode-range: U+002B-002F, U+0030-0039`).
- **`°`, `cm`, `mm`는 서브셋에 넣지 않는다**: 시스템 글꼴 700, 숫자보다 작게(숫자 크기의 0.6배), `--muted`(해설 꼬리표 안에서는 꼬리표 글자색). 전작 규칙과 같다. 새 서브셋을 만들 필요 없음.
- Canvas 안 글자는 눈금자 숫자(10·20…)뿐, 시스템 글꼴 `700 11px`. 정확한 값(키, 증가분, 해설 각도·mm)은 모두 DOM.

### 표기 규칙 (design.md 그대로)
- 키 `(mm/10).toFixed(1)` + ` cm` → `123.4 cm`. 증가 `+7.1 cm`. 새순 보너스 `+0.5`(새순 아이콘 옆, 단위 생략).
- 마디 `12/30`. 해설 각도 `9°`(정수 반올림, 1 미만이면 소수 1자리), 깊이 `3 mm`/`0 mm`, 길이 `41.0 mm`.
- 마이너스는 U+002D `-`(서브셋 안). U+2212 금지.

- 접수·칼·대목 면·눈금자·수평계는 **장면 영역**(세로: 위 70% / 가로: 왼쪽 2/3) 안. 끄는 곳은 권장 영역일 뿐이고 **판정은 `.stage` 전체**(design.md "어디서 끌어도 된다"). 칼선은 항상 K에 그려지므로 손가락이 어디 있든 칼·선·면을 가리지 않는다.

### 크기 계산 (art-ref.js `layout()`과 같음)
1. `--app-h = innerHeight px`(`resize`·`orientationchange`·`visualViewport.resize`), CSS 기본 `100dvh`. `html, body { height: var(--app-h); overflow: hidden; }`. body 패딩 `max(12px, env(safe-area-inset-*))`, 높이 ≤ 520이면 `max(6px, …)`. viewport `width=device-width, initial-scale=1, viewport-fit=cover`. (전작과 같음)
2. 상단 바 TB = 52(높이 ≤ 520이면 44), 아래 간격 8. 무대 `SW = min(패딩 뺀 폭, 1400)` 가운데, `SH = 남은 높이`. Canvas `width = SW × dpr`(dpr ≤ 2).
3. 방향: `SW > SH × 1.15`면 가로. 세로 = 끄는 곳 아래 `round(SH × 0.30)` / 가로 = 오른쪽 `round(SW / 3)`.
4. 무대 안(CSS px):
   - 칼 중심 **K** = (장면 가운데 x, `SH × 0.34`) / 대목 면 가운데 **S** = (같은 x, `SH × 0.55`). 무대 높이 < 420(폰 가로)이면 0.31 / 0.62(접수를 키우려고).
   - **1mm = (S.y − K.y) / 105 px** (design.md K→면 105mm). 접수·탑 폭 = 36mm.
   - 눈금자 x = 장면 오른쪽 끝 − 50(장면 폭 < 500이면 34). 숫자는 눈금자 오른쪽.
   - 대목 보조선 반길이 `guideExt = min(눈금자 x − K.x − 34, 반폭 × 5)` — 눈금자와 겹치지 않음.

## 장면 그리기 (Canvas, 그리는 순서)
1. 하늘(키 보간) → 2. 모래 땅(화분 바닥 높이에, 화분이 화면 밖이면 생략) → 3. **탑 + 화분**(`drawTower`) → 4. **수평계** → 5. 눈금자 → 6. 대목 면 + 보조선(`drawFace`) → 7. 1·2마디 정답 점선 → 8. 접수 + 집게(`drawScion`) → 9. 칼선(`drawKnife`) + 붙을 길이 괄호 → 10. 칼 높이 눈금 ▸◂ → 11. 연출(떨어지는 조각·쐐기·부스러기) → 12. 끄는 곳 + 끈 선 + 손가락 힌트. 장면 요소(1~11)는 장면 사각형으로 clip(끄는 곳 위로 넘치지 않음).

### 탑 (화분 + 시작 대목 + 붙은 마디) — `drawTower`, `drawSeg`, `drawSeam`
- 탑은 **강체**로 그린다: 축이 `tilt`만큼 화분 흙을 중심으로 기울고(+면 꼭대기가 왼쪽), **꼭대기 가운데(현재 대목 면)는 항상 S**에 오도록 카메라가 맞춘다 → 기울수록 화분이 반대쪽으로 밀려나 보인다.
- 시작 대목: 화분 위 30mm(키 0, art-ref `BASE_MM`; 세로 화면에서 화분 바닥이 끄는 곳 위에 오는 길이). 화분 = 테라코타 사다리꼴(폭 = 반폭 × 4.2, 높이 반폭 × 2.3) + 테두리 띠 + 흙 줄.
- 마디 = 직사각 기둥(세로 골 3줄 α .32, 흰 가시 점 4열 13px 간격, 옆 가시 12px 간격). 아랫면·윗면은 그 마디를 다듬을 때의 면 각도 d(축 기준)로 비스듬. **방금 붙은 마디는 둥근 머리**(접수 꼭대기 그대로), 다음 마디의 "면 다듬기"에서 평평한 면으로 잘린다.
- 접합선: 흰 2.2px(`seam`). **완벽 마디는 접합선 양끝에 금점 2개(지름 5.6)**가 영구로 남음 → 탑만 봐도 완벽 기록이 보인다. **좋음 마디는 위쪽 끝이 `dry` 띠(마디 길이 12%, 최소 6px)**로 시듦(“비뚤게 붙어 끝이 조금 시듦”). 새순 받은 마디 = 오른쪽 옆에 연두 타원 새순(반폭 × 0.24 × 0.32).
- 화면 밖(위·아래 40px 넘는) 마디는 그리지 않는다(최대 31개라 성능 문제 없음).

### 수평계 — `drawLevel` (design.md "화분 앞 수평계")
- **화분 앞면 가운데**(흙선 아래 반폭 × 1.9)에 위쪽 반원 눈금판. 반원 바탕 `level` + 2px `levelEdge`. 눈금: 0(굵게), ±5(가늘게), **±10(흙빨강 3.5px)**, ±10 바깥 부채꼴 `warnFill`(넘으면 쓰러짐). 가운데 축에서 위로 선 **작은 선인장 바늘**(폭 반지름 × 0.26) = tilt × **4배 과장**(눈금도 같은 배율이라 거짓이 아님 — ±10°가 ±40° 자리). 글 없음.
- \|tilt\| ≥ 7: 바늘 외곽 흙빨강 2.6px. 깜빡임 없음.
- **화분이 장면 아래로 사라지면**(탑이 자라 카메라가 올라가면) 수평계는 장면 왼쪽 아래 구석(x = 반지름 + 16, 바닥 − 12)에 **붙어 남는다**(sticky). 전환은 위치만 바뀌고 애니메이션 없음(사라졌다 생기는 순간 300ms 페이드).
- 탑 기울기 변화(좋음·어긋남·완벽 회복): 바늘이 새 각도로 350ms ease-in-out("자람"과 같은 시간), 탑 본체도 같은 350ms로 새 tilt까지 회전.

### 눈금자 (오른쪽) — `drawRuler`
- 세로 2px `ruler`. 0 = 시작 대목 윗면(design.md). 1cm 작은 눈금(4px, α .5) / 5cm(7px) / 10cm(10px + 숫자 11px 700 `rulerTxt`, 눈금자 오른쪽). 1cm < 3px면 1cm 눈금 생략, 0.8px/cm 미만이면 숫자 50cm마다.
- **현재 키 + 10cm까지만** 그림(위 하늘을 비워 접수와 겹치지 않음). 현재 키 = 눈금자 왼쪽 `mark` 삼각형 12×12.
- 키는 세계 mm 그대로(전작 같은 "확대 단계" 없음) — 카메라가 따라 올라가므로 눈금 간격은 판 내내 일정. 끝 연출에서만 축소.

### 대목 면 + 보조선 — `drawFace`
- 면 = 6px 속살 띠(`flesh`) + 가운데 3px 심(`core`) + 그 위 11px **빛 띠**(`guideGlow`, 접수 폭 × 1.15). 평상시 α .7 고정.
- **보조선**: 면과 같은 각도로 양옆 `guideExt`까지 **2.5px 점선 [10,7] `guide` α .7** + 양끝에 면에 수직인 14px 짧은 눈금(“이 선의 기울기를 보라”는 끝 표시). 이 긴 선과 위 칼선(72mm)을 나란히 비교하는 것이 핵심 시각 단서.
- 1~3마디 평행 빛(design.md: 지금 각도가 완벽 허용 안): 빛 띠·보조선·칼선이 모두 `perfect` 금색으로 바뀌고 **함께 맥박**(α .7 ↔ 1, 600ms 주기 sine, 그림자 blur 10↔14). 허용 밖으로 나가면 즉시 원래 색. 4마디부터 없음.
- 정답 점선(1·2마디, design.md): K를 지나는 θs 각도, 길이 반폭 × 6.4, 2px [3,6] `answer` α .4. 칼선 아래에 깔림(칼선이 겹치면 칼선이 위).

### 접수 + 집게 — `drawScion`, `knifeInfo`
- **기하(중요)**: 접수 축은 항상 **K를 지나고**, K를 중심으로 α만큼 흔들린다. K에서 축을 따라 아래로 u mm = 갈색 경계, 초록 꼭대기 = K 위 (80 − u)mm, 갈색 끝 = 경계 아래 B mm. → 칼선(K 지남)과 축의 교점이 항상 K라 **칼선 양끝의 축 방향 처짐 = 18·tan(φ−α) = design.md의 s**, 화면의 갈색 물든 구간과 엔진의 무름 판정(u − s ≤ 0)이 **정확히 같다**. 오르내림(u)·흔들림(α)은 엔진 해석식 값을 매 프레임 그대로(따로 easing 없음).
- 막대: 4px `rod`, 집게 경첩에서 화면 위 밖까지(흔들림과 함께 기욺). 집게: 초록 머리를 양옆에서 무는 회색 턱 2개 + 경첩 원(지름 11).
- 초록 몸통: 마디와 같은 무늬(세로 골·가시 점·옆 가시), 둥근 머리.
- **갈색 밑동**(design.md 8/30/34/38mm): `rot` 면 + 7px 간격 45° 빗금 2.2px `rotHatch` + 검은 반점(B/7개, 최소 2) + **가시 없음** + 들쭉날쭉한 아래 끝(뿌리 그루터기, 7꼭짓점) + 외곽 `rotEdge` + **경계 3px 진한 실선**. 1~3마디의 8mm는 "짧은 갈색 꼭지"로 보인다(렌더 확인).
- 말라 감(design.md τ/L): 몸 색이 `body → dry` 85%까지 선형(갈색은 그대로). **마지막 1.0초 고개 숙임**: 머리 둥근 부분이 납작해지고(0.6r → 0.24r) 옆 가시가 아래로 처지며 집게 밑에 주름 2줄. **몸 위치·폭·축·경계는 절대 바꾸지 않는다**(미리보기 = 판정 유지). 숫자 타이머 없음.
- 4마디 갈색 첫 등장(design.md B-4): 접수가 내려올 때 갈색 밑동 바깥에 흙빨강 3px 사각 테두리 **2번 맥박**(α 0 → 1 → 0, 각 400ms) + 갈색 위에 흙빨강 ✕(20px, 1초, α만). 오르내림 첫 맨 아래(τ = T/2)에서 칼선이 갈색에 걸려 있으면 물든 칼선 끝에 작은 ✕(14px, 600ms).

### 칼 + 칼선 미리보기 — `drawKnife`, `drawGainBracket`, `drawKTicks`
- 칼선 = K 중심, 각도 φ(= `previewAngle()`, 50ms 전 위치 규칙으로 엔진이 계산한 값 그대로 — 화면 쪽에서 보간·지연을 더하지 않는다), 길이 72mm.
- 그리기: 7px `knifeHalo` 테(α .7) 위에 3.5px `knife`. 가운데 K 점(지름 6.4).
- **상태 = 모양** (design.md "칼선 모양 = 상태 표시")

| 상태 | 칼선 | 끈 선(끄는 곳) |
|---|---|---|
| 지금 자르면 잘림 (끄는 중 준비됨 / 아무것도 안 누름 = 스페이스로 자를 수 있음) | **실선**, α 1, 칼날 아이콘 왼쪽 끝 | 실선 3px + 시작점 원(지름 12) + 기준점 고리(지름 26) |
| 끄는 중 40px 미만 (놓으면 취소) | **점선 [7,7]**, 전체 α .55 | 점선 [6,6], 시작점 둘레 반지름 40 점선 원 α .7(“여기 밖으로 끌어라”) |
| 칼선 일부가 갈색 위 (4마디~) | 그 구간만: 13px `flesh` 테 + **8px `rot` 갈색** + 2.2px `rotSpot` 점선(흑백 구분) | 같음 |
| 1~3마디 평행 빛 | 4.5px `perfect` 금색 + 빛, 대목 면·보조선과 같이 맥박 | 같음 |
| 겨누기 밖(면 다듬기·내려오기·판정·자람) | 실선이지만 α .55 (놓아도 안 잘림) | 같음 |
- **칼날 아이콘**: 칼선 왼쪽 끝에 붙은 은색 날(길이 max(26, 22mm), 높이 max(8, 5mm), 날이 칼선 위에 얹힘) + 바깥쪽 나무 손잡이(날 길이 × 0.7). 칼선과 같이 회전. 칼날이 "선이 곧 칼"임을 알려 준다.
- **붙을 길이 괄호**: 접수 왼쪽 10px, 초록 꼭대기 ~ K까지 2.5px `ok` 괄호(“이만큼 붙는다”, 낮게 자를수록 길어지는 것이 보임). 칼선이 갈색에 걸리면 괄호가 흙빨강. 숫자 없음.
- 칼 높이 눈금 ▸ ◂: K 높이, 장면 양 끝, 10×14 삼각형 `ink` α .5.
- 키보드 회전 중에도 같은 그림(칼선은 반올림한 정수 각도로).

### 손가락이 끄는 동안 (끄는 곳 위)
- 누른 점 S에 원(지름 12, `zoneInk`), 50ms 전 기준점 E에 고리(지름 26, 3px), S→E 선 3px. **이 선과 위 칼선이 같은 기울기** — 손가락이 그은 선이 그대로 위로 옮겨져 칼이 된다는 연결을 눈으로 보여 준다.
- 끄는 곳 밖(장면 위)에서 끌어도 같은 표시를 그 자리에 그린다(손가락 아래라 대부분 가려지지만 무해).
- 누르는 순간: S 자리에 물결 원(0 → 48px, α .35 → 0, 240ms).

## 한 마디 연출 (design.md 핵심 루프 시간 그대로)

### 5. 끝 연출 (design.md 쓰러짐 1.2초 / 꽃 1.5초)
- 시작하는 순간 **끄는 곳이 α 0(300ms)** 되고 장면이 무대 전체를 쓴다(렌더에서 끄는 곳이 쓰러진 탑·화분을 가리는 것 확인 → 필수).
- **완주(꽃 1.5초)**: 0~700ms 꼭대기 둥근 머리에서 꽃 피어남(bloom 0 → 1, cubic-bezier(.3,1.4,.5,1), 꽃 지름 = 탑 폭 × 3.2, 꽃잎 8장 — 전작 5장보다 크고 화려하게) + 꽃 아래 금빛 고리 1번 퍼짐(0 → 꽃 지름 × 2, α .5 → 0, 600ms). 300~1500ms 카메라가 **탑 전체가 무대 높이 88%에 들어오게 축소**(scale = 0.88 × 무대 높이 / (탑 + 화분 높이), ease-in-out) — 지금까지 자란 탑을 한눈에. 키 알약 `+10.0` 떠오름.
- **쓰러짐(1.2초)**: 탑 전체가 화분 흙을 축으로 기운 쪽(tilt 부호)으로 tilt → 75° 회전, cubic-bezier(.5,0,.9,.6)(점점 빨라짐, 전작 말라 쓰러짐과 같은 곡선). 동시에 카메라 축소(탑 전체가 보이게, 600ms). 900ms에 꼭대기가 땅에 닿는 자리에서 모래 먼지 원 3개(300ms). 화분은 그대로(뿌리는 남음).
- **실패 3번**: 3번째 실패 연출 뒤 탑이 좌우로 2번 흔들림(±tilt+2°, 각 200ms) 후 위 쓰러짐과 같은 회전(design.md "흔들리다 쓰러짐", 합계 1.2초).

## 개발자 체크리스트 (요약)
1. 장면은 Canvas 1장, `art-ref.js` 함수 구조·수치를 옮긴다. **각도는 design.md 부호(+ = 오른쪽 끝 위), Canvas에는 `cv()`로만 변환.**
2. **접수 축은 항상 K를 지나게** 그린다(K 중심 흔들림). 그래야 갈색 물든 칼선 구간 = `u − s ≤ 0` 판정. `knifeInfo()`의 갈색 구간을 엔진 `s`와 QA로 대조.
3. 칼선 = `previewAngle()` 그대로, 실선(자름)/점선 α .55(취소), 길이 72mm, 왼쪽 끝 칼날. 고개 숙임 연출은 칼선 근처 기하를 바꾸지 않음.
4. 대목 면: 속살 띠 + 빛 띠 + **양옆 긴 점선 보조선 + 끝 수직 눈금**. 1~3마디 평행 빛은 칼선·면·보조선이 함께 금색 맥박.
5. 탑은 강체(tilt), 꼭대기 = S 고정, 자람 350ms 카메라. 완벽 금점·좋음 시든 끝·새순은 영구.
6. 수평계: 화분 앞 → 화분이 사라지면 장면 왼쪽 아래 고정. 바늘 tilt × 4, ±10 흙빨강.
7. 판정 연출 5종 + 꼬리표는 숫자·아이콘만(`9°`, `3 mm`, 모래시계). 플레이 화면에 글 없음(QA 19).
8. 해설 카드 3종(`drawExplainMiss/Rot/Wither`) — 실제 값, 0.8초 잠금 고리, 탭 아이콘.
9. 끝 연출 시작에 끄는 곳 α 0, 탑 전체 축소(꽃 1.5초 / 쓰러짐 1.2초). 결과: 큰 키 → 끝 아이콘 → 마디 띠(색 + 모양) → 수 → 두 실력 → 아까운 한 칼 → 기록 → 버튼. 0.8초 잠금, 낮은 화면 2열, 스크롤 0.
10. 상단 바 폭 < 480 규칙(음소거·일시정지가 밀리지 않게). CactusDigits는 전작 파일 **복사**(상대 경로 공유 금지), `° cm mm`은 시스템 글꼴. 실험실 카드 `--tile-graft` 3곳 + 위 SVG.
