## 한 장 요약 (혜진님이 이것만 봐도 결정할 수 있게)
- **한 줄 후크**: "비 올 때만 숨을 열어 쑥쑥 — 1초만 더 욕심내면 모래가 박힌다."
- **장르 / 핵심 동사**: 욕심 타이밍 / **누르고 있는 동안 열기, 떼면 닫기**
- **어떤 재미**: "조금만 더" 하는 욕심과 긴장. 빗줄기는 **끝으로 갈수록 굵어지고**, 바로 뒤에 모래바람이 붙어 온다. 일찍 닫으면 안전하지만 덜 자라고, 늦게 닫으면 따끔하게 물을 잃는다. 날씨는 모두 3초 전에 보이므로 놓치면 "내 탓".
- **조작**: iPad — 화면 아래쪽 아무 곳이나 **누르고 있기** / PC — **스페이스 누르고 있기**(마우스 누르기도 됨)
- **한 판 길이 · 실패 조건**: 하루 = **150초**(새벽→해질녘). 몸속 물이 0이 되면 말라서 끝. 초보는 약 1분 30초~2분에 끝남(추정).
- **점수(순위표)**: **선인장 키(mm 정수)**, 화면엔 "52.6 cm". 몸이 통통하게 꽉 찬 뒤 더 머금은 물이 그대로 키가 된다.
- **처음 보는 사람이 글 없이 30초 안에 아는 것**: 누르면 선인장이 펴진다 → 비를 맞으면 통통해지고 키 눈금이 올라간다 → 해/모래바람에 펴진 채 맞으면 쭈글쭈글해진다 → 날씨는 오른쪽 하늘에서 미리 다가온다.
- **화면 스케치(세로)**:
  ```
  ┌──────────────────────────┐
  │ 오늘 52.6cm   해 위치(시계)│  ← 위: 키·남은 하루(해가 하늘을 가로지름)
  │ [지금]◀──── 3초 예고 ─────│  ← 날씨 띠: 오른쪽→왼쪽으로 흐름
  │  ☁|||  ≋≋≋  ☀  ☁|||     │     비=둥근 구름+세로줄, 모래=가로 물결, 해=원+빛살
  │   ▼                       │
  │   🌵 ← 키 눈금자(cm)      │  ← 선인장은 왼쪽 1/3, 바로 위가 "지금" 날씨
  │ ▁▁▁▁ 모래 언덕 ▁▁▁▁▁▁▁▁▁│
  │                           │
  │   (여기 아래 절반 = 누르는 곳, 손가락이 하늘을 가리지 않음) │
  └──────────────────────────┘
  ```
  가로 화면도 같은 배치(날씨 띠가 넓어지지만 **예고 시간은 항상 3초**로 맞춤 — 기기 유불리 없음).
- **우리 사이트 다른 게임과 다른 점**: 사이트에 "누르고 버티기(얼마나 오래 열어 둘까)" 동사와 "욕심의 손익" 감정이 없다. 몸 통통함 = 체력 = 성장 재료라 판단이 계속 이어진다.
- **박자 앵무새와 겹치지 않나**: 앵무새는 **들은 박자를 기억해 같은 간격으로 탭**(정답 리듬이 있음). 이쪽은 **박자·반복이 없고**, 날씨 길이가 매번 다르며, "닫는 순간"이 정답 하나가 아니라 **손익 선택**(일찍=안전·손해, 늦게=이득·위험)이다. 소리도 리듬 없이 바람·빗소리 환경음. 똥비 피하기와도 다르다: 움직여 피하지 않고 **제자리에서 노출 시간을 고른다**.
- **비슷한 장르가 있다면 무엇이 다른가(오리지널 근거)**: "누르는 동안 동작" 원버튼 게임은 흔한 형식이지만, 특정 상용 게임의 규칙·소재 재현이 아니다. 소재는 선인장의 실제 생태(기공을 열고 닫아 물을 지킴)에서 왔고, "끝물이 가장 굵은 비 + 바로 뒤 모래"라는 손익 구조가 이 게임 고유의 핵심이다.

## 규칙 (시스템 기획자)
**상태**: 몸속 물 W(0~100, 선인장 통통함으로만 표시, 시작 60), 키 H(시작 10.0cm), 열림 정도 o(0~1).

| 항목 | 값 |
|---|---|
| 열기 | 누르는 순간 물 **−2**(숨 들이쉬는 값, 연타 방지). 0.15초에 걸쳐 완전히 펴짐 |
| 닫기 | 떼면 0.10초에 걸쳐 닫힘 — **닫히는 동안은 아직 열린 셈**이라 미리 떼야 함 |
| 성장 | W가 90을 넘는 만큼은 키로 감: **물 20 = 1cm**(W는 90에 머묾). 자랄 때 몸이 위로 쭉 늘고 눈금이 오름 |
| 실패 | W ≤ 0 → 말라 쓰러짐, 판 끝 |
| 판 끝 | 150초에 해가 지면 끝(해질녘 도달 표시). 점수 = 그때 키 |

**날씨별 1초당 물 변화** (닫힘 / 열림)

| 날씨 | 모양(색만으로 구별하지 않음) | 닫힘 | 열림 |
|---|---|---|---|
| 맑음 | 빈 하늘 | −2.5 | −4 |
| 비 | 둥근 구름 + 세로 빗줄 (빗줄이 뒤로 갈수록 굵어짐) | −2 | **+12 → +30** (처음 0.6배 → 끝 1.5배) |
| 한낮 해 | 큰 원 + 빛살 | −4 | −30, 닿는 순간 **−6** |
| 모래바람 | 가로 물결 줄무늬 + 낮은 먼지 | −2.5 | −90, 닿는 순간 **−12 "따끔"**(모래알 박힘 효과) |

- 40~110초(한낮): 닫혀 있어도 추가 −3/초. 110초 이후: 추가 −2에서 시작해 초당 0.05씩 더 마름 → 가만히 버티기는 불가능, 비를 받아야 산다.
- "따끔"은 열림 정도 30% 이상으로 해/모래 구간에 들어갈 때 구간당 1번.

## 난이도 곡선 · 실력 상한
날씨는 정해진 조각을 시드로 섞어 만든다(구간별 길이 범위 고정).

| 구간 | 비 길이 | 비 뒤 간격 | 위험 | 배우는 것 |
|---|---|---|---|---|
| 0~20초 (아침) | 3.5~4.5초 | 맑음 1.5~2.5초 | 10초 뒤 해 1번(2초) | 누르면 펴짐 → 비 맞으면 통통 → 키 자람. 해에 펴면 쪼그라듦 |
| 20~55초 | 2~3.5초 | 0.6~1.2초 | 모래 60% / 해 40%, 1.5~2.5초 | 모래 "따끔". 예고 띠 보고 미리 떼기 |
| 55~100초 (한낮) | 1.2~2.5초 | 0.2~0.5초 | 1~2초 + 35% 확률로 "짧은 비(0.5~0.8초)+모래" | 짧은 비는 −2 여는 값보다 이득일까? 고르기 |
| 100~150초 (오후) | 0.8~1.8초 | **0초**(비 끝 = 모래 시작) | 짧은 비·모래 번갈아, 마름 가속 | 끝물 욕심 vs 따끔. 진짜 실력 구간 |

**실력 상한이 생기는 곳**: ① 비 끝 굵은 빗줄을 얼마나 오래 받다가 0.1초 일찍 떼는가 ② 앞이 맑음이면 비 직전에 미리 눌러 펴 두기(앞이 모래면 금지) ③ 짧은 비를 받을지 버릴지. 세 가지 모두 화면에 보이는 정보로만 판단한다.

## 점수 체계 · 서버 상한 제안
- **점수 = 키(mm, 정수)**, 표시 "52.6 cm". 단위 이름 "키".
- 같은 점수: 현행 서버 규칙(먼저 세운 사람이 위). mm 단위라 동점은 드묾(추정).
- **서버 상한 제안: 900** (90.0cm). 근거: 시드 2만 개 중 비 총시간 최대 75.4초 × 평균 열림 흡수 21/초 ÷ 20 = 79cm + 시작 10cm ≈ 89.1cm. 마름·여는 값을 **전혀 빼지 않은** 물리적 한계라 정상 기록은 넘을 수 없다. 완벽 봇 최고 58.3cm.
- 순위표 판 = **오늘의 날씨**(한국 날짜 시드, 그날 모두 같은 하루). 같은 날 여러 번 하면 날씨를 익힐 수 있다 → "어제보다 오늘" 재도전 동기. 결과 화면에 "오늘의 날씨 · 11월 27일" 표시.
- 운 비중: 날짜별 쉬운/어려운 하루 차이가 남음(아래 검증: 완벽 플레이 기준 p10~p90 약 ±5%). 줄이려면 생성기에서 구간별 **비 총시간을 고정하고 순서만 섞기**(개발 시 적용 권장).

## 검증 (시뮬레이션 — 모두 추정)
node 봇 시뮬, 1/60초 단위, 시드 400개. 봇의 손 떨림은 정규분포 가정. 실제 사람·iPad 터치 지연은 반영 안 됨.

| 봇 | 행동 | 키 중앙값(p10~p90) | 판 길이 중앙값 | 해질녘 도달 | 따끔/판 |
|---|---|---|---|---|---|
| 초보 | 비 오고 0.3초 뒤 누름, 끝나고 0.15초 뒤 뗌(±0.15) | 31.3cm (28~35) | 107초 | 0% | 6.6 |
| 겁쟁이 | 0.9초 미만 비는 버림, 끝나기 0.45초 전에 뗌 | 26.0cm (24~28) | 150초 | 49% | 0 |
| 욕심쟁이 | 모든 비, 끝까지 버팀(±0.09) | 39.6cm (36~43) | 128초 | 8% | 16.2 |
| 중간 | 0.6초 미만 버림, 0.2초 전 뗌(±0.06) | 39.8cm (37~43) | 150초 | 100% | 0.3 |
| 숙련 | 미리 펴 두기, 0.1초 전 뗌(±0.035) | 49.0cm (46~52) | 150초 | 100% | 3.5 |
| 완벽 | 손 떨림 0 | 52.6cm (50~55) | 150초 | 100% | 0 |

- **욕심이 양날**: 욕심쟁이는 겁쟁이보다 키는 크지만 92%가 해질녘 전에 말라 죽는다 → "조금만 더"의 위험·보상이 수치로 성립.
- **실력 차**: 초보 31 → 중간 40 → 숙련 49 → 완벽 53cm. 숙련자도 완벽까지 약 7% 여유(실력 상한 있음).
- **운 비중**: 날씨를 고정하면 숙련 봇 p10~p90이 48.7~51.2cm(손 떨림만), 날짜가 바뀌면 46~52cm. 즉 날짜 운이 손 실력 차보다 작지만 무시할 수준은 아님 → 비 총량 고정 셔플로 줄인다.
- **조작 지연 민감도**: 열림·닫힘 시간이 0.05초 길어지면(터치 지연 가정) 같은 타이밍의 숙련 봇이 49→45cm, 따끔 3.5→10회. 사람은 적응하겠지만 **iPad 실기기에서 지연을 꼭 확인**해야 한다.
- 시뮬 스크립트는 임시 폴더에만 있음(저장소에 넣지 않음). 수치는 개발 단계 game-designer가 다시 맞출 출발점.
