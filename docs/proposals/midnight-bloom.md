## 한 장 요약 (혜진님이 이것만 봐도 결정할 수 있게)
- **한 줄 후크**: "밤에만 피는 선인장 꽃. 식기 전에 살짝 문질러 데워 주고, 꽃이 필 때마다 선인장이 한 마디씩 자란다."
- **장르 / 핵심 동사**: 여러 개 동시에 돌보기 / **짧게 문지르기 + 다음 화분 고르기**
- **어떤 재미**: 분주함과 판단. 화분이 1개에서 6개로 늘고, 식는 속도가 다 다르며, 키가 큰 선인장일수록 꽃 점수는 크지만 더 빨리 식는다. "지금 누구를 데울까, 어디서 손을 뗄까"를 계속 고른다. 꽃이 피고 선인장이 쑥 자라는 순간의 뿌듯함.
- **조작**: iPad — 봉오리 위에서 손가락을 살짝 비비기(짧은 왕복). 손을 떼지 않고 옆 화분으로 미끄러져도 된다. / PC — 마우스 버튼 누른 채 봉오리 위에서 흔들기, 또는 숫자키 1~6 누르고 있기.
- **한 판 길이 · 실패 조건**: 해 뜰 때까지 최대 2분 30초. 봉오리를 3번 잃으면(얼거나 = 파랗게 굳음, 너무 데워 타거나 = 갈색) 그 자리에서 끝. 추정 판 길이: 처음 하는 사람 약 1분, 숙련자 2분 20초 전후.
- **점수(순위표)**: 꽃 한 송이 = 10 × 그 선인장의 마디 수(1~5마디 → 10~50점). 해 뜰 때까지 버티면 남은 마디 합 × 5 보너스. 추정 분포: 초보 약 560 / 보통 약 1,900 / 숙련 약 2,900 / 이론 상한 4,500.
- **처음 보는 사람이 글 없이 30초 안에 아는 것**: ① 문지르면 봉오리가 파랑 → 주황 → 금빛으로 바뀌고 꽃잎이 벌어진다 ② 너무 문지르면 빨갛게 떨다가 탄다 ③ 꽃이 피면 선인장이 한 마디 자란다 ④ 두 번째 화분이 생기면 번갈아 챙겨야 한다. (첫 화분에 반투명 손이 비비다가 금빛에서 멈추는 시범 1회)
- **화면 스케치** (가로 기준, 세로는 2개 × 3단):
  ```
  [ 달 ·········· 하늘이 점점 밝아짐(=남은 시간) ]   점수 1,240   ✿✿✿(남은 목숨)
  |창문 유리(찬바람 예고: 서리가 번짐)                          |
  |  (◎)        (◎)        (◎)     ← 봉오리 + 뒤의 달무리 색 = 온도 |
  |  ▥▥▥        ▥▥         ▥       ← 선인장 마디(=키우기, 점수 배율)|
  |  [화분1]    [화분2]    [화분3]  ── 윗 선반                       |
  |  (◎)        (◎)        (◎)                                      |
  |  ▥▥         ▥          ▥▥▥▥                                     |
  |  [화분4]    [화분5]    [화분6]  ── 아랫 선반                     |
  ```
- **우리 사이트 다른 게임과 다른 점**: "문지르기" 동사와 "계속 유지해야 하는 상태 여러 개를 동시에 관리"하는 감정은 사이트에 없다. 두더지 뿅뿅은 튀어나오면 한 번 때리고 끝, 이 게임은 데우고·멈추고·다른 데로 옮기는 판단이 이어진다.
- **비슷한 장르가 있다면 무엇이 다른가(오리지널 근거)**: 접시 돌리기형(여러 대상을 번갈아 유지)은 오래된 일반 장르다. 차이: ① 온도를 "너무 낮아도·너무 높아도" 잃는 양쪽 실패 ② 꽃이 필수록 선인장이 자라 점수 배율은 오르고 더 빨리 식는 성장-위험 교환 ③ 예고되는 찬바람에 대비해 미리 데워 두기. 특정 상용 게임의 이름·캐릭터·규칙 묶음을 재현하지 않는다.

## 규칙 (시스템 기획자)

**온도와 꽃**(화분마다 따로)
| 항목 | 값 | 화면 표현 |
|---|---|---|
| 온도 범위 | 0~100, 새 봉오리는 60에서 시작 | 봉오리 뒤 달무리 색 |
| 0 이하 | **얼어붙음**: 목숨 −1, 그 선인장 마디 −1(최소 1), 3초 뒤 새 봉오리 | 파랗게 굳고 금 가는 소리 |
| 1~39 | 차가움: 꽃이 안 벌어짐 | 푸른빛 |
| 40~54, 76~85 | 피는 중: 개화 +1/초 | 주황빛, 꽃잎 조금씩 벌어짐 |
| **55~75** | **금빛 구간**: 개화 +1.6/초 | 금빛 + 은은한 맥박 |
| 86~99 | 뜨거움: 개화 멈춤 | 빨갛게 떨림 + 지글 소리(경고) |
| 100 이상 | **타 버림**: 얼어붙음과 같은 벌칙 | 갈색으로 시듦 |
| 개화 7 도달 | 꽃 핌 → 점수, **선인장 +1마디(최대 5)**, 2초 쉰 뒤 새 봉오리(쉬는 동안 안 식음) | 꽃 활짝 + 향기 입자 + 마디 솟음 |

**식는 속도와 데우는 속도**
| 항목 | 값 |
|---|---|
| 기본 식는 속도 | 5/초(시작) → 12/초(2분 30초), 일정하게 증가 |
| 화분별 개성 | ×0.85~1.15 (판 시작 때 무작위) |
| 키가 큰 선인장 | 마디 하나당 +15% 더 빨리 식음 (5마디 = ×1.6) |
| 문지르기 | +110/초 (40→75까지 약 0.3초). **한 번에 한 화분만** 데워짐 |

**화분 등장**: 0초 1개 → 12초 2개 → 25초 3개 → 45초 4개 → 70초 5개 → 95초 6개.

**찬바람(위협) — 반드시 예고**
| 항목 | 값 |
|---|---|
| 첫 바람 | 35초 (연습용: 온도 −30) |
| 이후 | 10~16초마다, 이웃한 화분 2개에 **온도 −50** |
| 예고 | **3초 전**: 그 두 화분 뒤 창문에 서리가 번지고 커튼이 흔들리며 휘파람 소리가 커짐. 바람이 닿을 화분 테두리에 푸른 점선 |
| 대응 | 예고 3초 동안 두 화분을 미리 85 근처까지 데워 두기(너무 데우면 탐 → 욕심과 절제) |
| 쉬는 중인 화분 | 영향 없음 |

**조작 판정**
| 기기 | 판정 |
|---|---|
| iPad | 손가락이 봉오리 판정 원(반지름 약 60pt, 봉오리보다 큼) 안에서 최근 0.12초 동안 6pt 이상 움직이면 "문지르는 중". 가만히 누르기만 하면 안 데워짐. 손을 떼지 않고 다른 화분으로 미끄러지면 바로 전환. **두 번째 손가락은 무시**(PC와 공정하게) |
| PC 마우스 | 왼쪽 버튼 누른 채 판정 원 안에서 흔들기(같은 판정). 버튼 안 누르고 흔들면 안 데워짐 |
| PC 키보드 | 숫자키 1~6 누르고 있기 = 해당 화분 문지르기. 다른 화분으로 바꿀 때 0.2초 "손 옮기는 시간"(손 아이콘이 미끄러짐) — 손가락 이동 시간과 맞추기 위함 |

**끝**: 해 뜸(150초) 또는 목숨 3개 소진. 결과 화면에 다 자란 선인장 6개를 나란히 보여 준다(키우기 결과).

## 난이도 곡선 · 실력 상한

| 시간 | 화분 | 무엇을 배우나 | 압박 |
|---|---|---|---|
| 0~12초 | 1 | 문지르면 데워진다, 금빛에서 멈춘다, 첫 꽃 → 마디 +1 (반투명 손 시범 1회) | 낮음 |
| 12~25초 | 2 | 번갈아 챙기기 | 낮음 |
| 25~35초 | 3 | "누가 제일 급한가" 고르기 | 보통 |
| 35초 | 3 | 첫 찬바람(−30): 예고 → 결과를 안전하게 체험 | 보통 |
| 45~95초 | 4~6 | 우선순위 + 바람 대비 + 큰 선인장은 빨리 식음 | 높음 |
| 95~150초 | 6 | 식는 속도 10~12/초, 바람 10~16초 간격. 숙련자만 해 뜰 때까지 버팀 | 매우 높음 |

**실력 상한(숙련자가 차이를 내는 곳)**
1. **멈추는 정확도**: 금빛(55~75)에 머물면 꽃이 1.6배 빨리 핀다. 0.3초 안에 40→75로 오르므로 대충 문지르면 넘치거나 모자란다.
2. **누구를 키울지**: 큰 선인장은 꽃 한 송이 50점이지만 1.6배 빨리 식는다. 큰 것만 챙기면 작은 것이 얼고, 골고루 하면 점수가 낮다.
3. **바람 대비**: 예고 3초 안에 두 화분을 미리 데우기. 시뮬상 같은 실력에서 대비하면 중앙값 +340점(+13%).
4. **동선**: 손을 떼지 않고 이웃 화분으로 미끄러지는 경로 짜기.

## 검증 (시뮬레이션·추정 — 추정이면 추정이라고)

node로 단순 모델 봇 4종 × 400판을 돌렸다. 봇은 "가장 차가운 화분부터 데움"이 기본이고, 실력 차는 화분 전환 시간(0.45/0.30/0.20/0.12초), 멈추는 온도 오차(±12/±7/±3.5/±1), 바람 대비 여부로 줬다. **사람의 시선 이동·손 떨림·터치 판정 오차는 모델에 없음 → 모든 수치는 추정.**

| 봇 | 점수 p10 / 중앙 / p90 | 꽃 수 | 평균 판 길이 | 해 뜸까지 버팀 | 문지르는 시간 비율 |
|---|---|---|---|---|---|
| 초보 | 300 / 560 / 900 | 18 | 65초 | 0% | 17% |
| 보통 | 1,600 / 1,920 / 2,190 | 50 | 114초 | 0% | 33% |

- 실력 단계마다 중앙값이 약 1,000점씩 벌어진다 → 순위표 변별력 충분(추정).
- 초보 판이 약 1분으로 짧다 → "쉽지 않음" 조건 충족. 대신 첫 판 좌절이 걱정되면 첫 바람을 −30으로 둔 것처럼 45초 전까지만 부드럽게(아래 리스크).
- 바람 세기 비교: −40이면 대비해도 이득이 거의 없어(예고가 의미 없음) −50으로 정했다. −55는 초보가 너무 빨리 끝남(약 60초).
- 손 피로: 실제로 손가락을 움직이는 시간은 판 전체의 17~45%, 한 판 최대 약 70초(추정). 한 번 문지르기는 0.2~0.5초 짧은 비비기.
