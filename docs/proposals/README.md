# 기획실 기획안 보관함

기획실(기획 팀장 + 컨셉 기획자·시스템 기획자·플레이어 리서처)이 만든 새 게임 기획안을 모은다.
배포되지 않는 문서다(사이트에 올라가지 않음).

## 상태 흐름
| 상태 | 뜻 | 누가 바꾸나 |
|---|---|---|
| `제안` | 기획실이 혜진님께 보여 줌 | 기획실 |
| `수정 요청` | 혜진님이 고쳐 달라고 함 | 기획실(혜진님 말 기록) |
| `승인` | 혜진님이 "이거 해"라고 함 → 개발진에 전달 | 기획실(혜진님 승인 원문 기록) |
| `보류` | 지금은 안 함(나중에 다시 꺼낼 수 있음) | 기획실 |
| `개발 중` / `실험실` / `출시` | 개발진 진행 상황 | 개발진 |

## 파일
- `TEMPLATE.md` — 기획안 양식
- `<slug>.md` — 기획안 하나(맨 위 `상태:` 줄을 항상 최신으로)
- `<YYYY-MM-DD>-ideas.md` — 컨셉 기획자의 원안 목록
- `<YYYY-MM-DD>-review.md` — 플레이어 리서처의 심사표
