# 접붙이기 한 칼 (slug: cactus-graft)

상태: 보류 | 날짜: 2026-11-27 | 승인 원문: (승인 시 혜진님 말 그대로)

## 한 장 요약 (혜진님이 이것만 봐도 결정할 수 있게)
- **한 줄 후크**: "칼 한 번에 반듯하게 잘라 착! — 접붙일수록 선인장이 하늘로 자란다. 점수는 내 선인장의 키."
- **장르 / 핵심 동사**: 손맛 정밀 / **각도 맞춰 자르기**(칼을 기울여 놓고, 손을 떼는 순간 싹둑)
- **어떤 재미**: ① 자른 면이 딱 맞아 "착" 붙으며 빛이 한 줄로 번쩍하는 손맛 ② "조금만 더 길게 자르면 키가 더 크는데…" 하는 욕심(갈색 밑동을 건드리면 무른다).
- **조작**: iPad — 화면 아무 데나 누른 채 끌면 칼이 그 방향으로 기울고, 손을 떼면 자른다 / PC — 마우스로 똑같이 끌어 놓기, 또는 ←→로 칼 기울이기 + 스페이스로 자르기
- **한 판 길이 · 실패 조건**: 30마디 완주 시 약 85초, 보통 50~75초(추정). 실패 3번(어긋남·무름·말라 버림) 또는 탑 기울기 10° 이상이면 쓰러지며 끝.
- **점수(순위표)**: 선인장 키(정수 mm). 30마디 완주하면 꽃이 피고 +100mm.
- **처음 보는 사람이 글 없이 30초 안에 아는 것**: 끌면 칼이 기운다 → 떼면 잘린다 → 아래 빛나는 면과 나란하면 "착"·반짝, 비뚤면 틈이 벌어지며 툭 떨어진다 → 갈색 밑동을 자르면 무른다 → 붙을수록 선인장이 위로 자란다.
- **화면 스케치** (iPad 세로):

- **우리 사이트 다른 게임과 다른 점**: 사이트에 "각도"를 맞추는 게임이 없다. 블록 스택(낙하 블록 줄 지우기)·두더지(반응 탭)·박자 앵무새(박자)와 동사가 다르고, "오래 버틸수록 내 선인장이 실제로 높아지는" 성장 결과가 점수 그 자체다.
- **비슷한 장르가 있다면 무엇이 다른가(오리지널 근거)**: "잘라서 위에 얹는 탑" 캐주얼류(옆으로 미끄러지는 판을 떨어뜨리고 삐져나온 부분이 잘림)와 첫인상이 닮을 수 있다. 차이는 아래 표. 소재는 실제 선인장 재배 기술인 접목(대목+접수, 자른 면을 평행하게 맞춰 붙임)에서 왔다.

  | | 타이밍 탑 쌓기류 | 접붙이기 한 칼 |
  |---|---|---|
  | 플레이어가 고르는 것 | 떨어뜨리는 **순간**(좌우 위치) | 자르는 **각도** + 자르는 **높이**(욕심) |
  | 잘리는 것 | 겹치지 않은 부분이 자동으로 잘림 | 내가 칼로 직접 자름 |
  | 실패 감정 | 판이 점점 좁아짐 | 틈이 벌어져 툭 떨어짐 / 갈색을 건드려 무름 |
  | 시점 | 위에서 본 판 | 옆에서 본 화분·집게·칼 |
  | 점수 | 쌓은 층 수 | 자란 키(mm) — 길게 자를수록 큼 |

## 규칙 (시스템 기획자)
| 항목 | 내용 |
|---|---|
| 한 마디의 흐름 | ① 대목 윗면(탑 꼭대기 자른 면)이 각도 θs로 은은하게 빛남 → ② 위에서 집게가 접수(초록 몸통 80mm + 갈색 밑동)를 내려 오르내리고(주기 T) 살짝 흔듦(진폭 A) → ③ 플레이어가 칼 각도를 정하고 놓음 → ④ 잘린 초록 윗부분이 떨어져 대목 위에 붙음 → 판정 → 다음 마디 |
| 칼 | 칼의 중심은 화면에 고정된 "칼 높이"(양 옆 작은 눈금). 기울기만 바꿀 수 있고 범위 ±35°. 마디마다 0°(수평)로 돌아감 |
| 각도 판정 | 오차 e = \|칼 각도 − θs\|. e ≤ 완벽 허용 → **완벽**, e ≤ 좋음 허용 → **좋음**, 그보다 크면 **어긋남**(틈이 벌어져 떨어짐, 실패 1) |
| 길이(=키) | 칼선 아래로 남은 게 아니라, 칼선 **위쪽 초록 길이 h**(최대 80mm)가 붙는다. 낮게 자를수록 길다 |
| 무름 | 칼선이 갈색 밑동에 조금이라도 닿으면 무른다(실패 1). 칼선이 접수 축과 비스듬할수록 한쪽 끝이 갈색에 먼저 닿는다 → 대목이 많이 기울면 욕심을 줄여야 한다 |
| 말라 버림 | 접수가 나온 뒤 제한 시간 안에 안 자르면 시들어 떨어짐(실패 1). 남은 시간은 접수 색이 점점 바래는 것으로만 표시 |
| 붙은 결과 | 완벽: h 전부 + 탑 기울기 1° 회복 / 좋음: h×0.7(비뚤게 붙어 끝이 조금 시듦), 탑 기울기 += 오차×0.5(오차 방향) / 어긋남: 0, 기울기 += min(오차,6)×0.5 |
| 다음 대목 면 | θs = 탑 기울기 + 이번 마디 면 기울기 d(크기는 단계별 고정, 좌우 방향만 무작위) → **비뚤게 붙인 만큼 다음 판이 어려워진다** |
| 연속 완벽 | 3번째 연속 완벽부터 마디마다 새순 +5mm, 효과음이 한 음씩 올라감 |
| 끝 | 실패 3번 / 탑 기울기 10° 이상(쓰러짐) / 30마디 완주(꽃이 핌 +100mm) |

**조작 상세(손 떨림·기기 차 대책)**
| | iPad 터치 | PC 마우스 | PC 키보드 |
|---|---|---|---|
| 칼 기울이기 | 누른 점 → 현재 점의 **방향**으로 칼이 기욺(40px 이상 끌어야 칼이 나타남) | 같음 | ←→ 1번=1°, 누르고 있으면 60°/초 |
| 자르기 | 손 떼기 | 버튼 떼기 | 스페이스 |
| 떨림 대책 | 경로 중간은 무시하고 **시작점과 끝점만** 사용. 끝점은 떼기 직전 50ms의 위치(떼는 순간 튀는 것 무시). 각도는 1° 단위로 반올림 | 같음 | (해당 없음) |
| 빠른 한 칼 | 누르고 휙 그어 떼도 같은 규칙으로 잘림(숙련자용) | 같음 | — |

세 방식 모두 "칼을 기울여 두고 → 원하는 순간에 놓는다"는 **같은 두 가지 실력(각도 눈대중 + 놓는 타이밍)** 을 요구하도록 맞췄다. 터치는 각도를 빨리 바꾸고, 키보드는 정밀하지만 큰 각도를 돌리는 데 시간이 든다(20°에 약 0.35초).

## 구현 가능성 (단일 HTML · Canvas/SVG · Web Audio · iPad Safari)

|---|---|

| 입력 | Pointer Events, 캔버스 `touch-action:none`(스크롤·확대 방지). 시작점·끝점·최근 50ms 위치만 저장 |

| 미리 보이는 칼선 때문에 너무 쉬움 | 4마디부터 평행 미리 빛남 끔, 칼과 대목이 떨어져 있어 눈대중이 필요, 허용 2°까지 좁아짐, 제한 시간·오르내림·흔들림이 동시에 조여 옴 |
| iPad와 PC 키보드 유불리 | 조작 구조를 "기울여 두고 놓기"로 통일. 실험실에서 기록 비교 후 키보드 회전 속도·허용 각도 조정 |
| 운이 점수를 가름 | 대목 기울기 크기는 고정, 방향만 무작위(시드 고정 가능) |
| 말라 버림이 초보에게 억울함 | 남은 시간은 접수 색이 바래고 마지막 1초에 고개를 숙이는 것으로 미리 보여 줌 |

## 리서처 심사 (점수표 요약)
- 원안 7개 중 **2위, 합계 20점**(취향 4 / 차별성 4 / 독창·저작권 4 / 과거 교훈 3 / 순위표 5, 키우기 실체 "강"). 반응 근거 데이터는 없어 전부 추정.
- 좋은 점: 순위표 변별력이 7개 중 최고(각도 오차가 그대로 점수, 무작위 거의 없음), 접목이라는 실제 재배 기술이라 "키우기"가 규칙에 살아 있음.
- 조건과 반영:
  | 리서처 조건 | 반영 |
  |---|---|
  | 스와이프 판정 넉넉→좁게, 손 떨림 대책 | 허용 6°/14° → 2°/5°, 시작점·끝점만 사용, 떼기 직전 50ms 위치, 1° 반올림 |
  | 평행도를 빛·소리로 즉시 | 접합선 빛(한 줄/한쪽/틈) + 판정별 소리, 연속 완벽 음 상승 |
  | iPad·PC 유불리 | 모든 조작을 "기울여 두고 놓기"로 통일, 실험실 기록 비교 후 조정 |
  | 블록 스택(쌓기)과 차별 | 동사 = 자르는 각도·높이, 시점·실패 감정 다름(비교표) |
  | 접붙이기 = 선인장이 자라는 결과 | 붙을수록 탑이 위로 자라고 화면이 올라감, 점수 = 키(mm), 완주 시 꽃 |
  | 너무 쉽지 않게 | 숙련 봇도 욕심을 부리면 무름으로 실패, 보통 봇은 완주 0%(추정) |
